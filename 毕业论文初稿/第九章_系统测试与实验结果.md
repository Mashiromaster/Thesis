## 9.1 板级性能测试

### 9.1.1 ADC/DAC 有效位数与信噪比测试

**测试目的**：确定模拟前端的实际有效位数（ENOB）与信噪比，这决定了误差信号的检测精度下限，是第 9.3 节噪声建模的输入参数。

**理论依据**：理想 $N$ 位量化器的信噪比上限为

$$
\mathrm{SNR}_{\max} = 6.02N + 1.76\ \mathrm{dB}
$$

对 16 位系统即 98.1 dB。实测值必然低于此上界，差值来自孔径抖动、参考电压噪声、输入缓冲非线性与 FPGA 内部定点截断。由实测信噪比可反推有效位数：

$$
\mathrm{ENOB} = \frac{\mathrm{SNR}_{\mathrm{measured}} - 1.76}{6.02}
$$

采样时钟抖动 $\sigma_t$ 对信噪比的限制为

$$
\mathrm{SNR}_{\mathrm{jitter}} = -20\log_{10}(2\pi f_{in}\sigma_t)
$$

当该项与量化噪声可比时成为主导因素，故需在不同输入频率下测量以分离两项贡献。

**测试方法**：向 ADC 输入低噪声单频正弦信号，经 FPGA 内部的数据记录模块（`modules/data_logger/`）或波形存储上传通路（`modules/waveform_storage_upload/`，含 DDR4 缓存与以太网回传）采集时域数据，在上位机做 FFT 分析，由基波与噪声底的功率比计算 SNR、SINAD 与 ENOB。DAC 测试则由 FPGA 内部 DDS 产生单频信号，经 DAC 输出后用频谱分析仪测量。

**测试步骤**：
1. 完成板级初始化（`boards.py` 中对应板卡的 `init_*` 函数），确认 AD9528 / AD9680 / AD9152 均通过锁定校验；
2. 输入信号源经带通滤波后接入 ADC 通道，幅度设为满量程的约 −1 dBFS；
3. 采集不少于 $2^{16}$ 点数据，加窗后做 FFT；
4. 分别在若干输入频率下重复，以区分量化噪声与抖动贡献。

| 指标 | 通道 A | 通道 B | 测量条件 | 获取方法 |
|------|--------|--------|---------|---------|
| SNR (dB) | 【待测】 | 【待测】 | 【待测】 | FFT 分析 |
| SINAD (dB) | 【待测】 | 【待测】 | 【待测】 | FFT 分析 |
| ENOB (bit) | 【待测】 | 【待测】 | 【待测】 | 由 SINAD 换算 |
| THD (dB) | 【待测】 | 【待测】 | 【待测】 | FFT 谐波分量 |

### 9.1.2 系统环路延迟测量

**测试目的**：测定闭环系统的总延迟，这是决定控制带宽上限的关键参数，直接验证第七章 7.4.2 节的延迟预算推算。

**理论依据**：按第二章 2.3 节的分析，延迟 $\tau$ 在频率 $\omega$ 处引入附加相移 $\Delta\phi = -\omega\tau$。若要求相位裕度不低于 $\varphi_m$，单位增益带宽上限为

$$
f_{UGF} \le \frac{1}{2\pi\tau}\left(\frac{\pi}{2} - \varphi_m\right)
$$

取 $\varphi_m = 45°$ 时简化为 $f_{UGF} \lesssim 1/(8\tau)$。

**测试方法**：采用阶跃响应法与频响法两种方式交叉验证。

*阶跃响应法*：配置信号路由矩阵建立"ADC 输入 → 待测链路 → DAC 输出"的开环通路，在 ADC 输入端施加阶跃信号，用示波器同时观测输入与 DAC 输出，两者跳变的时间差即为总延迟。该方法直观但分辨率受示波器带宽限制。

*频响法*：以网络分析仪或信号源+锁相放大器测量开环链路的相频特性，由相位斜率求群延迟 $\tau = -d\phi/d\omega$。该方法精度更高，且可分辨延迟的频率依赖性。

**延迟分解**：总延迟应分项核算以便定位优化空间：

| 环节 | 理论估算 | 实测 | 说明 |
|------|---------|------|------|
| 模拟前端 + 抗混叠滤波 | 【待测】 | 【待测】 | 群延迟 |
| ADC 转换与输出流水线 | 【待测】 | 【待测】 | 查器件手册 + 实测 |
| 采样保持等效延迟 | $T/2 = 2$ ns | — | 理论值，$T = 4$ ns |
| 信号路由矩阵 | 1 周期 = 4 ns | 【待测】 | 第七章 7.4.2 节 |
| 混频器 | 2 周期 = 8 ns | 【待测】 | 同上 |
| FIR 滤波器 | 7 周期 = 28 ns | 【待测】 | 同上 |
| PID 控制器 | 3 周期 = 12 ns | 【待测】 | `buf_none` 配置 |
| DAC 建立时间 | 【待测】 | 【待测】 | 查器件手册 + 实测 |
| 执行器响应 | 【待测】 | 【待测】 | 取决于 AOM/EOM/压电 |
| **总计** | 【待测】 | 【待测】 | |

> FPGA 内部各项为按源码寄存器级数的**理论估算**，须经仿真与实测验证（见第七章 7.4.2 节的待补充说明）。模拟部分各项须实测。总延迟确定后，据上述公式计算带宽上限并与 9.3 节的实际锁定带宽对照。

**本节所需实验条件**：示波器（带宽不低于 500 MHz）、网络分析仪或锁相放大器、信号源。

## 9.2 功能验证实验

### 9.2.1 DDS 信号生成质量分析

**测试目的**：验证第七章 7.2.1 节所述 DDS 的频率精度、相位噪声与杂散抑制，确认其可作为 PDH 调制信号源与扫描信号源。

**理论依据**：$N$ 位相位累加器截断至 $M$ 位输出时，相位截断引入的杂散分量最大幅度约为

$$
\mathrm{SFDR} \approx 6.02M\ \mathrm{dB}
$$

本系统 $N = 64$、输出取高 16 位（$M = 16$），理论杂散抑制约 96 dB。频率分辨率为 $f_{clk}/2^{64} \approx 1.36\times10^{-11}$ Hz。CORDIC 的 19 级迭代与 24 位内部精度引入的幅度误差亦贡献杂散，需实测区分。

**测试方法**：配置累加器与 CORDIC 构成正弦发生器（可直接使用复合模块"正弦波发生器"），经 DAC 输出后用频谱分析仪测量。

**测试步骤**：
1. 经上位机设置目标频率（`ModuleAccumulator` 的 `freq` 间接参数），验证设置值与读回值一致；
2. 用频率计测量实际输出频率，与设定值比对验证频率精度；
3. 用频谱分析仪测量杂散抑制比与相位噪声谱；
4. 在若干频率点（覆盖低频至接近奈奎斯特频率）重复测量。

|---------|---------|---------|-----------|----------------|-----------------|

### 9.2.2 信号路由功能的灵活性验证

**测试目的**：验证第七章 7.1 节所述路由矩阵的核心主张——改变信号拓扑无需重新综合，且切换过程可做到无扰动。

**测试方法**：设计一组拓扑切换实验，每次仅经串口改写路由配置寄存器，记录切换耗时与输出波形。

**测试步骤**：
1. 建立初始拓扑（如 ADC→FIR→DAC），确认信号通路正常；
2. 经上位机改写路由配置，切换为另一拓扑（如 ADC→IIR→DAC），记录从发出命令到新拓扑生效的时间；
3. 用示波器观测切换瞬间的输出波形，验证保持位（配置字 `[7]` 位）置位时输出无跳变；
4. 测试同一模块被多路复用的场景，验证扇出能力；
5. 测试端口 0（`VOID`）的行为，确认接入该端口的信号被忽略、从该端口取值恒为零。

### 9.2.4 跨应用拓扑切换验证

**测试目的**：这是**平台通用性最直接的检验**。验证同一套比特流能否经纯寄存器配置在 PDH 锁定构型与双梳锁定构型之间切换，从而实证第三章 3.1.1 节"运算单元与连接关系分离"的架构主张。

**测试方法**：依次配置两种拓扑（第六章 6.2.8 节与 6.3 节给出连线清单），各自确认信号链路工作正常，记录切换所需的寄存器写入次数与总耗时。

## 9.3 激光 PDH 锁定实验

### 9.3.1 实验装置搭建

**光路构成**：激光器 → 电光调制器（EOM）→ 光隔离器 → 耦合透镜组 → 参考腔（F-P 腔或光学微腔）→ 光电探测器（PD）；腔反射光经分束后送入 PD，PD 输出经前置放大后接入 ADC；FPGA 的 DAC 输出经驱动电路接入激光器的频率调节端（压电陶瓷或电流调制端）。

### 9.3.3 锁定性能评估

**测试目的**：定量评估锁定性能，这是全文的最终性能指标。

**理论依据**：按第二章 2.1.5 节，闭环下的残余频率噪声谱密度为

$$
S_\nu^{\mathrm{closed}}(f) = \frac{S_\nu^{\mathrm{free}}(f)}{|1 + G(f)|^2}
$$

其中 $G(f)$ 为环路增益。中长期稳定度以阿伦方差表征：

$$
\sigma_y^2(\tau) = \frac{1}{2}\left\langle (\bar{y}_{k+1} - \bar{y}_k)^2 \right\rangle
$$

**测试方法**：

*时域*：长时间记录误差信号，统计残余误差的均方根值与漂移趋势，由频率计数器数据计算阿伦方差。

*频域*：用频谱分析仪或 FFT 分析仪测量误差信号的功率谱密度，分别在开环与闭环条件下测量，两者之比即环路的噪声抑制比，可与理论 $|1+G(f)|^{-2}$ 对照。

| 残余误差 RMS | 【待测】 | 【待测】 |
| 连续锁定时长 | 【待测】 | 【待测】 |
| 误差信号 PSD @1 Hz | 【待测】 | 【待测】 |
| 误差信号 PSD @100 Hz | 【待测】 | 【待测】 |
| 误差信号 PSD @1 kHz | 【待测】 | 【待测】 |

## 9.5 本章小结

本章给出了平台测试的完整方案，覆盖板级性能、平台功能验证与两类实验应用四个层次。板级测试确定 ADC/DAC 的有效位数与系统环路延迟，后者经 $f_{UGF} \lesssim 1/(8\tau)$ 直接决定控制带宽上限；资源与时序预算验证设计在目标器件上的可实现性。功能验证逐一确认 DDS 信号质量、路由矩阵的动态重构能力、各运算模块的实现正确性、跨应用拓扑切换能力，以及第八章智能体层由自然语言生成拓扑的可靠性，其中跨应用切换是平台通用性主张的直接证据。两类应用的锁定实验则分别检验平台的实际可用性：PDH 实验完整记录自动锁定过程、评估锁定性能、建立噪声模型并以频域方法分析闭环稳定性；双梳实验验证本振自校准算法与滑动窗平均的噪声抑制效果，其中前两项子测试无需真实双梳光源即可先行开展。方案设计中特别安排了若干**交叉验证环节**：环路延迟实测值与单位增益带宽的一致性检验、相对阈值方案在光功率变化下的自适应性验证、总增益调节时 Bode 图形状不变性的验证，这些检验可同时确认硬件实现与理论分析的自洽性。各项实测数据待实验完成后填入。
