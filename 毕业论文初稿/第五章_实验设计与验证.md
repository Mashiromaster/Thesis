# 第五章 实验设计与验证

本章围绕板级性能、平台功能及两类应用，说明实验配置、测试方法与评价指标，并分析可配置互联、模块复用和自动化控制的实验表现。

## 5.1 应用抽象与验证思路

### 5.1.1 应用的三要素

在本平台上，一个实验应用由三部分完全确定：

| 要素 | 内容 | 配置手段 |
|------|------|---------|
| 拓扑 | 哪些运算模块参与、如何连接 | 路由矩阵的配置字 |
| 参数 | 各模块的增益、系数、阈值 | 总线写入参数 RAM |
| 自动化逻辑 | 状态推进与模块使能的时序决策 | 应用层状态机 |

前两者是数据，第三者是逻辑。这一划分的实际意义是：**凡能以既有模块的重新连接与参数调整表达的实验，都无需改动硬件**；只有当实验需要新的自动化决策流程时，才需要在应用层增加一个状态机模块并重新综合。

两个案例恰好分处这一界线的两侧：PDH 锁定与双梳锁定各自需要专属的状态机（`pdh_state_machine` 与 `SCALO_state_machine`），因而都包含第三要素；但二者的运算层与互联层完全共用，没有为任一应用增加专用的运算模块。

### 5.1.2 状态机作为应用层的载体

应用层状态机的职责不是参与信号运算，而是**决策**：判断当前实验处于哪个阶段，据此门控运算模块的工作状态。其与运算层的交互仅通过两类信号——从数据路由矩阵读入用于判决的信号，向布尔路由矩阵输出复位或使能信号。

这一约定使状态机与被控运算模块之间通过布尔路由矩阵建立连接。状态机不绑定特定 PID 实例，运算模块也不依赖特定状态机，因此可以通过配置改变控制信号的作用对象。

## 5.2 板级性能与平台功能验证

### 5.2.1 ADC/DAC 有效位数与信噪比测试

**测试目的**：确定模拟前端的实际有效位数（ENOB）与信噪比，这决定了误差信号的检测精度下限，是第 5.4 节噪声建模的输入参数。

**理论依据**：理想 $N$ 位量化器的信噪比上限为

$$
\mathrm{SNR}_{\max} = 6.02N + 1.76\ \mathrm{dB}
$$

对 16 位系统即 98.1 dB。实测值必然低于此上界，差值来自孔径抖动、参考电压噪声、输入缓冲非线性与 FPGA 内部定点截断。由实测信噪比可反推有效位数：

$$
\mathrm{ENOB} = \frac{\mathrm{SNR}_{\mathrm{measured}} - 1.76}{6.02}
$$

采样时钟抖动 $\sigma_t$ 对信噪比的限制为

$$
\mathrm{SNR}_{\mathrm{jitter}} = -20\log_{10}(2\pi f_{in}\sigma_t)
$$

当该项与量化噪声可比时成为主导因素，故需在不同输入频率下测量以分离两项贡献。

**测试方法**：向 ADC 输入低噪声单频正弦信号，经 FPGA 内部的数据记录模块（`modules/data_logger/`）或波形存储上传通路（`modules/waveform_storage_upload/`，含 DDR4 缓存与以太网回传）采集时域数据，在上位机做 FFT 分析，由基波与噪声底的功率比计算 SNR、SINAD 与 ENOB。DAC 测试则由 FPGA 内部 DDS 产生单频信号，经 DAC 输出后用频谱分析仪测量。

**测试步骤**：
1. 完成板级初始化（`boards.py` 中对应板卡的 `init_*` 函数），确认 AD9528 / AD9680 / AD9152 均通过锁定校验；
2. 输入信号源经带通滤波后接入 ADC 通道，幅度设为满量程的约 −1 dBFS；
3. 采集不少于 $2^{16}$ 点数据，加窗后做 FFT；
4. 分别在若干输入频率下重复，以区分量化噪声与抖动贡献。

SNR、SINAD、ENOB、THD 与噪声底构成转换链路的评价指标。对 ADC 采样数据进行 FFT 分析，由基波、谐波和噪声功率计算各项指标；DAC 输出采用频谱分析仪测量。

测量记录同时注明 ADC/DAC 子卡型号、采样率、输入幅度、频谱窗函数及采集长度，使不同通道的指标具有可比性。

**实验条件**：低相噪信号源、带通滤波器、频谱分析仪、示波器、稳压电源。

### 5.2.2 系统环路延迟测量

**测试目的**：测定闭环系统的总延迟，这是决定控制带宽上限的关键参数，直接检验第二章 2.7.2 节的延迟预算推算。

**理论依据**：按第二章 2.1.5 节的分析，延迟 $\tau$ 在频率 $\omega$ 处引入附加相移 $\Delta\phi = -\omega\tau$。若要求相位裕度不低于 $\varphi_m$，单位增益带宽上限为

$$
f_{UGF} \le \frac{1}{2\pi\tau}\left(\frac{\pi}{2} - \varphi_m\right)
$$

取 $\varphi_m = 45°$ 时简化为 $f_{UGF} \lesssim 1/(8\tau)$。

**测试方法**：采用阶跃响应法与频响法两种方式交叉验证。

*阶跃响应法*：配置信号路由矩阵建立"ADC 输入 → 被测链路 → DAC 输出"的开环通路，在 ADC 输入端施加阶跃信号，用示波器同时观测输入与 DAC 输出，两者跳变的时间差即为总延迟。该方法直观但分辨率受示波器带宽限制。

*频响法*：以网络分析仪或信号源+锁相放大器测量开环链路的相频特性，由相位斜率求群延迟 $\tau = -d\phi/d\omega$。该方法精度更高，且可分辨延迟的频率依赖性。

**延迟分解**：总延迟应分项核算以便定位优化空间：

| 环节 | 延迟依据 |
|------|----------|
| 模拟前端及抗混叠滤波 | 由相频特性的群延迟表征 |
| ADC 转换与采样保持 | 器件转换流水线及 $T/2$ 的采样保持延迟 |
| 信号路由矩阵 | 1 周期，即 4 ns |
| 混频器 | 2 周期，即 8 ns |
| FIR 滤波器 | 7 周期，即 28 ns |
| PID 控制器 | 3 周期，即 12 ns（`buf_none` 配置） |
| DAC 与执行器 | 由建立时间及执行器响应表征 |

表中 FPGA 延迟依据寄存结构计算，模拟链路延迟由阶跃响应与相频曲线共同表征。将链路总延迟代入上述公式，可与闭环带宽进行一致性比较。

**实验条件**：示波器（带宽不低于 500 MHz）、网络分析仪或锁相放大器、信号源。

### 5.2.3 硬件资源与时序预算

**测试目的**：确认设计在目标器件上的资源占用与时序收敛情况，验证第二章对信号路由矩阵平方增长代价的判断。

测试方法为在 Vivado 中完成综合与实现，并导出层次化资源利用率报告及静态时序分析报告。

资源利用率分析以目标器件的 LUT、FF、BRAM 与 DSP48 使用量为基础，并结合第二章 2.7.1 节的模块结构解释主要开销。

资源分析分别统计 LUT、FF、BRAM 与 DSP48 的使用情况，并结合目标器件容量计算占用率；功耗由 Vivado `report_power` 估计。参数 RAM 主要影响 BRAM 使用量，FIR 并行乘法结构主要影响 DSP48 使用量。

时序分析覆盖以下时钟域。

静态时序分析分别覆盖 250 MHz 系统时钟域、125 MHz DAC 时钟域及 ADC DCO 时钟域。以最差负裕量（WNS）、总负裕量（TNS）和关键路径位置评价各时钟域的时序特征。

关键路径分析重点考察信号路由矩阵及其扇出、选择逻辑和布线负载。提高流水线级数、设置 `max_fanout` 约束和调整物理布局是该结构的主要时序优化手段。

**跨时钟域设计说明**：系统的跨时钟域处理由 `async_fifo.vhdl` 承担，该模块封装 Xilinx `xpm_fifo_async`，配置 `CDC_SYNC_STAGES => 3`，并对 `full`/`empty` 标志额外施加两级带 `ASYNC_REG` 属性的同步器，配套 `async_fifo.xdc` 中的 `set_max_delay -datapath_only` 约束。该模块在各 ADC/DAC 适配器中共约 20 处实例化，用于 ADC 器件时钟域到系统时钟域、系统时钟域到 DAC 时钟域的数据传递。

**实验条件**：Vivado 2023.2 或兼容版本、目标器件的完整器件库。

### 5.2.4 DDS 信号生成质量分析

**测试目的**：验证第二章 2.6.1 节所述 DDS 的频率精度、相位噪声与杂散抑制，确认其可作为 PDH 调制信号源与扫描信号源。

**理论依据**：$N$ 位相位累加器截断至 $M$ 位输出时，相位截断引入的杂散分量最大幅度约为

$$
\mathrm{SFDR} \approx 6.02M\ \mathrm{dB}
$$

本系统 $N = 64$、输出取高 16 位（$M = 16$），理论杂散抑制约 96 dB。频率分辨率为 $f_{clk}/2^{64} \approx 1.36\times10^{-11}$ Hz。CORDIC 的 19 级迭代与 24 位内部精度引入的幅度误差亦贡献杂散，频谱分析可区分相位截断与幅度误差的影响。

**测试方法**：配置累加器与 CORDIC 构成正弦发生器（可直接使用复合模块"正弦波发生器"），经 DAC 输出后用频谱分析仪测量。

**测试步骤**：
1. 经上位机设置目标频率（`ModuleAccumulator` 的 `freq` 间接参数），验证设置值与读回值一致；
2. 用频率计测量实际输出频率，与设定值比对验证频率精度；
3. 用频谱分析仪测量杂散抑制比与相位噪声谱；
4. 在若干频率点（覆盖低频至接近奈奎斯特频率）重复测量。

测量覆盖 1 kHz、1 MHz、10 MHz 和 50 MHz 四个设定频率，分别分析输出频率误差、杂散抑制比及 1 kHz、10 kHz 频偏处的相位噪声。

同时比较 `fast_out` 与 `acc_out` 的频率比，分析其与 $2^d$ 的对应关系，其中 $d$ 为 `divisor_digit` 确定的位偏移量（见第二章 2.6.1 节）。

**实验条件**：频谱分析仪、频率计、相位噪声测试仪或具备相噪测量功能的频谱分析仪。

### 5.2.5 信号路由功能的灵活性验证

**测试目的**：验证第二章 2.5 节所述路由矩阵的核心主张——改变信号拓扑无需重新综合，并评估保持位能否降低切换扰动。

**测试方法**：设计一组拓扑切换实验，每次仅经串口改写路由配置寄存器，记录切换耗时与输出波形。

**测试步骤**：
1. 建立初始拓扑（如 ADC→FIR→DAC），确认信号通路正常；
2. 经上位机改写路由配置，切换为另一拓扑（如 ADC→IIR→DAC），记录从发出命令到新拓扑生效的时间；
3. 用示波器观测切换瞬间的输出波形，验证保持位（配置字 `[7]` 位）置位时输出无跳变；
4. 测试同一模块被多路复用的场景，验证扇出能力；
5. 测试端口 0（`VOID`）的行为，确认接入该端口的信号被忽略、从该端口取值恒为零。

| 验证项 | 验收判据 |
| --- | --- |
| 拓扑切换耗时 | 串口命令往返时间量级（毫秒级） |
| 切换时输出扰动（保持位置位） | 无跳变 |
| 切换时输出扰动（保持位清零） | 存在跳变 |
| 单输出多路扇出 | 功能正常 |
| `VOID` 端口行为 | 输入忽略、输出为零 |
| 布尔控制交叉开关 | 独立于数据交叉开关正常工作 |

示波器波形记录切换过程；命令生效时间与重新综合布线的耗时进行量级比较，以表征运行时重配置的效率。

**实验条件**：示波器、信号源。

### 5.2.6 各 DSP 模块的功能验证

**测试目的**：分别验证滤波器、PID 和 CORDIC 等运算模块的功能及定点误差。

**测试方法**：对每个模块，以上位机设计参数、下发配置、注入已知激励、采集响应，与 Python/MATLAB 的理论计算结果比对。

| 模块 | 验证内容 | 方法 |
| --- | --- | --- |
| FIR 滤波器 | 冲激响应、幅频特性 | 注入冲激与扫频，比对 scipy 理论响应 |
| FIR 可变抽头 | 16/32/64 抽头切换的增益一致性 | 比对三种配置的直流增益 |
| IIR 滤波器 | 幅频/相频特性、稳定性 | 扫频测量，验证散射前瞻变换的等效性 |
| CORDIC 三角函数 | 正余弦精度 | 全相位区间扫描，统计最大/RMS 误差 |
| CORDIC 反三角 | atan2 精度与四象限正确性 | 同上 |
| PID 控制器 | 阶跃响应、三项独立性 | 分别单独使能 P/I/D 项观测响应 |
| PID 抗饱和 | 积分限幅与退饱和行为 | 施加长时间大误差后反向，观测恢复时间 |
| 漏积分 | 泄漏时间常数 | 施加恒定误差，测量积分项衰减曲线 |
| 混频器 | 乘法正确性与截断行为 | 注入双音，验证和频差频分量 |
| 相位解卷绕 | $2\pi$ 跳变消除 | 注入跨越 $\pm\pi$ 的相位斜坡 |

其中，IIR 的扫频响应用于检验散射前瞻变换后 9 个 b 系数与 2 个 a 系数在定点量化下的传递函数等效性；PID 抗饱和实验则考察积分器钳位值写回状态后的退饱和行为（见第二章 2.6.6 节）。

**实验条件**：信号源、示波器、频谱分析仪；上位机侧需 scipy 环境做理论对照。

### 5.2.7 跨应用拓扑切换验证

**测试目的**：这是**平台通用性最直接的检验**。检验同一套比特流能否经纯寄存器配置在 PDH 锁定构型与双梳锁定构型之间切换，以验证第二章 2.2.1 节"运算单元与连接关系分离"的架构主张。

**测试方法**：依次配置两种拓扑（5.3.8 节与 5.5.3 节给出连线清单），各自确认信号链路工作正常，记录切换所需的寄存器写入次数与总耗时。

**测试步骤**：
1. 配置 PDH 拓扑（累加器 → CORDIC → 混频器 → PID → 累加器，含 PDH 状态机），确认误差信号正常；
2. 记录切换起始时刻，改写路由配置为双梳拓扑（ADC → 反三角函数 → SCALO → PID），记录完成时刻；
3. 确认双梳链路工作正常；
4. 反向切换，验证可重复性；
5. 全程不重新下载比特流。

| 验证项 | 评价内容 |
| --- | --- |
| 同一比特流支持两种拓扑 | 比较切换前后的比特流标识与信号连通性 |
| 切换所需寄存器写入次数 | 统计路由和参数配置命令 |
| 切换总耗时 | 记录命令发出至新拓扑生效的时间 |
| 反向切换可重复性 | 检查往返切换后的拓扑与参数状态 |

跨应用切换测试在不连接光学装置的条件下进行，以配置生效时间、切换扰动及两种拓扑下的连通性评价运行时配置的作用。

### 5.2.8 智能体辅助设计的功能验证

**测试目的**：验证第四章智能体层能否由自然语言描述正确生成实验拓扑，并定量评估其可靠性。

**测试方法**：设计一组覆盖不同复杂度的典型请求，每条重复若干次独立试验（每次从空画布开始，以避免前次结果影响），记录模型的工具调用序列与最终画布状态。拓扑正确性以人工比对为准：节点类型与数量、每条连线的源宿端口、关键参数值三项全部符合预期方记为成功。

| 任务请求 | 任务类型 |
|----------|----------|
| 创建 10 MHz 正弦波发生器 | 单个复合模块构建 |
| 搭建 PDH 锁定系统 | 多模块拓扑构建 |
| 在 PID 前增加低通滤波 | 既有拓扑增量修改 |
| 将调制频率设为 20 MHz | 参数调整 |
| 创建三个 PID 控制器 | 实例数边界检查 |
| 生成并验证新基础模块 | Vivado 反馈驱动的工具自迭代 |

其中，一次通过率为首轮工具调用得到正确拓扑的比例，最终成功率为允许模型读取错误结果并继续调用后的成功比例。两项指标的差异可用于分析错误反馈的作用，但还应控制任务难度和模型版本。

基础模块自迭代实验以结构化 RTL 规格作为输入，连续记录模型生成版本、Vivado 编译与仿真结果、波形差异、时序报告及工具注册状态。验证过程表明，编译或功能失配能够转化为 ReAct 修正所需的观察信息；修正后的实现重新通过同一测试用例验收，随后封装为可在后续设计任务中调用的工具。评价这一闭环时，分别统计候选模块的首次通过情况、最终通过情况与迭代轮数，并检查工具复用时的接口一致性。

“创建三个 PID 控制器”请求为**负例测试**，其验收行为是模型尝试创建第三个 PID 控制器时收到"Max instances (2) reached"错误，随后向用户说明该限制。此项验证的是约束机制。

此外分析两项定性现象：

- **安全约束的有效性**。尝试以自然语言诱导模型建立类型不匹配的连线（如"把累加器的相位输出接到 PID 的误差输入"），确认连线被第三章 3.4.2 节的类型检查拒绝，且模型据错误信息作出解释而非绕道尝试。
- **服务端中立性**。同一组请求在不同模型服务下的表现差异，用于验证第四章 4.3.4 节所述的协议中立性，并为模型选型提供依据。

智能体任务结果与所用模型的工具调用能力有关。实验记录模型及其版本，将任务效果解释为模型与系统工具接口共同作用的结果。

**实验条件**：可用的模型 API 端点与密钥；无需硬件连接，画布拓扑的正确性可在离线状态下验证。

## 5.3 PDH 锁定应用实现

本节依据第一章的 PDH 鉴频原理，分析自动锁定状态机的判定条件、参数标定方法及其与反馈环路的时序关系。扫描、捕获与锁定决策由 FPGA 内部逻辑完成，响应时间由状态转移与模块流水线延迟共同决定。

### 5.3.1 物理约束决定的设计要求

第一章 1.3.4 节给出了一个关键推论：PDH 鉴频斜率 $D = -8\sqrt{P_cP_s}/\delta\nu$ 与腔线宽成反比，因此高灵敏度必然伴随窄捕获范围——线性区仅约一个腔线宽。对于精细度 $10^4$ 量级的参考腔，这意味着误差信号的有效区间远窄于激光的自由运转漂移范围。

由此可得两项设计要求：首先，系统应扫描激光频率或腔长以定位共振，再切换至闭环控制；其次，捕获判定与环路切换延迟应小于扫描信号通过有效鉴频区间所需的时间。因此，相关状态判定由 FPGA 内部逻辑完成。

### 5.3.2 接口与状态划分

状态机接收 256 位配置参数、16 位误差信号及 16 位扫描波形，输出 PID、混频器和锯齿波发生器的控制信号。三路控制信号采用低有效约定，其具体取值由相应状态决定。状态集合包括空闲态（`IDLE`）、自动幅度标定态（`AUTO_AMP`）、自动时间标定态（`AUTO_TIME`）、等待态（`AUTO_WAIT`）、自动扫描态（`AUTO_SCANNING`）、手动扫描态（`SCANNING`）、自动锁定态（`AUTO_LOCKING`）和手动锁定态（`LOCKING`）。其中自动与手动控制分别形成独立的状态转移路径。

八个状态构成两条并行的分支链路：

**手动链路**（由上位机指定阈值）：`IDLE` → `SCANNING` → `LOCKING` → `IDLE`。其中，命令字 `pc_cmd=01` 触发扫描；信号持续低于扫描阈值时进入锁定态；上位机撤销锁定命令后返回空闲态。

**自动链路**（硬件自行标定阈值）：`IDLE` → `AUTO_WAIT` → `AUTO_AMP` → `AUTO_TIME` → `AUTO_SCANNING` → `AUTO_LOCKING`。命令字 `pc_cmd=10` 触发该链路。

状态跳转由两位命令字 `pc_cmd`（来自参数总线地址 0x00 的最低两位）与锯齿波回扫沿 `sawtooth_jump` 共同驱动。

### 5.3.3 锯齿波回扫沿检测

自动标定的各阶段以扫描周期为单位推进，因此需要检测扫描波形的回扫边界。判据要求相邻采样的符号位翻转，且当前采样的符号位与次高位相异，以排除零点附近的小幅抖动。

### 5.3.4 自动幅度标定与阈值计算

自动幅度标定和时间标定分别确定信号判定阈值及持续时间门限。

在 `AUTO_AMP` 状态下，极值寄存器在一个完整扫描周期内逐点更新，得到误差信号的最小值 $V_{min}$ 和最大值 $V_{max}$。

两个极值寄存器在进入该态时被初始化为相反的极端值（`min_sig_in` 置为最大正值、`max_sig_in` 置为最小负值），以保证首个采样即可正确更新。

阈值经峰峰值求差、系数缩放和基准值相加三级流水计算，其关系为

$$
V_{th} = V_{min} + (V_{max} - V_{min}) \cdot c
$$

其中系数 $c$（`coef_scan` 与 `coef_lock`）为 Q1.15 格式的 16 位有符号数，由上位机配置。扫描阈值与锁定阈值使用各自独立的系数，因而可设置不同的判定水平——通常锁定判据应比扫描判据更严格，以避免在共振峰边缘误判为已锁定。

这一相对阈值方案的优势在于**自适应于信号幅度**。激光功率漂移、光路耦合效率变化、探测器增益差异都会改变误差信号的绝对幅度，固定阈值在此情况下需频繁重新标定；而相对阈值仅依赖峰峰值的比例，对幅度变化的敏感性较低。这一点对长时间无人值守运行尤为重要。

在 `AUTO_TIME` 状态下，系统测量误差信号连续低于扫描阈值的时长 $T_m$，并分别以 $T_m/2$ 和 $4T_m$ 作为扫描判定门限与锁定判定门限。

扫描判定时长取测得值的一半，锁定判定时长取四倍——两者均以移位实现，无需乘法器。取半的用意是使扫描阶段的判定比实测的共振峰宽度更宽松以确保捕获，取四倍则使锁定阶段的失锁判定更为迟缓以避免瞬态扰动引发误判。

仅当 $T_m$ 超过 500 个系统时钟周期（250 MHz 下为 2 μs）时，测量结果才被接受；该门限用于排除持续时间较短的扰动。

### 5.3.5 判定与锁定交接

**`AUTO_SCANNING` 态**执行持续时间判定：信号低于阈值时计数器累加，达到 `auto_time_duration_scanning` 则转入锁定；信号一旦高于阈值即将计数器清零。这一"连续满足"而非"瞬时满足"的判据有效抑制了噪声尖峰造成的误锁定。

**`AUTO_LOCKING` 态**置 `pid_enable <= '0'`、`mixer_enable <= '0'`（低有效，即启用 PID 与混频器），同时 `sawtooth_enable <= '1'` 停止扫描，系统进入闭环锁定。

状态机通过布尔路由矩阵控制相位累加器的暂停输入与 PID 的自动复位输入。在状态转移对应的时钟沿，扫描斜坡保持当前偏置，同时解除 PID 复位，使控制作用由扫描过程切换为闭环反馈。交接延迟包括路由及运算流水级，由时序仿真和状态转移波形共同确定。

### 5.3.6 失锁恢复的状态协同

状态转移逻辑中，`AUTO_LOCKING` 与 `AUTO_SCANNING` 分别承担闭环反馈和扫描捕获。锁定判据不再满足时，状态机清零相关计数器，由上位机命令控制状态重置与后续扫描。

离开该状态的路径是 `pc_cmd` 被上位机改写为 `"00"` 或 `"11"` 而回到 `IDLE`。手动链路的 `LOCKING` 态同理。失锁恢复由上位机命令与硬件状态机协同完成。

片上自动重锁扩展可在失锁持续时间超过预设门限时，增加由自动锁定态至自动扫描态的转移，并复用已经标定的阈值和时间参数。误触发概率与恢复时间是评价这一扩展的核心指标。

### 5.3.7 参数地址映射与平台集成

模块的可配置参数经 `parameter_ram_256` 映射如下：

| 地址 | 位段 | 参数 | 类型 |
|------|------|------|------|
| 0x00 | `[1:0]` | `pc_cmd` | 2 位命令字 |
| 0x01 | `[47:32]` | `threshold_signal_locking` | signed 16 |
| 0x02 | `[79:64]` | `threshold_signal_scanning` | signed 16 |
| 0x03 | `[127:96]` | `time_duration_scanning` | unsigned 32 |
| 0x04 | `[159:128]` | `time_duration_locking` | unsigned 32 |
| 0x05 | `[175:160]` | `coef_scan` | signed 16, Q1.15 |
| 0x06 | `[207:192]` | `coef_lock` | signed 16, Q1.15 |

该模块在片内总线上的地址为 26（`BUS_PDHS_ADDR`）。顶层 `Top.vhdl` 中的连接关系为：`sig_in` 接 `sig_bank_out(37)`，`saw_input` 接 `sig_bank_out(38)`，三路使能输出接 `ctrl_bank_in(2..4)`——即状态机的输入输出同样经过信号路由矩阵，其连接关系亦可由上位机动态配置。

这一点体现了第二章分层结构的价值：状态机并未被硬连线到特定的 PID 或混频器实例。实验者可以在运行时改变"由哪一路信号触发判决"、"复位哪一个 PID"，而无需修改状态机代码。

### 5.3.8 典型拓扑

一个完整的 PDH 锁定构型涉及五个模块与九条连线，其数据流为：

$$
\text{累加器} \to \text{CORDIC} \xrightarrow{\cos} \text{混频器} \xrightarrow{\text{解调}} \text{PID} \to \text{累加器（反馈）}
$$

其中累加器产生扫描斜坡与调制参考相位，CORDIC 将相位转为正交本振，混频器以余弦分量解调探测器信号得到误差信号，PID 计算校正量回授至累加器。PDH 状态机则并联于该链路之外，读入判决信号与斜坡信号，输出三路使能。

该拓扑的连线清单记录于上位机配置例程和智能体知识库，可用于重复配置与连通性验证。

## 5.4 PDH 锁定实验与分析

### 5.4.1 实验装置搭建

**光路构成**：激光器 → 电光调制器（EOM）→ 光隔离器 → 耦合透镜组 → 参考腔（F-P 腔或光学微腔）→ 光电探测器（PD）；腔反射光经分束后送入 PD，PD 输出经前置放大后接入 ADC；FPGA 的 DAC 输出经驱动电路接入激光器的频率调节端（压电陶瓷或电流调制端）。

**电学链路**：FPGA 内部 DDS 产生调制信号经 DAC 输出驱动 EOM；PD 信号经 ADC 进入 FPGA，与本振信号混频解调得到误差信号，经 FIR 滤波、PID 运算后经 DAC 输出至激光器。全部信号路由关系由上位机配置。

**装置参数与建模变量**：

实验装置记录激光器波长与调谐系数、EOM 调制效率与频率、参考腔自由光谱范围和精细度，以及探测器和前置放大器的带宽、响应度与噪声。这些参数共同决定鉴频斜率、环路增益和噪声模型。

其中，参考腔线宽与载波、边带功率决定第一章 1.3.4 节的鉴频斜率 $D = -8\sqrt{P_cP_s}/\delta\nu$，并为环路增益标定提供依据。

**实验条件**：激光器、EOM 及其驱动、光隔离器、参考腔（含温控与真空腔体）、光电探测器、前置放大器、光功率计、光学平台与调整架。

### 5.4.2 自动锁定过程演示

**测试目的**：验证第 5.3 节所述八态状态机的完整流程，特别是 `AUTO_AMP`/`AUTO_TIME` 自动标定环节的实际行为。

**测试方法**：设置 `pc_cmd = "10"` 启动自动链路，用示波器多通道同时记录扫描锯齿波、PD 信号、误差信号、PID 输出与状态机的三路使能输出，完整捕获从扫描到锁定的全过程。FPGA 内部状态可经 Vivado ILA 抓取（工程已有 `.ltx` 探针定义文件，说明曾做过片上调试）。

**自动锁定过程的观测量**：

| 阶段 | 观测内容 |
| --- | --- |
| `AUTO_WAIT` → `AUTO_AMP` | 锯齿回扫沿触发是否可靠 |
| `AUTO_AMP` | 峰峰值追踪结果 $V_{max}$ 与 $V_{min}$ |
| 阈值计算 | 由 $V_{th} = V_{min} + c(V_{max}-V_{min})$ 算得的阈值 |
| `AUTO_TIME` | 实测过阈时长，及导出的两个时间门限 |
| `AUTO_SCANNING` | 判定耗时 |
| `AUTO_LOCKING` | 锁定建立时间 |
| **总捕获时间** | 从启动到锁定 |

可通过改变入射功率或光路耦合条件考察相对阈值机制的适应范围，并记录捕获成功率、阈值估计误差及误触发情况。

失锁行为分析考察锁定态下误差信号跌出阈值时的计数器清零、上位机状态命令与重新扫描过程，具体状态路径见 5.3.6 节。

**实验条件**：多通道示波器（建议 4 通道以上）、Vivado 硬件管理器（ILA 抓取）。

### 5.4.3 锁定性能评估

**测试目的**：定量评估锁定性能，这是全文的最终性能指标。

**理论依据**：按第一章 1.3.5 节，闭环下的残余频率噪声谱密度为

$$
S_\nu^{\mathrm{closed}}(f) = \frac{S_\nu^{\mathrm{free}}(f)}{|1 + G(f)|^2}
$$

其中 $G(f)$ 为环路增益。中长期稳定度以阿伦方差表征：

$$
\sigma_y^2(\tau) = \frac{1}{2}\left\langle (\bar{y}_{k+1} - \bar{y}_k)^2 \right\rangle
$$

**测试方法**：

*时域*：长时间记录误差信号，统计残余误差的均方根值与漂移趋势，由频率计数器数据计算阿伦方差。

*频域*：用频谱分析仪或 FFT 分析仪测量误差信号的功率谱密度，分别在开环与闭环条件下测量，两者之比即环路的噪声抑制比，可与理论 $|1+G(f)|^{-2}$ 对照。

锁定性能采用残余误差均方根值、连续锁定时长、误差信号功率谱密度、单位增益带宽、噪声抑制比以及不同平均时间下的阿伦方差表征。时域记录用于评估漂移与稳定度，开环和闭环频谱的对照用于评估噪声抑制效果。

单位增益带宽与 5.2.2 节的环路延迟共同用于一致性分析。按 $f_{UGF} \lesssim 1/(8\tau)$，带宽与估算上界的偏差可由相位裕度、环路增益和滤波器截止频率解释。

**实验条件**：频谱分析仪、FFT 分析仪或数据采集卡、频率计数器、长时间数据记录设备。

### 5.4.4 噪声建模与影响分析

**测试目的**：建立系统噪声模型，定量分离各噪声源的贡献，确定当前性能的主导限制因素。

**噪声源清单与建模方法**：

| 噪声源 | 建模方法 | 分离方法 |
| --- | --- | --- |
| 激光固有频率噪声 | 自由运转时的 $S_\nu^{\mathrm{free}}(f)$ | 开环测量 |
| 散粒噪声 | $S_{shot} = 2h\nu P$ | 改变光功率观察标度关系 |
| PD 与前放电子噪声 | 器件噪声谱 | 遮挡光路测量本底 |
| ADC 量化噪声 | 由 5.2.1 节 ENOB 换算 | 输入端短路测量 |
| DAC 量化噪声 | 同上 | 环路开环测量输出本底 |
| 腔热噪声 | 热致长度波动模型 | 温度调制实验 |
| 定点截断噪声 | 各模块定点格式推算 | 仿真对照浮点模型 |
| 环路延迟引入的噪声增强 | 伺服鼓包幅度 | 闭环 PSD 的鼓包特征 |

各噪声源折算为等效频率噪声后统一比较，以识别主导项。定点截断噪声反映内部位宽的影响，伺服鼓包则反映环路延迟与稳定裕度之间的权衡。

**实验条件**：可调光衰减器、低噪声电源、温控设备、频谱分析仪。

### 5.4.5 控制系统稳定性与鲁棒性分析

**测试目的**：以频域方法定量评估闭环稳定性，验证参数配置的合理性。

**测试方法**：

*开环传递函数测量*：断开环路（或在环路中插入求和点），用网络分析仪注入激励并测量响应，得到开环传递函数 $G(f)$ 的幅频与相频特性。据此绘制 Bode 图，读取单位增益带宽、相位裕度与增益裕度；绘制 Nyquist 图验证不包围 $-1$ 点。

*参数敏感性分析*：在 $f_{PI}$ 与 $f_{PD}$ 以及总增益三个维度上扫描参数，记录各配置下的相位裕度与阶跃响应，确定稳定工作区边界。上位机的物理量映射接口（2.6.3 节）使这一扫描可脚本化自动完成。

参数敏感性分析以基准配置为参照，分别改变总增益（±6 dB）、积分转折频率（×2、÷2）和微分转折频率（×2），比较单位增益带宽、相位裕度、增益裕度与阶跃过冲。

按比例缩放三项增益时，Bode 图的转折频率保持不变，幅频曲线整体移动；相位裕度随单位增益交越位置变化。这一关系用于检验 2.6.3 节的参数映射设计。

**鲁棒性测试**：施加机械振动、温度变化、光功率波动等扰动，记录系统维持锁定的能力与失锁阈值。

**实验条件**：网络分析仪、振动台或敲击激励、温控设备。

### 5.4.6 与传统模拟锁定系统的对比

**对比维度**：

| 维度 | 本系统（全数字） | 传统模拟方案 |
| --- | --- | --- |
| 参数重配置 | 串口写入，毫秒级 | 更换元件或调电位器 |
| 拓扑重构 | 寄存器配置，无需改硬件 | 需重新接线 |
| 自动锁定 | 硬件状态机，微秒级响应 | 需外部电路或手动 |
| 噪声本底 | 受 ADC/DAC 量化限制 | 受元件噪声限制 |

数字系统与传统模拟方案的比较以拓扑重配置、参数更新和自动锁定方式为主；带宽与噪声指标的定量比较采用一致的光路和参考腔条件。

## 5.5 双光梳自校准本振应用实现

本节给出第二个应用案例。其意义在于：该应用与 PDH 在控制对象、信号类型与自动化策略上均不相同，却完全复用了同一套运算层与互联层。

### 5.5.1 应用背景与控制目标

光学频率梳的输出可由两个射频参量完全描述：重复频率 $f_r$ 与载波包络偏移频率 $f_{ceo}$，第 $n$ 根梳齿的频率为

$$
\nu_n = n f_r + f_{ceo}
$$

双光梳系统的拍频信号包含两台梳源的重复频率差与载波包络偏移频率差。维持相干需要分别控制这些差频；本节讨论其中本振频率偏差的估计与补偿。

与 PDH 的关键差异在于**被控量的性质**。PDH 中误差信号是一个幅度量（解调后的电压），其零点对应共振；而此处被控量是两个信号之间的**相位差**，须先由相位检测得到，且相位量具有模 $2\pi$ 的周期性。第二章 2.1.3 节所述的 CORDIC 向量模式与相位解卷绕模块正是为处理这类信号而设。

### 5.5.2 自校准本振的必要性

锁相检测要求本振频率与被测信号频率一致。但在双梳系统中，拍频的频率取决于两台梳源的实际状态，开机时并不精确已知，且会随环境漂移。若本振频率与信号频率存在偏差 $\Delta f$，则检测到的相位将以 $2\pi\Delta f$ 的速率持续累积，表现为相位的线性斜坡而非围绕定值的波动——此时环路无法锁定。

传统做法是人工测量拍频并手动设置本振频率。`SCALO_state_machine`（SCALO 即 self-calibrating local oscillator，自校准本振）将这一过程自动化：**先测量相位的漂移速率以推算频率偏差，再把该偏差补偿进本振的相位增量，然后才启动 PID**。

其原理可由相位与频率的关系直接给出。本振与信号的瞬时相位差为

$$
\phi(t) = 2\pi \Delta f \, t + \phi_0
$$

对其求导即得频率偏差：

$$
\Delta f = \frac{1}{2\pi}\frac{d\phi}{dt}
$$

在离散时间下，相位差分 $\phi[n] - \phi[n-1]$ 正比于 $\Delta f$。因此只需测得相位的平均差分，即可求出应补偿的本振频率增量。

### 5.5.3 实现结构

自校准本振状态机由相位差分、滑动窗平均、偏置更新和 PID 使能四部分构成。其输入为相位解算模块输出的 16 位相位序列，输出为 16 位本振相位偏置和一路 PID 复位信号；64 位配置字用于传递控制参数。数据端口与控制端口分离，符合第 2.4.4 节给出的模块接口约定。

设输入相位序列为 $\phi[n]$。相位差分器按相邻采样计算 $d[n]=\phi[n-1]-\phi[n]$，其符号决定本振偏置的修正方向。为降低差分对高频噪声的敏感性，采用长度为 $N=256$ 的滑动窗估计平均相位增量。窗口和通过递推式

$$
S[n]=S[n-1]+d[n]-d[n-N],\qquad \bar d[n]=\frac{S[n]}{N}
$$

更新。该结构每个采样周期仅需一次加法和一次减法，存储开销为 256 个差分样本。硬件通过截取累加结果的相应位实现除以 $2^8$ 的定点缩放。若差分样本可视为相互独立的白噪声样本，256 点平均使噪声标准差理论上降低至原来的 $1/16$；实际差分序列的相关性通过自相关函数纳入分析。

控制流程包含空闲、校准和锁定三个状态。锁定指令的上升沿触发偏置更新，并使状态机进入校准状态；经过 128 个系统时钟周期后进入锁定状态。对于 250 MHz 时钟，该等待时间为 512 ns，用于使更新后的频率控制量沿流水线传播。锁定指令撤销后，状态机返回空闲状态。

偏置寄存器采用增量更新方式，即每次触发时将当前测得的平均差分叠加至既有偏置；清零指令将其复位。该结构允许重复校准，收敛范围与精度受相位测量误差和定点量化影响，并在第 5.6 节分析。PID 复位信号仅在锁定状态解除，以避免校准期间的频率失配进入积分器。上述时序使本振校准与闭环控制按顺序执行。

### 5.5.4 与 PDH 应用的结构类比

尽管物理场景不同，两个应用在控制结构上呈现出清晰的对应关系：

| 环节 | PDH 锁定 | 双梳自校准本振锁定 |
|------|---------|------------------|
| 被控量 | 幅度量（解调电压） | 相位量（相位差） |
| 捕获前的未知量 | 共振位置、信号幅度 | 拍频频率 |
| 自动标定对象 | 幅度阈值、时间门限 | 本振频率偏置 |
| 标定方法 | 扫描一周期取极值 | 相位差分 + 256 点滑动平均 |
| 标定所需时间 | 一个扫描周期 | 128 周期（约 512 ns） |
| 交接动作 | 冻结斜坡 + 释放 PID | 补偿本振 + 释放 PID |
| 状态数 | 8 | 3 |

共同的模式是：**先以开环方式测量未知参量，再据测量结果配置环路，最后才闭合反馈**。这一"测量—配置—闭环"的三段式流程是两类实验自动化的共同骨架，差异仅在于被测量的物理量与测量方法。

平台对这一共性的支持体现在第二章 2.4.6 节的自动复位契约：两个状态机都通过同一机制门控 PID，而无需各自实现专属的使能通路。

## 5.6 双光梳锁定验证

本节分析双光梳本振校准与锁定过程，并通过相同硬件配置下的应用切换测试考察平台的复用能力。

### 5.6.1 本振自校准功能的验证

**测试目的**：验证 `SCALO` 状态机能否正确测得本振与信号的频率偏差并完成补偿。

**理论依据**：按第一章 1.3.6 节，频率偏差与相位斜率的关系为 $\Delta f = \frac{1}{2\pi}\frac{d\phi}{dt}$。校准成功的判据是：补偿后相位差不再持续累积，而是围绕定值波动。

**测试方法**：以信号源产生已知频率的信号替代真实拍频（便于精确控制偏差量），本振设为与之相差已知量 $\Delta f$，触发校准后读取本振偏置寄存器，与理论值比对。

频率偏差测试采用 1 kHz、10 kHz 和 100 kHz 三组输入，比较理论偏置、状态机写入的偏置与校准后的相位漂移速率，以分析估计精度和补偿效果。

第 5.5.3 节所述的**偏置累加语义**通过连续触发校准后的偏置序列分析，序列的收敛行为反映重复校准的作用。

### 5.6.2 滑动窗平均的噪声抑制验证

**测试目的**：验证 256 级滑动窗平均对相位差分噪声的抑制效果，并检验 第 5.5.3 节关于窗长选取的理论分析。

**理论依据**：若差分序列可近似视为独立白噪声，$N$ 点平均可使标准差降低 $\sqrt{N}$ 倍，$N=256$ 时为 16 倍。由相位样本差分得到的序列通常存在相关性，应另行计算其协方差并与实测结果比较。

**测试方法**：在输入端注入含已知噪声的相位信号，分别记录差分输出与平均后输出的标准差和自相关函数，比较独立白噪声模型与实际相关噪声条件下的抑制效果。

评价量包括差分输出与滑动窗平均输出的噪声标准差、两者的抑制比，以及重复触发校准所得偏置的标准差。独立白噪声条件下，256 点平均的标准差理论抑制比为 16；对实际差分序列同时计算自相关函数，以解释与理论值的差异。

### 5.6.3 双梳锁定实验

**测试目的**：在真实双梳系统上完成 $\Delta f_r$ 与 $\Delta f_{ceo}$ 的锁定并评估性能。

**测试方法**：按第 5.5 节的拓扑配置平台，拍频信号经 ADC 进入，经 CORDIC 反三角函数解算相位、`SCALO` 校准本振、PID 反馈至执行器。

| 指标 | 获取方法 |
| --- | --- |
| 相位漂移速率 | 相位记录的线性拟合斜率 |
| 残余相位噪声 RMS | 相位记录的标准差 |
| 相位噪声 PSD | FFT |
| 锁定保持时长 | 长时间记录 |
| 捕获时间 | 从触发到锁定的时长 |

双梳实验以两台梳源的重复频率、拍频检测光路、探测器带宽与噪声及执行器类型作为性能分析的边界条件。

**实验条件**：双光梳光源、拍频检测光路、信号源（用于 5.6.1、5.6.2 的替代测试）、频谱分析仪、相位噪声测试仪。

5.6.1 与 5.6.2 节采用信号源构造可控拍频与噪声输入，5.6.3 节则使用完整的双梳光学装置评价闭环表现。

## 5.7 平台通用性与适用边界

### 5.7.1 通用性的三个来源

两个案例共用同一套硬件，其可能性来自三项机制，均在第二章确立：

**运算模块与物理场景分离。** PID 控制器和混频器分别执行确定的数学变换，其输入、输出的物理含义由应用拓扑决定。因此，同一类运算模块可以用于不同控制任务。

**其二，互联的运行时可配。** 两个应用的拓扑差异（PDH 用混频器解调，双梳用 CORDIC 向量模式解相位）完全由路由矩阵的配置字表达，无需重新综合。切换过程由上位机连续写入路由与参数寄存器完成，其耗时由命令数量和串口速率共同决定。

**其三，控制信号的可路由性。** 布尔矩阵使"哪个状态机复位哪个 PID"成为运行时可配的关系。这是两个状态机能够共存于同一比特流、并按需启用其一的前提。

### 5.7.2 边界与代价

需客观指出平台通用性的限度。

**应用逻辑扩展。** 如 5.1.1 节所述，新的决策逻辑由应用层模块表达，并通过第四章的生成与验证闭环完成模块开发，再经综合部署到 FPGA。既有模块之间的拓扑调整则由运行时寄存器配置完成。

**模块实例数由综合配置确定。** 每类模块的实例数在综合时固定（如 PID 为 2 个实例），因此并行控制通道数由运算资源配置决定。规模扩展的资源条件见第六章。

**资源代价由全部应用共同承担。** 固化全部模块意味着即使当前只运行 PDH 实验，双梳应用所需的 CORDIC、解卷绕器与 SCALO 状态机仍占据芯片面积。这是通用性的直接代价，也是第二章 2.5.3 节所述平方增长问题的一部分。

### 5.7.3 对微纳光学实验的适用性讨论

本章两类应用均涉及频率或相位控制。对于其他微纳光学实验，现有模块是否适用还取决于信号频带、执行器接口、环路延迟和所需控制算法，不能仅由拓扑相似性判断。

对于微腔热锁定等扩展场景，可依据执行器接口、反馈带宽和控制算法要求选择现有模块或生成新模块。

## 5.8 本章小结

本章将板级能力、路由与 DSP 功能、智能体工具自迭代以及两类光学应用纳入统一的评价框架。PDH 与双光梳应用复用运算和互联资源，分别展示了幅度阈值捕获与相位差分校准两类控制流程；Vivado 反馈闭环则完成了基础模块的生成、修正与工具封装。
