# 摘要

微纳光学与精密测量实验的精度边界，往往不由光学元件本身决定，而由能否将系统稳定在期望工作点上决定。无论是激光稳频、双光梳相干锁定、微腔热锁定还是光机械模式冷却，其技术内核都是同一件事：从物理系统提取误差信号，经信号处理整形后实时反馈至执行器。不同实验的差异仅在误差信号的提取方式、控制器形式与执行器类型三处，而回路结构、延迟与噪声要求、自动化诉求则高度共通。这一共性意味着：若能构建一个在上述三处均可配置的通用平台，同一套硬件即可服务于形态各异的实验。

然而现有方案难以满足这一诉求。传统模拟方案受温漂、互连复杂与不可重构制约；而现有商用与开源数字控制产品（如 Moku 系列、Red Pitaya）存在一个贯穿性局限——**信号处理模块与它们之间的连接关系被耦合在同一份设计中，拓扑在编译期固化**。封闭产品的拓扑由厂商预设，开源平台虽可修改却需重新综合，耗时数十分钟乃至数小时，与实验现场反复试错的节奏完全不匹配。其后果是数字平台虽在参数层面充分灵活，却在拓扑层面依然刚性，而不同实验的差异恰恰大量体现在拓扑上。

本文设计并实现了一套基于 Xilinx Kintex UltraScale FPGA 的通用微纳光学实时控制平台。其核心组织原则是把"有哪些运算单元"与"它们如何连接"彻底分离：前者综合时一次性固化，后者留给运行时的寄存器配置决定。依此原则平台划分为应用层、运算层、互联层与接口层四层，层间契约明确。支撑该结构的三项机制为：统一的模块设计范式（三段式结构、以 `io_buf` 泛型将延迟与时序裕量的权衡提升为模块参数、自动复位契约使控制信号与数据同等可路由）、总线契约（二级寻址、分层命令编码、影子寄存器配合 `WRITE_HOLD` 实现超宽参数原子更新）与 $64\times64$ 双套全交叉信号路由矩阵。平台的核心抽象是数据流图，它与实验者的物理直觉同构、与流水线实现相容，且使环路延迟可加，从而让延迟—带宽约束 $f_{UGF} \le \frac{1}{2\pi\tau}(\frac{\pi}{2}-\varphi_m)$ 可直接用于指导拓扑设计。

平台以 250 MHz 系统时钟与 16 位定点数据通路为基础，实现了完整的运算模块库，包括 64 位相位累加器、19 级 CORDIC 运算器、64 抽头 FIR、采用四阶散射前瞻变换的并联双二次 IIR，以及具备两级限幅抗饱和与漏积分的 48 位 PID 控制器。

平台的复用能力以两类异质应用的控制逻辑实现为例说明；跨应用运行与锁定性能仍待实验验证。**激光 PDH 锁定**的设计要求源于鉴频斜率 $D = -8\sqrt{P_cP_s}/\delta\nu$ 与腔线宽成反比所导致的窄捕获范围，故自动锁定逻辑下沉为八态硬件状态机，按 $V_{th} = V_{min} + c(V_{max}-V_{min})$ 导出相对阈值以减轻激光功率漂移与探测器增益差异对阈值设定的影响。**双光梳自校准本振锁定**处理相位量而非幅度量，以相位差分推算频率偏差 $\Delta f = \frac{1}{2\pi}\frac{d\phi}{dt}$，经 256 级增量式滑动窗平均抑制差分噪声后补偿本振相位增量。两类应用在被控物理量、误差信号形态与自动化策略上均不相同，其设计共用同一套运算层与互联层、未增加专用运算模块，并遵循共同的"测量—配置—闭环"三段式骨架。

上位机软件构建了四层结构，完成寄存器整数值与物理量的双向换算，并实现可视化节点编辑器——其画布拓扑直接映射硬件路由配置，以四类信号类型的设计期检查将一类物理含义错误前移至连线阶段。平台最顶层进一步构建了基于大语言模型的智能体辅助设计层，通过工具边界、类型检查与错误反馈限制模型操作范围；参数校验与异常处理仍需完善。

本文同时设计了覆盖板级性能、平台功能验证与两类应用锁定实验的测试方案。需要说明的是，本稿的实验数据尚待补齐，各章中以【待测】标注之处需在实测后回填；平台对微腔、光机械等其他微纳光学场景的适用性属架构层面的推断，尚待实验验证。

**关键词**：微纳光学；实时反馈控制；FPGA；信号路由矩阵；运行时可重构；PDH 锁定；双光梳锁定；软硬件协同设计；大语言模型智能体

# Abstract

The precision limit of experiments in nanophotonics and precision metrology is often set not by the optical components themselves, but by whether the system can be held at its intended operating point. Laser frequency stabilization, dual-comb coherent locking, microcavity thermal locking, and optomechanical mode cooling all share the same technical core: extracting an error signal from a physical system, shaping it through signal processing, and feeding it back to an actuator in real time. Experiments differ in only three respects — how the error signal is obtained, the form of the controller, and the type of actuator — while the loop structure, the delay and noise requirements, and the demand for automation are largely common. This commonality implies that a single platform configurable in those three respects could serve experiments of widely differing form.

Existing solutions fall short of this goal. Analog approaches suffer from thermal drift, wiring complexity, and poor reconfigurability. Commercial and open-source digital control products (such as the Moku series and Red Pitaya) share a pervasive limitation: **signal processing modules and the connections among them are coupled within a single design, so the topology is fixed at compile time.** Closed products expose only vendor-defined topologies, while open platforms permit modification but require re-synthesis taking tens of minutes to hours — a timescale incompatible with iterative work at the optical bench. Consequently, digital platforms are fully flexible at the level of *parameters* yet remain rigid at the level of *topology*, even though it is precisely in topology that experiments differ most.

This thesis presents the design and implementation of a general-purpose real-time control platform for nanophotonics experiments, based on a Xilinx Kintex UltraScale FPGA. Its organizing principle is a complete separation between *which computational units exist* and *how they are connected*: the former is fixed once at synthesis, the latter left to runtime register configuration. The platform is accordingly divided into application, computation, interconnect, and interface layers with explicit inter-layer contracts. Three mechanisms support this structure: a uniform module design paradigm (three-part structure, an `io_buf` generic that elevates the delay-versus-timing-margin trade-off to a module parameter, and an auto-reset contract making control signals as routable as data); a bus contract (two-level addressing, hierarchical command encoding, and shadow registers with a `WRITE_HOLD` command for atomic updates of over-wide parameters); and a $64\times64$ dual fully-crossed signal routing matrix. The platform's central abstraction is the dataflow graph, which is isomorphic to the experimenter's physical intuition, compatible with pipelined implementation, and renders loop delay additive — so that the delay-bandwidth constraint $f_{UGF} \le \frac{1}{2\pi\tau}(\frac{\pi}{2}-\varphi_m)$ can directly guide topology design.

Built on a 250 MHz system clock with a 16-bit fixed-point datapath, the platform implements a complete module library: a 64-bit phase accumulator, a 19-stage CORDIC engine, a 64-tap FIR filter, a parallel biquad IIR filter using a fourth-order scattered look-ahead transformation, and a 48-bit PID controller with two-stage anti-windup clamping and leaky integration.

The platform's reuse is illustrated by the implementation of control logic for two heterogeneous applications; cross-application operation and locking performance still require experimental verification. **Laser PDH locking** is shaped by the narrow capture range implied by the discriminator slope $D = -8\sqrt{P_cP_s}/\delta\nu$ being inversely proportional to cavity linewidth; the locking logic is therefore pushed into an eight-state hardware state machine that derives a relative threshold as $V_{th} = V_{min} + c(V_{max}-V_{min})$, to reduce the sensitivity of threshold setting to laser power drift and detector gain variation. **Dual-comb self-calibrating local oscillator locking** operates on phase rather than amplitude, inferring frequency offset from phase differentiation as $\Delta f = \frac{1}{2\pi}\frac{d\phi}{dt}$ and compensating the LO phase increment after suppressing differentiation noise through a 256-stage incremental sliding-window averager. The two application designs differ in controlled quantity, error-signal form, and automation strategy, yet share the same computation and interconnect layers with no application-specific computational module added, and follow a common measure–configure–close-the-loop skeleton.

The host software is organized into four layers providing bidirectional conversion between register integers and physical quantities, and implements a visual node editor whose canvas topology maps directly onto hardware routing configuration, applying design-time checking over four signal types to move a class of physical-semantic errors forward to the wiring stage. At the very top, an LLM-based agent layer enables topologies to be generated from natural language, with tool boundaries, type checking, and error feedback limiting the model’s operations; parameter validation and exception handling still require improvement.

A test plan covering board-level performance, platform functional verification, and locking experiments for both applications is also presented. It should be noted that experimental data for this draft remain to be collected; points marked 【待测】 are to be filled in after measurement. The platform's applicability to other nanophotonic scenarios such as microcavities and optomechanics is an architectural inference awaiting experimental validation.

**Keywords**: nanophotonics; real-time feedback control; FPGA; signal routing matrix; runtime reconfigurability; PDH locking; dual-comb locking; hardware-software co-design; LLM agent
