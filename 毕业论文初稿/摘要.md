# 摘要

微纳光学实验中的激光稳频和相位同步通常依赖低延迟反馈控制。不同实验对误差信号提取、控制参数和信号连接方式的要求不同，固定拓扑的数字控制系统在实验方案调整时需要重新配置或修改设计。针对这一问题，本文设计了一套基于 Kintex UltraScale FPGA 的可配置实时控制平台，将运算模块与模块间连接分离，使既有模块的信号拓扑能够通过寄存器配置改变。

本文首先分析 PDH 稳频、双光梳相位控制及离散时间反馈系统的设计约束；随后构建应用层、运算层、互联层和接口层组成的平台架构。系统采用 250 MHz 主时钟和 16 位定点数据通路，实现 64 路数据信号与 64 路控制信号的独立交叉路由，并集成相位累加、CORDIC、FIR、IIR 和 PID 等运算模块。上位机软件完成物理参数到寄存器值的映射及可视化拓扑配置，智能体通过受约束的工具接口辅助生成和编辑画布连接。在应用层，分别实现 PDH 自动扫描与锁定状态机，以及基于相位差分和滑动窗平均的双光梳本振校准状态机。两类应用复用既有运算与互联资源，说明所提出架构能够表达不同类型的控制流程。

本文给出了资源与时序、拓扑切换、模块功能、智能体配置以及两类锁定应用的验证方案。目前尚缺少完整的综合报告和实验测量结果，因此平台的时序性能、锁定稳定度及跨应用运行效果仍有待验证。本文的结论限于架构设计与现有实现所能支持的范围。

**关键词**：微纳光学；FPGA；实时反馈控制；可配置互联；PDH 锁定；双光梳；智能体辅助设计

# Abstract

Laser frequency stabilization and phase synchronization in nanophotonic experiments require feedback control with low latency. Experimental setups differ in how error signals are extracted, how controllers are parameterized, and how signal-processing modules are connected. This thesis presents a configurable real-time control platform based on a Kintex UltraScale FPGA. Computational modules are separated from their interconnections so that signal paths among existing modules can be changed through register configuration.

The thesis first examines design constraints arising from Pound–Drever–Hall (PDH) stabilization, dual-comb phase control, and discrete-time feedback. It then develops a four-layer architecture comprising application, computation, interconnect, and interface layers. The implementation uses a 250 MHz system clock and a 16-bit fixed-point datapath. Separate crossbars route 64 data signals and 64 control signals, while a module library provides phase accumulation, CORDIC, FIR, IIR, and PID operations. Host software maps physical parameters to register values and supports visual topology configuration. An agent assists with canvas editing through a constrained tool interface. At the application layer, the platform implements a PDH scanning and locking state machine and a dual-comb local-oscillator calibration state machine based on phase differencing and sliding-window averaging. Both application designs reuse the existing computation and interconnect resources.

A verification plan is specified for resource utilization, timing, topology switching, module behavior, agent-assisted configuration, and the two locking applications. Complete implementation reports and experimental measurements are not yet available. Timing performance, locking stability, and cross-application operation therefore remain to be established experimentally. The conclusions are restricted to the architecture and implementation evidence currently available.

**Keywords**: nanophotonics; FPGA; real-time feedback control; configurable interconnect; PDH locking; dual-comb system; agent-assisted design
