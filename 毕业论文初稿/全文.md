# 基于 FPGA 架构的微纳光学控制平台

# 摘要

微纳光学实验中的激光稳频和相位同步通常依赖低延迟反馈控制。不同实验对误差信号提取、控制参数和信号连接方式的要求不同，固定拓扑的数字控制系统在实验方案调整时需要重新配置或修改设计。针对这一问题，本文设计了一套基于 Kintex UltraScale FPGA 的可配置实时控制平台，将运算模块与模块间连接分离，使既有模块的信号拓扑能够通过寄存器配置改变。

本文首先分析 PDH 稳频、双光梳相位控制及离散时间反馈系统的设计约束；随后构建应用层、运算层、互联层和接口层组成的平台架构。系统采用 250 MHz 主时钟和 16 位定点数据通路，实现 64 路数据信号与 64 路控制信号的独立交叉路由，并集成相位累加、CORDIC、FIR、IIR 和 PID 等运算模块。上位机软件完成物理参数到寄存器值的映射及可视化拓扑配置，智能体通过受约束的工具接口辅助生成和编辑画布连接。在应用层，分别实现 PDH 自动扫描与锁定状态机，以及基于相位差分和滑动窗平均的双光梳本振校准状态机。两类应用复用既有运算与互联资源，说明所提出架构能够表达不同类型的控制流程。

本文给出了资源与时序、拓扑切换、模块功能、智能体配置以及两类锁定应用的验证方案。目前尚缺少完整的综合报告和实验测量结果，因此平台的时序性能、锁定稳定度及跨应用运行效果仍有待验证。本文的结论限于架构设计与现有实现所能支持的范围。

**关键词**：微纳光学；FPGA；实时反馈控制；可配置互联；PDH 锁定；双光梳；智能体辅助设计

# Abstract

Laser frequency stabilization and phase synchronization in nanophotonic experiments require feedback control with low latency. Experimental setups differ in how error signals are extracted, how controllers are parameterized, and how signal-processing modules are connected. This thesis presents a configurable real-time control platform based on a Kintex UltraScale FPGA. Computational modules are separated from their interconnections so that signal paths among existing modules can be changed through register configuration.

The thesis first examines design constraints arising from Pound–Drever–Hall (PDH) stabilization, dual-comb phase control, and discrete-time feedback. It then develops a four-layer architecture comprising application, computation, interconnect, and interface layers. The implementation uses a 250 MHz system clock and a 16-bit fixed-point datapath. Separate crossbars route 64 data signals and 64 control signals, while a module library provides phase accumulation, CORDIC, FIR, IIR, and PID operations. Host software maps physical parameters to register values and supports visual topology configuration. An agent assists with canvas editing through a constrained tool interface. At the application layer, the platform implements a PDH scanning and locking state machine and a dual-comb local-oscillator calibration state machine based on phase differencing and sliding-window averaging. Both application designs reuse the existing computation and interconnect resources.

A verification plan is specified for resource utilization, timing, topology switching, module behavior, agent-assisted configuration, and the two locking applications. Complete implementation reports and experimental measurements are not yet available. Timing performance, locking stability, and cross-application operation therefore remain to be established experimentally. The conclusions are restricted to the architecture and implementation evidence currently available.

**Keywords**: nanophotonics; FPGA; real-time feedback control; configurable interconnect; PDH locking; dual-comb system; agent-assisted design

# 第一章 绪论

本章从微纳光学实验的实时反馈需求出发，梳理数字控制平台的研究背景，给出 PDH 稳频与双光梳锁定的物理依据，并说明本文的目标与六章结构。

## 1.1 研究背景与意义

### 1.1.1 微纳光学实验中的实时反馈控制需求

激光频率稳定、微腔谐振跟踪和双光梳相干控制等实验均需要将系统维持在规定工作点。此类任务通常包括误差信号提取、控制器整形与执行器反馈三个环节。

这一共性可以形式化地表述。设被控物理量为 $x(t)$，期望值为 $x_0$，则反馈控制系统须实现

$$
u(t) = \mathcal{K}\left[x(t) - x_0\right]
$$

其中 $\mathcal{K}$ 为控制器的传递算子，$u(t)$ 为施加于执行器的校正量。不同实验的重要差异体现在三个方面：误差信号的提取方式（直接探测、相位调制解调、拍频检测）、控制器 $\mathcal{K}$ 的具体形式（比例积分、高阶滤波、状态反馈），以及执行器的类型（压电陶瓷、声光调制器、电光调制器、激光二极管电流、加热器）。这些实验同时具有对环路延迟、噪声和自动捕获能力的共同需求。

基于这些共性，本文研究在既定硬件资源范围内配置运算模块、连接关系和控制流程的方法。

以下三类实验说明了需求的多样性与共通性。

**激光频率稳定。** 高精度光频标对激光频率噪声提出严格要求 [1]。自由运转激光器受到自发辐射、机械振动与温度变化等因素影响，通常需要借助外部频率参考及反馈环路降低频率漂移。第 1.1.3 节以 PDH 稳频为例说明相应的误差信号获取方法。

**双光梳相干锁定。** 光学频率梳的输出由重复频率 $f_r$ 与载波包络偏移频率 $f_{ceo}$ 两个射频参量完全描述，第 $n$ 根梳齿的频率为 $\nu_n = n f_r + f_{ceo}$。双光梳系统须将两台梳源的这两个差频分别锁定，方能维持相干。此类应用的被控量是**相位**而非幅度，须经相位解算与解卷绕处理，对信号处理的要求与激光稳频显著不同。本文平台的第二个应用案例（第五章 5.5 节）正属此类。

**微腔与光机械系统。** 高品质因子微腔的谐振频率随温度与光功率漂移，须经热锁定或自适应反馈维持在工作点；光机械系统中的模式冷却则须对振子的位移信号作相位精确的反馈。这类实验的控制带宽要求往往更高，对环路延迟更为敏感。

三类实验的误差信号形态、控制带宽与执行器各不相同，但都需要：低延迟的信号通路、可灵活整形的控制器、以及能自动寻找并维持工作点的逻辑。这构成了本文平台的设计需求来源。

### 1.1.2 传统模拟方案与分立仪器的局限

长期以来，上述反馈环路主要由分立的模拟电路模块实现：混频器完成解调，运算放大器构成的比例–积分–微分（PID）网络提供环路增益，再经高压放大器驱动压电陶瓷或经电流调制端口驱动激光二极管。模拟方案的优势在于不存在采样延迟与量化噪声，理论上可以获得极高的单位增益带宽。但在工程实践中，它存在若干难以回避的问题。

首先是直流漂移与温度稳定性。模拟积分器的输出会随运算放大器的输入失调电压及其温漂而缓慢移动，混频器的直流偏置同样随环境温度变化。这些漂移在误差信号中表现为一个随时间变化的虚假零点，使系统锁定在偏离真实工作点的位置上，并引入难以区分的长期漂移。

其次是参数调节的不可重复性。模拟 PID 的增益与转折频率由电阻、电容的具体取值确定，调节依赖电位器或更换元件。这使得环路参数既无法精确记录和复现，也无法在实验过程中按需快速扫描寻优；在需要多路同时锁定的系统中，逐路手工整定的工作量迅速变得不可接受。

第三是互连复杂与串扰。一套完整的锁定系统通常需要本振源、相移器、混频器、低通滤波器、伺服放大器、扫描斜坡发生器、高压放大器等多个独立机箱，彼此以同轴电缆连接。连线数量随通道数增加，可能引入地环路与射频串扰，也使系统的拓扑一旦确定便难以改动。

第四是功能不可重构。模拟硬件的信号流向由物理连线决定。当实验需求从简单的单环锁定扩展到调制转移光谱、双色锁定、腔长伺服与激光伺服级联等更复杂的方案时，往往意味着重新设计电路板。实验方案的调整因此可能伴随较高的硬件改造成本。

此外，若缺少独立的数字控制逻辑，工作点搜索、捕获判断及失锁恢复可能需要人工操作或额外电路支持。这既限制了实验效率，也使长时间无人值守运行难以保证。

### 1.1.3 典型应用：PDH 稳频技术原理概述

作为本文平台的主要应用案例，本节先介绍 PDH 技术的基本原理，为后续章节建立物理背景。完整推导见 1.3 节。

高精细度 Fabry–Pérot（F-P）光学参考腔可充当频率鉴别器。将激光锁定到超稳腔的本征模式上，可以把腔长的稳定度转移为激光频率的稳定度。但直接利用腔的透射或反射强度存在一个根本困难：**强度信号在共振点附近是偶对称的**，无法区分频率偏高还是偏低，因而不能作为误差信号。

Pound–Drever–Hall（PDH）技术 [2,3] 解决了这一问题。其思路是对入射光进行相位调制，在载波两侧产生频率为 $\omega \pm \Omega$ 的边带；载波与边带经腔反射后获得不同的相位响应，彼此干涉使反射光强出现 $\Omega$ 频率的分量，其幅度与相位携带了载波相对于共振点的偏离方向。对反射光作 $\Omega$ 频率的同步解调，即可得到一个在共振点**反对称、过零且斜率陡峭**的误差信号。

该误差信号在近共振区的鉴频斜率为

$$
D = -\frac{8\sqrt{P_c P_s}}{\delta\nu}
$$

其中 $P_c$ 与 $P_s$ 分别为载波与边带功率，$\delta\nu$ 为腔线宽。这一结果有两重含义。其一，斜率与腔线宽成反比，故高精细度腔可获得极高的鉴频灵敏度——这是 PDH 能实现亚赫兹线宽 [4] 的根本原因。其二，**高灵敏度必然伴随窄捕获范围**：误差信号的线性区仅约一个腔线宽，远窄于激光的自由运转漂移范围。

第二项含义对自动捕获提出了时序要求：系统需先扫描共振位置，再在误差信号进入有效区间时切换至闭环控制。由于有效区间有限，捕获判定与环路切换由 FPGA 内部逻辑实现（见第 5.3 节）。

PDH 解调提供频率偏差的观测量；闭环抑噪效果还取决于控制器增益、带宽、相位裕度及电子学噪声。因此，伺服系统的实现与评价是本文的研究重点。

### 1.1.4 全数字控制平台的优势与代价

随着现场可编程门阵列（FPGA）以及高速模数/数模转换器（ADC/DAC）性能的提升与成本的下降，将反馈环路的信号处理部分整体数字化已成为可行且主流的技术路线 [5]。在全数字方案中，光电探测器输出的射频信号经 ADC 采样后进入 FPGA，在数字域内完成解调、滤波、环路整形与状态判决，再经 DAC 输出到执行器。

数字实现具有以下特点。其一，参数的可记录与可重复性：增益、滤波器系数、阈值等全部以寄存器数值形式存在，可被精确记录、保存与恢复，为自动整定提供了前提。其二，数字积分器的寄存器状态不受模拟器件失调漂移的直接影响，但 ADC、DAC 和模拟前端仍可能引入温度相关误差。其三，既有模块的参数和连接关系可由配置改变，从而支持不同控制链路。其四，数字域适合实现 IIR 滤波、CORDIC 相位解算与相位解卷绕等离散运算。其五，状态机可以与信号处理链路在 FPGA 内协同工作，减少自动捕获过程中对上位机轮询的依赖。

数字方案固有的代价是采样延迟与量化噪声。采样保持、ADC/DAC 转换以及流水线运算共同构成环路的纯延迟 $\tau$，它在频率 $\omega$ 处引入与频率成正比的附加相移 $\Delta\phi = -\omega\tau$，从而限制可达到的单位增益带宽。第二章 2.1.5 节将定量给出这一约束：

$$
f_{UGF} \le \frac{1}{2\pi\tau}\left(\frac{\pi}{2} - \varphi_m\right)
$$

因此，数字控制平台需在运算复杂度、时序裕量与环路延迟之间进行权衡。本文在模块接口和流水线设计中显式考虑这一约束。

## 1.2 国内外研究现状

### 1.2.1 商用与开源数字控制平台分析

基于 FPGA 的数字控制平台已应用于光学实验。相关方案包括商用仪器平台与开源硬件平台，两类方案在可访问的设计层次、拓扑配置方式及开发成本方面存在差异。以下以 Moku 系列和 Red Pitaya 为例讨论这些差异；具体产品指标与功能范围仍需以文献或官方资料核实。

**Moku 系列。** 此类商用平台通过预定义仪器功能及软件接口提供参数配置能力。其优势在于仪器集成与使用便利性；用户可配置的运算结构及互联方式取决于具体型号和软件功能。不同型号的拓扑范围、带宽、噪声与延迟指标需另行查证，本文不据此作定量比较。

**Red Pitaya。** 开源硬件平台允许研究者修改 FPGA 逻辑并重新综合，因此可扩展信号处理功能。新增运算或改变原有数据通路通常伴随硬件描述、验证和重新构建。其资源容量与模拟性能取决于具体型号，相关指标及与本平台的比较有待补充可靠来源。

科研界亦提出面向精密光学实验的开源数字伺服方案。Leibrandt 与 Heidecker 的研究讨论了数字环路延迟与可达带宽的权衡 [5]。不同平台的运行时拓扑配置能力仍需依据具体设计文献逐项比较。

### 1.2.2 现有方案的共同局限：拓扑的编译期固化

上述方案表明，模块连接的可配置范围受仪器固件与硬件资源共同约束。对于需要频繁改变实验信号链的场景，有必要研究在既有模块集合内通过运行时配置调整拓扑的方法。

当目标连接不在已有配置范围内时，开源方案通常需要修改逻辑并重新综合；实际耗时随设计规模、工具设置和计算资源变化。本文关注的是无需重新综合即可切换既有运算模块之间的连接关系，切换效率将在第五章的实验方案中评估。

参数可配置性与拓扑可配置性是两个独立维度。本文针对需要改变误差信号提取、控制器级联和交叉耦合方式的实验，研究后一维度的实现。

据此，本文将既有模块间的拓扑配置作为平台的主要设计目标。

### 1.2.3 自研高性能平台的必要性

综合上述分析，现有方案在三个维度上留下了空白，构成了自研平台的必要性。

第一，平台应支持既有模块间连接关系的运行时配置，以减少拓扑调整对重新综合的依赖。本文采用全交叉路由矩阵实现该功能（见第 2.5 节）。

第二是**性能与资源**的需求。高性能控制要求低延迟与高采样率，复杂方案又要求大量并行的滤波与运算资源，二者共同指向更大规模、更高速度等级的 FPGA。选用独立的 Kintex UltraScale 器件而非入门级 SoC，可以在数据通路上同时容纳数十个全精度流水线运算模块，并以较高的系统时钟降低单位运算的延迟代价。

第三，平台需要提供可检查的硬件逻辑与通信接口，便于扩展和维护。多通道配置的总体成本仍需结合器件、开发及维护开销进行评估。

本文的研究目标是实现可检查、可扩展的运行时拓扑配置机制，其性能和成本应在明确测试条件下与其他方案比较。

## 1.3 典型光学锁定原理与指标

### 1.3.1 Fabry–Pérot 腔的反射特性

PDH 技术以高精细度 F-P 腔作为频率参考。考察一个由两面反射镜构成的对称光学腔，设镜面的幅度反射系数与透射系数分别为 $r$ 和 $t$，腔长为 $L$。入射光场在腔内往返一周所积累的相位为

$$
\phi(\omega) = \frac{2L\omega}{c} = \frac{\omega}{\Delta\nu_{\mathrm{FSR}}/2\pi}
$$

其中 $\Delta\nu_{\mathrm{FSR}} = c/2L$ 为自由光谱范围。将腔内多次往返的部分波相干叠加，可得腔的幅度反射系数

$$
F(\omega) = \frac{E_{\mathrm{ref}}}{E_{\mathrm{inc}}} = \frac{r\left[\exp\left(i\,\omega/\Delta\nu_{\mathrm{FSR}}\right) - 1\right]}{1 - r^{2}\exp\left(i\,\omega/\Delta\nu_{\mathrm{FSR}}\right)}
$$

此处已省略了与总体传播相位相关的常数因子，并采用了无损镜面假设 $r^2 + t^2 = 1$ [3]。$F(\omega)$ 是一个复函数：其模方 $|F(\omega)|^{2}$ 给出反射功率的归一化值，在共振频率 $\omega_q = q\,\omega_{\mathrm{FSR}}$ 处取极小（理想无损对称腔中为零），呈现周期性的反射凹陷；其相位 $\arg F(\omega)$ 在共振点附近随频率快速变化，并在穿过共振时改变符号。

腔的频率选择性由精细度描述。定义精细度

$$
\mathcal{F} = \frac{\pi r}{1 - r^{2}}
$$

则反射凹陷（亦即腔线宽）的半高全宽为

$$
\delta\nu = \frac{\Delta\nu_{\mathrm{FSR}}}{\mathcal{F}}
$$

精细度越高，线宽越窄，相位随频率变化的斜率越陡，可获得的鉴频灵敏度也越高。

需要强调的是，仅凭反射功率 $|F(\omega)|^{2}$ 无法构成有效的误差信号：它在共振点处取极值，因而关于共振点对称，其一阶导数为零，无法分辨频率偏离的方向。PDH 技术的关键，正是通过相位调制与同步解调，把 $F(\omega)$ 的**相位信息**转换为一个在共振点过零且具有确定符号的直流信号。

### 1.3.2 相位调制光场与边带展开

设入射激光的角频率为 $\omega$，经电光调制器（EOM）施加角频率为 $\Omega$、调制深度为 $\beta$ 的正弦相位调制，则入射光场可写为

$$
E_{\mathrm{inc}} = E_{0}\exp\left[i\left(\omega t + \beta\sin\Omega t\right)\right]
$$

利用 Jacobi–Anger 展开 $\exp(i\beta\sin\Omega t) = \sum_{n=-\infty}^{\infty} J_{n}(\beta)\exp(in\Omega t)$，其中 $J_n$ 为第一类 $n$ 阶贝塞尔函数，得

$$
E_{\mathrm{inc}} = E_{0}\sum_{n=-\infty}^{\infty} J_{n}(\beta)\exp\left[i(\omega + n\Omega)t\right]
$$

在小调制深度（$\beta \lesssim 1$）条件下，二阶以上边带可忽略，光场近似为载波与一对一阶边带的叠加：

$$
E_{\mathrm{inc}} \approx E_{0}\left[J_{0}(\beta)e^{i\omega t} + J_{1}(\beta)e^{i(\omega+\Omega)t} - J_{1}(\beta)e^{i(\omega-\Omega)t}\right]
$$

其中利用了 $J_{-1}(\beta) = -J_{1}(\beta)$。两个一阶边带相位相反，这一反对称性是误差信号具有奇对称形状的根源。

三个频率分量各自被腔以不同的反射系数反射，故反射光场为

$$
E_{\mathrm{ref}} \approx E_{0}\left[F(\omega)J_{0}(\beta)e^{i\omega t} + F(\omega+\Omega)J_{1}(\beta)e^{i(\omega+\Omega)t} - F(\omega-\Omega)J_{1}(\beta)e^{i(\omega-\Omega)t}\right]
$$

### 1.3.3 反射光功率与误差信号

光电探测器响应光强，即 $P_{\mathrm{ref}} = |E_{\mathrm{ref}}|^{2}$。将上式展开并记总入射功率 $P_{0} = |E_{0}|^{2}$，保留直流项与 $\Omega$ 频率项（$2\Omega$ 及更高项在解调后被低通滤除），得

$$
\begin{aligned}
P_{\mathrm{ref}} = P_{0}\Big\{ & J_{0}^{2}(\beta)\left|F(\omega)\right|^{2} + J_{1}^{2}(\beta)\left[\left|F(\omega+\Omega)\right|^{2} + \left|F(\omega-\Omega)\right|^{2}\right] \\
& + 2J_{0}(\beta)J_{1}(\beta)\Big( \mathrm{Re}\left[F(\omega)F^{*}(\omega+\Omega) - F^{*}(\omega)F(\omega-\Omega)\right]\cos\Omega t \\
& \qquad\qquad\quad + \mathrm{Im}\left[F(\omega)F^{*}(\omega+\Omega) - F^{*}(\omega)F(\omega-\Omega)\right]\sin\Omega t \Big) \\
& + \left(2\Omega\ \text{项}\right) \Big\}
\end{aligned}
$$

式中第一行为直流分量，即前述无方向信息的反射凹陷；第二、三行为载波与边带的拍频项，是 PDH 信号的载体。该拍频项包含同相（$\cos\Omega t$）与正交（$\sin\Omega t$）两个分量，分别由同一复组合量的实部与虚部给出。

将探测器输出与本振 $\sin\Omega t$ 相乘并经低通滤波（即同步解调），即可提取正交分量，得到误差信号

$$
\epsilon \propto \mathrm{Im}\left[F(\omega)F^{*}(\omega+\Omega) - F^{*}(\omega)F(\omega-\Omega)\right]
$$

这就是 PDH 误差信号的一般表达式。其幅度与 $2J_{0}(\beta)J_{1}(\beta)P_{0}$ 成正比，故存在一个使信号最大的最佳调制深度；对小 $\beta$ 的近似表达式求极值可得 $\beta \approx 1.08$ [3]。若改为解调同相分量，则得到实部形式的信号，其在共振点附近不过零，一般不用作误差信号；本振相位的失配会使两种分量混合，导致误差信号畸变与零点偏移，因此实际系统中需要对解调相位进行调节与标定。

### 1.3.4 近共振线性区与鉴频斜率

实际稳频工作在共振点附近，且通常选取调制频率远大于腔线宽的情形，即 $\Omega \gg \delta\nu \cdot 2\pi$。此时两个边带被腔完全反射而几乎不进入腔内，可近似认为 $F(\omega \pm \Omega) \approx -1$。代入误差信号表达式，括号内化简为 $-F(\omega) + F^{*}(\omega)$，即

$$
\epsilon \propto \mathrm{Im}\left[-F(\omega) + F^{*}(\omega)\right] = -2\mathrm{Im}\left[F(\omega)\right]
$$

于是误差信号正比于腔反射系数的虚部。设激光频率相对共振点的偏移为 $\delta\omega = \omega - \omega_q$，在 $|\delta\omega| \ll 2\pi\,\delta\nu$ 的范围内将 $F(\omega)$ 作一阶展开，可得

$$
\epsilon \approx D\,\delta\nu_{\mathrm{laser}}
$$

其中鉴频斜率（判别器斜率）为

$$
D = \left.\frac{\partial \epsilon}{\partial \nu}\right|_{\nu = \nu_q} = -\frac{8\sqrt{P_{c}P_{s}}}{\delta\nu}
$$

式中 $P_{c} = J_{0}^{2}(\beta)P_{0}$ 为载波功率，$P_{s} = J_{1}^{2}(\beta)P_{0}$ 为单个一阶边带的功率 [3]。符号表示误差信号随频率增大而减小，具体正负取决于解调相位与电路极性的约定。

该式概括了 PDH 鉴频的全部设计要点：斜率与 $\sqrt{P_cP_s}$ 成正比，故提高光功率和采用最佳调制深度有利；斜率与腔线宽 $\delta\nu$ 成反比，故高精细度腔具有更高的灵敏度，但同时线性区宽度亦随之收窄——线性区大致只有约一个腔线宽，捕获范围因而很小。这一事实直接决定了自动锁定的必要性：若激光频率偏离共振超出线性区，误差信号迅速失去单调性甚至反号，环路无法自行捕获，必须先以扫描方式使激光频率缓慢通过共振，再在恰当时刻闭合环路。本文第 5.3 节的自动锁定状态机正是为完成这一"扫描—判决—闭环"序列而设计的。

在线性区之外，误差信号呈现为以共振点为中心的奇对称曲线，并在 $\pm\Omega$ 处因边带与腔的共振而出现符号相反的次级结构。这一特征在实验上常被用作频率标尺：相邻两个边带特征之间的间隔对应已知的 $2\Omega$，由此可标定扫描速率与误差信号的频率坐标。

### 1.3.5 稳频性能指标

伺服环路闭合后，残余频率噪声需以统一的指标体系来评价。

**频率噪声功率谱密度**。设瞬时频率偏差为 $\delta\nu(t)$，其单边功率谱密度 $S_{\nu}(f)$（单位 $\mathrm{Hz^{2}/Hz}$）描述噪声的频率分布，是分析伺服环路作用最直接的量。相应的相位噪声谱满足 $S_{\phi}(f) = S_{\nu}(f)/f^{2}$。亦常用归一化频率偏差 $y(t) = \delta\nu(t)/\nu_{0}$ 的谱密度 $S_{y}(f) = S_{\nu}(f)/\nu_{0}^{2}$。

**Allan 方差**。时域稳定度以 Allan 方差描述。对取样时间 $\tau$，有

$$
\sigma_{y}^{2}(\tau) = \frac{1}{2}\left\langle \left(\bar{y}_{k+1} - \bar{y}_{k}\right)^{2} \right\rangle
$$

其中 $\bar{y}_{k}$ 为第 $k$ 个长度为 $\tau$ 的区间上的平均归一化频率偏差。实际数据处理中更常用重叠 Allan 偏差以提高置信度。$\sigma_{y}(\tau)$ 的双对数斜率可用于识别主导噪声类型：白频率噪声对应 $\tau^{-1/2}$，闪变频率噪声对应平台，频率随机游走对应 $\tau^{1/2}$，线性漂移对应 $\tau^{1}$。

**激光线宽**。线宽是频率噪声谱的积分效果。当频率噪声以白噪声为主且满足快速调制条件时，谱线为洛伦兹型，半高全宽 $\Delta\nu = \pi S_{\nu}$。更一般的情形下可采用 $\beta$ 分离线法估算线宽，即以 $S_{\nu}(f) = 8\ln 2\,f/\pi^{2}$ 为分界线，只有高于该线的噪声成分对线宽有贡献。

**误差信号的噪声本底与可达极限**。鉴频斜率 $D$ 把频率噪声映射为电压噪声，反过来，误差信号通路上的噪声 $S_{V}$ 也会被折算为等效频率噪声

$$
S_{\nu}^{\mathrm{eq}}(f) = \frac{S_{V}(f)}{D^{2}}
$$

该式说明，高鉴频斜率不仅提高灵敏度，也直接压低了电子学噪声的等效贡献。在理想情况下，PDH 锁定的极限由反射光的散粒噪声决定；而在实际系统中，探测器噪声、ADC 量化噪声与残余幅度调制（RAM）往往先于散粒噪声成为限制因素。其中 RAM 尤其值得注意：它在误差信号中表现为一个随温度缓慢变化的直流偏置，无法与真实的频率偏差相区分，是长期稳定度的主要限制之一。

**环路内外的区别**。必须指出，环路内测得的残余误差信号小，并不等于激光频率真的稳定。伺服环路只能抑制它所能观测到的噪声；参考腔自身的长度抖动、鉴频零点的漂移都会被环路忠实地复制到激光频率上。因此对稳频性能的严格评价须依赖独立的外部参考，例如与另一台独立稳频激光器作拍频测量，或借助光学频率梳与微波频标比对。本文第五章的测试即在此前提下讨论可验证的指标与尚不可验证的部分。

### 1.3.6 双光梳锁定的频率关系

本节给出第五章第二类应用的物理基础。与 PDH 的幅度量反馈不同，双光梳锁定的被控量是相位，其理论处理方式亦随之不同。

**梳齿频率的双参量描述。** 锁模激光器输出的光学频率梳在频域上是一组等间距谱线，第 $n$ 根梳齿的绝对频率由两个射频参量完全确定：

$$
\nu_n = n f_r + f_{ceo}
$$

其中 $f_r$ 为重复频率（等于腔往返频率，典型值为数十至数百 MHz），$f_{ceo}$ 为载波包络偏移频率（源于腔内群速度与相速度之差，取值范围在 $[0, f_r)$），$n$ 为梳齿序数（典型值 $10^5 \sim 10^6$）。这一关系是光学频率梳作为"频率齿轮"的基础：它把光学频率 $\nu_n$（$\sim 10^{14}$ Hz）与可直接计数的射频量 $f_r$、$f_{ceo}$ 联系起来 [6,7]。

**双梳系统的差频。** 考虑两台梳源，参量分别为 $(f_{r1}, f_{ceo1})$ 与 $(f_{r2}, f_{ceo2})$。将二者的输出合束后由探测器接收，第 $n$ 对梳齿产生的拍频为

$$
\Delta\nu_n = \nu_n^{(1)} - \nu_n^{(2)} = n\,(f_{r1} - f_{r2}) + (f_{ceo1} - f_{ceo2}) = n\,\Delta f_r + \Delta f_{ceo}
$$

因此，双梳系统的相干控制需要分别处理重复频率差和载波包络偏移频率差；本文平台的应用设计围绕这两个差频展开。

该式同时揭示了双梳系统的一项重要特征：拍频随梳齿序数 $n$ 线性展开，使光学频率上的巨大跨度被映射到射频波段的一组可分辨拍频上。这是双梳光谱与双梳测距等应用的原理基础。

**相位反馈与频率反馈的等价性。** 锁定差频 $\Delta f_r$ 时，可以选择直接测频反馈，也可以测量相位并反馈。后者在精度上更优，原因在于相位是频率的积分：

$$
\phi(t) = 2\pi\int_0^t \Delta f(t')\,dt'
$$

相位测量因而天然具有对频率噪声的积分平滑作用，且相位误差不随测量时间衰减——这使相位锁定可以达到远高于直接测频的长期稳定度。本文平台以 CORDIC 向量模式（第二章 2.1.3 节）实现相位解算，正是为支持这类反馈。

**相位的周期性及其后果。** 相位反馈面临一个 PDH 不存在的问题：相位的物理值在 $[-\pi, \pi)$ 上定义，而实际的相位演化可以无界增长。当被测相位越过 $\pm\pi$ 边界时，解算结果发生 $2\pi$ 跳变，若直接送入控制器将被误认为一次巨大的误差突变。

这一问题有两种处理途径。其一是**相位解卷绕**：检测相邻采样间的跳变并累加补偿量，恢复连续的相位轨迹，本文平台以专门的解卷绕模块实现（第二章）。其二是**本振频率校准**：若本振频率与待测信号精确一致，则相位差围绕定值波动而不持续累积，自然不会越界。

后者正是第五章 5.5 节 `SCALO` 状态机的设计依据。设本振与信号的频率偏差为 $\Delta f$，则相位差按

$$
\phi(t) = 2\pi\,\Delta f\,t + \phi_0
$$

线性增长，其斜率即正比于频率偏差：

$$
\Delta f = \frac{1}{2\pi}\frac{d\phi}{dt}
$$

因此只须测量相位的平均变化率，即可推算出应补偿的本振频率。该式是 `SCALO` 自校准算法的理论依据，其硬件实现以相位差分配合滑动窗平均完成。需注意差分运算会放大高频噪声（见 2.1.4 节关于微分项的讨论），故平均环节是必需的而非可选的。

**两类应用的理论对照。** 至此可以总结 PDH 与双梳锁定在理论层面的差异：

| 方面 | PDH 稳频 | 双光梳锁定 |
|------|---------|-----------|
| 被控物理量 | 激光频率 | 梳参量差频的相位 |
| 误差信号来源 | 相位调制 + 同步解调 | 拍频 + 相位解算 |
| 误差信号性质 | 幅度量，共振点反对称过零 | 相位量，具 $2\pi$ 周期性 |
| 捕获前的未知量 | 共振位置（线宽量级的窄窗口） | 拍频频率 |
| 主要理论约束 | 鉴频斜率与线宽成反比 | 相位周期性与差分噪声放大 |
| 对应平台模块 | 混频器、PID | CORDIC 向量模式、解卷绕器、PID |

二者共用 PID 控制器与第 2.1 节的全部控制理论，差异集中在误差信号的提取环节。这一对照说明了平台分层的合理性：**物理差异被局限在信号提取与应用层状态机，而控制层与互联层可以完全共用。**

本文的研究内容可概括为：**构建一个以运行时拓扑可重构为核心特征的 FPGA 微纳光学控制平台，并以两类实验应用验证其通用性。**

### 1.4.1 平台架构与设计方法

本文将运算模块集合与模块间连接关系分离：模块实例在综合时确定，既有模块的连接由运行时寄存器配置。第二章给出具体架构与实现。

依此原则，平台在纵向上划分为应用层、运算层、互联层与接口层四层，层间以明确接口衔接，以降低模块变更对其他层的影响。支撑该结构的三项机制分别是：统一的模块设计范式（三段式结构、可配置 IO 缓冲、自动复位契约）、总线契约（二级寻址、分层命令编码、影子寄存器原子更新）与全交叉路由矩阵。平台的核心抽象是**数据流图**——它与实验者的物理直觉同构，与流水线实现相容，且使环路延迟可加，从而让第二章 2.1.5 节的带宽约束可直接用于指导拓扑设计。

### 1.4.2 硬件平台与运算模块

本文以 Xilinx Kintex UltraScale 系列 FPGA（KU060）为核心搭建硬件平台 `[具体器件型号与速度等级待补充]`。系统数据通路采用 16 位定点表示，整数范围为 $-32768$ 至 $32767$；系统工作时钟为 250 MHz，即单个时钟周期为 4 ns，这一时钟频率同时决定了流水线延迟的时间粒度与数字滤波器的采样率。高速射频链路由 AD9680 ADC、AD9152 DAC 与 AD9528 时钟分发器件构成（第二章）。

在互联层之上，本文实现了一组 VHDL 信号处理模块（第二章），主要包括：

- **PID 控制器**：并行（位置）型结构，具备可编程的积分限幅抗饱和、可编程泄漏积分以及输出限幅；为在高时钟频率下闭合长位宽积分路径的时序，积分支路采用半速率交织处理。
- **相位累加器（DDS）**：64 位相位累加器，取高 16 位作为相位输出，配合三角函数模块构成数控振荡器；内部另集成比例–积分环路滤波器，可直接用于相位跟踪。
- **CORDIC 三角函数与反三角函数**：分别工作于旋转模式与向量模式，提供正弦/余弦生成与四象限反正切（atan2）解算，19 级迭代，内部 24 位精度。
- **FIR 滤波器**：64 抽头直接型结构，系数 24 位定点，可在运行时重新加载；支持 16/32/64 抽头长度切换并自动调整归一化因子。
- **IIR 滤波器**：四阶，采用两节双二次（biquad）并联结构，并对每节施加四阶散射超前变换，以打破递归反馈对时钟频率的制约。
- **混频器、线性变换器、缩放器、相位解卷绕器**等辅助模块，分别用于解调、双路线性组合、输出调理与相位连续化。

这些模块均遵循统一范式，因而可被不同应用以统一方式复用。

### 1.4.3 两类实验应用的实现与平台通用性验证

平台的复用能力需结合不同应用的实现与实验结果评价。本文实现两类应用的控制逻辑，并在第五章给出相应验证方案。

**激光 PDH 锁定。** 如 1.1.3 节所述，PDH 的窄捕获范围要求主动扫描与快速捕获判断。本文将这一流程下沉为八态硬件状态机，其中 `AUTO_AMP` 与 `AUTO_TIME` 两态构成自动参数标定环节：前者在一个扫描周期内追踪信号极值，后者测量过阈时长，据此按

$$
V_{th} = V_{min} + c\,(V_{max} - V_{min})
$$

导出相对阈值。该方案的关键优势是**减轻信号幅度变化对固定阈值的影响**——激光功率漂移、耦合效率变化、探测器增益差异均会改变误差信号的绝对幅度，固定阈值方案需频繁重新标定，而相对阈值仅依赖峰峰值比例。状态转移同时控制扫描斜坡保持与 PID 复位解除，具体交接延迟需由时序仿真确认。

**双光梳自校准本振锁定。** 该应用的被控量是相位而非幅度，其未知参量是拍频频率而非共振位置。`SCALO` 状态机以相位差分推算频率偏差 $\Delta f = \frac{1}{2\pi}\frac{d\phi}{dt}$，经 256 级滑动窗平均抑制差分噪声，将结果补偿进本振相位增量后再释放 PID。

两类应用在物理场景、信号类型与自动化策略上均不相同，却共用同一套运算层与互联层，未为任一应用增加专用运算模块。这一实现为平台通用性提供了结构层面的案例；跨应用运行效果仍需第五章的实验验证。

### 1.4.4 上位机软件与智能体辅助设计

硬件的可重构性只有在易用的配置手段支持下才能转化为实际效率。本文为此设计了分层的 Python 上位机软件（第三章）：驱动层、协议层、硬件抽象层与应用层四层结构，其中硬件抽象层完成寄存器整数值与物理量（频率、增益、转折频率）的双向换算，使实验脚本可直接以物理量表达意图。应用层实现了一个可视化节点编辑器，用户以拖放方式实例化模块、以连线方式建立数据通路；每一次连线操作都被翻译为路由矩阵的寄存器写入，从而在界面操作与硬件拓扑之间建立直接对应，并以四类信号类型的设计期检查将一类物理含义错误前移至连线阶段。

## 2.1 数字控制理论与设计约束

### 2.1.1 离散时间控制系统的稳定性分析

数字伺服对误差信号以采样周期 $T$（采样率 $f_{s} = 1/T$）等间隔采样。设采样序列为 $x[n] = x(nT)$，其 $Z$ 变换定义为

$$
X(z) = \mathcal{Z}\{x[n]\} = \sum_{n=-\infty}^{\infty} x[n]\,z^{-n}
$$

$Z$ 变换将差分方程转化为代数方程，其中 $z^{-1}$ 对应一个采样周期的延迟，即 $\mathcal{Z}\{x[n-k]\} = z^{-k}X(z)$。离散系统的传递函数定义为输出与输入 $Z$ 变换之比 $H(z) = Y(z)/X(z)$，而频率响应由单位圆上的取值给出：

$$
H\!\left(e^{j\omega T}\right),\qquad \omega \in \left[0,\ \pi/T\right]
$$

上限 $\omega = \pi/T$ 即 Nyquist 频率 $f_{s}/2$。这一有限的频率范围是数字系统的根本限制：高于 Nyquist 频率的噪声成分会被折叠（混叠）到带内，因此 ADC 之前必须配置模拟抗混叠滤波器。

连续域与离散域在稳定性判据上存在对应关系。连续系统稳定要求极点位于左半 $s$ 平面；由映射 $z = e^{sT}$ 可知，左半平面被映射到 $z$ 平面的**单位圆内部**，虚轴映射为单位圆。因此离散时间系统的稳定条件为：$H(z)$ 的全部极点满足 $|z| < 1$。

这一映射是多值的：$s$ 与 $s + j2\pi k/T$ 映射到同一点，这正是混叠在变换层面的体现。实用的离散化方法是对该映射作有理近似。常用的三种方法为：

- **前向差分（显式 Euler）**：$s \to (z-1)/T$。实现简单，但会把左半平面的一部分映射到单位圆外，可能使稳定的连续系统离散化后不稳定。
- **后向差分（隐式 Euler）**：$s \to (z-1)/(Tz)$。保证稳定系统离散化后仍稳定，但频率响应在高频处有明显畸变。
- **双线性变换（Tustin 变换）**：

$$
s \to \frac{2}{T}\,\frac{z-1}{z+1},\qquad \text{逆变换}\quad z = \frac{1 + sT/2}{1 - sT/2}
$$

双线性变换把整个左半 $s$ 平面一对一地映射到单位圆内部，故严格保持稳定性，且不引入混叠。其代价是频率轴的非线性压缩（频率弯折）：

$$
\omega_{d} = \frac{2}{T}\arctan\left(\frac{\omega_{a}T}{2}\right)
$$

其中 $\omega_a$ 与 $\omega_d$ 分别为模拟与数字频率。当需要某一特征频率（如滤波器转折频率或 PI 转折点）精确落在设计值上时，可对该频率作预弯折补偿。在 $\omega T \ll 1$ 的低频区，三种方法趋于一致。

离散系统的相对稳定性仍以 Bode 与 Nyquist 判据评价。对开环传递函数 $G(z)$，Nyquist 曲线为 $G(e^{j\omega T})$ 在 $\omega$ 从 $0$ 变到 $\pi/T$ 时在复平面上的轨迹；对开环稳定的系统，闭环稳定要求该轨迹不包围 $-1$ 点。工程上更常用 Bode 图上的两个裕度：**增益裕度**为相位穿越 $-180^{\circ}$ 时开环增益距 $0\ \mathrm{dB}$ 的余量；**相位裕度** $\varphi_{m}$ 为开环增益穿越 $0\ \mathrm{dB}$（单位增益带宽 $f_{\mathrm{UGF}}$）时相位距 $-180^{\circ}$ 的余量。激光伺服中通常要求 $\varphi_{m}$ 不低于 $30^{\circ}\sim45^{\circ}$，以避免在单位增益带宽附近出现明显的噪声增益峰（即伺服鼓包，servo bump）。

### 2.1.2 数字滤波器的设计与延迟分析

数字滤波器在伺服系统中承担两类任务：解调后滤除 $\Omega$ 及其谐波分量，以及对环路进行频率整形（如陷波抑制执行器的机械共振）。两类结构各有取舍。

**FIR 滤波器**。$N$ 抽头有限冲激响应滤波器的差分方程与传递函数为

$$
y[n] = \sum_{k=0}^{N-1} b_{k}\,x[n-k],\qquad H(z) = \sum_{k=0}^{N-1} b_{k}z^{-k}
$$

其极点全部位于原点，故**无条件稳定**，不存在系数量化导致失稳的风险；若系数满足对称性 $b_{k} = b_{N-1-k}$，则相位严格线性，群延迟为常数 $(N-1)T/2$。FIR 的代价是：要获得陡峭的过渡带需要很多抽头，而抽头数直接转化为乘法器数量与群延迟。本文实现的 FIR 为 64 抽头、系数 24 位定点，采用直接型结构配合平衡加法树；由于不利用系数对称性，它需要 64 个并行乘法器，但换来了较短的加法树深度与对任意（含非对称）冲激响应的支持。该模块支持 16/32/64 抽头长度切换，并对不同长度施加不同的归一化因子以保持冲激响应的 $L_1$ 范数一致。其内部流水线延迟为 6 个时钟周期。

**IIR 滤波器**。无限冲激响应滤波器的差分方程与传递函数为

$$
y[n] = \sum_{k=0}^{M} b_{k}x[n-k] - \sum_{k=1}^{N} a_{k}y[n-k],\qquad H(z) = \frac{\sum_{k=0}^{M}b_{k}z^{-k}}{1 + \sum_{k=1}^{N}a_{k}z^{-k}}
$$

IIR 以远少于 FIR 的阶数实现同等陡峭的幅频响应，因而延迟小、资源省，是伺服整形的首选。但它存在反馈，需关注三个问题：极点必须严格位于单位圆内；系数量化会移动极点位置，在高阶直接型结构中尤为敏感，故实际实现应分解为低阶（通常为二阶双二次）节的级联或并联；内部累加需有足够位宽与饱和处理以避免溢出与极限环振荡。

IIR 在高速 FPGA 实现中还面临一个结构性障碍：反馈路径构成递归依赖，$y[n]$ 必须在下一个采样时刻之前算完，于是乘法与加法的组合逻辑延迟直接限制了最高时钟频率。**散射超前变换（scattered look-ahead）** 是解决这一矛盾的经典方法：通过给传递函数的分子分母同乘一个适当的多项式，使分母中只保留 $z^{-M}$ 的若干次幂项，从而把递归依赖的跨度由 1 个采样周期拉长到 $M$ 个采样周期，为反馈乘法器留出 $M$ 个时钟周期的流水线空间，代价是分子系数数量增加。本文实现的四阶 IIR 即采用两节双二次并联结构，并对每节施加四阶散射超前变换：原始四阶传递函数先经部分分式分解拆为两节，每节再经散射变换后仅保留两个反馈系数，使 $250\ \mathrm{MHz}$ 下的时序闭合成为可能。系数采用 Q3.24（分子）与 Q2.25（分母）格式，内部状态为 30 位 Q4.26，输出级设有显式饱和。

**延迟是数字伺服的核心代价**。任何数字滤波器都引入群延迟，而伺服环路中的总延迟 $\tau$ 还包括 ADC 的转换与流水线延迟、模块间路由的寄存器级、以及 DAC 的建立时间。对于采样保持过程，其等效延迟约为 $T/2$。这些延迟相加后，在频域中表现为一个纯延迟环节 $e^{-j\omega\tau}$，其幅度恒为 1 而相位线性下降。这正是 2.1.5 节将定量讨论的、限制环路带宽的首要因素。因此，滤波器的选择必须在频率选择性与群延迟之间权衡：用于解调后抑制载波泄漏时，通带外衰减是主要诉求；而用于环路整形时，应优先选用低阶 IIR 并尽量减少级联深度。

### 2.1.3 CORDIC 算法及其在数字混频与相位解算中的应用

数字伺服需要在芯片内生成调制与解调所用的正交本振，并在相位检测类应用中由正交分量反解相位角。直接查表（ROM 查找）会消耗大量存储资源且精度受表深度限制，而多项式逼近需要多个乘法器。CORDIC（Coordinate Rotation Digital Computer）算法仅用移位与加法即可完成这两类运算，是 FPGA 实现的标准方案。

**算法原理**。CORDIC 的核心是把任意角度的旋转分解为一系列固定角度的微旋转。平面向量旋转 $\theta$ 角的变换为

$$
\begin{bmatrix} x' \\ y' \end{bmatrix} = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}\begin{bmatrix} x \\ y \end{bmatrix}
$$

提出 $\cos\theta$ 并限定 $\tan\theta_{i} = 2^{-i}$，则该矩阵中的乘法退化为移位。第 $i$ 次迭代写为

$$
\begin{aligned}
x_{i+1} &= x_{i} - d_{i}\,y_{i}\,2^{-i} \\
y_{i+1} &= y_{i} + d_{i}\,x_{i}\,2^{-i} \\
z_{i+1} &= z_{i} - d_{i}\arctan\left(2^{-i}\right)
\end{aligned}
$$

其中 $d_{i} \in \{+1,-1\}$ 为旋转方向，$z$ 为剩余角度，$\arctan(2^{-i})$ 预存于常数表中。省略的 $\cos\theta_i$ 因子使向量模长在每次迭代中放大 $\sqrt{1 + 2^{-2i}}$ 倍，$n$ 次迭代后累积增益为

$$
K_{n} = \prod_{i=0}^{n-1}\sqrt{1 + 2^{-2i}},\qquad K_{\infty} \approx 1.64676,\qquad 1/K_{\infty} \approx 0.60725
$$

该增益为与输入无关的常数，故可以通过把 $1/K_n$ 预乘到初始向量中来补偿，无需任何额外乘法器。

**两种工作模式**。CORDIC 的两种模式仅在 $d_i$ 的判决依据上不同，却对应完全不同的功能。

- **旋转模式**：取 $d_{i} = \mathrm{sign}(z_{i})$，迭代驱使剩余角 $z \to 0$。若初始化 $x_{0} = 1/K_{n}$、$y_{0} = 0$、$z_{0} = \theta$，则收敛后 $x_{n} \to \cos\theta$、$y_{n} \to \sin\theta$，即实现正弦余弦发生。
- **向量模式**：取 $d_{i} = -\mathrm{sign}(y_{i})$，迭代驱使 $y \to 0$。若初始化 $x_{0} = x$、$y_{0} = y$、$z_{0} = 0$，则收敛后 $x_{n} \to K_{n}\sqrt{x^{2}+y^{2}}$、$z_{n} \to \arctan(y/x)$，即同时实现模值与相角解算。

每次迭代约可确定结果的 1 位有效精度，故迭代次数与所需位宽大致相当。基本迭代式的收敛域为 $|\theta| \lesssim 99.9^{\circ}$，不覆盖全圆，因此需要象限预处理：先把输入折叠到第一、四象限，记录象限信息，迭代完成后再作相应的符号翻转或 $\pi$ 偏置。

**本文的实现与设计取舍**。本文实现了一对结构高度一致的 CORDIC 模块：正向模块工作于旋转模式，由相位生成正弦与余弦；反向模块工作于向量模式，由正交分量计算四象限反正切（atan2）。二者均采用 19 级迭代、24 位内部精度、16 位输入输出，增益以预缩放初始向量的方式补偿。两者在源码上的唯一本质差别即旋转方向的判决依据（取自剩余角符号还是取自 $y$ 分量符号），这正是旋转模式与向量模式关系的直接体现。

实现中有两点值得强调。第一，为满足 250 MHz 时序而又不让流水线深度等于迭代次数，设计令剩余角 $z$ 的计算超前一级，使 $x$、$y$ 的更新不被 $z$ 的关键路径阻塞，从而可以每两级迭代只插入一级寄存器，19 级迭代的内部延迟压缩为 10 个寄存器级（含首级的一级与隔级插入的九级），计入输入输出缓冲后模块总延迟为 12 个时钟周期，详见 2.6.2 节。第二，象限处理被简化为对输入高两位的一次异或与输出端的条件取负，无需额外迭代。

**统一的相位编码**。贯穿本文全部相位相关模块的一项基础约定是：16 位有符号整数表示整个 $2\pi$ 区间，即 $\mathrm{0x8000}$ 对应 $\pm\pi$，相位的最低有效位为 $2\pi/65536$。这一编码使相位的模 $2\pi$ 运算与二进制补码的自然溢出完全等价，由此带来三项便利：数控振荡器的相位累加器无需取模运算；CORDIC 的范围归约退化为一次符号判断；相位解卷绕无需显式的 $2\pi$ 常数。

**数字混频与相位解卷绕**。基于上述模块，数字域的解调由一个全精度乘法器完成：$16\times16$ 位相乘得到 32 位全精度积，取高 16 位作为输出，对应 Q1.15 定点格式的乘法约定；低通滤波由后续独立的 FIR 或 IIR 模块承担，使"混频—滤波"的组合可按需配置。相位解卷绕模块则利用上述编码的性质：直接对相邻两个包裹相位作 16 位补码减法，只要真实相位步进不超过 $\pi$，所得差值自动等于最短路径增量；将该增量符号扩展后累加，即得到连续的相位轨迹。本文实现中累加器位宽为 17 位，并在接近饱和时作限幅而非回绕，以避免计数翻转造成的突变。

### 2.1.4 PID 控制算法及其数字化实现

PDH 稳频环路的整形通常以 PID 控制器为核心。连续域的理想 PID 控制器为

$$
u(t) = K_{p}\,e(t) + K_{i}\int_{0}^{t} e(\tau)\,\mathrm{d}\tau + K_{d}\,\frac{\mathrm{d}e(t)}{\mathrm{d}t}
$$

其传递函数为

$$
C(s) = K_{p} + \frac{K_{i}}{s} + K_{d}s = K_{p}\left(1 + \frac{\omega_{i}}{s} + \frac{s}{\omega_{d}}\right)
$$

三项的作用在频域中界限分明。积分项在低频提供理论上无限大的增益，从而消除稳态误差、抑制慢漂移，其代价是引入 $-90^{\circ}$ 的相移；比例项在中频段提供平坦增益，不引入相移，直接决定单位增益带宽的位置；微分项在高频提供 $+90^{\circ}$ 的相位超前，可用于补偿执行器的极点。积分转折频率 $\omega_{i} = K_{i}/K_{p}$ 以下由积分主导，微分转折频率 $\omega_{d} = K_{p}/K_{d}$ 以上由微分主导。实际系统中微分项必须加以带限（即用 $K_ds/(1+s/\omega_{\mathrm{lp}})$ 代替 $K_ds$），否则会无界地放大高频噪声。

**离散化**。对 $C(s)$ 应用 2.1.1 节的变换即得数字 PID。采用后向差分离散积分、前向差分离散微分，可得最常用的位置型（并行型）差分方程

$$
u[n] = K_{p}e[n] + K_{i}T\sum_{k=0}^{n}e[k] + \frac{K_{d}}{T}\left(e[n] - e[n-1]\right)
$$

记积分状态 $I[n] = I[n-1] + K_{i}T\,e[n]$，则实现为递推形式

$$
u[n] = K_{p}\,e[n] + I[n] + \frac{K_{d}}{T}\left(e[n]-e[n-1]\right),\qquad I[n] = I[n-1] + K_{i}T\,e[n]
$$

若改用双线性变换离散积分项，则 $I[n] = I[n-1] + \tfrac{K_{i}T}{2}\left(e[n]+e[n-1]\right)$，即梯形积分，其相位特性在接近 Nyquist 频率处更接近连续域，但需多保存一个状态。另一种常见形式是增量型（速度型）

$$
\Delta u[n] = u[n]-u[n-1] = K_{p}\Delta e[n] + K_{i}T\,e[n] + \frac{K_{d}}{T}\left(\Delta e[n]-\Delta e[n-1]\right)
$$

增量型便于与带记忆的执行器配合且天然不易饱和，但不便于施加绝对输出限幅。本文采用位置型并行结构，以便对积分状态与输出分别施加独立的限幅。

**定点实现的关键问题**。在 FPGA 上以定点算术实现上式，需处理若干在连续域中不存在的问题。

*增益的定标*。三路增益以定点整数表示，乘积通过固定的移位（取位切片）对齐到输出格式。由于积分支路的乘积在累加前还要再右移，其增益系数应给予更多位宽以保持有效精度。本文实现中比例与微分增益为 24 位、积分增益为 32 位，各支路乘积分别以固定移位量对齐。一个有用的定标参照是：当比例与积分增益取相同数值时，PI 转折频率为 $f_{i} = f_{s}/(2\pi\cdot 65536)$，在 250 MHz 时钟下约为 600 Hz。

*积分饱和与抗饱和*。当误差长期同号（例如尚未捕获共振，或执行器已到行程末端）时，积分状态会持续增长至溢出，其后即便误差反号也需很长时间才能退出饱和，表现为严重的滞后甚至失控。标准对策是积分限幅（clamping）：把积分状态约束在一个可编程的对称范围内，并在反馈路径中施加该限幅，使状态本身永不越界。本文即采用这一方案，并额外对输出求和结果设置独立的可编程限幅。

*泄漏积分*。纯积分器在开环时会无限累积任意微小的偏置。引入泄漏项 $I[n] = \lambda I[n-1] + K_{i}T e[n]$（$\lambda$ 略小于 1）可使积分器具有有限的直流增益，把低频极点从原点移入单位圆内，从而避免长期累积，代价是不再具备严格的零稳态误差。由于除法在 FPGA 上代价高昂，本文以"按位选择的移位和"实现泄漏量，即泄漏率由若干 2 的负整数次幂之和构成，由一个掩码寄存器选择。

*微分项的噪声*。一阶差分的频响为 $\left(1-z^{-1}\right)/T$，其幅度随频率单调上升至 Nyquist 频率，对量化噪声与宽带噪声有显著放大作用。因此微分项应配合低通滤波使用；本文的 PID 内核采用未经滤波的原始一阶差分，必要的带限由路由矩阵在其前级或后级串入 FIR/IIR 模块实现——这正是可重构架构带来的灵活性。另需注意，本文实现中微分支路取自设定点减除之前的原始误差，对于恒定设定点而言与标准形式等价，且可避免设定点跳变时产生微分冲击。

*高频下的时序约束*。积分支路的关键路径包含一个宽位累加器及泄漏项的减法，在 250 MHz 下难以单周期闭合。本文采用半速率交织处理：积分支路每两个时钟周期更新一次，等效于把积分运算的采样率降为 125 MHz，而比例与微分支路仍以全速率运行。这一取舍的理由在于积分项主要作用于远低于 Nyquist 频率的低频段，降半采样率对其频响的影响可忽略；而比例支路决定单位增益带宽，必须保持最低延迟。

### 2.1.5 环路延迟、相位裕度与控制带宽

伺服环路的开环传递函数可写为

$$
G(s) = C(s)\,A(s)\,P(s)\,e^{-s\tau}
$$

其中 $C$ 为控制器，$A$ 为执行器（PZT 或激光电流）传递函数，$P$ 为鉴频器与探测通道增益（含 $D$），$e^{-s\tau}$ 为环路纯延迟。

纯延迟环节的幅度恒为 1，但贡献随频率线性增长的相位滞后

$$
\Delta\phi(\omega) = -\omega\tau = -2\pi f\tau
$$

这是数字伺服最重要的约束。设理想 PI 控制器在穿越频率处已贡献约 $-90^{\circ}$ 相移，为保留相位裕度 $\varphi_{m}$，延迟允许贡献的相移上限为 $90^{\circ}-\varphi_{m}$，于是单位增益带宽满足

$$
2\pi f_{\mathrm{UGF}}\,\tau \le \frac{\pi}{2} - \varphi_{m}
\quad\Longrightarrow\quad
f_{\mathrm{UGF}} \le \frac{1}{2\pi\tau}\left(\frac{\pi}{2}-\varphi_{m}\right)
$$

其中 $\varphi_m$ 以弧度计。两个有代表性的结论是：若不要求任何裕度（$\varphi_m = 0$），则 $f_{\mathrm{UGF}} \le 1/(4\tau)$；若要求 $\varphi_{m} = 45^{\circ}$，则 $f_{\mathrm{UGF}} \le 1/(8\tau)$。可见**可达带宽与总延迟成反比**，且与裕度要求成线性折减关系。若环路中还存在执行器极点或抗混叠滤波器的附加相移，则上述上限会进一步收紧。

该式为数字伺服的工程设计给出了明确的量化目标：总延迟 $\tau$ 是必须在系统层面逐项核算并压缩的预算，包括模拟前端与抗混叠滤波器的群延迟、ADC 转换与输出流水线延迟、采样保持的等效 $T/2$、FPGA 内部各模块的流水线级数与路由矩阵的寄存器级、DAC 的建立时间，以及执行器驱动电路的响应时间。本文把系统时钟设置在 250 MHz（单周期 4 ns）、在关键支路选择性地去除输入输出缓冲寄存器、以及在 CORDIC 与 IIR 中采用超前技术压缩流水线级数，其共同动机都是压缩这一预算中的数字部分。各模块的流水线延迟见第 4.4 节，环路总延迟的实测结果与由此推算的带宽上限将在第 3.1 节给出。

### 2.1.6 噪声抑制比与伺服鼓包

闭合环路后，输入频率噪声被抑制的程度由灵敏度函数给出。设自由运转激光的频率噪声为 $\delta\nu_{\mathrm{free}}$，则闭环后的残余噪声为

$$
\delta\nu_{\mathrm{res}}(f) = \frac{\delta\nu_{\mathrm{free}}(f)}{1 + G(f)}
$$

相应地，噪声抑制比（误差抑制因子）为

$$
\mathrm{NSR}(f) = \left|1 + G(f)\right| \approx \left|G(f)\right| \quad (\left|G\right| \gg 1)
$$

以功率谱密度表示则为 $S_{\nu}^{\mathrm{res}}(f) = S_{\nu}^{\mathrm{free}}(f)/\left|1+G(f)\right|^{2}$。

这一关系揭示了三条设计原则。

第一，**抑制比直接等于开环增益**。要在某一频率上把噪声压低 $40\ \mathrm{dB}$，就必须在该频率上具备 $40\ \mathrm{dB}$ 的开环增益。由于 PI 控制器的增益以 $-20\ \mathrm{dB/dec}$ 的斜率从单位增益带宽向低频上升，低频处的抑制能力由 $f_{\mathrm{UGF}}$ 与该频率的间距决定：$f_{\mathrm{UGF}}$ 每提高十倍，低频抑制比即改善 $20\ \mathrm{dB}$。换言之，**带宽是低频稳定度的前提**，而 2.1.5 节已表明带宽由延迟决定。这构成了从"压缩延迟"到"提升稳定度"的完整逻辑链条，也是本文在架构上追求低延迟的根本理由。

第二，**存在不可避免的噪声增益区**。当 $\left|1+G\right| < 1$ 时，环路实际上放大了噪声。由 Bode 积分定理可知，对于稳定且满足一定条件的系统，灵敏度函数对数的积分受到约束，低频处的抑制必然以某些频段的放大为代价。在实践中这表现为单位增益带宽附近的一个噪声峰，即**伺服鼓包**。鼓包的高度由该处的相位裕度决定：裕度越小，$1+G$ 在 $-1$ 点附近越小，峰越高越尖。因此一味提高增益以追求带宽，会在鼓包处制造新的噪声成分，反而可能恶化激光线宽与原子探询的效果。合理的做法是在"低频抑制—鼓包高度—稳定余量"之间取折中，并在必要时对误差信号作陷波整形。

第三，**量化噪声与执行器噪声构成本底**。环路只能抑制环路之外引入的噪声，而伺服链路自身注入的噪声（ADC 量化噪声、DAC 量化与输出噪声、执行器驱动噪声）会被完整地写入激光频率，且不因增益提高而减小——提高增益只会使其更忠实地复制到输出。因此数字伺服的噪声本底由转换器位宽、参考电压噪声与定点运算的位宽设计共同决定。本文采用 16 位数据通路并在各运算模块内部保留显著更高的中间位宽（CORDIC 为 24 位、IIR 内部状态为 30 位、PID 积分状态为 48 位），其目的正是把运算过程引入的量化误差压低到远小于转换器本底的水平。

还需注意定点运算中舍入策略的系统性影响。本文多数模块采用截断取高位，截断会引入约半个最低有效位的负向直流偏置；少数对偏置敏感的位置（CORDIC 输出、PID 积分输入、缩放器输出）采用了四舍五入处理。在直流偏置直接等效为鉴频零点偏移的 PDH 系统中，这类偏置应作为误差预算的一项加以核算。

## 2.2 平台分层与数据流架构

### 2.2.1 从专用系统到通用平台

针对单一实验的专用 RTL 设计可将运算模块直接连接为固定信号链，并按目标应用配置资源。

固定连接的设计在改变模块顺序或添加处理环节时通常需要修改 RTL 并重新综合。对于需要比较多种控制拓扑的实验，这增加了配置迭代的时间成本。

据此，平台将运算模块集合与模块间连接关系分离：前者在综合时确定，后者由运行时寄存器配置。形式化地说，若记平台固化的模块集合为 $\mathcal{M}$，模块间的连接关系为映射 $\sigma$，则传统专用设计中二者绑定为单一实现：

$$
\text{专用设计}: \quad (\mathcal{M}, \sigma) \xrightarrow{\text{综合}} \text{比特流}
$$

而本平台将其解耦：

$$
\text{平台设计}: \quad \mathcal{M} \xrightarrow{\text{综合}} \text{比特流}, \qquad \sigma \xrightarrow{\text{寄存器写入}} \text{运行时可变}
$$

该结构使既有模块间的连接成为运行时可配置参数。同一比特流因而具备表达多种拓扑的条件，但未使用的模块仍占据硬件资源，互联网络也增加选择逻辑。资源代价见第 2.5.3 节。

### 2.2.2 四层结构

依据运算单元与连接关系分离的原则，平台划分为应用层、运算层、互联层和接口层。应用层实现实验流程，运算层完成定点信号处理，互联层配置模块间连接，接口层负责参数下发与器件初始化。

分层降低了模块间的直接依赖。新增实验状态机或运算模块时，需要完成相应逻辑设计、接口接入和重新综合；已有模块之间的拓扑调整则可通过路由配置完成。

本章的四层结构描述 FPGA 侧的功能组织；第三章的四层结构描述上位机软件。两者通过命令帧和寄存器操作相连接。

### 2.2.3 以数据流为中心的抽象

平台以数据流图描述信号处理过程：运算模块对应节点，模块连接对应有向边。该抽象与物理信号链、流水线实现及延迟分析具有直接对应关系。

首先，数据流图能够表示从探测器、解调器、控制器到执行器的信号传递关系。第三章的画布拓扑据此映射到硬件配置。

其次，各运算模块可以独立选择内部流水级数，但相邻模块的采样时序仍须满足接口约定。

最后，在固定采样路径上，可将模块延迟与路由延迟相加，得到反馈环路数字部分的估计延迟。该估计可用于初步评估带宽约束，准确数值仍需测量。

该抽象的边界也需明确：数据流图不直接表达**反馈**。闭环路径在图上表现为一个环，其延迟不可简单相加，稳定性须按 2.1 节的方法分析。平台不阻止用户建立反馈环（反馈正是控制系统的本质），但也不自动验证其稳定性——这是实验者的责任。

## 2.3 板卡、转换器与时钟架构

### 2.3.1 设计约束与方案选择

全数字 PDH 锁定系统的硬件设计受三项基本约束支配。

其一是**环路延迟约束**。如 2.1.5 节所述，闭环系统的相位裕度直接受环路延迟 $\tau$ 制约，附加相移为 $\Delta\phi = -\omega\tau$。数字系统的延迟来自 ADC 转换、FPGA 内部流水线、DAC 建立三个环节，其中 FPGA 内部处理延迟与时钟频率成反比。因此系统时钟频率应尽可能高，且信号处理链路的流水线级数应尽可能少。

其二是**量化噪声约束**。误差信号的检测精度受 ADC 有效位数限制。理想 $N$ 位量化器的信噪比上限为

$$
\mathrm{SNR}_{\max} = 6.02N + 1.76 \ \mathrm{dB}
$$

该式给出噪声本底的理论下界，实际系统还需考虑孔径抖动、参考电压噪声与 FPGA 内部定点截断的贡献。

其三是**可重构性约束**。实验平台需要在不重新综合布线的前提下改变信号处理拓扑，这要求 FPGA 内部预先实例化全部功能模块，并通过可配置的互联网络连接，而非按固定链路硬连线。这一约束直接导出了第二章 2.5 节的信号路由矩阵设计。

基于上述约束，系统选用 Xilinx Kintex UltraScale 系列 FPGA 作为主控单元，以承载多路并行的定点信号处理链路。系统时钟频率设定为 250 MHz。

系统内部数据通路统一采用 16 位有符号定点格式，并以数组类型组织多路信号。

该类型用于信号路由矩阵的输入输出端口以及顶层接口，是全系统信号互联的统一载体。16 位宽度与所选 ADC/DAC 的分辨率相匹配，在动态范围与资源占用之间取得折衷。

### 2.3.2 板卡与时钟架构

平台通过载板适配层支持 PZ-KU060-FHT、KU060 定制板和通用载板。适配层处理时钟、引脚及外设差异，运算模块共用相同的片内接口。顶层功能逻辑主要位于单一系统时钟域，多时钟生成与参考源选择由载板适配层负责。

MMCM 的输入参考时钟频率为 200 MHz，相应时钟周期约束为 5 ns。

MMCM 输出 250 MHz 系统主时钟与 125 MHz DAC 时钟。其余两路 250 MHz 和 500 MHz 时钟已接入缓冲器，但在当前设计中未用于下游功能模块。

各时钟缓冲器由 MMCM 锁定状态控制，在时钟未稳定时抑制输出。参考源切换控制器与按键去抖模块位于 MMCM 之前的时钟域，避免切换过程中丢失控制逻辑的时序基准。

### 2.3.3 模数/数模转换架构

系统通过 FMC 接口接入 ADC、DAC 及组合式转换子卡。各子卡适配器负责引脚映射、时钟转接和必要的跨时钟域缓冲，并向片内逻辑提供统一的数据接口。已实现的适配器覆盖多个 ADC 与 DAC 子卡型号；其分辨率、采样率及有效位数应分别依据器件资料和板级测量结果确认，不能由 HDL 端口位宽直接推断。

高速射频转换链路的核心器件由 `python control/chips.py` 中的 SPI 初始化例程配置，包括：

- **AD9680**——高速 ADC，初始化函数 `init_AD9680(spi, port, chip)`，配置完成后读取寄存器 `0x056F` 校验锁定状态，未锁定则抛出异常；
- **AD9152**——高速 DAC，初始化函数 `init_AD9152(spi, port, chip)`，校验寄存器 `0x0281`；
- **AD9528**——时钟分发与抖动清理 PLL，初始化函数 `init_AD9528(spi, port, chip)`，校验寄存器 `0x0508`，并可检测外部参考是否存在。

器件初始化序列以查找表形式固化在 FPGA 中，由 SPI 任务序列器在上电后执行。状态查询序列周期性读取关键寄存器，并将查询结果用于面板状态指示。

时钟分发器件 AD9528 的抖动性能直接影响 ADC 的有效位数。采样时钟的抖动 $\sigma_t$ 在输入信号频率 $f_{in}$ 处引入的信噪比上限为

$$
\mathrm{SNR}_{\mathrm{jitter}} = -20\log_{10}(2\pi f_{in}\sigma_t)
$$

当该项与量化噪声可比时，将成为系统噪声本底的主导因素。

AD9528 的时钟抖动及其对 ADC 有效位数的影响尚缺少测量依据，需结合器件资料和相位噪声测试结果评估。

## 2.4 通信接口与模块契约

系统的接口设计分为三个层次：上位机与 FPGA 之间的 UART 链路、FPGA 片内连接各功能模块的自定义总线、以及 FPGA 对板上射频器件的 SPI 配置接口。三者构成从 Python 脚本到器件寄存器的完整控制通路。

### 2.4.1 上位机通信链路

上位机与 FPGA 之间采用 115200 波特率的 UART 串行链路。

选择 UART 而非 PCIe 或以太网作为控制链路，是基于控制与数据两类业务的分离考虑：参数配置属于低频、小数据量、强可靠性需求的业务，UART 的实现复杂度最低且时序确定；而大数据量的波形回传则由独立的以太网通路承担（`modules/waveform_storage_upload/`，含 DDR4 缓存与完整 MAC 协议栈）。两条通路互不干扰。

FPGA 侧以串行收发模块和命令解析状态机处理帧识别、字段解析、片内总线访问及响应回传。

上位机侧采用回显比对和命令应答检查。配置链路以较低吞吐量换取传输错误检测能力，具体校验流程见第 3.1 节。

### 2.4.2 板级总线协议设计

片内总线是本系统架构的核心。为使 34 个功能模块（`module_count = 34`）以统一方式接受配置，系统设计了一套自定义的并行总线协议，其主要参数如下：

| 常量 | 位宽 | 含义 |
|------|------|------|
| `dbus_w` | 32 | 数据总线宽度 |
| `abus_w` | 7 | 地址总线宽度，决定每模块参数 RAM 容量为 $2^7=128$ 字 |
| `mbus_w` | 6 | 模块选择总线宽度，最多寻址 $2^6=64$ 个模块 |
| `cbus_w` | 5 | 控制总线宽度 |
| `rdbus_w` | 32 | 响应数据总线宽度 |
| `rsbus_w` | 3 | 响应状态总线宽度 |

由地址位宽和数据位宽可得单模块参数空间上限为 $2^{7}\times32=4096$ 位。

各模块按需使用这一地址空间：PDH 状态机与 PID 控制器使用 256 位（`core_param_in : in std_logic_vector(255 downto 0)`），信号路由矩阵使用 1024 位，FIR 滤波器因需存储 64 个 24 位系数而使用全部 4096 位。

总线采用集中式主从结构，中央控制器为唯一主设备，各功能模块通过独立的总线接口接入。模块地址静态分配，路由矩阵、三角函数运算器、累加器和 PID 控制器分别对应地址 1、2、3 和 6。

地址 0 保留表示"无模块"，响应总线类型 `rdbus_type` 与 `rsbus_type` 的索引范围均为 `0 to module_count`，其中 0 号位置不对应实际模块。响应数据经 `response_mux.vhdl` 多路选择后回传主设备。

**命令编码方案**定义于 `packages/bus_protocol.vhdl`。控制总线的 5 位命令字采用分层编码：高 2 位标识命令类型，低 3 位标识具体动作。这一编码方式使从设备可先按高 2 位快速分支，再解析具体操作，降低解码逻辑深度。

| 类型头 | 编码 | 命令 | 低 3 位 | 功能 |
|--------|------|------|---------|------|
| `CONTROL_HEAD` | `00` | `SET_CORE` | `010` | 模块内核复位置 0 |
| | | `RST_CORE` | `011` | 模块内核复位置 1 |
| | | `SET_RAM` | `100` | 参数 RAM 复位置 0 |
| | | `RST_RAM` | `101` | 参数 RAM 复位置 1 |
| `WRITE_HEAD` | `01` | `WRITE` | `000` | 写入并立即生效 |
| | | `WRITE_HOLD` | `001` | 写入但暂不生效 |
| | | `WRITE_MASK` | `100` | 带掩码写入并立即生效 |
| | | `WRITE_MASK_HOLD` | `101` | 带掩码写入但暂不生效 |
| `READ_HEAD` | `10` | `READ` | `000` | 读取指定地址 |
| `MISC_HEAD` | `11` | — | — | 由各模块的总线处理器自定义 |

响应状态总线有两个取值：`ROGER`（`001`）表示命令已执行，`ERROR`（`111`）表示执行失败，错误详情经响应数据总线返回。

协议中 `HOLD` 变体的设计值得专门说明。许多模块的参数宽度超过 32 位数据总线——例如 PID 控制器的积分限幅 `limit_integral` 为 48 位，累加器的频率字 `delta` 为 64 位。若分多次写入且每次立即生效，参数将在中间状态下短暂作用于运行中的控制环路，可能造成输出跳变甚至失锁。`WRITE_HOLD` 命令将数据写入影子寄存器而不提交，待最后一条 `WRITE` 命令到达时一并生效，从而实现**多寄存器参数的原子化更新**。`module_pid_controller.vhdl` 中 `wen`（写使能）与 `wval`（写生效）两个信号的分离正是这一机制在模块侧的落地。

`WRITE_MASK` 变体用于位域级更新：同一地址内可能打包多个逻辑参数（如 PDH 状态机将 2 位的 `pc_cmd` 放在地址 0x00 的最低两位），掩码写入使上位机可只修改目标位域而不扰动同址的其他参数。该命令需占用两个总线周期，第一周期传数据、第二周期传掩码。

### 2.4.3 器件配置接口

板上射频器件（AD9680、AD9152、AD9528 等）通过 SPI 接口配置。FPGA 分别实现物理层收发与任务序列化，SPI 时钟频率设定为 1 MHz。

SPI 时钟由系统时钟经计数器分频产生。

SPI 片选地址同时编码 FMC 端口号与片上器件编号，使多个端口上的器件可以共用控制逻辑。

配置流程存在两条并行通路，分别服务于不同场景：

1. **上电自动配置**：初始化寄存器序列以查找表形式存储，由 SPI 任务控制器在复位释放后执行。时钟器件配置过程包含用于等待锁定的延时步骤；该延时方式的有效性仍需与器件时序要求核对。

2. **上位机按需配置**：由 `python control/chips.py` 中的 `init_AD9680` / `init_AD9152` / `init_AD9528` 等函数经 SPI 通路下发，并读回状态寄存器校验锁定。`python control/boards.py` 将这些函数组织为板级初始化流程。该通路用于调试阶段的参数迭代与故障诊断。

两条通路共用同一套 SPI 硬件逻辑，区别仅在于命令来源。上位机侧的 SPI 访问封装在 `python control/spi.py` 中，与 `bus.py` 并列构成硬件抽象层的两个分支，详见第三章 3.1 节。

**模块设计范式。**

平台将运算内核、总线封装和参数存储作为统一的模块组织方式；新增模块按相同接口约定接入。

### 2.4.4 三段式结构

每个模块由三个部分构成：

| 部分 | 职责 |
|------|------|
| 运算内核 | 实现定点运算及流水线 |
| 总线封装 | 解析命令并传递参数与控制信号 |
| 参数存储 | 保存配置字并支持保持提交 |

将运算逻辑、协议解析和参数存储分离，可复用总线处理机制并降低各模块的接口差异。参数存储的保持提交机制见第 2.4.9 节。

各运算内核采用统一接口，包括时钟、复位、参数向量、数据端口、控制端口及自动复位输入。

其中 `core_param_in` 是参数 RAM 的全部内容以单一向量形式送入内核——内核以切片方式取用所需字段。这一设计使参数的位域划分成为内核的内部知识，总线封装无需了解。

### 2.4.5 可配置 IO 缓冲：延迟与时序的显式权衡

模块通过 `io_buf` 参数在输入和输出缓冲之间选择四种配置。

四种配置分别为双端缓冲、仅输入缓冲、仅输出缓冲及无缓冲，均通过条件生成逻辑实现。

该缓冲配置需结合第 2.1.5 节的延迟约束选择。每级寄存器为模块增加一个时钟周期（4 ns）的延迟，但同时缩短组合逻辑路径、改善时序裕量。二者的权衡没有普适的最优解：对于处在闭环反馈路径上的模块，延迟直接压缩控制带宽，应尽量取 `buf_none`；对于处在开环监测路径上的模块，延迟无害，取 `buf_for_io` 以换取时序裕量。

把这一权衡**提升为模块的泛型参数**，意味着同一份内核代码可以在不同实例上采用不同的延迟—时序取舍。平台因此得以在关键路径上追求极低延迟，而在非关键路径上保持时序收敛的余量，无需维护两份代码。这是"延迟作为一等设计变量"这一理念在代码层面的体现。

### 2.4.6 自动复位契约

模块的内部复位由两个来源合成——来自总线的全局复位 `rst`，以及来自其他模块的 `auto_reset_in`，后者受参数 `enable_auto_reset` 门控。

这一契约是**跨模块协同的基础**。应用层的状态机需要在特定时刻复位运算模块：PDH 状态机在扫描阶段保持 PID 复位，捕获瞬间再释放复位使 PID 接管（第五章 5.3 节）。若没有统一的自动复位契约，这类协同须为每对模块单独布线；有了该契约，状态机只需把复位信号送入布尔路由矩阵，再配置到目标模块的 `auto_reset_in` 端口即可——**复位也成为一种可路由的信号**。

`enable_auto_reset` 的门控作用则保证了该机制的可选性：不参与自动流程的模块可将其置零，从而忽略一切外部复位请求。

**总线契约。**

接口层的核心是一套自定义并行总线。本节说明其设计选择，其中 2.4.9 节的影子寄存器机制是平台"参数原子更新"能力的硬件基础。

### 2.4.7 寻址方案

总线采用二级寻址：6 位模块选择信号可寻址至多 64 个模块，7 位地址在模块内部选择 32 位参数字。`Top.vhdl` 当前实例化了 34 个模块，为扩展留有余量。

选择并行总线而非 AXI 等标准接口的理由是**延迟与资源**。标准总线为通用性引入了握手、突发传输、仲裁等机制，而本平台的参数配置具有明确特征：写操作远多于读操作、无需突发、单一主控、对吞吐无要求但对解码逻辑的面积敏感。自定义总线因而可以极简：34 个模块的解码只需一级比较器。

### 2.4.8 分层命令编码

命令字采用分层编码而非平坦编码——先以高位字段区分命令大类（总线读写、模块控制、SPI 事务等），再在类内以低位字段区分具体操作。这一安排降低了解码逻辑的深度：中央控制状态机只需先对大类做一次判决，再在相应分支内做二次判决，而非对全部命令做一次宽比较。在 250 MHz 时钟下，解码路径的逻辑级数直接影响时序收敛，分层编码因此是一项必要的优化。

### 2.4.9 影子寄存器与原子更新

平台面临一个由数据宽度不匹配引起的问题：总线一次传输 32 位，而许多参数宽于 32 位——64 位 DDS 频率控制字、64 个 FIR 系数、IIR 的 11 个系数。若逐字写入且每字立即生效，参数在更新过程中将经历中间状态。对于运行中的闭环系统，这意味着滤波器会在数个时钟周期内以"新旧系数混合"的非法构型工作，可能产生输出跳变甚至发散。

解决方案是参数 RAM 的**影子寄存器**结构，配合总线的 `WRITE_HOLD` 命令。写入时，数据先进入影子寄存器而不影响内核；`HOLD` 标志置位的写操作只更新影子，清零的写操作则在更新影子的同时将全部影子内容一次性提交至工作寄存器。于是一个 $N$ 字参数的更新序列为：前 $N-1$ 字以 `HOLD` 写入，第 $N$ 字正常写入并触发提交。内核看到的是**单次原子切换**，不存在中间状态。

这一机制贯穿三个层次：硬件的影子寄存器提供能力，总线的 `WRITE_HOLD` 命令提供控制手段，上位机的间接参数机制（第三章 3.2.2 节）将其封装为对用户透明的物理量赋值。三者协同是本平台软硬件协同设计的典型例证——任一层单独都无法实现该功能。

### 2.4.10 可靠性设计

总线之上的 UART 链路采用三重错误检测：硬件偶校验、完整命令回显、`:ACKN` 应答。三者检测的失效模式不同——偶校验捕获单比特误码，回显校验捕获多比特误码与帧错位，应答校验则确认命令在逻辑上被成功执行（地址合法、参数有效）。

链路误码或命令解析错误可能使实际参数偏离请求值。偶校验、回显比对和应答检查分别针对部分传输错误与命令执行失败；其覆盖范围仍需通过故障注入测试评估。

## 2.5 运行时可重构的信号路由

本节分析信号路由矩阵的配置机制、资源代价及模块级实现。

### 2.5.1 全交叉结构

互联层由两个相互独立的 $64\times64$ 全交叉开关构成，分别承载 16 位数据信号与 1 位布尔控制信号。任一输入端口可被连接至任意数量的输出端口，连接关系完全由寄存器决定。

数据与控制分离是一项有意的设计。二者的特征截然不同：数据信号为 16 位、持续流动、关注延迟与截断；控制信号为 1 位、事件性、关注边沿与时序关系。若混用同一套矩阵，16 位的通路承载 1 位信号将浪费 15/16 的资源。分离后，布尔矩阵的资源开销仅为数据矩阵的 1/16，却使"复位、使能、触发"等控制信号获得了与数据同等的可路由性——这正是 2.4.6 节自动复位契约得以成立的前提。

每个输出通道由一个 8 位配置字描述：6 位指定源端口编号，1 位使能，1 位保持。

### 2.5.2 保持位与切换过程

配置字中的保持位解决了一个实际问题：在运行中的闭环系统上改变路由时，若输出在切换瞬间出现毛刺，该毛刺将作为扰动注入控制环路，可能导致失锁。保持位置位时输出冻结于当前值，待新配置写入完毕后再释放，从而减少配置写入期间的瞬态。释放保持位后仍可能因新旧信号值不同而产生跳变，闭环切换效果须通过实验确认。

这一能力的实验价值在于：**拓扑调整具备降低切换扰动的条件**。例如在已锁定的 PDH 环路上插入一级额外的低通滤波以抑制高频噪声，切换扰动可能使环路偏离锁定范围；保持位可减轻配置过程中的扰动；能否保持锁定须由第五章实验验证。

### 2.5.3 资源代价与设计权衡

全交叉结构的资源消耗随端口数平方增长。对 $N$ 个端口、位宽 $W$ 的矩阵，所需的选择逻辑规模约为

$$
\text{资源} \propto N^2 \cdot W
$$

当前配置采用 $N=64$、$W=16$。其选择逻辑可能形成较高的扇出与布线负载，设计中设置了扇出约束；实际资源占比及关键路径需以综合实现报告为准。

路由矩阵的资源代价应与拓扑调整效率共同评价。扩展至更多端口时，可研究多级交换网络等替代结构，但需要同时比较资源、阻塞特性与附加延迟。

### 2.5.4 未连接语义、VOID 约定与扇出

当配置字的使能位（bit 6）为零时，相应输出通道被置零。

该设计使未使能通道具有确定的零输出，便于初始化与配置检查；零输入对不同运算模块的影响仍取决于其内部状态。

在此基础上，上位机将数据端口 0 和布尔端口 64 分别约定为空端口。

空端口编号属于上位机的软件约定，路由矩阵并未对物理端口 0 添加特殊逻辑。未连接状态主要由通道使能位表达，布尔矩阵的空端口编号为 64。

**扇出。** 矩阵天然支持单输出多扇出：由于每个输出通道独立选择其源端口，同一个源端口可被任意多个输出通道同时选择。这在实验中对应"同一信号既送入控制环路又送往监测通道"的常见需求，无需额外的分路模块。其代价由布线压力承担——这也是 `Top.vhdl` 对总线信号施加 `max_fanout` 约束的原因之一。

### 2.5.5 设计动机

对于由 RTL 固定连接的信号处理链路，改变处理顺序或插入运算模块通常需要修改逻辑并重新综合。综合实现时间与设计规模及工具环境相关，本文将其作为拓扑切换实验的对照项。

本系统预先实例化功能模块，并以可配置交叉网络连接各端口。对于已有模块间的连接调整，上位机通过寄存器写入更新路由选择码；切换耗时与运行扰动将在第五章测定。

### 2.5.6 结构与实现

信号路由矩阵分别接收 64 路 16 位数据输入和 64 路单比特控制输入，并提供对应数量的输出。

两套交叉开关分别处理 16 位数据和单比特控制信号，避免将控制信号映射到完整的数据位宽。

每个输出通道通过寄存后的 64 选 1 多路选择结构选择数据源。

第 $i$ 路输出的数据源由对应配置字的 6 位选择码决定。每通道占用 8 位配置空间，位域分配为：

| 位域 | 功能 |
|------|------|
| `[5:0]` | 源端口编号（0–63） |
| `[6]` | 通道使能 |
| `[7]` | 保持（hold） |

每套交叉开关的 64 个通道共需 $64\times8=512$ 位配置空间，两套合计 1024 位；前、后 512 位分别配置数据路由和控制路由。

上位机约定端口 0 表示空端口；该约定不改变路由矩阵的硬件选择逻辑。

`[7]` 位的保持功能由 `sig_out_hold_reg` 与 `ctrl_out_hold_reg` 两组寄存器实现。切换路由配置时，若直接改变选择码，输出将在新旧数据源之间产生一次跳变；置位保持位可令输出锁定在当前值，待配置稳定后再释放，从而降低配置写入过程的瞬态扰动；释放保持后能否平滑切换仍需实测。这对运行中的闭环系统尤为重要——锁定状态下的输出跳变足以导致失锁。

### 2.5.7 资源与时序考量

全交叉结构的资源消耗随端口数近似按平方增长。64 路 16 位数据路由对应 1024 个按位实现的 64 选 1 选择结构，因此需要控制扇出并关注布局布线压力。

将扇出上限设为 10，强制综合工具复制驱动寄存器以缩短关键路径。此外每个输出通道均经过寄存器缓冲（`sig_out_buf`），使交叉开关自身构成一级流水，代价是引入 1 个时钟周期的延迟。

路由矩阵的 LUT、FF 占用及最差负裕量仍需由目标器件上的综合实现报告确定，验证方法见第 5.2 节。

## 2.6 核心数字信号处理模块

全部 DSP 模块遵循统一的架构范式：VHDL 内核（`<name>.vhdl`）实现算法，模块封装（`module_<name>.vhdl`）将内核与总线处理器 `bus_handler.vhdl`、参数存储 `parameter_ram.vhdl` 组装为可挂载到片内总线的单元。各内核均带有 `io_buf : buf_type` 泛型参数，可在 `buf_for_io`（输入输出均缓冲）、`buf_i_only`、`buf_o_only`、`buf_none` 四种模式间选择，用于在延迟与时序裕量之间做权衡——对延迟敏感的环路可去掉缓冲级，对时序紧张的路径则保留。

### 2.6.1 直接数字频率合成与信号发生器

DDS 由相位累加器 `modules/accumulator/accumulator.vhdl` 与 CORDIC 三角函数运算器级联构成。

相位累加器采用 64 位频率控制字和 64 位累加状态。

每个时钟周期执行 `acc <= acc + total_incre`。输出频率与频率字的关系为

$$
f_{out} = \frac{\Delta \cdot f_{clk}}{2^{64}}
$$

其中 $f_{clk} = 250$ MHz。由此得到频率分辨率

$$
\Delta f = \frac{f_{clk}}{2^{64}} = \frac{2.5 \times 10^8}{1.8447 \times 10^{19}} \approx 1.36 \times 10^{-11}\ \mathrm{Hz}
$$

该数值是 64 位频率字在理想时钟条件下的理论步进，实际输出频率精度还受参考时钟、相位截断和执行器分辨率影响。

累加器提供常规相位输出和可配置倍频的辅助输出，两者均为 16 位。

`acc_out` 取累加器最高 16 位作为相位输出；`fast_out` 取一个向低位偏移 `divisor_digit` 的 16 位窗口，其相位变化速度为 `acc_out` 的 $2^{\text{divisor\_digit}}$ 倍，即**倍频输出**。偏移量由 `divisor` 参数经优先级编码器求出对数得到，故 `divisor` 仅支持 2 的整数次幂。

`fast_out` 相对于 `acc_out` 的倍频关系由累加器位选方式确定，下文均按这一关系定义端口功能。

辅助输出可在位选范围内提高相位变化速率，但相应缩小常规输出的可用动态范围。在 PDH 应用中，`fast_out` 用作扫描锯齿波与状态机的扫描监测输入，`acc_out` 则作为相位送入 CORDIC 生成调制信号。

累加器内部另集成一个环路滤波器（比例系数 `lf_kp` 为 24 位、积分系数 `lf_ki` 为 32 位，积分项带饱和钳位），使累加器本身即可作为数字锁相环的压控振荡器使用。实际累加增量为 `total_incre <= delta + total_feedback`，其中反馈项由 `bias_in` 外部偏置与环路滤波器输出移位合成。

### 2.6.2 CORDIC 三角函数与相位解算

三角函数运算器 `modules/trigonometric/trigonometric.vhdl` 采用 CORDIC（Coordinate Rotation Digital Computer）算法，以纯移位加法实现正余弦生成，避免查找表的存储开销与乘法器占用。

CORDIC 的 19 个迭代角按 $\arctan(2^{-i})$ 预先量化并存储，其中 $i=0,1,\ldots,18$。

即第 0 级做初始旋转，其后 18 级迭代，共 19 级。内部运算位宽为 24 位，输入输出为 16 位——内部增加 8 位余量用于抑制迭代过程的累积截断误差。

相位与幅度的归一化约定为：相位值 `x8000` 代表 $\pm\pi$，幅度值 `x7586a5` 代表 1.0。CORDIC 的固有增益

$$
K = \prod_{i=0}^{n-1}\sqrt{1 + 2^{-2i}} \approx 1.64676
$$

通过初值预缩放补偿，初始常量取 `c(0) <= x"475e34"`，即 $0.607253 \times \texttt{x7586a5}$，其中 $0.607253 = 1/K$。

CORDIC 采用隔级寄存的流水线组织方式，19 级迭代对应 10 个内部寄存级。这是面积—延迟—时序的三方折衷：全流水可达最高时钟但占用 19 级寄存器，纯组合延迟最小但无法满足 250 MHz 时序。

反三角函数运算器采用相近的流水线结构，由正交分量解算相位。其输入端另有一级预缩放（乘 `x"6DED"`）以防止向量模长溢出。

两个 CORDIC 模块的总延迟目前依据寄存结构分别估计为 12 和 13 个周期；相位、幅度精度及准确延迟仍需仿真与实测确认。

### 2.6.3 数字混频器

混频器对两路 16 位有符号输入进行乘法运算，并截取 32 位乘积的高 16 位作为输出，用于 PDH 误差信号解调。

两路 16 位有符号输入相乘得到 32 位乘积，输出截取高 16 位，相当于按 $2^{-16}$ 缩放。该位选方式可限制输出位宽，但会引入截断误差；其动态范围与定点标度需结合输入表示分析。

该模块无可配置参数，其封装 `module_mixer.vhdl` 使用 `parameter_ram_0`（零容量参数存储）。延迟为 2 个时钟周期（`buf_for_io` 配置下输入输出各一级缓冲）。

### 2.6.4 FIR 低通滤波器

FIR 滤波器采用 64 抽头直接型结构，系数精度为 24 位。

FIR 滤波器存储 64 个 Q1.23 格式的系数，并针对 16、32 和 64 抽头配置设置相应归一化因子。

结构为 64 抽头直接型，**未利用线性相位滤波器的系数对称性做折叠优化**——`gen_product` generate 语句实例化 64 个独立乘法器。这是一个明确的资源—通用性折衷：折叠结构可将乘法器数量减半，但要求系数严格对称，从而排除了非线性相位滤波器的使用。

可变抽头数采用三条缩放支路，分别对应 16、32 和 64 抽头配置，并为各配置设置独立的定标系数。系数范围及输出幅度需要在上位机量化后验证。

加法树分三级实现：`sum_0`（16 个四输入加法器）→ `sum_1`（4 个）→ `sum_2`（1 个），中间结果均为 Q6.21 格式。延迟按寄存器级数计为 7 拍（输入缓冲、乘积、三级加法树、缩放、输出缓冲各一级）。

### 2.6.5 IIR 滤波器

IIR 滤波器采用两节并联双二次结构，并对递归路径应用四阶散射前瞻变换。

IIR 滤波器由两节双二次结构并联，输出为两支路结果之和。

每节双二次结构包含 9 个前馈系数和 2 个反馈系数。

每节需 9 个 b 系数（Q3.24）与 2 个 a 系数（Q2.25），均为 27 位。两节合计 22 个系数。

采用并联而非串联、并引入散射前瞻变换，根本原因在于 IIR 的递归结构与高速流水线的内在冲突。直接型 IIR 的反馈环路要求上一个输出在下一个采样时刻前完成计算，即环路内不能插入流水线寄存器，这直接限制了最高时钟频率。四阶散射前瞻变换通过在分子分母同乘一个多项式，将递归的最小延迟从 1 拍扩展到 4 拍，从而允许环路内插入 4 级流水线——代价是系数数量从 3 个 b、2 个 a 膨胀至 9 个 b、2 个 a。这是本系统在 250 MHz 下实现 IIR 滤波的关键技术。

反馈路径的乘法采用长乘法拆分：将 Q4.26 的中间结果拆为高 18 位与低 12 位分别相乘再合并，以适配 DSP48 硬核的 18×27 位输入格式。输出端带饱和检测，溢出时钳位至 `x"7FFF"` 或 `x"8000"` 而非回绕，避免递归结构中溢出回绕引发的自激振荡。

滤波器系数的设计由上位机完成，详见第三章 3.3 节。

### 2.6.6 高性能数字 PID 控制器

PID 控制器 `modules/pid_controller/pid_controller.vhdl` 是闭环系统的核心，其定点设计体现了多项工程考量。

PID 控制器采用 16 位误差输入、48 位积分器及按运算结果扩展的乘积和限幅位宽。

积分器取 48 位远宽于 16 位数据通路，这是为积分作用预留足够的动态范围——积分项需累积微小误差至显著修正量，位宽不足将导致小误差被截断而无法消除静态偏差。

**增益定标。** 依据定点增益定义，当比例与积分增益相等时，PI 转折频率为

$$
f_{PI} = \frac{f_{clk}}{2\pi \cdot 2^{16}} = \frac{2.5\times 10^8}{2\pi \times 65536} \approx 600\ \mathrm{Hz}
$$

该式为参数配置提供了物理标定基准，上位机据此实现物理量到寄存器值的换算（见第三章 3.2.3 节）。

PID 运算首先计算输入与设定值之差，微分支路采用一阶后向差分，比例、积分和微分支路分别计算后相加。

抗积分饱和机制包含积分器状态限幅与总输出限幅两个层次。

关键在于钳位后的值**写回积分器状态**，而非仅限制输出——这才构成真正的 anti-windup。若仅限制输出而放任积分器继续累积，误差反向后需要很长时间才能退出饱和，表现为明显的恢复滞后。其二为总输出限幅，按 `±limit_sum` 钳位，防止送往 DAC 的修正量超出量程。

漏积分机制通过移位运算近似实现衰减项，以避免在反馈路径中使用通用除法器。

由 `leak_array` 生成 32 个移位版本后逐位或运算合成泄漏量，再从积分项中减去。等效泄漏系数为 $\alpha = 1 - 1/(\texttt{leak\_digit} \cdot 2^8)$。因实现方式为移位，`leak_digit` 只能取 2 的整数次幂，上位机在换算时需做幂次对齐并提示量化误差（见 2.6 节）。

**流水线与延迟。** 积分支路采用二分频交错计算，有效更新频率为 125 MHz；微分支路按 250 MHz 系统时钟更新。上位机参数换算分别采用相应频率。闭环配置省略输入输出缓冲，依据寄存结构估计比例与微分通路为 3 级；准确延迟需要仿真确认。

**平台的扩展流程。**

平台的生命力在于可扩展性。依据前述范式，新增一个运算模块的完整流程如下：

1. **由模板派生内核**。复制 `core_template.vhdl`，填入模块名、参数 RAM 深度与数据流端口，在 IO 缓冲块之间实现运算主体。
2. **由模板派生总线封装**。复制 `module_template.vhdl`，确定参数 RAM 的位宽与参数的位域划分。
3. **在 `Top.vhdl` 中实例化**，分配模块编号，将数据端口接入路由矩阵的相应端口、控制端口接入布尔矩阵。
4. **在 `mypak.vhdl` 中登记**模块的总线地址常量。
5. **编写上位机硬件类**，继承 `ModuleBase`，声明参数字典与物理量换算（第三章 3.2 节）。
6. **编写图形界面节点类**，声明端口的信号类型与参数模式（第三章 3.4 节）。

六个步骤中前四步属硬件、后两步属软件，且各步骤的接口均由范式固定。这一流程的高度模式化正是第四章代码生成工具得以自动产出样板代码的前提——该工具可自动完成第 1、2、5、6 步的框架部分，而第 1 步中的运算主体（涉及定点格式选择与流水线划分）仍需人工填写。

需要指出流程中的一项**人工维护负担**：模块的端口定义在硬件侧（`Top.vhdl`）与软件侧（界面节点类、模块知识库）各有一份，须保持一致。不一致不会引起综合错误，但会导致界面连线与实际硬件路由不符，是一类隐蔽的故障来源。第六章将其列为改进方向。

## 2.8 本章小结

本章建立了从控制约束到 FPGA 实现的硬件链路：板级转换与时钟、模块及总线契约、可配置路由和定点运算模块共同支撑同一套平台。路由资源、时序裕量及端到端延迟仍需用综合报告和板级测量核定。

# 第三章 上位机软件设计

本章说明 Python 上位机如何将实验参数转换为硬件寄存器操作，并通过可视化节点编辑器配置平台拓扑。实时反馈仍由 FPGA 完成。

## 3.1 软件分层与通信封装

上位机软件由应用层、硬件抽象层、协议层和驱动层构成。应用层处理物理量与实验流程，硬件抽象层完成参数映射，协议层形成命令帧，驱动层完成串行传输。

通过分层，应用层以物理量描述控制目标，寄存器地址、定点格式和事务次数由下层完成映射。

### 3.1.1 驱动层

驱动层基于 pyserial 封装命令发送与响应接收，并在每次事务中执行回显和应答校验。

串行事务采用回显校验与应答校验两个阶段：

1. **回显校验阶段**（`repeated=True` 时启用）：读取 FPGA 回传数据直至遇到帧结束符 `b"!"`，循环等待至响应长度不小于 11 字节且在倒数第 6、第 11 字节位置出现分隔符 `.`，随后将回显与原始命令逐字节比对，不一致则抛出异常。FPGA 对每条命令原样回显，使链路上的位错误可被立即发现。

2. **应答校验阶段**：再次读取至 `b"!"`，要求响应前 5 字节为 `b":ACKN"`，否则判定为执行失败。

两阶段分别校验"命令是否被正确接收"与"命令是否被正确执行"，二者是不同的失效模式：前者对应链路误码，后者对应地址越界、参数非法等逻辑错误。

链路参数为 115200 波特、8 数据位、偶校验、1 停止位。FPGA 侧的偶校验在 `uart_rx.vhdl` 中以组合逻辑实现（`parity <= xor data`），与上位机的 `parity="E"` 配置对应。因此系统共有三重错误检测：硬件偶校验、完整命令回显、`:ACKN` 应答。

运行配置与硬件常量均采用 115200 波特率；测试例程中的其他配置不作为系统工作参数。

### 3.1.2 协议层

协议层将寄存器读写请求编码为 ASCII 命令帧，并将返回帧解析为寄存器数据或执行状态。

总线写操作依次编码模块标识、寄存器地址、数据和可选的保持标志。

地址与数据均接受整数或十六进制字符串两种输入，统一规整为 4 字节大端序。命令帧以 `:` 起始、`!` 结束、`.` 分隔字段，模块名为 4 字符大写标识（如 `ROUT`、`PIDC`、`FIRF`），与 `mypak.vhdl` 中的 `BUS_*_ADDR` 常量一一对应。

读操作提交模块标识和寄存器地址，并从应答帧解析四字节数据载荷。

`hold` 参数直接对应第二章 2.4.2 节所述的 `WRITE_HOLD` 总线命令，是实现多寄存器原子更新的协议层支点。

SPI 通路对总传输长度和写入长度分别编码，以支持同一事务中的全双工读写。

返回数据为 `response[-1 - read_length:-1]`，其中 `read_length = length - write_length`。`SpiChip` 子类针对 ADI 系列器件的 2 字节寄存器地址做了特化：写操作为 3 字节出、0 字节回，读操作为 2 字节出、1 字节回。这解释了 `chips.py` 中所有调用均为 6 位十六进制字符串的原因——`"057115"` 表示向地址 `0x0571` 写入 `0x15`，而读操作通过置位地址最高位实现（`"856F"` 即读 `0x056F`），符合 ADI 器件的读写位约定。

### 3.1.3 硬件抽象层

硬件抽象层通过模块基类及其子类统一组织寄存器映射与物理量参数转换，具体方法见第 3.2 节。

## 3.2 模块化控制与参数映射

### 3.2.1 参数描述的三类字典

硬件抽象层通过三类参数描述统一模块配置：

- `parameter_list` 是**寄存器映射表**，记录每个地址对应的参数名与位宽。位宽信息用于负数的补码转换与布尔参数的合法性校验。
- `alias_list` 提供参数别名。例如 `ModulePID` 将 `"gain_p"`、`"p"`、`"kp"`、`"k_p"` 四个名称均映射到地址 0，使实验脚本的书写更自然。
- `deduced_parameter_list` 是**间接参数**，即没有单一寄存器与之对应、需经计算才能落地的物理量，其值为一个方法而非地址。

参数解析先查询寄存器别名，再查询间接参数映射；前者返回地址并执行直接写入，后者返回换算函数并生成多个寄存器更新。

### 3.2.2 原子化多寄存器写入

对于间接参数，处理函数将物理量转换为地址—数据对序列，`write` 将前 N−1 条以 `hold=True` 发送、最后一条才提交。于是一次物理量赋值在硬件侧表现为**单次原子生效**，中间状态不会作用于运行中的控制环路。这是协议层 `hold` 机制、硬件 `wen`/`wval` 分离机制与软件层参数抽象三者协同的结果，贯穿三个层次。

`ModuleBase` 的其余方法各司其职：`reset()` 依次发送 `RSTR`/`SETR`/`RSTC`/`SETC` 四条控制命令，分别复位参数 RAM 与模块内核；`set()` 仅接受位宽为 1 的布尔参数并容纳多种真值写法；`readv()` 在 `read()` 之上做有符号整数转换；`flip_on()`/`flip_off()` 用于为脉冲触发型参数制造干净的边沿——先读当前值，若已处于目标电平则先写反相值，再写目标值，确保边沿必然产生。

### 3.2.3 参数的物理量映射

以 PID 控制器为例，物理参数与定点增益之间的换算关系为

$$
\text{总增益(dB)} = 20\log_{10}\left(\frac{g_p}{2^{16}}\right)
$$

$$
f_{PI} = \frac{f_s}{2\pi}\cdot\frac{g_i}{g_p}\cdot\frac{1}{2^{16}}, \qquad
f_{PD} = \frac{f_s}{2\pi}\cdot\frac{g_p}{g_d}
$$

$$
\alpha = 1 - \frac{1}{\texttt{leak\_digit}\cdot 2^{8}}, \qquad
f_{sat} = \frac{f_s}{2\pi\cdot\texttt{leak\_digit}\cdot 256}
$$

积分支路采用二分频交错计算，因而 PI 转折频率的换算采用 125 MHz 的有效采样率；微分支路采用 250 MHz 的系统采样率。参数映射必须与两条硬件通路的实际更新频率一致。

调整总增益时，$g_p$、$g_i$ 和 $g_d$ 按相同比例变化，从而保持 $f_{PI}$ 与 $f_{PD}$ 不变。三个寄存器值通过保持提交机制同步生效，避免更新期间改变暂态频率响应。

DDS 频率字由目标输出频率、系统时钟和频率比例系数确定，即 $\Delta = \mathrm{round}\!\left(f \cdot 2^{64} / (f_{clk}\cdot r)\right)$，64 位频率字拆为两个 32 位寄存器原子写入，并在入口处做奈奎斯特限制校验。反向换算为 $f = \Delta \cdot f_{clk} / 2^{64} \cdot r$，分辨率即第二章给出的 $1.36\times10^{-11}$ Hz。

漏积分系数受到移位实现的离散取值约束。上位机量化目标参数后，同时显示请求值和实际生效值，使量化偏差可以记录并用于后续分析。

**线性变换矩阵系数**的映射较为直接：系数取值限定在 $[-1, 1]$，按 `coef_int = int(round(data * (2 ** 15 - 1)))` 转为 Q1.15 整数，负数以 `2 ** 16 + coef_int` 转补码。

定点数运算的通用支撑由 `python control/fixed.py` 的 `fixed` 类提供。该类以 `Qm.n` 格式字符串构造（正则 `^Q([0-9]+)\.([0-9]+)$`），`scale = 2 ** frac_bits`，`value = int(round(value * scale))`，并实现了完整的算符重载与溢出检查。该类主要服务于 `IIR.py` 的系数量化与测试向量生成；`module.py` 中的换算则以 `2 **` 字面量内联实现。

## 3.3 初始化与校准流程

### 3.3.1 环境初始化

实验环境层负责建立设备连接，并提供下列配置例程：

| 函数 | 用途 |
|------|------|
| `init()` | 标准初始化（含外部参考） |
| `init_no_ref()` | 无外部参考初始化 |
| `setup_pll()` | 锁相环配置 |
| `setup_duallock()` | 双路锁定配置 |
| `setup_pdh()` | PDH 锁定配置 |
| `setup_sclodpllpid()` | SCLO + 数字锁相环 + PID 配置 |

实验配置例程记录路由关系、模块参数与使能状态，使同一拓扑可按相同命令序列重复加载。实际状态的一致性仍需通过参数回读和信号连通性确认。

### 3.3.2 时钟与 PLL 校准

板级初始化按器件依赖关系进行：先配置并检查时钟分发器，再配置 ADC 与 DAC，以保证转换器初始化时已有有效采样时钟。

`chips.py` 中各初始化函数的末尾均带锁定校验：

| 函数 | 校验寄存器 | 期望值 |
|------|-----------|--------|
| `init_AD9680` | `0x056F` | `0x80` |
| `init_AD9152` | `0x0281` | `0x03` |
| `init_AD9528` | `0x0508` | `f2`/`f3`/`e6`/`e7` 之一 |

校验失败即抛出异常，使配置错误在初始化阶段暴露而非在实验中表现为难以定位的信号异常。

AD9528 的初始化包括 PLL2 校准、SYSREF 请求和同步操作。当前配置对应的输出频率规划如下，其数值仍需与器件寄存器设置交叉核验：

| 通道 | 频率 | 用途 |
|------|------|------|
| 2 | 1 GHz | ADC 器件时钟 |
| 4 | 1 GHz | DAC 器件时钟 |
| 1, 5, 8, 9 | 3.90625 MHz | SYSREF |
| 3, 6, 7, 10, 13 | 250 MHz | 参考/核心时钟 |

`init_AD9528_ext_ref` 为外部参考变体，差异在于寄存器 `0106`/`0107`（使能 PLL1）以及通道 6、10 输出 200 MHz 而非 250 MHz。

上述频率为配置文件中的标称值，尚未依据器件寄存器译码和实测时钟结果确认。

### 3.3.3 FIR 系数加载

FIR 系数加载首先对输入序列归一化并预留幅度裕量，然后计算其 L1 范数对应的定标系数。

定标过程包括两个步骤：

1. **峰值归一化**使系数落入 Q1.23 格式可表示的 $[-1, 1]$ 区间，`×0.98` 的余量防止舍入后溢出；
2. **L1 范数定标**利用系数绝对值之和作为有界输入条件下输出幅度的上界，并预留额外裕量。具体输出范围还取决于内部累加位宽和后续截断位置，应通过定点仿真验证。

系数被加载到 `fir` 与 `fir2` 两个实例，对应正交解调链路的 I、Q 两路。

上位机将系数量化为 Q1.23 格式，负值按 24 位补码编码后写入寄存器。

64 个系数写入地址 0–63，归一化因子按抽头数写入不同地址（64 抽头→地址 64，32 抽头→65，16 抽头→66），最后将 `taps - 1` 写入地址 67 作为提交写入——即抽头数的写入同时充当"配置生效"的触发，使 68 个寄存器的更新构成一次原子事务。

`fir_coef.txt` 为纯文本格式，每行一个十进制系数，共 64 个值，呈对称低通冲激响应。

除文件加载外，上位机还通过 Parks–McClellan 等波纹算法设计低通 FIR 系数。

### 3.3.4 IIR 系数设计

IIR 滤波器采用并联双二次结构与四阶散射前瞻变换，前馈、反馈和中间结果分别使用 Q3.24、Q2.25 和 Q4.26 定点格式。

`get_IIR_parameters(ftype, cutoff_frequency, sample_frequency)` 的处理流程分五步：

1. **原型设计**：`signal.iirfilter(4, ..., btype='lowpass', ftype=ftype, rs=80, rp=0.05)`，四阶低通，阻带衰减 80 dB、通带波纹 0.05 dB。`ftype` 透传至 scipy，故 `butter`、`cheby1`、`cheby2`、`ellip`、`bessel` 均可使用。
2. **部分分式分解**：`signal.residuez(b, a)` 将直接型转为留数—极点表示，为并联结构做准备。
3. **共轭极点配对重组**：将共轭极点对重组为实系数双二次节，如 `a_0 = [1, -2*Re(p[0]), |p[0]|**2]`。
4. **增益均衡**：`balance_direct` 在两节之间分配常数增益，使系数落入定点可表示范围。提供 `uniform`、`min_max`、`balanced_gain`、`balanced_norm`、`balanced_pole` 五种策略，按滤波器类型自动选择（`butter`→`balanced_pole`，`ellip`→`balanced_gain`，其余→`balanced_norm`），其中两种策略通过黄金分割搜索寻优。
5. **散射前瞻变换**：`scatter_look_ahead` 求解 6×6 线性方程组得到乘子多项式，再将其卷积进分子分母，使每节递归获得 4 拍延迟余量——即第二章 2.6.5 节所述变换的系数求解实现。

最后做符号翻转以适配硬件的累加约定（`a_0[1:] = -a_0[1:]`）。

IIR 前馈系数和反馈系数分别按 Q3.24 与 Q2.25 格式量化。

22 个系数中前 21 个以 `hold=True` 写入、最后一个提交。

## 3.4 可视化节点编辑与类型检查

### 3.4.1 节点编辑器

图形界面基于 PySide6 实现，由窗口控制、图形场景和模块节点三个部分组成，分别处理设备连接与配置、拓扑显示和端口参数编辑。

交互方式为：从右侧面板拖拽模块到画布、点击输出端口拖至输入端口建立连线、双击模块弹出参数对话框、拖动节点至右侧区域删除、点击已连接的输入端口断开连线。

画布连接映射为信号路由矩阵中的选择码，因此画布拓扑可以直接表示硬件信号连接状态。

### 3.4.2 设计期类型检查

系统定义了四类信号类型，并以不同图形标记区分端口：

| 信号类型 | 图形标记 | 可接受输入 | 含义 |
|---------|---------|-----------|------|
| `level` | 五角星 | level, phase, differential | 通用幅度量 |
| `phase` | 圆形 | phase | 相位量 |
| `differential` | 菱形 | level, differential | 相位差分量 |
| `bool` | 方形 | bool | 单比特控制 |

标记由 `PortItem._draw_signal_markers`（位于 `qt_module.py`）绘制，类型不匹配的连线在建立阶段即被拒绝。

这一机制的意义在于将一类错误前移至设计阶段。相位量与幅度量在硬件上均为 16 位整数，混接不会产生任何电气错误，但物理含义错误——例如把相位信号直接送入 PID 的误差输入，环路会因相位的 $2\pi$ 回绕而无法稳定。此类错误可能表现为闭环不稳定，类型检查可在连线阶段识别部分不兼容配置。开发者模式可解除物理信号类型间的限制，以支持非常规实验。

### 3.4.3 智能体层的接入方式

在节点编辑器之上，系统增加基于大语言模型的设计辅助层，用于将自然语言描述转换为画布编辑操作。其设计见第四章。

智能体层通过 Qt 信号槽与既有窗口连接，能够独立启用或停用；手动画布操作不依赖智能体服务。

接口上的关键一点是：智能体对画布的全部操作经 `CanvasBridge` 门面类进行，而该门面最终调用的仍是 `scene.create_connection` 与 `view._alloc_index` 等本章既有方法。这意味着 3.4.2 节的信号类型检查与模块实例数上限对智能体同样生效，模型无法绕过——自动化层继承了既有的安全约束而非替代它们。

## 3.5 本章小结

上位机通过驱动、协议、硬件抽象和应用层把物理量转换为可重复的寄存器配置；节点编辑器进一步把拓扑配置可视化，并在设计阶段检查信号类型。

# 第四章 大语言模型智能体辅助设计系统

本章研究大语言模型智能体在实验拓扑配置与基础模块扩展中的辅助作用，分析其工具调用机制、知识表示方式、代码生成流程及操作约束，并提出仿真反馈驱动的工具自迭代设计。智能体不参与 FPGA 实时反馈环路。

## 4.1 设计动机与总体架构

### 4.1.1 自然语言辅助配置的需求

第二章所述路由矩阵允许在运行时配置模块连接，但可选连接数量随端口规模增加。第三章的节点编辑器提供拓扑可视化及信号类型检查，具体模块选择和端口匹配仍需要领域知识。

以 PDH 锁定为例，用户给出的控制目标需要进一步分解为模块实例、端口连接和参数配置。本章将这一转换表示为

$$
\text{自然语言意图} \xrightarrow{\text{LLM + 工具调用}} \text{画布拓扑} \xrightarrow{\text{第三章映射}} \text{路由寄存器配置}
$$

物理参数到寄存器配置的映射与画布拓扑到硬件连接的映射分别在第二、三章讨论。本章首先研究自然语言意图到画布拓扑的转换，再讨论新模块生成与验证的扩展路径。

### 4.1.2 分层结构

智能体系统由七个功能层次构成，各层职责如表所示。

| 层次 | 主要职责 |
|------|----------|
| 交互层 | 呈现用户请求、模型响应和工具执行结果 |
| 编排层 | 管理对话上下文、函数调用循环与后台任务 |
| 接口层 | 封装兼容 Chat Completions 的模型服务接口 |
| 工具层 | 声明工具参数结构并分发调用 |
| 隔离层 | 将结构化参数转换为画布操作，并实施前置校验 |
| 知识层 | 提供模块端口、参数及典型拓扑的结构化描述 |
| 生成层 | 根据模块规格生成硬件与软件框架 |

层间依赖是单向的：交互层仅与编排层通信，编排层经工具层操作隔离层，隔离层是唯一接触 Qt 对象的环节。知识层为编排层提供系统提示词中的模块描述，为工具层提供模块元数据查询。

系统入口通过 Qt 信号槽连接聊天面板与智能体编排层，分别传递用户输入、模型响应、工具执行结果和错误状态。该集成方式使智能体功能可以独立启用或停用，并保持现有手动配置流程的可用性。

## 4.2 工具层与错误反馈

### 4.2.1 工具集合

智能体通过九类工具查询或修改画布。工具参数以 JSON Schema 声明，并由统一的分发机制映射到画布操作：

| 工具 | 作用 | 关键参数 |
|------|------|---------|
| `list_modules` | 列出可用模块类型与画布现状 | `scope`: available / on_canvas / both |
| `get_module_info` | 查询单个模块的端口与参数详情 | `module_type` |
| `create_module` | 在画布上创建模块节点 | `module_type`, `position_x/y`, `params` |
| `connect_modules` | 建立端口间连线 | `source_node`, `source_port`, `destination_node`, `destination_port` |
| `disconnect_module` | 断开输入端口或删除节点 | `node_name`, `port_index`（省略则删除节点） |
| `set_parameter` | 设置模块参数 | `node_name`, `params` |
| `auto_layout` | 自动布局 | 无 |
| `generate_module` | 生成新模块类型的代码 | `module_name`, `inputs`, `outputs`, `params` |
| `clear_canvas` | 清空画布 | `confirm`（必须显式为真） |

工具接口区分查询与修改操作。模块查询为只读，连线前可用于取得端口索引与信号类型；清空画布操作要求显式确认参数，以减少由模型误判引发的意外清空。该约束的有效性需要通过边界测试验证。

### 4.2.2 错误作为反馈

工具分发层将可捕获的执行异常转换为包含工具名称和错误原因的结构化结果；画布隔离层则返回执行状态及相应数据。这一机制使失败信息能够进入后续对话上下文，同时避免已处理的异常直接传播至 Qt 事件循环。

错误结果包括端口越界、输入端口占用、未知模块类型和实例数超限等信息，分别提供合法范围、冲突位置或可查询的模块列表。结果作为工具消息加入对话历史，使模型能够依据失败原因调整下一轮操作。该反馈机制是否提高任务成功率，需要比较首次生成与允许纠错后的最终结果。

已覆盖的校验错误由工具层返回；未覆盖的参数边界与异常传播仍需进一步测试。

### 4.2.3 门面隔离

画布隔离层是智能体与图形界面之间的调用边界，以结构化参数和结果封装画布操作。其作用体现在三个方面。

**类型边界。** 模型以 JSON 传递节点标识、端口索引和坐标；隔离层将其转换为 Qt 画布对象，并返回可序列化的执行结果。

**前置校验。** 连线前检查节点存在性、端口索引范围及目标输入端口的占用情况。通过检查后，画布层继续执行第 3.4.2 节的信号类型约束。参数取值范围的校验仍不完整，见第 4.7 节。

**能力边界。** 智能体接口只提供画布编辑操作，未提供串口直通或寄存器裸写工具。模块实例上限与复合模块展开仍由既有画布逻辑处理。

## 4.3 编排层与函数调用循环

### 4.3.1 循环结构

编排层将用户请求加入对话历史，并在后台线程中执行函数调用循环。主要步骤如下：

1. 以当前消息列表与工具声明请求模型；
2. 将模型返回的助手消息（含文本与 `tool_calls`）追加至历史；
3. 若无 `tool_calls`，返回文本，循环结束；
4. 否则顺序执行每个工具调用，将结果以 `role: "tool"` 消息追加至历史；
5. 调用一次 `auto_layout` 整理版面；
6. 回到第 1 步。

模型根据工具结果决定后续调用，直至给出最终答复或达到迭代上限。其中第 5 步的自动布局是便利性设计——模型创建节点时若未指定坐标，门面以 `_next_auto_position` 顺次向右排布，循环末尾的分层布局则将其整理为符合信号流向的版面。布局失败不会中断拓扑编辑，但应在后续版本中记录该异常以便诊断。

### 4.3.2 迭代上限

循环的最大迭代次数设为 15。达到上限时，系统终止本轮工具调用并向用户返回状态说明。

这一机制针对的是函数调用式智能体的典型失效模式：模型在工具结果不符预期时反复尝试同类调用而不收敛。设定上限使单次请求的开销有界——每次迭代对应一次模型 API 调用，无上限的循环在失效时既消耗配额又可能持续改动画布。

上限值的选取需权衡。搭建一个完整 PDH 拓扑需要约 5 个 `create_module` 与 9 个 `connect_modules` 调用；由于模型可在单轮中并行返回多个 `tool_calls`，循环的迭代次数通常远少于工具调用总数，15 轮对该规模的任务有相当余量。但对于更复杂的拓扑，该值可能偏紧，此时上限消息提示用户检查画布并续发指令，而非使系统陷入沉默。

### 4.3.3 线程模型与错误处理

模型服务调用为阻塞式网络请求。为维持界面响应，函数调用循环运行于 Qt 工作线程，并通过信号将工具状态与结果传递至主线程。

错误处理分两级。模型 API 层面的失败（网络异常、认证失败、非 200 响应）由 `LLMClient` 转换为 `LLMError` 抛出，在循环内被捕获后转为一条用户可见的错误消息并终止循环，而非使线程崩溃。工作线程的 `run` 方法则以 `try/except` 兜底捕获一切未预期异常，经 `error` 信号报告并附完整 traceback——此处保留 traceback 是有意的，因为这类异常意味着程序缺陷而非使用错误，调试信息对开发有价值。

### 4.3.4 接口层的服务端中立性

接口层封装兼容 Chat Completions 的请求格式，传递对话历史、模型参数及工具声明。模型服务地址与模型名称可由用户配置。

采用兼容接口使系统能够适配实现相同调用格式的模型服务；不同服务的工具调用行为仍需分别测试。`temperature` 默认取 0.1 的较低值，因为本场景需要的是对工具规格的准确遵循，而非表达的多样性。

当前模型服务凭据由本地配置文件保存。后续应改用环境变量或系统凭据存储，并检查配置文件的版本控制规则。

## 4.4 模块知识库

### 4.4.1 结构化模块描述

模型需要知道系统有哪些模块、各模块的端口语义与参数含义，才能生成合理的拓扑。`module_registry.py` 以三个字典承载这一知识：

- `MODULE_REGISTRY`——12 个基础模块：PID 控制器、累加器、三角函数运算器、反三角函数运算器、线性缩放器、FIR 滤波器、IIR 滤波器、线性变换器、混频器、解卷绕器、PDH 状态机、LO 自动校准状态机；
- `COMPOSITE_MODULES`——2 个复合模块：正弦波发生器、数字控制振荡器，各自展开为若干基础模块及其内部连线；
- `SPECIAL_NODES`——2 个常量节点：布尔值真、布尔值假，用于为控制输入提供固定电平。

每个条目记录显示名、内部短名列表、实例数上限、类别、用途说明，以及输入输出端口的索引、名称、显示名与信号类型。参数分为 `direct_params`（单寄存器直写）与 `indirect_params`（多寄存器原子写入）两类，与第三章 3.2.1 节的参数字典体系对应。

知识库与第三章的 `qt_module.py` 存在信息重叠，这是一处需要指出的设计代价：模块的端口定义在两处各有一份，新增模块时须同步维护，否则智能体会依据过时信息生成非法连线。更稳健的做法是由单一来源自动导出，`code_generator.py` 的运行时注册机制（见 4.5.2 节）已部分缓解该问题，但既有模块的两份描述仍需人工保持一致。后续应建立启动时的一致性校验，比较两处端口定义并报告差异。

### 4.4.2 上下文构建与拓扑范式

`build_llm_context` 将上述字典格式化为 Markdown 文本，注入系统提示词的 `{module_descriptions}` 占位符。输出内容依次为基础模块（含全部端口与信号类型）、常量节点、复合模块、系统 IO 边界端口（输入通道 A–H 对应 ADC，输出通道 A–H 对应 DAC），最后可选附加 `PDH_LOCKING_PATTERN`。

知识库中的 PDH 参考拓扑按五类连接组织：信号生成链（累加器 → 三角函数）、误差信号链（三角函数余弦输出 → 混频器参考端，探测器信号 → 混频器信号端）、反馈链（混频器 → PID → 累加器误差输入）、状态机控制（PDH 状态机的三路复位控制分别门控 PID、混频器与累加器，累加器快速输出回授状态机的扫描输入）、输出监测（累加器与 PID 输出接至 DAC 通道）。

注入该范式的理由是：PDH 锁定是本系统的主要应用场景，其拓扑在领域内固定且端口对应关系琐碎易错。将其作为参考清单写入提示词，使模型在处理最常见请求时有确定依据，而不必从端口语义逐步推断。这本质上是以领域知识换取可靠性——代价是提示词与范式耦合，若硬件端口分配变更，该常量须同步更新。

## 4.5 代码生成与能力边界

### 4.5.1 生成流程

`generate_module` 工具针对的场景是：用户需要的模块类型在系统中不存在。`CodeGenerator.generate` 接收模块名、显示名、描述、输入输出端口列表与参数列表，产出六类文件：

| 产物类别 | 作用 |
|----------|------|
| VHDL 运算内核骨架 | 定义端口、参数接口与缓冲结构 |
| VHDL 模块封装 | 对接总线和参数存储 |
| Python 硬件类 | 将寄存器配置封装为模块参数 |
| Python 节点类 | 提供画布端口与参数编辑能力 |
| 参数模式 | 描述参数类型及默认值 |
| 端口分配记录 | 保存数据与控制端口编号 |

生成过程中有两项自动推导。其一是参数 RAM 深度：按参数个数向上取到不小于 8 的 2 的幂，再乘 32 位得到总位宽，与第二章 2.4.2 节的参数 RAM 结构对应。其二是端口号分配：`_alloc_ports` 依据输入输出的信号类型分别在数据通道与布尔通道的端口空间中分配编号，并持久化记录以避免重复占用——这直接对应第二章路由矩阵的端口编号体系。

### 4.5.2 运行时注册

`register_runtime` 以运行时打补丁的方式将生成的模块注入正在运行的应用：向 `module_factory` 字典登记节点类、扩展端口号解析函数、更新组件面板。这使新生成的 Python 侧模块无需重启即可用于 `create_module`。

### 4.5.3 能力边界

代码生成功能的适用范围由生成产物及其运行条件决定。

**生成的 VHDL 内核是骨架而非实现。** 代码生成器的返回值中显式包含这一说明：实体声明、端口定义、参数 RAM 接口、输入输出缓冲与总线封装完整且可综合，但 `use_input_buffer` 与 `use_output_buffer` 之间的信号处理主体留空，须由硬件工程师填写。换言之，生成器自动化的是模块的**外壳与接口**——这部分在本系统中高度模式化（第三章 3.2 节所述的"内核 + 总线封装 + 参数 RAM"统一骨架），因而适合模板化生成；而算法主体涉及定点格式选择、流水线划分与时序收敛，不是模板所能覆盖的。

**新模块需要重新综合才能真正可用。** 运行时注册仅使 Python 侧的节点类生效，画布上可以放置该模块、可以连线、可以设参数，但 FPGA 中并不存在对应的硬件逻辑。真正可用须经填写内核、重新综合实现、下载比特流三步。因此该功能的实际价值在于**加速模块开发的样板代码环节**，而非实现"自然语言直接生成可运行硬件"。

因此，生成结果仍需完成算法实现、仿真验证与时序分析，不能直接视为可运行硬件模块。

## 4.6 仿真反馈驱动的工具自迭代设计

### 4.6.1 闭环生成与验证流程

针对第 4.5 节中运算内核仍需人工实现的问题，本文进一步设计由生成、验证、修正与封装组成的工具级自迭代闭环。其输入为结构化模块规格，包括功能定义、端口及位宽、时钟与复位方式、定点格式、目标时序约束和测试用例。大语言模型依据该规格生成基础模块的 RTL 实现及相应测试平台，并将候选代码置于独立的工程目录中。结构化规格同时作为验证基准，以避免后续修正偏离原始功能要求。

验证环节通过 Vivado 自动化接口调用编译、展开与行为仿真，收集编译日志、测试断言和波形数据。功能判定以模块规格规定的测试用例及独立参考结果为依据，并结合波形检查复位、握手及关键状态转移，避免以候选代码自身的输出作为正确性标准。时序判定则依据综合与实现后的静态时序分析报告；行为仿真中的波形正确并不等价于目标器件上的时序收敛。对于资源占用敏感的模块，还应将资源利用率纳入验收条件。

### 4.6.2 基于 ReAct 的修正与停止条件

当编译、功能或时序检查失败时，系统将错误类别、对应日志、失配波形位置及关键路径信息组织为观察结果，反馈给智能体。智能体按照“分析原因—修改 RTL—重新验证”的 ReAct 过程生成下一版候选模块，不得通过修改验收用例消除失配。修正仅作用于当前候选版本；每轮保存模块规格、代码版本、工具配置与验证结果，以便定位回归错误并复现实验。

设第 $i$ 轮候选代码为 $C_i$，验证反馈为 $E_i$，则迭代过程可表示为 $C_{i+1}=F(C_i,E_i)$。只有功能测试通过且预设的时序与资源约束得到满足时，候选模块才进入封装阶段。若达到迭代上限或连续修正未能消除错误，流程终止并保留失败记录，由人工检查模块规格、测试平台或实现方案。该条件防止智能体将未通过验证的候选代码直接纳入工具集合。

### 4.6.3 工具封装与能力边界

通过验证的 RTL 模块与第 4.5 节所述的总线封装、参数模式、Python 硬件类和画布节点类关联，形成具有明确端口、参数及验证记录的候选工具。候选工具经注册后可为后续模块生成或拓扑设计提供可复用的能力；新增工具又可作为下一轮设计任务的构件，从而构成工具集合的递归扩展。本文所称工具级自迭代，即这一受验证条件约束的能力积累过程，并不涉及大语言模型参数的自主更新。

该闭环属于系统设计，现有代码生成功能尚未完成 Vivado 自动验证与修正流程的集成。即使候选模块通过仿真和静态时序检查，仍须经过系统级集成、比特流生成及板级测试，才能认定其可用于实际 FPGA 控制平台。闭环的收敛率、平均迭代次数与工具复用效果也需在固定任务集上另行评估。

## 4.7 可靠性边界

针对现有画布编辑路径，智能体层的操作约束由多道校验机制叠加构成。按模型输出的流经顺序：

| 层次 | 约束机制 | 阻止的失效 |
|------|---------|-----------|
| 接口层 | 工具 JSON Schema 的 `required` 与类型声明 | 参数缺失、类型错误 |
| 工具层 | 统一异常捕获，错误转结构化返回 | 异常穿透至事件循环 |
| 工具层 | `clear_canvas` 显式确认 | 误清空画布 |
| 隔离层 | 节点存在性与端口索引范围校验 | 越界访问、空引用 |
| 隔离层 | 输入端口独占性检查 | 多驱动冲突 |
| 隔离层 | 仅暴露画布操作，无串口直通 | 绕过协议层的任意硬件写入 |
| 既有层 | 信号类型检查（第三章 3.4.2 节） | 物理含义错误的连线 |
| 既有层 | 实例数上限（`_alloc_index`） | 超出硬件可用模块数 |
| 编排层 | 迭代上限 15 轮 | 不收敛的工具调用循环 |

其中，门面的能力边界限制了模型对运行中硬件的直接操作，既有类型检查则继续约束画布连线。这些机制限制了模型可调用的操作范围，但参数校验与异常处理尚有缺口，不能据此断言所有错误都只影响画布。

仍需指出两处尚未解决的薄弱环节。其一，`set_parameter` 的参数值校验依赖各节点类的 `set_params` 实现，智能体层本身不做范围检查，若某模块的实现对越界值未作防护，模型可能写入非法参数。其二，门面在节点创建后的参数应用失败时未返回完整错误状态，这会使"模块已创建但参数未生效"的状态对模型不可见，可能导致后续推理建立在错误前提上。两者均建议改进，后者的修正尤为直接：将参数应用结果并入返回字典即可。

## 4.8 本章小结

大语言模型智能体通过受限工具编辑画布，利用结构化错误反馈调整操作，并由知识库提供模块语义。针对新模块开发，本文进一步提出基于 Vivado 验证反馈的工具自迭代闭环，以功能、时序和资源约束控制候选模块的封装与复用。现有实现的有效性，以及新增闭环的收敛性和硬件适用性，仍需分别通过交互记录、自动化验证与板级测试予以评估。

# 第五章 实验设计与验证

本章围绕板级性能、平台功能及两类应用建立验证方案。当前综合报告与实验数据尚未归档；表格中的“—”表示尚未取得测量值，不构成性能结论。

## 5.1 应用抽象与验证思路

### 5.1.1 应用的三要素

在本平台上，一个实验应用由三部分完全确定：

| 要素 | 内容 | 配置手段 |
|------|------|---------|
| 拓扑 | 哪些运算模块参与、如何连接 | 路由矩阵的配置字 |
| 参数 | 各模块的增益、系数、阈值 | 总线写入参数 RAM |
| 自动化逻辑 | 状态推进与模块使能的时序决策 | 应用层状态机 |

前两者是数据，第三者是逻辑。这一划分的实际意义是：**凡能以既有模块的重新连接与参数调整表达的实验，都无需改动硬件**；只有当实验需要新的自动化决策流程时，才需要在应用层增加一个状态机模块并重新综合。

两个案例恰好分处这一界线的两侧：PDH 锁定与双梳锁定各自需要专属的状态机（`pdh_state_machine` 与 `SCALO_state_machine`），因而都包含第三要素；但二者的运算层与互联层完全共用，没有为任一应用增加专用的运算模块。

### 5.1.2 状态机作为应用层的载体

应用层状态机的职责不是参与信号运算，而是**决策**：判断当前实验处于哪个阶段，据此门控运算模块的工作状态。其与运算层的交互仅通过两类信号——从数据路由矩阵读入用于判决的信号，向布尔路由矩阵输出复位或使能信号。

这一约定使状态机与被控运算模块之间通过布尔路由矩阵建立连接。状态机不绑定特定 PID 实例，运算模块也不依赖特定状态机，因此可以通过配置改变控制信号的作用对象。

## 5.2 板级性能与平台功能测试方案

### 5.2.1 ADC/DAC 有效位数与信噪比测试

**测试目的**：确定模拟前端的实际有效位数（ENOB）与信噪比，这决定了误差信号的检测精度下限，是第 5.4 节噪声建模的输入参数。

**理论依据**：理想 $N$ 位量化器的信噪比上限为

$$
\mathrm{SNR}_{\max} = 6.02N + 1.76\ \mathrm{dB}
$$

对 16 位系统即 98.1 dB。实测值必然低于此上界，差值来自孔径抖动、参考电压噪声、输入缓冲非线性与 FPGA 内部定点截断。由实测信噪比可反推有效位数：

$$
\mathrm{ENOB} = \frac{\mathrm{SNR}_{\mathrm{measured}} - 1.76}{6.02}
$$

采样时钟抖动 $\sigma_t$ 对信噪比的限制为

$$
\mathrm{SNR}_{\mathrm{jitter}} = -20\log_{10}(2\pi f_{in}\sigma_t)
$$

当该项与量化噪声可比时成为主导因素，故需在不同输入频率下测量以分离两项贡献。

**测试方法**：向 ADC 输入低噪声单频正弦信号，经 FPGA 内部的数据记录模块（`modules/data_logger/`）或波形存储上传通路（`modules/waveform_storage_upload/`，含 DDR4 缓存与以太网回传）采集时域数据，在上位机做 FFT 分析，由基波与噪声底的功率比计算 SNR、SINAD 与 ENOB。DAC 测试则由 FPGA 内部 DDS 产生单频信号，经 DAC 输出后用频谱分析仪测量。

**测试步骤**：
1. 完成板级初始化（`boards.py` 中对应板卡的 `init_*` 函数），确认 AD9528 / AD9680 / AD9152 均通过锁定校验；
2. 输入信号源经带通滤波后接入 ADC 通道，幅度设为满量程的约 −1 dBFS；
3. 采集不少于 $2^{16}$ 点数据，加窗后做 FFT；
4. 分别在若干输入频率下重复，以区分量化噪声与抖动贡献。

| 指标 | 通道 A | 通道 B | 测量条件 | 获取方法 |
|------|--------|--------|---------|---------|
| SNR (dB) | — | — | — | FFT 分析 |
| SINAD (dB) | — | — | — | FFT 分析 |
| ENOB (bit) | — | — | — | 由 SINAD 换算 |
| THD (dB) | — | — | — | FFT 谐波分量 |
| 噪声底 (dBFS/Hz) | — | — | — | FFT 本底 |

> 上表数据须在完成实测后填入，测量方法见本节正文。同时应记录实际使用的 ADC/DAC 子卡型号与采样率（对应第二章 2.3.3 节的待补充项）。

**本节所需实验条件**：低相噪信号源、带通滤波器、频谱分析仪、示波器、稳压电源。

### 5.2.2 系统环路延迟测量

**测试目的**：测定闭环系统的总延迟，这是决定控制带宽上限的关键参数，直接检验第二章 2.7.2 节的延迟预算推算。

**理论依据**：按第二章 2.1.5 节的分析，延迟 $\tau$ 在频率 $\omega$ 处引入附加相移 $\Delta\phi = -\omega\tau$。若要求相位裕度不低于 $\varphi_m$，单位增益带宽上限为

$$
f_{UGF} \le \frac{1}{2\pi\tau}\left(\frac{\pi}{2} - \varphi_m\right)
$$

取 $\varphi_m = 45°$ 时简化为 $f_{UGF} \lesssim 1/(8\tau)$。

**测试方法**：采用阶跃响应法与频响法两种方式交叉验证。

*阶跃响应法*：配置信号路由矩阵建立"ADC 输入 → 待测链路 → DAC 输出"的开环通路，在 ADC 输入端施加阶跃信号，用示波器同时观测输入与 DAC 输出，两者跳变的时间差即为总延迟。该方法直观但分辨率受示波器带宽限制。

*频响法*：以网络分析仪或信号源+锁相放大器测量开环链路的相频特性，由相位斜率求群延迟 $\tau = -d\phi/d\omega$。该方法精度更高，且可分辨延迟的频率依赖性。

**延迟分解**：总延迟应分项核算以便定位优化空间：

| 环节 | 理论估算 | 实测 | 说明 |
|------|---------|------|------|
| 模拟前端 + 抗混叠滤波 | — | — | 群延迟 |
| ADC 转换与输出流水线 | — | — | 查器件手册 + 实测 |
| 采样保持等效延迟 | $T/2 = 2$ ns | — | 理论值，$T = 4$ ns |
| 信号路由矩阵 | 1 周期 = 4 ns | — | 第二章 2.7.2 节 |
| 混频器 | 2 周期 = 8 ns | — | 同上 |
| FIR 滤波器 | 7 周期 = 28 ns | — | 同上 |
| PID 控制器 | 3 周期 = 12 ns | — | `buf_none` 配置 |
| DAC 建立时间 | — | — | 查器件手册 + 实测 |
| 执行器响应 | — | — | 取决于 AOM/EOM/压电 |
| **总计** | — | — | |

表中 FPGA 延迟为依据寄存结构得到的估计值，模拟链路延迟与总延迟尚需测定。完成测量后，应按上述公式计算带宽约束，并与实际闭环带宽比较。

**本节所需实验条件**：示波器（带宽不低于 500 MHz）、网络分析仪或锁相放大器、信号源。

### 5.2.4 DDS 信号生成质量分析

**测试目的**：验证第二章 2.6.1 节所述 DDS 的频率精度、相位噪声与杂散抑制，确认其可作为 PDH 调制信号源与扫描信号源。

**理论依据**：$N$ 位相位累加器截断至 $M$ 位输出时，相位截断引入的杂散分量最大幅度约为

$$
\mathrm{SFDR} \approx 6.02M\ \mathrm{dB}
$$

本系统 $N = 64$、输出取高 16 位（$M = 16$），理论杂散抑制约 96 dB。频率分辨率为 $f_{clk}/2^{64} \approx 1.36\times10^{-11}$ Hz。CORDIC 的 19 级迭代与 24 位内部精度引入的幅度误差亦贡献杂散，需实测区分。

**测试方法**：配置累加器与 CORDIC 构成正弦发生器（可直接使用复合模块"正弦波发生器"），经 DAC 输出后用频谱分析仪测量。

2. 用频率计测量实际输出频率，与设定值比对验证频率精度；
3. 用频谱分析仪测量杂散抑制比与相位噪声谱；
4. 在若干频率点（覆盖低频至接近奈奎斯特频率）重复测量。

## 5.3 PDH 锁定应用实现

本节依据第一章的 PDH 鉴频原理，分析自动锁定状态机的判定条件、参数标定方法及其与反馈环路的时序关系。扫描、捕获与锁定决策由 FPGA 内部逻辑完成，其实际响应时间仍需结合模块延迟进行测定。

### 5.3.1 物理约束决定的设计要求

第一章 1.3.4 节给出了一个关键推论：PDH 鉴频斜率 $D = -8\sqrt{P_cP_s}/\delta\nu$ 与腔线宽成反比，因此高灵敏度必然伴随窄捕获范围——线性区仅约一个腔线宽。对于精细度 $10^4$ 量级的参考腔，这意味着误差信号的有效区间远窄于激光的自由运转漂移范围。

由此可得两项设计要求：首先，系统应扫描激光频率或腔长以定位共振，再切换至闭环控制；其次，捕获判定与环路切换延迟应小于扫描信号通过有效鉴频区间所需的时间。因此，相关状态判定由 FPGA 内部逻辑完成。

### 5.3.2 接口与状态划分

状态机接收 256 位配置参数、16 位误差信号及 16 位扫描波形，输出 PID、混频器和锯齿波发生器的控制信号。三路控制信号采用低有效约定，其具体取值由相应状态决定。状态集合包括空闲态（`IDLE`）、自动幅度标定态（`AUTO_AMP`）、自动时间标定态（`AUTO_TIME`）、等待态（`AUTO_WAIT`）、自动扫描态（`AUTO_SCANNING`）、手动扫描态（`SCANNING`）、自动锁定态（`AUTO_LOCKING`）和手动锁定态（`LOCKING`）。其中自动与手动控制分别形成独立的状态转移路径。

八个状态构成两条并行的分支链路：

**手动链路**（由上位机指定阈值）：
$$
\texttt{IDLE} \xrightarrow{\texttt{pc\_cmd}=01} \texttt{SCANNING} \xrightarrow{\text{信号持续低于扫描阈值}} \texttt{LOCKING} \xrightarrow{\text{上位机撤销锁定命令}} \texttt{IDLE}
$$

**自动链路**（硬件自行标定阈值）：
$$
\texttt{IDLE} \xrightarrow{\texttt{pc\_cmd}=10} \texttt{AUTO\_WAIT} \to \texttt{AUTO\_AMP} \to \texttt{AUTO\_TIME} \to \texttt{AUTO\_SCANNING} \to \texttt{AUTO\_LOCKING}
$$

状态跳转由两位命令字 `pc_cmd`（来自参数总线地址 0x00 的最低两位）与锯齿波回扫沿 `sawtooth_jump` 共同驱动。

### 5.3.3 锯齿波回扫沿检测

自动标定的各阶段以扫描周期为单位推进，因此需要检测扫描波形的回扫边界。判据要求相邻采样的符号位翻转，且当前采样的符号位与次高位相异，以排除零点附近的小幅抖动。

### 5.3.4 自动幅度标定与阈值计算

自动幅度标定和时间标定分别确定信号判定阈值及持续时间门限。

在 `AUTO_AMP` 状态下，极值寄存器在一个完整扫描周期内逐点更新，得到误差信号的最小值 $V_{min}$ 和最大值 $V_{max}$。

两个极值寄存器在进入该态时被初始化为相反的极端值（`min_sig_in` 置为最大正值、`max_sig_in` 置为最小负值），以保证首个采样即可正确更新。

阈值经峰峰值求差、系数缩放和基准值相加三级流水计算，其关系为

$$
V_{th} = V_{min} + (V_{max} - V_{min}) \cdot c
$$

其中系数 $c$（`coef_scan` 与 `coef_lock`）为 Q1.15 格式的 16 位有符号数，由上位机配置。扫描阈值与锁定阈值使用各自独立的系数，因而可设置不同的判定水平——通常锁定判据应比扫描判据更严格，以避免在共振峰边缘误判为已锁定。

这一相对阈值方案的优势在于**自适应于信号幅度**。激光功率漂移、光路耦合效率变化、探测器增益差异都会改变误差信号的绝对幅度，固定阈值在此情况下需频繁重新标定；而相对阈值仅依赖峰峰值的比例，对幅度变化的敏感性较低，实际适应范围待测。这一点对长时间无人值守运行尤为重要。

在 `AUTO_TIME` 状态下，系统测量误差信号连续低于扫描阈值的时长 $T_m$，并分别以 $T_m/2$ 和 $4T_m$ 作为扫描判定门限与锁定判定门限。

扫描判定时长取测得值的一半，锁定判定时长取四倍——两者均以移位实现，无需乘法器。取半的用意是使扫描阶段的判定比实测的共振峰宽度更宽松以确保捕获，取四倍则使锁定阶段的失锁判定更为迟缓以避免瞬态扰动引发误判。

仅当 $T_m$ 超过 500 个系统时钟周期（250 MHz 下为 2 μs）时，测量结果才被接受；该门限用于排除持续时间较短的扰动。

### 5.3.5 判定与锁定交接

**`AUTO_SCANNING` 态**执行持续时间判定：信号低于阈值时计数器累加，达到 `auto_time_duration_scanning` 则转入锁定；信号一旦高于阈值即将计数器清零。这一"连续满足"而非"瞬时满足"的判据有效抑制了噪声尖峰造成的误锁定。

**`AUTO_LOCKING` 态**置 `pid_enable <= '0'`、`mixer_enable <= '0'`（低有效，即启用 PID 与混频器），同时 `sawtooth_enable <= '1'` 停止扫描，系统进入闭环锁定。

状态机通过布尔路由矩阵控制相位累加器的暂停输入与 PID 的自动复位输入。在状态转移对应的时钟沿，扫描斜坡保持当前偏置，同时解除 PID 复位，使控制作用由扫描过程切换为闭环反馈。实际交接延迟还应包括路由及运算流水级，需通过时序仿真确认。

### 5.3.6 关于自动重锁机制

当前状态转移逻辑尚未包含由 `AUTO_LOCKING` 返回 `AUTO_SCANNING` 的自动重锁路径。在锁定判据不再满足时，状态机仅清零相关计数器，不触发重新扫描。

离开该状态的唯一路径是 `pc_cmd` 被上位机改写为 `"00"` 或 `"11"` 而回到 `IDLE`。手动链路的 `LOCKING` 态同理。因此当前的失锁恢复仍需上位机介入，不属于硬件自主重锁。

后续可在失锁持续时间超过预设门限时增加由自动锁定态至自动扫描态的转移，并复用已经标定的阈值和时间参数。该机制的误触发概率与恢复时间应通过实验评估。

### 5.3.7 参数地址映射与平台集成

模块的可配置参数经 `parameter_ram_256` 映射如下：

| 地址 | 位段 | 参数 | 类型 |
|------|------|------|------|
| 0x00 | `[1:0]` | `pc_cmd` | 2 位命令字 |
| 0x01 | `[47:32]` | `threshold_signal_locking` | signed 16 |
| 0x02 | `[79:64]` | `threshold_signal_scanning` | signed 16 |
| 0x03 | `[127:96]` | `time_duration_scanning` | unsigned 32 |
| 0x04 | `[159:128]` | `time_duration_locking` | unsigned 32 |
| 0x05 | `[175:160]` | `coef_scan` | signed 16, Q1.15 |
| 0x06 | `[207:192]` | `coef_lock` | signed 16, Q1.15 |

该模块在片内总线上的地址为 26（`BUS_PDHS_ADDR`）。顶层 `Top.vhdl` 中的连接关系为：`sig_in` 接 `sig_bank_out(37)`，`saw_input` 接 `sig_bank_out(38)`，三路使能输出接 `ctrl_bank_in(2..4)`——即状态机的输入输出同样经过信号路由矩阵，其连接关系亦可由上位机动态配置。

这一点体现了第二章分层结构的价值：状态机并未被硬连线到特定的 PID 或混频器实例。实验者可以在运行时改变"由哪一路信号触发判决"、"复位哪一个 PID"，而无需修改状态机代码。

### 5.3.8 典型拓扑

一个完整的 PDH 锁定构型涉及五个模块与九条连线，其数据流为：

$$
\text{累加器} \to \text{CORDIC} \xrightarrow{\cos} \text{混频器} \xrightarrow{\text{解调}} \text{PID} \to \text{累加器（反馈）}
$$

其中累加器产生扫描斜坡与调制参考相位，CORDIC 将相位转为正交本振，混频器以余弦分量解调探测器信号得到误差信号，PID 计算校正量回授至累加器。PDH 状态机则并联于该链路之外，读入判决信号与斜坡信号，输出三路使能。

该拓扑的连线清单记录于上位机配置例程和智能体知识库，可用于重复配置与连通性验证。

## 5.5 双光梳自校准本振应用实现

本节给出第二个应用案例。其意义在于：该应用与 PDH 在控制对象、信号类型与自动化策略上均不相同，却完全复用了同一套运算层与互联层。

### 5.5.1 应用背景与控制目标

光学频率梳的输出可由两个射频参量完全描述：重复频率 $f_r$ 与载波包络偏移频率 $f_{ceo}$，第 $n$ 根梳齿的频率为

$$
\nu_n = n f_r + f_{ceo}
$$

双光梳系统的拍频信号包含两台梳源的重复频率差与载波包络偏移频率差。维持相干需要分别控制这些差频；本节讨论其中本振频率偏差的估计与补偿。

与 PDH 的关键差异在于**被控量的性质**。PDH 中误差信号是一个幅度量（解调后的电压），其零点对应共振；而此处被控量是两个信号之间的**相位差**，须先由相位检测得到，且相位量具有模 $2\pi$ 的周期性。第二章 2.1.3 节所述的 CORDIC 向量模式与相位解卷绕模块正是为处理这类信号而设。

### 5.5.2 自校准本振的必要性

锁相检测要求本振频率与待测信号频率一致。但在双梳系统中，拍频的频率取决于两台梳源的实际状态，开机时并不精确已知，且会随环境漂移。若本振频率与信号频率存在偏差 $\Delta f$，则检测到的相位将以 $2\pi\Delta f$ 的速率持续累积，表现为相位的线性斜坡而非围绕定值的波动——此时环路无法锁定。

传统做法是人工测量拍频并手动设置本振频率。`SCALO_state_machine`（SCALO 即 self-calibrating local oscillator，自校准本振）将这一过程自动化：**先测量相位的漂移速率以推算频率偏差，再把该偏差补偿进本振的相位增量，然后才启动 PID**。

其原理可由相位与频率的关系直接给出。本振与信号的瞬时相位差为

$$
\phi(t) = 2\pi \Delta f \, t + \phi_0
$$

对其求导即得频率偏差：

$$
\Delta f = \frac{1}{2\pi}\frac{d\phi}{dt}
$$

在离散时间下，相位差分 $\phi[n] - \phi[n-1]$ 正比于 $\Delta f$。因此只需测得相位的平均差分，即可求出应补偿的本振频率增量。

### 5.5.3 实现结构

自校准本振状态机由相位差分、滑动窗平均、偏置更新和 PID 使能四部分构成。其输入为相位解算模块输出的 16 位相位序列，输出为 16 位本振相位偏置和一路 PID 复位信号；64 位配置字用于传递控制参数。数据端口与控制端口分离，符合第 2.4.4 节给出的模块接口约定。

设输入相位序列为 $\phi[n]$。相位差分器按相邻采样计算 $d[n]=\phi[n-1]-\phi[n]$，其符号决定本振偏置的修正方向。为降低差分对高频噪声的敏感性，采用长度为 $N=256$ 的滑动窗估计平均相位增量。窗口和通过递推式

$$
S[n]=S[n-1]+d[n]-d[n-N],\qquad \bar d[n]=\frac{S[n]}{N}
$$

更新。该结构每个采样周期仅需一次加法和一次减法，存储开销为 256 个差分样本。硬件通过截取累加结果的相应位实现除以 $2^8$ 的定点缩放。若差分样本可视为相互独立的白噪声样本，256 点平均使噪声标准差理论上降低至原来的 $1/16$；由于相邻差分可能存在相关性，实际抑噪效果仍需通过实验测定。

控制流程包含空闲、校准和锁定三个状态。锁定指令的上升沿触发偏置更新，并使状态机进入校准状态；经过 128 个系统时钟周期后进入锁定状态。对于 250 MHz 时钟，该等待时间为 512 ns，用于使更新后的频率控制量沿流水线传播。锁定指令撤销后，状态机返回空闲状态。

偏置寄存器采用增量更新方式，即每次触发时将当前测得的平均差分叠加至既有偏置；清零指令将其复位。该结构允许重复校准，但其收敛范围与精度取决于相位测量误差和定点量化，需要通过第 5.6 节的实验验证。PID 复位信号仅在锁定状态解除，以避免校准期间的频率失配进入积分器。上述时序使本振校准与闭环控制按顺序执行。

### 5.5.4 与 PDH 应用的结构类比

尽管物理场景不同，两个应用在控制结构上呈现出清晰的对应关系：

| 环节 | PDH 锁定 | 双梳自校准本振锁定 |
|------|---------|------------------|
| 被控量 | 幅度量（解调电压） | 相位量（相位差） |
| 捕获前的未知量 | 共振位置、信号幅度 | 拍频频率 |
| 自动标定对象 | 幅度阈值、时间门限 | 本振频率偏置 |
| 标定方法 | 扫描一周期取极值 | 相位差分 + 256 点滑动平均 |
| 标定所需时间 | 一个扫描周期 | 128 周期（约 512 ns） |
| 交接动作 | 冻结斜坡 + 释放 PID | 补偿本振 + 释放 PID |
| 状态数 | 8 | 3 |

共同的模式是：**先以开环方式测量未知参量，再据测量结果配置环路，最后才闭合反馈**。这一"测量—配置—闭环"的三段式流程是两类实验自动化的共同骨架，差异仅在于被测量的物理量与测量方法。

平台对这一共性的支持体现在第二章 2.4.6 节的自动复位契约：两个状态机都通过同一机制门控 PID，而无需各自实现专属的使能通路。

> 需说明：5.6.1 与 5.6.2 两项**无需真实双梳光源**，以信号源即可完成，成本低且可先行开展；5.6.3 则须完整的光学装置。

## 5.7 平台通用性与适用边界

### 5.7.1 通用性的三个来源

两个案例共用同一套硬件，其可能性来自三项机制，均在第二章确立：

**运算模块与物理场景分离。** PID 控制器和混频器分别执行确定的数学变换，其输入、输出的物理含义由应用拓扑决定。因此，同一类运算模块可以用于不同控制任务。

**其二，互联的运行时可配。** 两个应用的拓扑差异（PDH 用混频器解调，双梳用 CORDIC 向量模式解相位）完全由路由矩阵的配置字表达，无需重新综合。切换应用预计需要数十次寄存器写入，完整耗时仍需实测。

**其三，控制信号的可路由性。** 布尔矩阵使"哪个状态机复位哪个 PID"成为运行时可配的关系。这是两个状态机能够共存于同一比特流、并按需启用其一的前提。

### 5.7.2 边界与代价

需客观指出平台通用性的限度。

**新的自动化流程仍需重新综合。** 如 5.1.1 节所述，若实验需要一种既有状态机都无法表达的决策逻辑，须新增应用层模块并重新综合。平台降低的是拓扑调整的成本，而非逻辑开发的成本。第四章的代码生成工具针对的正是这一环节的样板代码负担。

**模块实例数构成硬上限。** 每类模块的实例数在综合时固定（如 PID 为 2 个实例），超出即无法实现。这使平台当前难以支持多路激光同时锁定，相关讨论见第六章。

**资源代价由全部应用共同承担。** 固化全部模块意味着即使当前只运行 PDH 实验，双梳应用所需的 CORDIC、解卷绕器与 SCALO 状态机仍占据芯片面积。这是通用性的直接代价，也是第二章 2.5.3 节所述平方增长问题的一部分。

### 5.7.3 对微纳光学实验的适用性讨论

本章两类应用均涉及频率或相位控制。对于其他微纳光学实验，现有模块是否适用还取决于信号频带、执行器接口、环路延迟和所需控制算法，不能仅由拓扑相似性判断。

微腔热锁定等场景可作为后续研究对象；其适用性须通过对应的接口、带宽和控制性能测试确认。

## 5.8 本章小结

本章把板级能力、路由与 DSP 功能以及两类应用置于同一验证框架。PDH 与双光梳的 RTL 实现可说明平台能够表达不同控制流程；跨应用运行、锁定性能和通用性强度须以实测数据判定。

# 第六章 总结与展望

本章归纳平台架构、实现方法及两类应用的设计结果，讨论现阶段证据能够支持的结论，并提出后续验证与改进方向。

## 6.1 研究工作总结

本文面向微纳光学实验中反馈控制结构随应用变化、控制链路对延迟敏感的需求，设计了一套基于 Kintex UltraScale FPGA 的数字控制平台。研究工作包括光学锁定与数字控制约束分析、硬件与互联架构设计、上位机参数映射、智能体辅助配置，以及 PDH 锁定和双光梳本振校准两类应用逻辑的实现。

在理论分析方面，本文建立了 PDH 误差信号、鉴频斜率与稳频评价指标之间的联系，并依据双光梳拍频关系推导了相位差分估计频率偏差的依据。对数字环路中的量化、流水线延迟和相位裕度进行分析后，给出了环路延迟约束控制带宽的关系。上述分析为模块位宽、反馈路径和自动捕获流程的设计提供了依据。

在硬件架构方面，平台将运算单元与连接关系分离：运算资源在综合时确定，数据与控制信号的连接由运行时寄存器配置。应用层、运算层、互联层和接口层分别承担实验逻辑、定点运算、信号路由及参数传输。系统以 250 MHz 主时钟和 16 位定点数据通路为基础，实现 64 路数据与 64 路控制信号的独立交叉路由，以及相位累加器、CORDIC、FIR、IIR 和 PID 等运算模块。统一接口、可选输入输出缓冲和参数保持提交机制使不同模块能够按相同规则接入平台。

在软件层面，上位机以驱动、协议、硬件抽象和应用四层结构完成物理参数到寄存器配置的映射，并通过节点编辑器将画布连接映射为路由配置。智能体在此基础上提供自然语言辅助配置能力，模型操作由工具接口和画布校验机制约束。该功能属于非实时交互层，其有效性与安全边界尚需按第五章的方案进行量化评估。

在应用层面，本文分别构建了 PDH 自动扫描与锁定状态机、双光梳本振频率偏差估计与校准状态机。两者使用相同的运算模块和互联机制，说明现有资源能够表达不同的控制流程。然而，目前尚缺少跨应用运行记录、光学锁定性能数据及综合时序报告，因此平台通用性与性能结论仍需实验验证。

## 6.2 主要结论

### 6.2.1 运算与互联分离的可配置架构

通过将模块实例与模块间连接分别处理，平台能够在既有资源范围内以寄存器配置改变信号拓扑。数据路由和布尔控制路由分离，使复位、使能等控制信号也可纳入配置过程。这一结构在实现层面支持多种控制链路的复用；拓扑切换时间、切换扰动及其相对于重新综合的收益，仍须以实测数据确定。

全交叉结构的代价是选择逻辑和布线需求随端口数增长。对于当前的 64 路配置，该代价需要通过资源利用率与静态时序报告评估。在更大规模下，可研究分级交换结构，但其额外延迟和可表达拓扑范围也必须同时纳入比较。

### 6.2.2 面向不同被控量的应用复用

PDH 应用以解调后的幅度信号作为误差量，需要扫描捕获窄线宽共振，并在捕获时切换至 PID 反馈。双光梳应用以相位为观测量，需要先估计本振频率偏差，再进入闭环控制。两类逻辑分别采用八态和三态状态机，但均可归纳为测量、参数配置和闭环控制三个阶段。

两类应用共享现有运算层与互联层，无需新增专用运算单元。这一结果支持架构的复用能力；具体锁定稳定度、捕获概率和校准精度仍不能仅由设计结构推断，须通过第五章所列实验测定。

### 6.2.3 参数映射与受约束的辅助配置

上位机将频率、转折频率和增益等物理量映射为定点寄存器值，并通过保持提交机制协调多寄存器更新。画布端口的信号类型约束可在连线阶段拒绝部分物理语义不相容的配置。智能体通过受限工具调用这些既有能力，并接收结构化错误信息以调整后续操作。

上述机制形成了从实验参数描述到硬件配置的分层路径。其正确性需分别通过参数回读、拓扑连通性及任务成功率验证；模型服务差异和参数边界检查的完整性也应纳入评价。

## 6.3 局限与后续工作

### 6.3.1 补充实验与实现证据

目前缺少目标器件的资源利用率、时序收敛和关键路径报告，也缺少两类应用的连续运行数据。模块延迟主要依据寄存器结构估计，其中递归滤波器的实际延迟尤其需要行为仿真和硬件测量确认。后续应优先完成路由切换、参数原子更新、状态机转移以及智能体离线拓扑生成测试，再开展闭环带宽、残余误差谱和长期稳定度测量。所有性能结论均应明确测量条件、仪器配置和不确定度。

### 6.3.2 完善失锁恢复与模块扩展

当前 PDH 自动锁定状态缺少自主返回扫描状态的转移路径，失锁后的恢复需要上位机介入。后续可利用已标定的幅度和时间门限建立失锁判定，再触发重新扫描；其误触发率和恢复时间需要实验评估。模块实例数在综合时固定，多通道并行锁定会受到资源数量限制。扩大规模时应联合优化路由拓扑、运算资源复用及闭环延迟。

### 6.3.3 改进参数校验与知识维护

智能体参数写入仍依赖各节点实现的局部校验，部分参数失败情形缺少完整的结果反馈。后续应统一参数取值范围、量化规则和失败返回结构，并将模块端口定义收敛为单一数据来源，以减少画布描述与硬件配置不一致的风险。代码生成器当前主要生成接口与封装框架，算法主体、定点误差分析及流水线设计仍需人工完成。

## 6.4 结语

本文给出了面向微纳光学反馈实验的可配置数字控制平台架构，并完成主要软硬件模块与两类应用控制逻辑的实现。运算与互联分离、物理参数映射及受约束的辅助配置，为不同实验流程复用同一硬件资源提供了设计依据。平台的性能优势与适用范围尚需以完整的综合报告、功能测试及光学实验结果进一步确认。
