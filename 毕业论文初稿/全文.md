# 摘要

精密物理测量对激光频率稳定度的要求日益严苛，而传统模拟 PDH 锁定模块受温漂、连线复杂与不易重构的制约，现有商用数字锁频产品则在通道数、互联灵活性与自动化程度上难以满足多方案并行探索的实验需求。本文设计并实现了一套基于 Xilinx Kintex UltraScale FPGA 的全数字自动激光 PDH 锁定系统，覆盖从物理原理分析、硬件平台搭建、RTL 逻辑设计到上位机软件开发的完整链路。

理论方面，本文自 Fabry–Pérot 腔的反射特性出发，经相位调制光场的边带展开推导了 PDH 误差信号的完整表达式，给出近共振线性区的鉴频斜率 $D = -8\sqrt{P_cP_s}/\delta\nu$，并建立了环路延迟 $\tau$ 与控制带宽上限的定量关系 $f_{UGF} \le \frac{1}{2\pi\tau}(\frac{\pi}{2}-\varphi_m)$，该关系贯穿后续全部设计决策。

系统以 250 MHz 系统时钟与 16 位有符号定点数据通路为基础。架构的核心特征是一个 $64\times64$ 全交叉信号路由矩阵，将全部功能模块的输入输出纳入统一可配置互联网络，使信号链路重构由重新综合布线降为寄存器写入，配置字中的保持位进一步实现无扰动切换。在矩阵之上实现了完整的定点信号处理模块库，包括 64 位相位累加器、19 级 CORDIC 运算器、64 抽头 FIR、采用四阶散射前瞻变换的并联双二次 IIR，以及具备两级限幅抗饱和与漏积分的 48 位 PID 控制器。自动锁定流程下沉至硬件，实现为八态 PDH 锁定状态机，其中 `AUTO_AMP` 与 `AUTO_TIME` 两态构成自动参数标定环节，按 $V_{th} = V_{min} + c\,(V_{max}-V_{min})$ 导出相对阈值，使系统对激光功率漂移与探测器增益差异免疫。

上位机软件构建了驱动层、协议层、硬件抽象层与应用层四层结构，以总线 `HOLD` 命令、硬件信号分离与软件间接参数序列三者协同实现超宽参数的原子化更新，并完成寄存器整数值与物理量的双向换算。在此之上实现了可视化节点编辑器，其画布拓扑直接映射硬件路由配置，并以四类信号类型的设计期检查将一类物理含义错误前移至连线阶段；进一步集成基于大语言模型的智能体层，支持自然语言生成实验拓扑。

本文同时设计了覆盖板级性能、功能验证与激光锁定实验三个层次的测试方案，并安排了交叉验证环节以确认硬件实现与理论分析的自洽性。需要说明的是，本稿的实验数据尚待补齐，第四、六章中以【待测】标注之处需在实测后回填。

# Abstract

Precision physical measurements place increasingly stringent demands on laser frequency stability. Conventional analog PDH locking modules are limited by thermal drift, wiring complexity, and poor reconfigurability, while existing commercial digital laser-servo products fall short in channel count, interconnect flexibility, and automation when experiments require exploring multiple control schemes in parallel. This thesis presents the design and implementation of a fully digital automatic laser PDH locking system based on a Xilinx Kintex UltraScale FPGA, spanning the complete chain from physical principle analysis and hardware platform construction through RTL logic design to host software development.

On the theoretical side, starting from the reflection characteristics of a Fabry–Pérot cavity and proceeding through the sideband expansion of a phase-modulated optical field, the complete expression for the PDH error signal is derived, yielding the discriminator slope near resonance, $D = -8\sqrt{P_cP_s}/\delta\nu$. The quantitative relation between loop delay $\tau$ and the upper bound on control bandwidth, $f_{UGF} \le \frac{1}{2\pi\tau}(\frac{\pi}{2}-\varphi_m)$, is established and informs every subsequent design decision.

The system is built on a 250 MHz system clock with a 16-bit signed fixed-point datapath. Its defining architectural feature is a $64\times64$ fully crossed signal routing matrix that brings the inputs and outputs of all functional modules into a single configurable interconnect, reducing signal-chain reconfiguration from re-synthesis and re-routing to a register write; a hold bit in each configuration word further enables glitch-free switching. Above the matrix, a complete fixed-point signal processing module library is implemented, comprising a 64-bit phase accumulator, a 19-stage CORDIC engine, a 64-tap FIR filter, a parallel biquad IIR filter employing a fourth-order scattered look-ahead transformation, and a 48-bit PID controller with two-stage anti-windup clamping and leaky integration. The automatic locking procedure is moved into hardware as an eight-state PDH locking state machine, in which the `AUTO_AMP` and `AUTO_TIME` states form an automatic parameter calibration stage that derives a relative threshold as $V_{th} = V_{min} + c\,(V_{max}-V_{min})$, rendering the system immune to laser power drift and detector gain variation.

The host software is organized into driver, protocol, hardware abstraction, and application layers. Atomic updates of parameters wider than the bus are achieved through the coordinated action of a bus `HOLD` command, separated hardware write-enable signals, and an indirect-parameter write sequence in software; bidirectional conversion between register integers and physical quantities is also provided. A visual node editor maps canvas topology directly onto hardware routing configuration and applies design-time checking over four signal types, moving a class of physical-semantic errors forward to the wiring stage. An LLM-based agent layer is integrated on top, enabling experimental topologies to be generated from natural language descriptions.

A three-tier test plan covering board-level performance, functional verification, and laser locking experiments is also presented, with cross-validation steps included to confirm consistency between the hardware implementation and the theoretical analysis. It should be noted that experimental data for this draft remain to be collected; points marked 【待测】 in Chapters 4 and 6 are to be filled in after measurement.

**Keywords**: laser frequency stabilization; PDH locking; FPGA; fully digital control; signal routing matrix; automatic parameter calibration; PID controller; hardware-software co-design

# 第一章 绪论

本章阐述激光频率稳定技术在精密物理测量中的作用，分析传统模拟锁定方案与现有商用数字锁频产品的局限，并在此基础上提出本文自研全数字激光锁定系统的研究内容与目标。

## 1.1 研究背景与意义

### 1.1.1 精密物理测量对激光频率稳定度的需求

频率是目前人类能够测量得最为精确的物理量。自光频标与光学频率梳技术成熟以来，以中性原子光晶格钟和单离子光钟为代表的光频标，其系统不确定度与频率稳定度已进入 $10^{-18}$ 量级 [1]，较基于铯原子微波跃迁的秒定义提升了两个数量级以上。这一进展直接支撑了基本物理常数测量、相对论大地测量、暗物质候选粒子搜寻以及引力波探测等前沿研究，同时也推动了"秒"的重新定义进程。

在上述所有应用中，激光器都充当连接原子跃迁与可观测信号的桥梁，其频率噪声直接决定了测量的极限精度。以光晶格钟为例，钟激光的线宽与短期稳定度决定了原子跃迁谱线的可分辨程度；由于量子投影噪声与 Dick 效应的存在，钟跃迁探询激光的频率噪声会经由采样过程混叠到钟的输出，成为限制稳定度的主要技术噪声之一。而自由运转的半导体激光器或固体激光器，受增益介质自发辐射、谐振腔机械振动、温度漂移与泵浦源噪声的共同作用，其线宽通常在百千赫兹至兆赫兹量级，频率漂移可达每秒数兆赫兹，与光频标所需的赫兹乃至亚赫兹线宽相差六个数量级以上。因此，必须引入外部频率参考与伺服反馈，将激光频率锁定到一个稳定的鉴频器上。

高精细度 Fabry–Pérot（F-P）光学参考腔正是这样一个鉴频器。将激光锁定到超稳腔的本征模式上，可以把腔长的稳定度转移为激光频率的稳定度。Pound–Drever–Hall（PDH）技术 [2,3] 通过对入射光进行相位调制并对腔反射光作同步解调，得到一个在共振点附近线性、过零且斜率陡峭的误差信号，是实现这一转移的标准手段。借助低热膨胀材料腔体、振动隔离与温度控制，PDH 锁定已实现亚赫兹量级的激光线宽 [4]。

然而，PDH 技术给出的只是误差信号；把误差信号转化为对激光频率的有效抑制，依赖于伺服电子学。伺服环路的增益、带宽、相位裕度以及自身的电子学噪声，共同决定了最终可达到的频率稳定度。在腔体与隔振技术日趋成熟的今天，伺服电子学的性能与可靠性常常成为系统的实际瓶颈，这也是本文研究的出发点。

### 1.1.2 传统模拟锁定模块的局限性

长期以来，PDH 伺服环路主要由分立的模拟电路模块实现：混频器完成解调，运算放大器构成的比例–积分–微分（PID）网络提供环路增益，再经高压放大器驱动压电陶瓷（PZT）或经电流调制端口驱动激光二极管。模拟方案的优势在于不存在采样延迟与量化噪声，理论上可以获得极高的单位增益带宽。但在工程实践中，它存在若干难以回避的问题。

首先是直流漂移与温度稳定性。模拟积分器的输出会随运算放大器的输入失调电压及其温漂而缓慢移动，混频器的直流偏置同样随环境温度变化。这些漂移在误差信号中表现为一个随时间变化的虚假零点，使激光锁定在偏离腔共振中心的位置上，并引入难以区分的长期频率漂移。

其次是参数调节的不可重复性。模拟 PID 的增益与转折频率由电阻、电容的具体取值确定，调节依赖电位器或更换元件。这使得环路参数既无法精确记录和复现，也无法在实验过程中按需快速扫描寻优；在需要多台激光器同时锁定的系统中，逐台手工整定的工作量迅速变得不可接受。

第三是互连复杂与串扰。一套完整的 PDH 系统通常需要本振源、相移器、混频器、低通滤波器、伺服放大器、扫描斜坡发生器、高压放大器等多个独立机箱，彼此以同轴电缆连接。连线数量随通道数呈平方增长，不仅引入地环路与射频串扰，也使系统的拓扑一旦确定便难以改动。

第四是功能不可重构。模拟硬件的信号流向由物理连线决定。当实验需求从简单的 PDH 锁定扩展到调制转移光谱、双色锁定、腔长伺服与激光伺服级联等更复杂的方案时，往往意味着重新设计电路板。

最后是自动化程度低。寻找共振、判断是否捕获、失锁后重新捕获等操作在模拟系统中难以实现，通常需要实验人员目视示波器并手动操作扫描幅度与积分开关。这既限制了实验效率，也使长时间无人值守运行难以保证。

### 1.1.3 全数字控制系统的发展现状与优势

随着现场可编程门阵列（FPGA）以及高速模数/数模转换器（ADC/DAC）性能的提升与成本的下降，将伺服环路的信号处理部分整体数字化已成为可行且主流的技术路线 [5]。在全数字方案中，光电探测器输出的射频信号经 ADC 采样后进入 FPGA，在数字域内完成混频解调、滤波、环路整形与状态判决，再经 DAC 输出到执行器。

数字化带来的优势是系统性的。其一，参数的绝对可重复性：增益、滤波器系数、阈值等全部以寄存器数值形式存在，可被精确记录、保存与恢复，为自动整定提供了前提。其二，不存在模拟漂移：数字积分器的状态是一个整数寄存器，不会因温度变化而漂移，直流偏置可以通过数字方式精确扣除。其三，功能由固件定义：同一套硬件通过加载不同配置即可实现 PDH 锁定、锁相放大、频率计数等不同功能，极大提升了设备的复用率。其四，易于实现复杂算法：数字域内可以方便地实现高阶无限冲激响应（IIR）滤波器、CORDIC 相位解算、相位解卷绕等在模拟域中代价高昂或根本无法实现的运算。其五，便于集成与自动化：状态机、数据记录、网络通信可与信号处理共存于同一芯片，使自动锁定、失锁检测与远程监控成为硬件的内生能力。

数字方案固有的代价是采样延迟与量化噪声。采样保持、ADC/DAC 转换以及流水线运算共同构成环路的纯延迟，它在高频处引入与频率成正比的附加相移，从而限制可达到的单位增益带宽；这一机理将在第 2.3 节中定量分析。因此数字伺服设计的核心矛盾，在于以尽可能低的延迟实现尽可能复杂的信号处理。本文采用的高时钟频率、深度流水线与并行结构的设计策略，正是针对这一矛盾展开的。

## 1.2 国内外研究现状

### 1.2.1 商用 FPGA 锁频产品分析

目前已有若干基于 FPGA 的通用化数字伺服产品被广泛用于原子分子光物理实验室，其中以 Liquid Instruments 公司的 Moku 系列（Moku:Lab、Moku:Pro 等）与 Red Pitaya 开源硬件平台最具代表性。两者在架构上具有共同特征：均以 Xilinx Zynq 系列 SoC 为核心，将 ARM 处理器与 FPGA 可编程逻辑集成于单芯片内，由 ARM 端运行 Linux 承担网络通信与用户界面，FPGA 端承担实时信号处理；设备的功能由固件定义，用户通过切换"仪器"固件，使同一硬件分别表现为示波器、锁相放大器、PID 控制器或频率响应分析仪。

Moku 系列采用封闭的商业模式。其硬件设计与 FPGA 固件源码均不公开，用户通过官方应用或 Python/MATLAB 接口调用预定义的仪器功能，可配置的范围限于厂商暴露的参数集。这一模式的优点是开箱可用、指标明确、软件成熟度高，对不以电子学为研究内容的实验室极具吸引力。其局限则在于：用户无法在数据通路中插入自定义运算，不同仪器之间的互连受限于厂商提供的多仪器模式所允许的拓扑；当实验需要一个厂商未预见的信号处理环节（例如特定形式的相位解卷绕、与实验时序深度耦合的自动捕获逻辑）时，便无从下手。其各项具体指标（输入带宽、噪声本底、环路延迟、价格）`[指标待查证]`。

Red Pitaya 走的是另一条路线。其硬件原理图与 FPGA 工程以开源形式发布，用户可以修改 Verilog/VHDL 源码并重新综合，社区亦围绕其发展出 PyRPL 等用于 PDH 锁定与锁相检测的开源软件框架 `[待核实文献]`。开源带来了充分的可定制性，但 Red Pitaya 的定位是低成本通用平台，其 FPGA 规模、ADC 位数与采样率、模拟前端的噪声性能均受限于该定位；在需要多通道、高位宽数据通路或大量并行滤波器资源的场合容易遇到资源与性能上限。相关指标 `[指标待查证]`。

除商用产品外，科研界也发表了多套开源数字伺服方案。Leibrandt 与 Heidecker 报道了一种面向 AMO 实验的开源数字伺服，详细讨论了数字环路延迟与可达带宽的权衡 [5]；基于 Red Pitaya 的锁相与实验控制器亦有报道 `[待核实文献]`。这些工作证明了数字伺服在激光稳频中的可行性，但多以单一功能为目标，其信号通路在综合时即固定，缺乏运行时重构能力。

### 1.2.2 自研高性能 FPGA 控制系统的必要性

综合上述分析，现有方案在三个维度上留下了空白，构成了自研系统的必要性。

第一是定制化与运行时可重构的需求。封闭产品不允许修改数据通路，开源平台虽允许修改却需要重新综合——而一次综合与实现在中等规模设计上往往耗时数十分钟乃至数小时，这与实验现场反复尝试不同锁定方案的节奏完全不匹配。理想的系统应当在不重新综合的前提下，允许用户任意改变模块之间的连接关系，即把"改接线"从编译期操作变为运行期操作。本文采用的全交叉路由矩阵正是为此设计。

第二是性能与资源的需求。高性能稳频要求低延迟与高采样率，复杂方案又要求大量并行的滤波与运算资源，二者共同指向更大规模、更高速度等级的 FPGA。选用独立的 Kintex UltraScale 器件而非入门级 SoC，可以在数据通路上同时容纳数十个全精度流水线运算模块，并以较高的系统时钟降低单位运算的延迟代价。

第三是开放性与成本的需求。对于需要同时锁定多台激光器的实验装置，设备成本按通道数线性累加；而自研方案在硬件成本之外几乎不存在许可费用。更重要的是，完全掌握硬件描述语言源码与通信协议意味着系统具备长期可维护性，不会因厂商停产或接口变更而失效，也便于在课题组内部传承与二次开发。

需要说明的是，自研并不意味着在所有指标上超越商用产品。本文的目标是在架构层面提供商用产品所不具备的可重构性与自动化能力，并使系统的每一层都对使用者开放。

## 1.3 本文研究内容与目标

围绕上述问题，本文的研究内容可概括为"一个平台、一条可重构链路、一套自动锁定逻辑"，并辅以相应的上位机软件体系。

### 1.3.1 搭建自定义 FPGA 硬件平台

本文以 Xilinx Kintex UltraScale 系列 FPGA（KU060）为核心搭建硬件平台 `[具体器件型号与速度等级待补充]`。系统数据通路采用 16 位定点表示，所有信号统一以 16 位有符号整数在模块间传递，满量程对应 $\pm 32768$；系统工作时钟为 250 MHz，即单个时钟周期为 4 ns，这一时钟频率同时决定了流水线延迟的时间粒度与数字滤波器的采样率。

平台包含多路 ADC 与 DAC 通道，并通过一个统一的模块总线实现参数配置。该总线采用"模块编号 + 寄存器地址"的二级寻址方式：6 位模块选择信号可寻址至多 64 个功能模块，7 位地址在模块内部选择 32 位参数字。每个功能模块均由"运算内核 + 参数 RAM + 总线接口"三部分构成统一骨架，参数 RAM 采用影子寄存器结构，使宽度超过 32 位的参数（如 64 位频率控制字、64 个滤波器系数）能够以原子方式整体生效，避免参数更新过程中出现中间非法状态。上位机经串行接口与总线主控通信，由中央控制状态机完成协议解析。

### 1.3.2 设计可动态重构的信号处理链路

本文的核心架构特征是在 FPGA 内部实现一个全交叉信号路由矩阵。该矩阵由两个相互独立的 $64\times64$ 无阻塞交叉开关组成：一个用于 16 位数据信号，一个用于 1 位布尔控制信号。任一输入端口均可被连接到任意数量的输出端口，连接关系完全由寄存器配置决定。每个输出通道占用一个配置字节，其中 6 位指定源端口编号，1 位为通道使能，1 位为保持位；保持位的作用是在重新配置路由期间冻结输出，使拓扑切换不会在数据通路上产生毛刺。矩阵的输出为寄存器输出，引入一个时钟周期的延迟。

这一设计的意义在于，它把信号处理模块与它们之间的连接关系彻底解耦。各类运算模块在综合时一次性实例化并固定在芯片中，而"用哪些模块、以何种顺序串接"则完全交由运行时的寄存器写入决定。用户因此能够像在光学平台上连接真实仪器那样自由地组合数字模块，而无需任何重新综合。

在矩阵之上，本文实现了一套完整的 VHDL 信号处理模块库，各模块的算法原理将在第二章讨论，实现细节见第四章，主要包括：

- **PID 控制器**：并行（位置）型结构，具备可编程的积分限幅抗饱和、可编程泄漏积分以及输出限幅；为在高时钟频率下闭合长位宽积分路径的时序，积分支路采用半速率交织处理。
- **相位累加器（DDS）**：64 位相位累加器，取高 16 位作为相位输出，配合三角函数模块构成数控振荡器；内部另集成比例–积分环路滤波器，可直接用于相位跟踪。
- **CORDIC 三角函数与反三角函数**：分别工作于旋转模式与向量模式，提供正弦/余弦生成与四象限反正切（atan2）解算，19 级迭代，内部 24 位精度。
- **FIR 滤波器**：64 抽头直接型结构，系数 24 位定点，可在运行时重新加载；支持 16/32/64 抽头长度切换并自动调整归一化因子。
- **IIR 滤波器**：四阶，采用两节双二次（biquad）并联结构，并对每节施加四阶散射超前变换，以打破递归反馈对时钟频率的制约。
- **混频器、线性变换器、缩放器、相位解卷绕器**等辅助模块，分别用于解调、双路线性组合、输出调理与相位连续化。

### 1.3.3 实现自动 PDH 锁定状态机

本文将自动锁定流程下沉到硬件，实现为一个独立的 PDH 锁定状态机模块，使锁定的全过程无需上位机参与实时决策。状态机包含空闲、同步等待、幅度标定、时间标定、自动扫描、自动锁定以及一组对应的手动扫描/锁定状态。其关键机制有三。

其一是**自动幅度标定**。状态机以外部斜坡信号的满量程翻转作为扫描周期的边界标志，在一个完整扫描周期内对输入信号作最小值/最大值跟踪，从而测得当前光学信号的实际动态范围。该机制使系统无须预先知道探测器增益与光功率。

其二是**自动阈值计算**。在测得极值后，阈值按

$$
\text{threshold} = \min + \text{coef}\times(\max - \min)
$$

计算，其中系数为 Q1.15 定点数，扫描判决与锁定判决各用一个独立系数。由此得到的阈值随信号幅度自动缩放，避免了人工设定绝对阈值的繁琐与易失效。与此同时，状态机通过统计信号低于阈值的持续时长，推算出共振之间的间隔，并据此自动生成扫描判决与锁定判决所需的时间窗长度。

其三是**扫描与反馈的交接**。状态机本身不产生斜坡，而是通过控制交叉矩阵中的布尔通道，分别门控相位累加器的暂停输入与 PID 控制器的自动复位输入。标定与扫描阶段 PID 保持复位、斜坡自由扫描；当信号连续满足捕获条件达到预定时长时，状态机在同一个时钟沿上冻结斜坡并释放 PID，使累加器保持捕获时刻的偏置、由 PID 接管后续校正。整个交接过程在硬件内部单周期完成，不存在软件轮询带来的不确定延迟。

### 1.3.4 上位机软件与智能体辅助设计

硬件的可重构性只有在易用的配置手段支持下才能转化为实际效率。本文为此设计了分层的 Python 上位机软件：入口层负责启动与主窗口装配，编排层负责参数分发与配置文件读写，图形层与工具层负责可视化与端口映射，设备与模块层负责串行通信与各模块寄存器的抽象。其中图形层实现了一个可视化节点编辑器，用户以拖放方式实例化模块、以连线方式建立数据通路，连线的颜色与线型编码信号的来源与类型，并在建立时进行类型检查；每一次连线操作都被翻译为交叉矩阵的寄存器写入，从而在界面操作与硬件拓扑之间建立直接对应。

在此之上，本文进一步引入基于大语言模型的智能体辅助设计模块。该模块以函数调用方式操作节点画布，可根据自然语言描述创建模块、建立连接、设置参数并自动布局，其提示词中内置了 PDH 锁定的参考拓扑，使系统具备从自然语言需求直接生成信号处理方案的能力。

### 1.3.5 研究目标

综上，本文的总体目标是：建立一套以自研 Kintex UltraScale 硬件平台为基础、以运行时全交叉重构为架构特征、以硬件自动状态机为自动化手段、以分层上位机与智能体为交互入口的全数字激光 PDH 锁定系统，并验证其在激光稳频应用中的可用性。

## 1.4 本文组织结构

全文共分七章，组织如下。

**第一章 绪论**。阐述精密物理测量对激光频率稳定度的需求，分析模拟锁定方案与现有商用数字锁频产品的局限，提出本文的研究内容与目标，并给出全文结构。

**第二章 激光稳频原理与全数字控制理论**。推导 PDH 稳频的误差信号表达式及其鉴频斜率，给出稳频性能的评价指标；在此基础上介绍离散时间控制系统的稳定性分析方法、数字滤波器的设计与延迟特性、CORDIC 算法在数字混频与相位解算中的应用；最后讨论 PID 的数字化实现以及控制带宽、相位裕度与噪声抑制比之间的制约关系。

**第三章 系统硬件架构与接口设计**。介绍以 Kintex UltraScale FPGA 为核心的总体硬件方案、模数/数模转换与时钟分发架构，并分三个层次说明接口设计：上位机 UART 通信链路、片内自定义总线协议（含分层命令编码与超宽参数的原子化更新机制）以及板上射频器件的 SPI 配置接口。

**第四章 FPGA 逻辑设计与控制算法实现**。首先给出作为架构核心的 $64\times64$ 全交叉信号路由矩阵的设计与实现；随后逐一说明 PID、相位累加器、CORDIC 三角与反三角函数、FIR、IIR、混频器等模块的定点格式、流水线结构与延迟，重点讨论为在 250 MHz 时钟下闭合时序所采用的关键技术；最后详述 PDH 自动锁定状态机的八态转移关系、自动幅度标定与自动阈值计算算法，并对各模块做资源占用与延迟分析。

**第五章 上位机软件系统设计**。介绍 Python 上位机的驱动层、硬件抽象层与应用层分层架构，面向对象的模块封装与参数物理量映射关系，自动化初始化与系数加载校准流程，以及可视化节点编辑器与基于大语言模型的智能体辅助设计。

**第六章 系统测试与实验结果**。给出板级性能测试、功能验证实验与激光 PDH 锁定实验的测试方案，包括 ADC/DAC 有效位数与信噪比测试、系统环路延迟测量、硬件资源与时序预算、DDS 信号质量分析、自动锁定过程记录与误差信号功率谱密度分析。

**第七章 总结与展望**。总结本文工作，回顾创新点，并讨论不足与改进方向，其中包括将基于神经网络的自适应 PID 控制引入环路整形、增加硬件自主重捕获机制、以及向多通道并行锁定扩展等。

# 第二章 激光稳频原理与全数字控制理论

本章建立全文的理论基础：先推导 PDH 稳频的误差信号及其鉴频斜率并给出稳频性能指标，再介绍离散时间系统的稳定性分析、数字滤波器与 CORDIC 算法，最后讨论数字 PID 的实现以及环路延迟对控制带宽、相位裕度与噪声抑制能力的制约。

## 2.1 激光频率稳定原理

### 2.1.1 Fabry–Pérot 腔的反射特性

PDH 技术以高精细度 F-P 腔作为频率参考。考察一个由两面反射镜构成的对称光学腔，设镜面的幅度反射系数与透射系数分别为 $r$ 和 $t$，腔长为 $L$。入射光场在腔内往返一周所积累的相位为

$$
\phi(\omega) = \frac{2L\omega}{c} = \frac{\omega}{\Delta\nu_{\mathrm{FSR}}/2\pi}
$$

其中 $\Delta\nu_{\mathrm{FSR}} = c/2L$ 为自由光谱范围。将腔内多次往返的部分波相干叠加，可得腔的幅度反射系数

$$
F(\omega) = \frac{E_{\mathrm{ref}}}{E_{\mathrm{inc}}} = \frac{r\left[\exp\left(i\,\omega/\Delta\nu_{\mathrm{FSR}}\right) - 1\right]}{1 - r^{2}\exp\left(i\,\omega/\Delta\nu_{\mathrm{FSR}}\right)}
$$

此处已省略了与总体传播相位相关的常数因子，并采用了无损镜面假设 $r^2 + t^2 = 1$ [3]。$F(\omega)$ 是一个复函数：其模方 $|F(\omega)|^{2}$ 给出反射功率的归一化值，在共振频率 $\omega_q = q\,\omega_{\mathrm{FSR}}$ 处取极小（理想无损对称腔中为零），呈现周期性的反射凹陷；其相位 $\arg F(\omega)$ 在共振点附近随频率快速变化，并在穿过共振时改变符号。

腔的频率选择性由精细度描述。定义精细度

$$
\mathcal{F} = \frac{\pi r}{1 - r^{2}}
$$

则反射凹陷（亦即腔线宽）的半高全宽为

$$
\delta\nu = \frac{\Delta\nu_{\mathrm{FSR}}}{\mathcal{F}}
$$

精细度越高，线宽越窄，相位随频率变化的斜率越陡，可获得的鉴频灵敏度也越高。

需要强调的是，仅凭反射功率 $|F(\omega)|^{2}$ 无法构成有效的误差信号：它在共振点处取极值，因而关于共振点对称，其一阶导数为零，无法分辨频率偏离的方向。PDH 技术的关键，正是通过相位调制与同步解调，把 $F(\omega)$ 的**相位信息**转换为一个在共振点过零且具有确定符号的直流信号。

### 2.1.2 相位调制光场与边带展开

设入射激光的角频率为 $\omega$，经电光调制器（EOM）施加角频率为 $\Omega$、调制深度为 $\beta$ 的正弦相位调制，则入射光场可写为

$$
E_{\mathrm{inc}} = E_{0}\exp\left[i\left(\omega t + \beta\sin\Omega t\right)\right]
$$

利用 Jacobi–Anger 展开 $\exp(i\beta\sin\Omega t) = \sum_{n=-\infty}^{\infty} J_{n}(\beta)\exp(in\Omega t)$，其中 $J_n$ 为第一类 $n$ 阶贝塞尔函数，得

$$
E_{\mathrm{inc}} = E_{0}\sum_{n=-\infty}^{\infty} J_{n}(\beta)\exp\left[i(\omega + n\Omega)t\right]
$$

在小调制深度（$\beta \lesssim 1$）条件下，二阶以上边带可忽略，光场近似为载波与一对一阶边带的叠加：

$$
E_{\mathrm{inc}} \approx E_{0}\left[J_{0}(\beta)e^{i\omega t} + J_{1}(\beta)e^{i(\omega+\Omega)t} - J_{1}(\beta)e^{i(\omega-\Omega)t}\right]
$$

其中利用了 $J_{-1}(\beta) = -J_{1}(\beta)$。两个一阶边带相位相反，这一反对称性是误差信号具有奇对称形状的根源。

三个频率分量各自被腔以不同的反射系数反射，故反射光场为

$$
E_{\mathrm{ref}} \approx E_{0}\left[F(\omega)J_{0}(\beta)e^{i\omega t} + F(\omega+\Omega)J_{1}(\beta)e^{i(\omega+\Omega)t} - F(\omega-\Omega)J_{1}(\beta)e^{i(\omega-\Omega)t}\right]
$$

### 2.1.3 反射光功率与误差信号

光电探测器响应光强，即 $P_{\mathrm{ref}} = |E_{\mathrm{ref}}|^{2}$。将上式展开并记总入射功率 $P_{0} = |E_{0}|^{2}$，保留直流项与 $\Omega$ 频率项（$2\Omega$ 及更高项在解调后被低通滤除），得

$$
\begin{aligned}
P_{\mathrm{ref}} = P_{0}\Big\{ & J_{0}^{2}(\beta)\left|F(\omega)\right|^{2} + J_{1}^{2}(\beta)\left[\left|F(\omega+\Omega)\right|^{2} + \left|F(\omega-\Omega)\right|^{2}\right] \\
& + 2J_{0}(\beta)J_{1}(\beta)\Big( \operatorname{Re}\left[F(\omega)F^{*}(\omega+\Omega) - F^{*}(\omega)F(\omega-\Omega)\right]\cos\Omega t \\
& \qquad\qquad\quad + \operatorname{Im}\left[F(\omega)F^{*}(\omega+\Omega) - F^{*}(\omega)F(\omega-\Omega)\right]\sin\Omega t \Big) \\
& + \left(2\Omega\ \text{项}\right) \Big\}
\end{aligned}
$$

式中第一行为直流分量，即前述无方向信息的反射凹陷；第二、三行为载波与边带的拍频项，是 PDH 信号的载体。该拍频项包含同相（$\cos\Omega t$）与正交（$\sin\Omega t$）两个分量，分别由同一复组合量的实部与虚部给出。

将探测器输出与本振 $\sin\Omega t$ 相乘并经低通滤波（即同步解调），即可提取正交分量，得到误差信号

$$
\epsilon \propto \operatorname{Im}\left[F(\omega)F^{*}(\omega+\Omega) - F^{*}(\omega)F(\omega-\Omega)\right]
$$

这就是 PDH 误差信号的一般表达式。其幅度与 $2J_{0}(\beta)J_{1}(\beta)P_{0}$ 成正比，故存在一个使信号最大的最佳调制深度；对小 $\beta$ 的近似表达式求极值可得 $\beta \approx 1.08$ [3]。若改为解调同相分量，则得到实部形式的信号，其在共振点附近不过零，一般不用作误差信号；本振相位的失配会使两种分量混合，导致误差信号畸变与零点偏移，因此实际系统中需要对解调相位进行调节与标定。

### 2.1.4 近共振线性区与鉴频斜率

实际稳频工作在共振点附近，且通常选取调制频率远大于腔线宽的情形，即 $\Omega \gg \delta\nu \cdot 2\pi$。此时两个边带被腔完全反射而几乎不进入腔内，可近似认为 $F(\omega \pm \Omega) \approx -1$。代入误差信号表达式，括号内化简为 $-F(\omega) + F^{*}(\omega)$，即

$$
\epsilon \propto \operatorname{Im}\left[-F(\omega) + F^{*}(\omega)\right] = -2\operatorname{Im}\left[F(\omega)\right]
$$

于是误差信号正比于腔反射系数的虚部。设激光频率相对共振点的偏移为 $\delta\omega = \omega - \omega_q$，在 $|\delta\omega| \ll 2\pi\,\delta\nu$ 的范围内将 $F(\omega)$ 作一阶展开，可得

$$
\epsilon \approx -D\,\frac{\delta\nu_{\mathrm{laser}}}{1} = D\cdot\delta\nu_{\mathrm{laser}}
$$

其中鉴频斜率（判别器斜率）为

$$
D = \left.\frac{\partial \epsilon}{\partial \nu}\right|_{\nu = \nu_q} = -\frac{8\sqrt{P_{c}P_{s}}}{\delta\nu}
$$

式中 $P_{c} = J_{0}^{2}(\beta)P_{0}$ 为载波功率，$P_{s} = J_{1}^{2}(\beta)P_{0}$ 为单个一阶边带的功率 [3]。符号表示误差信号随频率增大而减小，具体正负取决于解调相位与电路极性的约定。

该式概括了 PDH 鉴频的全部设计要点：斜率与 $\sqrt{P_cP_s}$ 成正比，故提高光功率和采用最佳调制深度有利；斜率与腔线宽 $\delta\nu$ 成反比，故高精细度腔具有更高的灵敏度，但同时线性区宽度亦随之收窄——线性区大致只有约一个腔线宽，捕获范围因而很小。这一事实直接决定了自动锁定的必要性：若激光频率偏离共振超出线性区，误差信号迅速失去单调性甚至反号，环路无法自行捕获，必须先以扫描方式使激光频率缓慢通过共振，再在恰当时刻闭合环路。本文第 4.3 节的自动锁定状态机正是为完成这一"扫描—判决—闭环"序列而设计的。

在线性区之外，误差信号呈现为以共振点为中心的奇对称曲线，并在 $\pm\Omega$ 处因边带与腔的共振而出现符号相反的次级结构。这一特征在实验上常被用作频率标尺：相邻两个边带特征之间的间隔对应已知的 $2\Omega$，由此可标定扫描速率与误差信号的频率坐标。

### 2.1.5 稳频性能指标

伺服环路闭合后，残余频率噪声需以统一的指标体系来评价。

**频率噪声功率谱密度**。设瞬时频率偏差为 $\delta\nu(t)$，其单边功率谱密度 $S_{\nu}(f)$（单位 $\mathrm{Hz^{2}/Hz}$）描述噪声的频率分布，是分析伺服环路作用最直接的量。相应的相位噪声谱满足 $S_{\phi}(f) = S_{\nu}(f)/f^{2}$。亦常用归一化频率偏差 $y(t) = \delta\nu(t)/\nu_{0}$ 的谱密度 $S_{y}(f) = S_{\nu}(f)/\nu_{0}^{2}$。

**Allan 方差**。时域稳定度以 Allan 方差描述。对取样时间 $\tau$，有

$$
\sigma_{y}^{2}(\tau) = \frac{1}{2}\left\langle \left(\bar{y}_{k+1} - \bar{y}_{k}\right)^{2} \right\rangle
$$

其中 $\bar{y}_{k}$ 为第 $k$ 个长度为 $\tau$ 的区间上的平均归一化频率偏差。实际数据处理中更常用重叠 Allan 偏差以提高置信度。$\sigma_{y}(\tau)$ 的双对数斜率可用于识别主导噪声类型：白频率噪声对应 $\tau^{-1/2}$，闪变频率噪声对应平台，频率随机游走对应 $\tau^{1/2}$，线性漂移对应 $\tau^{1}$。

**激光线宽**。线宽是频率噪声谱的积分效果。当频率噪声以白噪声为主且满足快速调制条件时，谱线为洛伦兹型，半高全宽 $\Delta\nu = \pi S_{\nu}$。更一般的情形下可采用 $\beta$ 分离线法估算线宽，即以 $S_{\nu}(f) = 8\ln 2\,f/\pi^{2}$ 为分界线，只有高于该线的噪声成分对线宽有贡献。

**误差信号的噪声本底与可达极限**。鉴频斜率 $D$ 把频率噪声映射为电压噪声，反过来，误差信号通路上的噪声 $S_{V}$ 也会被折算为等效频率噪声

$$
S_{\nu}^{\mathrm{eq}}(f) = \frac{S_{V}(f)}{D^{2}}
$$

该式说明，高鉴频斜率不仅提高灵敏度，也直接压低了电子学噪声的等效贡献。在理想情况下，PDH 锁定的极限由反射光的散粒噪声决定；而在实际系统中，探测器噪声、ADC 量化噪声与残余幅度调制（RAM）往往先于散粒噪声成为限制因素。其中 RAM 尤其值得注意：它在误差信号中表现为一个随温度缓慢变化的直流偏置，无法与真实的频率偏差相区分，是长期稳定度的主要限制之一。

**环路内外的区别**。必须指出，环路内测得的残余误差信号小，并不等于激光频率真的稳定。伺服环路只能抑制它所能观测到的噪声；参考腔自身的长度抖动、鉴频零点的漂移都会被环路忠实地复制到激光频率上。因此对稳频性能的严格评价须依赖独立的外部参考，例如与另一台独立稳频激光器作拍频测量，或借助光学频率梳与微波频标比对。本文第六章的测试即在此前提下讨论可验证的指标与尚不可验证的部分。

## 2.2 数字信号处理基础

### 2.2.1 离散时间控制系统的稳定性分析

数字伺服对误差信号以采样周期 $T$（采样率 $f_{s} = 1/T$）等间隔采样。设采样序列为 $x[n] = x(nT)$，其 $Z$ 变换定义为

$$
X(z) = \mathcal{Z}\{x[n]\} = \sum_{n=-\infty}^{\infty} x[n]\,z^{-n}
$$

$Z$ 变换将差分方程转化为代数方程，其中 $z^{-1}$ 对应一个采样周期的延迟，即 $\mathcal{Z}\{x[n-k]\} = z^{-k}X(z)$。离散系统的传递函数定义为输出与输入 $Z$ 变换之比 $H(z) = Y(z)/X(z)$，而频率响应由单位圆上的取值给出：

$$
H\!\left(e^{j\omega T}\right),\qquad \omega \in \left[0,\ \pi/T\right]
$$

上限 $\omega = \pi/T$ 即 Nyquist 频率 $f_{s}/2$。这一有限的频率范围是数字系统的根本限制：高于 Nyquist 频率的噪声成分会被折叠（混叠）到带内，因此 ADC 之前必须配置模拟抗混叠滤波器。

连续域与离散域在稳定性判据上存在对应关系。连续系统稳定要求极点位于左半 $s$ 平面；由映射 $z = e^{sT}$ 可知，左半平面被映射到 $z$ 平面的**单位圆内部**，虚轴映射为单位圆。因此离散时间系统的稳定条件为：$H(z)$ 的全部极点满足 $|z| < 1$。

这一映射是多值的：$s$ 与 $s + j2\pi k/T$ 映射到同一点，这正是混叠在变换层面的体现。实用的离散化方法是对该映射作有理近似。常用的三种方法为：

- **前向差分（显式 Euler）**：$s \to (z-1)/T$。实现简单，但会把左半平面的一部分映射到单位圆外，可能使稳定的连续系统离散化后不稳定。
- **后向差分（隐式 Euler）**：$s \to (z-1)/(Tz)$。保证稳定系统离散化后仍稳定，但频率响应在高频处有明显畸变。
- **双线性变换（Tustin 变换）**：

$$
s \to \frac{2}{T}\,\frac{z-1}{z+1},\qquad \text{逆变换}\quad z = \frac{1 + sT/2}{1 - sT/2}
$$

双线性变换把整个左半 $s$ 平面一对一地映射到单位圆内部，故严格保持稳定性，且不引入混叠。其代价是频率轴的非线性压缩（频率弯折）：

$$
\omega_{d} = \frac{2}{T}\arctan\left(\frac{\omega_{a}T}{2}\right)
$$

其中 $\omega_a$ 与 $\omega_d$ 分别为模拟与数字频率。当需要某一特征频率（如滤波器转折频率或 PI 转折点）精确落在设计值上时，可对该频率作预弯折补偿。在 $\omega T \ll 1$ 的低频区，三种方法趋于一致。

离散系统的相对稳定性仍以 Bode 与 Nyquist 判据评价。对开环传递函数 $G(z)$，Nyquist 曲线为 $G(e^{j\omega T})$ 在 $\omega$ 从 $0$ 变到 $\pi/T$ 时在复平面上的轨迹；对开环稳定的系统，闭环稳定要求该轨迹不包围 $-1$ 点。工程上更常用 Bode 图上的两个裕度：**增益裕度**为相位穿越 $-180^{\circ}$ 时开环增益距 $0\ \mathrm{dB}$ 的余量；**相位裕度** $\varphi_{m}$ 为开环增益穿越 $0\ \mathrm{dB}$（单位增益带宽 $f_{\mathrm{UGF}}$）时相位距 $-180^{\circ}$ 的余量。激光伺服中通常要求 $\varphi_{m}$ 不低于 $30^{\circ}\sim45^{\circ}$，以避免在单位增益带宽附近出现明显的噪声增益峰（即伺服鼓包，servo bump）。

### 2.2.2 数字滤波器的设计与延迟分析

数字滤波器在伺服系统中承担两类任务：解调后滤除 $\Omega$ 及其谐波分量，以及对环路进行频率整形（如陷波抑制执行器的机械共振）。两类结构各有取舍。

**FIR 滤波器**。$N$ 抽头有限冲激响应滤波器的差分方程与传递函数为

$$
y[n] = \sum_{k=0}^{N-1} b_{k}\,x[n-k],\qquad H(z) = \sum_{k=0}^{N-1} b_{k}z^{-k}
$$

其极点全部位于原点，故**无条件稳定**，不存在系数量化导致失稳的风险；若系数满足对称性 $b_{k} = b_{N-1-k}$，则相位严格线性，群延迟为常数 $(N-1)T/2$。FIR 的代价是：要获得陡峭的过渡带需要很多抽头，而抽头数直接转化为乘法器数量与群延迟。本文实现的 FIR 为 64 抽头、系数 24 位定点，采用直接型结构配合平衡加法树；由于不利用系数对称性，它需要 64 个并行乘法器，但换来了较短的加法树深度与对任意（含非对称）冲激响应的支持。该模块支持 16/32/64 抽头长度切换，并对不同长度施加不同的归一化因子以保持冲激响应的 $L_1$ 范数一致。其内部流水线延迟为 6 个时钟周期。

**IIR 滤波器**。无限冲激响应滤波器的差分方程与传递函数为

$$
y[n] = \sum_{k=0}^{M} b_{k}x[n-k] - \sum_{k=1}^{N} a_{k}y[n-k],\qquad H(z) = \frac{\sum_{k=0}^{M}b_{k}z^{-k}}{1 + \sum_{k=1}^{N}a_{k}z^{-k}}
$$

IIR 以远少于 FIR 的阶数实现同等陡峭的幅频响应，因而延迟小、资源省，是伺服整形的首选。但它存在反馈，需关注三个问题：极点必须严格位于单位圆内；系数量化会移动极点位置，在高阶直接型结构中尤为敏感，故实际实现应分解为低阶（通常为二阶双二次）节的级联或并联；内部累加需有足够位宽与饱和处理以避免溢出与极限环振荡。

IIR 在高速 FPGA 实现中还面临一个结构性障碍：反馈路径构成递归依赖，$y[n]$ 必须在下一个采样时刻之前算完，于是乘法与加法的组合逻辑延迟直接限制了最高时钟频率。**散射超前变换（scattered look-ahead）** 是解决这一矛盾的经典方法：通过给传递函数的分子分母同乘一个适当的多项式，使分母中只保留 $z^{-M}$ 的若干次幂项，从而把递归依赖的跨度由 1 个采样周期拉长到 $M$ 个采样周期，为反馈乘法器留出 $M$ 个时钟周期的流水线空间，代价是分子系数数量增加。本文实现的四阶 IIR 即采用两节双二次并联结构，并对每节施加四阶散射超前变换：原始四阶传递函数先经部分分式分解拆为两节，每节再经散射变换后仅保留两个反馈系数，使 $250\ \mathrm{MHz}$ 下的时序闭合成为可能。系数采用 Q3.24（分子）与 Q2.25（分母）格式，内部状态为 30 位 Q4.26，输出级设有显式饱和。

**延迟是数字伺服的核心代价**。任何数字滤波器都引入群延迟，而伺服环路中的总延迟 $\tau$ 还包括 ADC 的转换与流水线延迟、模块间路由的寄存器级、以及 DAC 的建立时间。对于采样保持过程，其等效延迟约为 $T/2$。这些延迟相加后，在频域中表现为一个纯延迟环节 $e^{-j\omega\tau}$，其幅度恒为 1 而相位线性下降。这正是 2.3.2 节将定量讨论的、限制环路带宽的首要因素。因此，滤波器的选择必须在频率选择性与群延迟之间权衡：用于解调后抑制载波泄漏时，通带外衰减是主要诉求；而用于环路整形时，应优先选用低阶 IIR 并尽量减少级联深度。

### 2.2.3 CORDIC 算法及其在数字混频与相位解算中的应用

数字伺服需要在芯片内生成调制与解调所用的正交本振，并在相位检测类应用中由正交分量反解相位角。直接查表（ROM 查找）会消耗大量存储资源且精度受表深度限制，而多项式逼近需要多个乘法器。CORDIC（Coordinate Rotation Digital Computer）算法仅用移位与加法即可完成这两类运算，是 FPGA 实现的标准方案。

**算法原理**。CORDIC 的核心是把任意角度的旋转分解为一系列固定角度的微旋转。平面向量旋转 $\theta$ 角的变换为

$$
\begin{bmatrix} x' \\ y' \end{bmatrix} = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}\begin{bmatrix} x \\ y \end{bmatrix}
$$

提出 $\cos\theta$ 并限定 $\tan\theta_{i} = 2^{-i}$，则该矩阵中的乘法退化为移位。第 $i$ 次迭代写为

$$
\begin{aligned}
x_{i+1} &= x_{i} - d_{i}\,y_{i}\,2^{-i} \\
y_{i+1} &= y_{i} + d_{i}\,x_{i}\,2^{-i} \\
z_{i+1} &= z_{i} - d_{i}\arctan\left(2^{-i}\right)
\end{aligned}
$$

其中 $d_{i} \in \{+1,-1\}$ 为旋转方向，$z$ 为剩余角度，$\arctan(2^{-i})$ 预存于常数表中。省略的 $\cos\theta_i$ 因子使向量模长在每次迭代中放大 $\sqrt{1 + 2^{-2i}}$ 倍，$n$ 次迭代后累积增益为

$$
K_{n} = \prod_{i=0}^{n-1}\sqrt{1 + 2^{-2i}},\qquad K_{\infty} \approx 1.64676,\qquad 1/K_{\infty} \approx 0.60725
$$

该增益为与输入无关的常数，故可以通过把 $1/K_n$ 预乘到初始向量中来补偿，无需任何额外乘法器。

**两种工作模式**。CORDIC 的两种模式仅在 $d_i$ 的判决依据上不同，却对应完全不同的功能。

- **旋转模式**：取 $d_{i} = \operatorname{sign}(z_{i})$，迭代驱使剩余角 $z \to 0$。若初始化 $x_{0} = 1/K_{n}$、$y_{0} = 0$、$z_{0} = \theta$，则收敛后 $x_{n} \to \cos\theta$、$y_{n} \to \sin\theta$，即实现正弦余弦发生。
- **向量模式**：取 $d_{i} = -\operatorname{sign}(y_{i})$，迭代驱使 $y \to 0$。若初始化 $x_{0} = x$、$y_{0} = y$、$z_{0} = 0$，则收敛后 $x_{n} \to K_{n}\sqrt{x^{2}+y^{2}}$、$z_{n} \to \arctan(y/x)$，即同时实现模值与相角解算。

每次迭代约可确定结果的 1 位有效精度，故迭代次数与所需位宽大致相当。基本迭代式的收敛域为 $|\theta| \lesssim 99.9^{\circ}$，不覆盖全圆，因此需要象限预处理：先把输入折叠到第一、四象限，记录象限信息，迭代完成后再作相应的符号翻转或 $\pi$ 偏置。

**本文的实现与设计取舍**。本文实现了一对结构高度一致的 CORDIC 模块：正向模块工作于旋转模式，由相位生成正弦与余弦；反向模块工作于向量模式，由正交分量计算四象限反正切（atan2）。二者均采用 19 级迭代、24 位内部精度、16 位输入输出，增益以预缩放初始向量的方式补偿。两者在源码上的唯一本质差别即旋转方向的判决依据（取自剩余角符号还是取自 $y$ 分量符号），这正是旋转模式与向量模式关系的直接体现。

实现中有两点值得强调。第一，为满足 250 MHz 时序而又不让流水线深度等于迭代次数，设计令剩余角 $z$ 的计算超前一级，使 $x$、$y$ 的更新不被 $z$ 的关键路径阻塞，从而可以每两级迭代只插入一级寄存器，19 级迭代的内部延迟压缩为 10 个寄存器级（含首级的一级与隔级插入的九级），计入输入输出缓冲后模块总延迟为 12 个时钟周期，详见第 4.2.2 节。第二，象限处理被简化为对输入高两位的一次异或与输出端的条件取负，无需额外迭代。

**统一的相位编码**。贯穿本文全部相位相关模块的一项基础约定是：16 位有符号整数表示整个 $2\pi$ 区间，即 $\mathrm{0x8000}$ 对应 $\pm\pi$，相位的最低有效位为 $2\pi/65536$。这一编码使相位的模 $2\pi$ 运算与二进制补码的自然溢出完全等价，由此带来三项便利：数控振荡器的相位累加器无需取模运算；CORDIC 的范围归约退化为一次符号判断；相位解卷绕无需显式的 $2\pi$ 常数。

**数字混频与相位解卷绕**。基于上述模块，数字域的解调由一个全精度乘法器完成：$16\times16$ 位相乘得到 32 位全精度积，取高 16 位作为输出，对应 Q1.15 定点格式的乘法约定；低通滤波由后续独立的 FIR 或 IIR 模块承担，使"混频—滤波"的组合可按需配置。相位解卷绕模块则利用上述编码的性质：直接对相邻两个包裹相位作 16 位补码减法，只要真实相位步进不超过 $\pi$，所得差值自动等于最短路径增量；将该增量符号扩展后累加，即得到连续的相位轨迹。本文实现中累加器位宽为 17 位，并在接近饱和时作限幅而非回绕，以避免计数翻转造成的突变。

## 2.3 控制回路理论

### 2.3.1 PID 控制算法及其数字化实现

PDH 稳频环路的整形通常以 PID 控制器为核心。连续域的理想 PID 控制器为

$$
u(t) = K_{p}\,e(t) + K_{i}\int_{0}^{t} e(\tau)\,\mathrm{d}\tau + K_{d}\,\frac{\mathrm{d}e(t)}{\mathrm{d}t}
$$

其传递函数为

$$
C(s) = K_{p} + \frac{K_{i}}{s} + K_{d}s = K_{p}\left(1 + \frac{\omega_{i}}{s} + \frac{s}{\omega_{d}}\right)
$$

三项的作用在频域中界限分明。积分项在低频提供理论上无限大的增益，从而消除稳态误差、抑制慢漂移，其代价是引入 $-90^{\circ}$ 的相移；比例项在中频段提供平坦增益，不引入相移，直接决定单位增益带宽的位置；微分项在高频提供 $+90^{\circ}$ 的相位超前，可用于补偿执行器的极点。积分转折频率 $\omega_{i} = K_{i}/K_{p}$ 以下由积分主导，微分转折频率 $\omega_{d} = K_{p}/K_{d}$ 以上由微分主导。实际系统中微分项必须加以带限（即用 $K_ds/(1+s/\omega_{\mathrm{lp}})$ 代替 $K_ds$），否则会无界地放大高频噪声。

**离散化**。对 $C(s)$ 应用 2.2.1 节的变换即得数字 PID。采用后向差分离散积分、前向差分离散微分，可得最常用的位置型（并行型）差分方程

$$
u[n] = K_{p}e[n] + K_{i}T\sum_{k=0}^{n}e[k] + \frac{K_{d}}{T}\left(e[n] - e[n-1]\right)
$$

记积分状态 $I[n] = I[n-1] + K_{i}T\,e[n]$，则实现为递推形式

$$
\boxed{\;u[n] = K_{p}\,e[n] + I[n] + \frac{K_{d}}{T}\left(e[n]-e[n-1]\right),\qquad I[n] = I[n-1] + K_{i}T\,e[n]\;}
$$

若改用双线性变换离散积分项，则 $I[n] = I[n-1] + \tfrac{K_{i}T}{2}\left(e[n]+e[n-1]\right)$，即梯形积分，其相位特性在接近 Nyquist 频率处更接近连续域，但需多保存一个状态。另一种常见形式是增量型（速度型）

$$
\Delta u[n] = u[n]-u[n-1] = K_{p}\Delta e[n] + K_{i}T\,e[n] + \frac{K_{d}}{T}\left(\Delta e[n]-\Delta e[n-1]\right)
$$

增量型便于与带记忆的执行器配合且天然不易饱和，但不便于施加绝对输出限幅。本文采用位置型并行结构，以便对积分状态与输出分别施加独立的限幅。

**定点实现的关键问题**。在 FPGA 上以定点算术实现上式，需处理若干在连续域中不存在的问题。

*增益的定标*。三路增益以定点整数表示，乘积通过固定的移位（取位切片）对齐到输出格式。由于积分支路的乘积在累加前还要再右移，其增益系数应给予更多位宽以保持有效精度。本文实现中比例与微分增益为 24 位、积分增益为 32 位，各支路乘积分别以固定移位量对齐。一个有用的定标参照是：当比例与积分增益取相同数值时，PI 转折频率为 $f_{i} = f_{s}/(2\pi\cdot 65536)$，在 250 MHz 时钟下约为 600 Hz。

*积分饱和与抗饱和*。当误差长期同号（例如尚未捕获共振，或执行器已到行程末端）时，积分状态会持续增长至溢出，其后即便误差反号也需很长时间才能退出饱和，表现为严重的滞后甚至失控。标准对策是积分限幅（clamping）：把积分状态约束在一个可编程的对称范围内，并在反馈路径中施加该限幅，使状态本身永不越界。本文即采用这一方案，并额外对输出求和结果设置独立的可编程限幅。

*泄漏积分*。纯积分器在开环时会无限累积任意微小的偏置。引入泄漏项 $I[n] = \lambda I[n-1] + K_{i}T e[n]$（$\lambda$ 略小于 1）可使积分器具有有限的直流增益，把低频极点从原点移入单位圆内，从而避免长期累积，代价是不再具备严格的零稳态误差。由于除法在 FPGA 上代价高昂，本文以"按位选择的移位和"实现泄漏量，即泄漏率由若干 2 的负整数次幂之和构成，由一个掩码寄存器选择。

*微分项的噪声*。一阶差分的频响为 $\left(1-z^{-1}\right)/T$，其幅度随频率单调上升至 Nyquist 频率，对量化噪声与宽带噪声有显著放大作用。因此微分项应配合低通滤波使用；本文的 PID 内核采用未经滤波的原始一阶差分，必要的带限由路由矩阵在其前级或后级串入 FIR/IIR 模块实现——这正是可重构架构带来的灵活性。另需注意，本文实现中微分支路取自设定点减除之前的原始误差，对于恒定设定点而言与标准形式等价，且可避免设定点跳变时产生微分冲击。

*高频下的时序约束*。积分支路的关键路径包含一个宽位累加器及泄漏项的减法，在 250 MHz 下难以单周期闭合。本文采用半速率交织处理：积分支路每两个时钟周期更新一次，等效于把积分运算的采样率降为 125 MHz，而比例与微分支路仍以全速率运行。这一取舍的理由在于积分项主要作用于远低于 Nyquist 频率的低频段，降半采样率对其频响的影响可忽略；而比例支路决定单位增益带宽，必须保持最低延迟。

### 2.3.2 环路延迟、相位裕度与控制带宽

伺服环路的开环传递函数可写为

$$
G(s) = C(s)\,A(s)\,P(s)\,e^{-s\tau}
$$

其中 $C$ 为控制器，$A$ 为执行器（PZT 或激光电流）传递函数，$P$ 为鉴频器与探测通道增益（含 $D$），$e^{-s\tau}$ 为环路纯延迟。

纯延迟环节的幅度恒为 1，但贡献随频率线性增长的相位滞后

$$
\Delta\phi(\omega) = -\omega\tau = -2\pi f\tau
$$

这是数字伺服最重要的约束。设理想 PI 控制器在穿越频率处已贡献约 $-90^{\circ}$ 相移，为保留相位裕度 $\varphi_{m}$，延迟允许贡献的相移上限为 $90^{\circ}-\varphi_{m}$，于是单位增益带宽满足

$$
2\pi f_{\mathrm{UGF}}\,\tau \le \frac{\pi}{2} - \varphi_{m}
\quad\Longrightarrow\quad
f_{\mathrm{UGF}} \le \frac{1}{2\pi\tau}\left(\frac{\pi}{2}-\varphi_{m}\right)
$$

其中 $\varphi_m$ 以弧度计。两个有代表性的结论是：若不要求任何裕度（$\varphi_m = 0$），则 $f_{\mathrm{UGF}} \le 1/(4\tau)$；若要求 $\varphi_{m} = 45^{\circ}$，则 $f_{\mathrm{UGF}} \le 1/(8\tau)$。可见**可达带宽与总延迟成反比**，且与裕度要求成线性折减关系。若环路中还存在执行器极点或抗混叠滤波器的附加相移，则上述上限会进一步收紧。

该式为数字伺服的工程设计给出了明确的量化目标：总延迟 $\tau$ 是必须在系统层面逐项核算并压缩的预算，包括模拟前端与抗混叠滤波器的群延迟、ADC 转换与输出流水线延迟、采样保持的等效 $T/2$、FPGA 内部各模块的流水线级数与路由矩阵的寄存器级、DAC 的建立时间，以及执行器驱动电路的响应时间。本文把系统时钟设置在 250 MHz（单周期 4 ns）、在关键支路选择性地去除输入输出缓冲寄存器、以及在 CORDIC 与 IIR 中采用超前技术压缩流水线级数，其共同动机都是压缩这一预算中的数字部分。各模块的流水线延迟见第 4.4 节，环路总延迟的实测结果与由此推算的带宽上限将在第 6.1 节给出。

### 2.3.3 噪声抑制比与伺服鼓包

闭合环路后，输入频率噪声被抑制的程度由灵敏度函数给出。设自由运转激光的频率噪声为 $\delta\nu_{\mathrm{free}}$，则闭环后的残余噪声为

$$
\delta\nu_{\mathrm{res}}(f) = \frac{\delta\nu_{\mathrm{free}}(f)}{1 + G(f)}
$$

相应地，噪声抑制比（误差抑制因子）为

$$
\mathrm{NSR}(f) = \left|1 + G(f)\right| \approx \left|G(f)\right| \quad (\left|G\right| \gg 1)
$$

以功率谱密度表示则为 $S_{\nu}^{\mathrm{res}}(f) = S_{\nu}^{\mathrm{free}}(f)/\left|1+G(f)\right|^{2}$。

这一关系揭示了三条设计原则。

第一，**抑制比直接等于开环增益**。要在某一频率上把噪声压低 $40\ \mathrm{dB}$，就必须在该频率上具备 $40\ \mathrm{dB}$ 的开环增益。由于 PI 控制器的增益以 $-20\ \mathrm{dB/dec}$ 的斜率从单位增益带宽向低频上升，低频处的抑制能力由 $f_{\mathrm{UGF}}$ 与该频率的间距决定：$f_{\mathrm{UGF}}$ 每提高十倍，低频抑制比即改善 $20\ \mathrm{dB}$。换言之，**带宽是低频稳定度的前提**，而 2.3.2 节已表明带宽由延迟决定。这构成了从"压缩延迟"到"提升稳定度"的完整逻辑链条，也是本文在架构上追求低延迟的根本理由。

第二，**存在不可避免的噪声增益区**。当 $\left|1+G\right| < 1$ 时，环路实际上放大了噪声。由 Bode 积分定理可知，对于稳定且满足一定条件的系统，灵敏度函数对数的积分受到约束，低频处的抑制必然以某些频段的放大为代价。在实践中这表现为单位增益带宽附近的一个噪声峰，即**伺服鼓包**。鼓包的高度由该处的相位裕度决定：裕度越小，$1+G$ 在 $-1$ 点附近越小，峰越高越尖。因此一味提高增益以追求带宽，会在鼓包处制造新的噪声成分，反而可能恶化激光线宽与原子探询的效果。合理的做法是在"低频抑制—鼓包高度—稳定余量"之间取折中，并在必要时对误差信号作陷波整形。

第三，**量化噪声与执行器噪声构成本底**。环路只能抑制环路之外引入的噪声，而伺服链路自身注入的噪声（ADC 量化噪声、DAC 量化与输出噪声、执行器驱动噪声）会被完整地写入激光频率，且不因增益提高而减小——提高增益只会使其更忠实地复制到输出。因此数字伺服的噪声本底由转换器位宽、参考电压噪声与定点运算的位宽设计共同决定。本文采用 16 位数据通路并在各运算模块内部保留显著更高的中间位宽（CORDIC 为 24 位、IIR 内部状态为 30 位、PID 积分状态为 48 位），其目的正是把运算过程引入的量化误差压低到远小于转换器本底的水平。

还需注意定点运算中舍入策略的系统性影响。本文多数模块采用截断取高位，截断会引入约半个最低有效位的负向直流偏置；少数对偏置敏感的位置（CORDIC 输出、PID 积分输入、缩放器输出）采用了四舍五入处理。在直流偏置直接等效为鉴频零点偏移的 PDH 系统中，这类偏置应作为误差预算的一项加以核算。

## 2.4 本章小结

本章建立了全文的理论基础，可归结为一条贯穿的逻辑链条。

在物理层面，PDH 技术通过相位调制与同步解调，把 F-P 腔反射系数的相位信息转换为误差信号 $\epsilon \propto \operatorname{Im}\left[F(\omega)F^{*}(\omega+\Omega) - F^{*}(\omega)F(\omega-\Omega)\right]$；在调制频率远大于腔线宽的条件下该式简化为 $-2\operatorname{Im}[F(\omega)]$，并在共振点附近给出鉴频斜率 $D = -8\sqrt{P_{c}P_{s}}/\delta\nu$。该斜率与腔线宽成反比的事实带来一个关键推论：高灵敏度必然伴随窄捕获范围，线性区仅约一个腔线宽，环路无法自行捕获，这构成了本文设计硬件自动锁定状态机的物理依据。

在信号处理层面，$Z$ 变换把稳定性判据归结为极点位于单位圆内，双线性变换 $s \to \frac{2}{T}\frac{z-1}{z+1}$ 则提供了保稳定、无混叠的离散化途径。FIR 与 IIR 的取舍本质上是"无条件稳定与线性相位"对"低阶数与小延迟"的权衡；而 CORDIC 算法以移位与加法同时解决了正交本振生成（旋转模式）与相位解算（向量模式）两个问题，二者仅在旋转方向的判决依据上不同。本章同时指出，以 16 位整数表示整个 $2\pi$ 区间（$\mathrm{0x8000}$ 对应 $\pm\pi$）这一统一编码，使相位的模 $2\pi$ 运算与补码溢出等价，是 DDS、CORDIC 与相位解卷绕三者得以简化的共同基础。

在控制层面，数字 PID 由 $u[n] = K_{p}e[n] + I[n] + \frac{K_{d}}{T}(e[n]-e[n-1])$ 给出，其定点实现须额外处理增益定标、积分抗饱和、泄漏积分与微分噪声放大等连续域中不存在的问题。最核心的结论是环路延迟的约束：纯延迟贡献相移 $\Delta\phi = -\omega\tau$，由此 $f_{\mathrm{UGF}} \le \frac{1}{2\pi\tau}\left(\frac{\pi}{2}-\varphi_{m}\right)$，在 $45^{\circ}$ 相位裕度下即 $f_{\mathrm{UGF}} \le 1/(8\tau)$；而噪声抑制比又等于开环增益 $|1+G|$，低频抑制能力随单位增益带宽同步提升。延迟因而经由带宽直接决定稳定度，这正是本文在架构上追求高时钟频率与短流水线的根本理由，也解释了后续各章中散射超前变换、CORDIC 隔级流水与 PID 积分支路交织等技术取舍的共同动机。

# 第三章 系统硬件架构与接口设计

本章描述自动激光 PDH 锁定系统的硬件平台构成与各级接口设计，依次介绍以 Xilinx Kintex UltraScale FPGA 为核心的总体方案、模数/数模转换与时钟分发架构，以及上位机通信链路、片内自定义总线协议和器件配置接口三个层次的接口设计。

## 3.1 总体硬件方案

### 3.1.1 设计约束与方案选择

全数字 PDH 锁定系统的硬件设计受三项基本约束支配。

其一是**环路延迟约束**。如第二章 2.3 节所述，闭环系统的相位裕度直接受环路延迟 $\tau$ 制约，附加相移为 $\Delta\phi = -\omega\tau$。数字系统的延迟来自 ADC 转换、FPGA 内部流水线、DAC 建立三个环节，其中 FPGA 内部处理延迟与时钟频率成反比。因此系统时钟频率应尽可能高，且信号处理链路的流水线级数应尽可能少。

其二是**量化噪声约束**。误差信号的检测精度受 ADC 有效位数限制。理想 $N$ 位量化器的信噪比上限为

$$
\mathrm{SNR}_{\max} = 6.02N + 1.76 \ \mathrm{dB}
$$

该式给出噪声本底的理论下界，实际系统还需考虑孔径抖动、参考电压噪声与 FPGA 内部定点截断的贡献。

其三是**可重构性约束**。实验平台需要在不重新综合布线的前提下改变信号处理拓扑，这要求 FPGA 内部预先实例化全部功能模块，并通过可配置的互联网络连接，而非按固定链路硬连线。这一约束直接导出了第四章 4.1 节的信号路由矩阵设计。

基于上述约束，系统选用 Xilinx Kintex UltraScale 系列 FPGA 作为主控单元。该系列在逻辑资源、DSP48 硬核乘法器数量与高速串行接口能力之间取得平衡，适合承载多路并行的定点信号处理链路。系统时钟频率设定为 250 MHz，定义于 `packages/mypak.vhdl`：

```vhdl
constant clk_freq : integer := 250_000_000; -- Clock frequency in Hz.
```

系统内部数据通路统一采用 16 位有符号定点格式，定义为 `signal_array` 类型：

```vhdl
type signal_array is array(natural range <>) of std_logic_vector(15 downto 0);
```

该类型用于信号路由矩阵的输入输出端口以及顶层接口，是全系统信号互联的统一载体。16 位宽度与所选 ADC/DAC 的分辨率相匹配，在动态范围与资源占用之间取得折衷。

### 3.1.2 板卡与时钟架构

工程支持多种载板，通过不同的顶层封装文件区分：

| 载板 | 顶层封装文件 | 配置包 |
|------|-------------|--------|
| PZ-KU060-FHT | `wrapper_PZ-KU060-FHT.vhdl` | `packages/PZ_KU060_config.vhdl` |
| KU060 定制板 | `wrapper_KU060_custom.v` | `packages/KU060_custom_config.vhdl` |
| 通用板 | `wrapper.vhdl` | — |

顶层实体 `Top.vhdl`（871 行）为单时钟域设计，其 entity 仅声明一个 `clk` 端口，全部挂载在片内总线上的模块均由该时钟驱动。多时钟管理集中在封装层 `wrapper.vhdl` 中，由 MMCM（Mixed-Mode Clock Manager）完成。

MMCM 的输入参考时钟为 200 MHz，对应 `KU060_custom.xdc` 中的约束：

```tcl
create_clock -period 5.000 [get_ports sysclk_p]
```

MMCM 输出四路时钟，其中 `clk_out1` 为 250 MHz 系统主时钟（送入 `Top`），`clk_out2` 为 125 MHz DAC 时钟。`AN9767_adapter.vhdl` 中的注释明确了这一分频关系："AN9767 works at 125MHz, which is half of the system clock"。另两路 250 MHz 与 500 MHz 输出在代码中已实例化 BUFGCE 缓冲，但当前版本未见下游使用。

四路 BUFGCE 的时钟使能端均连接至 `sys_clk_locked`，在 MMCM 未锁定期间门控输出，避免未稳定时钟进入逻辑。MMCM 支持内部/外部参考切换，由 `sys_mmcm_sel` 信号选择。值得注意的是，切换控制器 `sys_mmcm_sel_ctrl` 与按键去抖模块 `debouncer` 均运行在 MMCM 之前的时钟域上，源码中有明确注释说明"Don't use clock from MMCM"——若控制器本身依赖被切换的时钟，切换瞬间将失去时序基准。

### 3.1.3 模数/数模转换架构

系统通过 FMC 接口支持多种 ADC/DAC 子卡，各子卡由独立的适配器模块（adapter）对接到统一的内部接口。`io management/` 目录下的适配器清单如下：

| 适配器文件 | 功能 |
|-----------|------|
| `FH8052_adapter.vhdl` | ADC 子卡适配 |
| `FH9767D_adapter.vhdl` | ADC 子卡适配 |
| `FL9613_adapter.vhdl` | ADC/DAC 子卡适配（16 位数据端口） |
| `FL9627_adapter.vhdl` | DAC 子卡适配 |
| `FL9781_adapter.vhdl` | ADC 子卡适配 |
| `FL1010_adapter.vhdl` | ADC 子卡适配 |
| `AN9767_adapter.vhdl` | DAC 子卡适配（125 MHz） |
| `ADDC/board_ku060_adda_top.v` | ADDC 高速 ADC/DAC 板 |

> 【待补充】上表各子卡的分辨率与采样率指标。代码中的适配器仅实现信号映射与 FIFO 逻辑，未在注释中标注器件的位数与采样率。`FL9613_adapter.vhdl` 的数据端口为 16 位（`adc_a_data` 至 `adc_d_data`，各 `std_logic_vector(15 downto 0)`），可推知该子卡为 16 位四通道，但采样率需查阅器件手册确认后填入。

适配器的典型职责由 `FL9613_adapter.vhdl` 的文件头注释概括："Maps input data, output clock and spi signals to the universal LPC interface. Contains FIFO logic."——即将子卡特定的引脚映射到统一的 LPC（Low Pin Count）FMC 接口，并处理跨时钟域的 FIFO 缓冲。

高速射频转换链路的核心器件由 `python control/chips.py` 中的 SPI 初始化例程配置，包括：

- **AD9680**——高速 ADC，初始化函数 `init_AD9680(spi, port, chip)`，配置完成后读取寄存器 `0x056F` 校验锁定状态，未锁定则抛出异常；
- **AD9152**——高速 DAC，初始化函数 `init_AD9152(spi, port, chip)`，校验寄存器 `0x0281`；
- **AD9528**——时钟分发与抖动清理 PLL，初始化函数 `init_AD9528(spi, port, chip)`，校验寄存器 `0x0508`，并可检测外部参考是否存在。

这三类器件的寄存器初始化序列同时以查找表形式固化在 `packages/PZ_KU060_config.vhdl` 中（`init_lut`，共 161 项），由 FPGA 内部的 SPI 任务序列器在上电时自动执行，无需上位机干预。该文件中另有 `query_lut`（3 项）用于周期性查询器件状态，查询结果经 `query_result` 输出至面板指示灯——`wrapper.vhdl:835` 的注释说明 `panel_led_2` 用于指示 AD9680 是否正常运行。

时钟分发器件 AD9528 的抖动性能直接影响 ADC 的有效位数。采样时钟的抖动 $\sigma_t$ 在输入信号频率 $f_{in}$ 处引入的信噪比上限为

$$
\mathrm{SNR}_{\mathrm{jitter}} = -20\log_{10}(2\pi f_{in}\sigma_t)
$$

当该项与量化噪声可比时，将成为系统噪声本底的主导因素。

> 【待补充】AD9528 的实测抖动指标与由此推算的 ADC 有效位数上限。需查阅器件手册典型值并结合实测相位噪声谱确认。

## 3.2 通信接口设计

系统的接口设计分为三个层次：上位机与 FPGA 之间的 UART 链路、FPGA 片内连接各功能模块的自定义总线、以及 FPGA 对板上射频器件的 SPI 配置接口。三者构成从 Python 脚本到器件寄存器的完整控制通路。

### 3.2.1 上位机通信链路

上位机与 FPGA 之间采用 UART 串行链路，波特率定义于 `packages/mypak.vhdl`：

```vhdl
constant baudrate : integer := 115200; -- Baudrate for the UART.
```

该文件中另有一条被注释掉的 3 906 250 波特配置，注释标明"Only use in simulation"——仿真时提高波特率可缩短验证周期。

选择 UART 而非 PCIe 或以太网作为控制链路，是基于控制与数据两类业务的分离考虑：参数配置属于低频、小数据量、强可靠性需求的业务，UART 的实现复杂度最低且时序确定；而大数据量的波形回传则由独立的以太网通路承担（`modules/waveform_storage_upload/`，含 DDR4 缓存与完整 MAC 协议栈）。两条通路互不干扰。

FPGA 侧的 UART 收发由 `uart_tx.vhdl` 与 `uart_rx.vhdl` 实现，命令解析由 `central_control.vhdl`（829 行）承担。该模块是一个状态机，负责从串行字节流中识别命令帧、解析字段、驱动片内总线，并组织响应回传。

上位机侧的驱动封装为 `python control/uart.py` 中的 `MySerial` 类，继承自 pyserial 的 `Serial`。其核心方法 `post()` 采用回显校验机制：发送命令后读回 FPGA 的回显并与原始命令比对，不一致则重发。这一机制以牺牲吞吐量换取链路可靠性，对参数配置类业务是合适的权衡。

### 3.2.2 板级总线协议设计

片内总线是本系统架构的核心。为使 34 个功能模块（`module_count = 34`）以统一方式接受配置，系统设计了一套自定义的并行总线协议，其信号定义集中在 `packages/mypak.vhdl`：

| 常量 | 位宽 | 含义 |
|------|------|------|
| `dbus_w` | 32 | 数据总线宽度 |
| `abus_w` | 7 | 地址总线宽度，决定每模块参数 RAM 容量为 $2^7=128$ 字 |
| `mbus_w` | 6 | 模块选择总线宽度，最多寻址 $2^6=64$ 个模块 |
| `cbus_w` | 5 | 控制总线宽度 |
| `rdbus_w` | 32 | 响应数据总线宽度 |
| `rsbus_w` | 3 | 响应状态总线宽度 |

由此导出单模块参数存储容量上限：

```vhdl
constant core_param_size : integer := 2 ** abus_w * dbus_w; -- = 4096 bit
```

即每个模块最多可拥有 4096 位参数空间。实际各模块按需取用：PDH 状态机与 PID 控制器使用 256 位（`core_param_in : in std_logic_vector(255 downto 0)`），信号路由矩阵使用 1024 位，FIR 滤波器因需存储 64 个 24 位系数而使用全部 4096 位。

总线采用集中式主从结构。`central_control.vhdl` 作为唯一主设备，各模块通过专属的 `bus_handler.vhdl` 实例接入。模块地址以常量形式静态分配，例如：

```vhdl
constant BUS_ROUT_ADDR : ... := to_unsigned(1, mbus_w);  -- 信号路由矩阵
constant BUS_TRIG_ADDR : ... := to_unsigned(2, mbus_w);  -- 三角函数运算器
constant BUS_ACCM_ADDR : ... := to_unsigned(3, mbus_w);  -- 累加器
constant BUS_PIDC_ADDR : ... := to_unsigned(6, mbus_w);  -- PID 控制器
```

地址 0 保留表示"无模块"，响应总线类型 `rdbus_type` 与 `rsbus_type` 的索引范围均为 `0 to module_count`，其中 0 号位置不对应实际模块。响应数据经 `response_mux.vhdl` 多路选择后回传主设备。

**命令编码方案**定义于 `packages/bus_protocol.vhdl`。控制总线的 5 位命令字采用分层编码：高 2 位标识命令类型，低 3 位标识具体动作。这一编码方式使从设备可先按高 2 位快速分支，再解析具体操作，降低解码逻辑深度。

| 类型头 | 编码 | 命令 | 低 3 位 | 功能 |
|--------|------|------|---------|------|
| `CONTROL_HEAD` | `00` | `SET_CORE` | `010` | 模块内核复位置 0 |
| | | `RST_CORE` | `011` | 模块内核复位置 1 |
| | | `SET_RAM` | `100` | 参数 RAM 复位置 0 |
| | | `RST_RAM` | `101` | 参数 RAM 复位置 1 |
| `WRITE_HEAD` | `01` | `WRITE` | `000` | 写入并立即生效 |
| | | `WRITE_HOLD` | `001` | 写入但暂不生效 |
| | | `WRITE_MASK` | `100` | 带掩码写入并立即生效 |
| | | `WRITE_MASK_HOLD` | `101` | 带掩码写入但暂不生效 |
| `READ_HEAD` | `10` | `READ` | `000` | 读取指定地址 |
| `MISC_HEAD` | `11` | — | — | 由各模块的总线处理器自定义 |

响应状态总线有两个取值：`ROGER`（`001`）表示命令已执行，`ERROR`（`111`）表示执行失败，错误详情经响应数据总线返回。

协议中 `HOLD` 变体的设计值得专门说明。许多模块的参数宽度超过 32 位数据总线——例如 PID 控制器的积分限幅 `limit_integral` 为 48 位，累加器的频率字 `delta` 为 64 位。若分多次写入且每次立即生效，参数将在中间状态下短暂作用于运行中的控制环路，可能造成输出跳变甚至失锁。`WRITE_HOLD` 命令将数据写入影子寄存器而不提交，待最后一条 `WRITE` 命令到达时一并生效，从而实现**多寄存器参数的原子化更新**。`module_pid_controller.vhdl` 中 `wen`（写使能）与 `wval`（写生效）两个信号的分离正是这一机制在模块侧的落地。

`WRITE_MASK` 变体用于位域级更新：同一地址内可能打包多个逻辑参数（如 PDH 状态机将 2 位的 `pc_cmd` 放在地址 0x00 的最低两位），掩码写入使上位机可只修改目标位域而不扰动同址的其他参数。该命令需占用两个总线周期，第一周期传数据、第二周期传掩码。

### 3.2.3 器件配置接口

板上射频器件（AD9680、AD9152、AD9528 等）通过 SPI 接口配置。FPGA 侧由 `spi_trx.vhdl` 实现物理层收发，`spi_task_control.vhdl` 实现任务序列化。SPI 时钟频率定义为

```vhdl
constant spi_clk_freq : integer := 1_000_000; -- SPI clock frequency in Hz.
```

即 1 MHz，远低于系统时钟，由计数器分频产生。

SPI 片选通过地址常量映射到 FMC 端口与芯片编号的组合，例如：

```vhdl
constant SPI_P4C3_ADDR : integer := 14; -- Address of chip 3 on FMC Port 4.
constant SPI_P4C4_ADDR : integer := 15; -- Address of chip 4 on FMC Port 4.
```

这种编址方式使同一套 SPI 控制逻辑可服务于多个 FMC 端口上的多片器件。

配置流程存在两条并行通路，分别服务于不同场景：

1. **上电自动配置**：初始化序列以查找表形式固化在板卡配置包中（如 `PZ_KU060_config.vhdl` 的 `init_lut`，161 项），由 `spi_task_control.vhdl` 在复位释放后自动遍历执行。该通路不依赖上位机，保证 FPGA 单板上电即可进入可用状态。配置包中对 AD9528 有一条特殊处理——向不存在的地址写入以制造延时（源码注释："write to non-existing address to simulate delay"），这是因 PLL 锁定需要建立时间，而查找表机制本身不支持显式等待指令。

2. **上位机按需配置**：由 `python control/chips.py` 中的 `init_AD9680` / `init_AD9152` / `init_AD9528` 等函数经 SPI 通路下发，并读回状态寄存器校验锁定。`python control/boards.py` 将这些函数组织为板级初始化流程。该通路用于调试阶段的参数迭代与故障诊断。

两条通路共用同一套 SPI 硬件逻辑，区别仅在于命令来源。上位机侧的 SPI 访问封装在 `python control/spi.py` 中，与 `bus.py` 并列构成硬件抽象层的两个分支，详见第五章 5.1 节。

## 3.3 本章小结

本章介绍了系统的硬件架构与接口设计。硬件平台以 Xilinx Kintex UltraScale FPGA 为核心，运行于 250 MHz 系统时钟，内部数据通路统一为 16 位有符号定点格式；通过 FMC 接口支持多种 ADC/DAC 子卡，高速射频链路由 AD9680 ADC、AD9152 DAC 与 AD9528 时钟分发器件构成，经 SPI 接口配置并校验锁定状态。接口设计分三个层次：UART 承担低速高可靠的参数配置业务并以回显校验保证链路可靠性；片内自定义并行总线以 32 位数据、7 位地址、6 位模块选择的编址方案连接 34 个功能模块，其分层命令编码与 `HOLD` 机制分别降低了解码复杂度、实现了超宽参数的原子化更新；SPI 接口则以固化查找表与上位机下发两条通路完成板上器件配置。本章确立的总线协议与数据格式是第四章各功能模块设计的共同基础。

# 第四章 FPGA 逻辑设计与控制算法实现

本章是全文的技术核心，依次介绍动态信号路由矩阵的设计原理、各核心 DSP 模块（DDS 信号发生器、CORDIC 运算器、数字混频器、FIR/IIR 滤波器、PID 控制器）的定点实现，以及 PDH 自动锁定状态机的状态划分与自动阈值标定算法。

## 4.1 动态信号路由矩阵设计

### 4.1.1 设计动机

传统 FPGA 锁频系统的信号处理链路通常在 RTL 代码中硬连线，形如 ADC → 混频器 → 滤波器 → PID → DAC 的固定拓扑。实验中若需改变处理顺序、插入额外环节或复用某个模块，必须修改源码并重新综合布线——对于中等规模设计，一次完整的综合实现耗时可达数十分钟，严重制约实验迭代效率。

本系统的解决思路是：在 FPGA 内部一次性实例化全部功能模块，并在它们之间插入一个全交叉的可配置互联网络。改变信号流向退化为改写若干配置寄存器，耗时从"分钟级重新综合"降至"毫秒级串口写入"。这是第七章所述"软件定义信号链路"创新点的硬件基础。

### 4.1.2 结构与实现

信号路由矩阵实现于 `modules/signal_router/signal_router.vhdl`，其端口声明揭示了矩阵规模：

```vhdl
port(
    core_param_in : in  std_logic_vector(1023 downto 0);
    sig_in        : in  signal_array(63 downto 0);   -- 64 路 16 位数据输入
    sig_out       : out signal_array(63 downto 0);   -- 64 路 16 位数据输出
    ctrl_in       : in  std_logic_vector(63 downto 0); -- 64 路 1 位控制输入
    ctrl_out      : out std_logic_vector(63 downto 0)  -- 64 路 1 位控制输出
);
```

系统实际包含**两套相互独立的交叉开关**：一套处理 64 路 16 位宽的物理信号（`sig_in`/`sig_out`），另一套处理 64 路单比特的布尔控制信号（`ctrl_in`/`ctrl_out`）。将数据与控制分离的理由是资源效率——布尔信号的交叉开关每路仅需 1 位宽的多路选择器，若与 16 位数据混用同一套网络，将浪费 15/16 的选择器资源。

每个输出通道由一个寄存的 64 选 1 多路选择器驱动，核心逻辑为一行 generate 语句：

```vhdl
sig_out_buf(i) <= sig_in_buf(to_integer(unsigned(control(i * 8 + 5 downto i * 8))));
```

即第 $i$ 路输出的数据源，由配置字中对应该通道的 6 位选择码决定。每通道占用 8 位配置空间，位域分配为：

| 位域 | 功能 |
|------|------|
| `[5:0]` | 源端口编号（0–63） |
| `[6]` | 通道使能 |
| `[7]` | 保持（hold） |

64 个通道共需 $64 \times 8 = 512$ 位配置空间，两套交叉开关合计 1024 位，正对应 `core_param_in` 的宽度。控制交叉开关的配置基址定义为

```vhdl
constant ctrl_base_addr : integer := 512;
```

即低 512 位配置数据路由、高 512 位配置控制路由。

端口 0 被保留为特殊值：上位机常量定义 `VOID = 0`，注释说明"Signals to port 0 are ignored. Signals from port 0 are always zero"。这一约定使"未连接"成为一个合法的可表达状态，而无需额外的使能位判断。

`[7]` 位的保持功能由 `sig_out_hold_reg` 与 `ctrl_out_hold_reg` 两组寄存器实现。切换路由配置时，若直接改变选择码，输出将在新旧数据源之间产生一次跳变；置位保持位可令输出锁定在当前值，待配置稳定后再释放，从而实现**无扰动的信号源切换**。这对运行中的闭环系统尤为重要——锁定状态下的输出跳变足以导致失锁。

### 4.1.3 资源与时序考量

全交叉结构的资源消耗随端口数呈平方增长。64 路 16 位的数据交叉开关理论上需要 $64 \times 16 = 1024$ 个 64 选 1 多路选择器，是全系统中布线压力最大的模块。源码中对此有专门的优化约束：

```vhdl
attribute max_fanout : integer;
attribute max_fanout of ... : signal is 10;
```

将扇出上限设为 10，强制综合工具复制驱动寄存器以缩短关键路径。此外每个输出通道均经过寄存器缓冲（`sig_out_buf`），使交叉开关自身构成一级流水，代价是引入 1 个时钟周期的延迟。

> 【待补充】路由矩阵的实际资源占用（LUT / FF 数量）与时序收敛情况（WNS）。需运行 Vivado 综合实现后从资源报告与时序报告中提取，这是评估平方增长代价的关键数据，见第六章 6.1 节。

## 4.2 核心 DSP 模块设计

全部 DSP 模块遵循统一的架构范式：VHDL 内核（`<name>.vhdl`）实现算法，模块封装（`module_<name>.vhdl`）将内核与总线处理器 `bus_handler.vhdl`、参数存储 `parameter_ram.vhdl` 组装为可挂载到片内总线的单元。各内核均带有 `io_buf : buf_type` 泛型参数，可在 `buf_for_io`（输入输出均缓冲）、`buf_i_only`、`buf_o_only`、`buf_none` 四种模式间选择，用于在延迟与时序裕量之间做权衡——对延迟敏感的环路可去掉缓冲级，对时序紧张的路径则保留。

### 4.2.1 直接数字频率合成与信号发生器

DDS 由相位累加器 `modules/accumulator/accumulator.vhdl` 与 CORDIC 三角函数运算器级联构成。

累加器采用 64 位相位累加结构：

```vhdl
signal delta       : unsigned(63 downto 0);  -- 频率字
signal total_incre : unsigned(63 downto 0);  -- 实际累加增量
```

每个时钟周期执行 `acc <= acc + total_incre`。输出频率与频率字的关系为

$$
f_{out} = \frac{\Delta \cdot f_{clk}}{2^{64}}
$$

其中 $f_{clk} = 250$ MHz。由此得到频率分辨率

$$
\Delta f = \frac{f_{clk}}{2^{64}} = \frac{2.5 \times 10^8}{1.8447 \times 10^{19}} \approx 1.36 \times 10^{-11}\ \mathrm{Hz}
$$

这一极高的分辨率对激光稳频有实际意义：扫描腔共振峰时需要极精细的频率步进，而锁定后的频率修正量也可能远小于 1 Hz。

累加器提供两路输出：

```vhdl
acc_out  : out std_logic_vector(15 downto 0);
fast_out : out std_logic_vector(15 downto 0); -- provide an aux output N times the frequency of acc_out
```

取值方式为

```vhdl
acc_out_buf  <= acc(63 downto 48);
fast_out_buf <= acc(63 - to_integer(divisor_digit) downto 48 - to_integer(divisor_digit));
```

`acc_out` 取累加器最高 16 位作为相位输出；`fast_out` 取一个向低位偏移 `divisor_digit` 的 16 位窗口，其相位变化速度为 `acc_out` 的 $2^{\text{divisor\_digit}}$ 倍，即**倍频输出**。偏移量由 `divisor` 参数经优先级编码器求出对数得到，故 `divisor` 仅支持 2 的整数次幂。

> 需要说明：源码注释将 `fast_out` 描述为"N times the frequency of acc_out"，即倍频关系。上位机 Python 层中该端口的显示名为"默认输出"，而 `acc_out` 对应"分频输出"。论文中统一按硬件实际关系表述为倍频。

这一设计的意图在源码注释中说明：使 `fast_out` 可调至接近 0.5 倍采样率，代价是 `acc_out` 的动态范围缩小相应倍数。在 PDH 应用中，`fast_out` 用作扫描锯齿波与状态机的扫描监测输入，`acc_out` 则作为相位送入 CORDIC 生成调制信号。

累加器内部另集成一个环路滤波器（比例系数 `lf_kp` 为 24 位、积分系数 `lf_ki` 为 32 位，积分项带饱和钳位），使累加器本身即可作为数字锁相环的压控振荡器使用。实际累加增量为 `total_incre <= delta + total_feedback`，其中反馈项由 `bias_in` 外部偏置与环路滤波器输出移位合成。

### 4.2.2 CORDIC 三角函数与相位解算

三角函数运算器 `modules/trigonometric/trigonometric.vhdl` 采用 CORDIC（Coordinate Rotation Digital Computer）算法，以纯移位加法实现正余弦生成，避免查找表的存储开销与乘法器占用。

算法的旋转角序列以常量数组存储：

```vhdl
type signed_array is array(natural range <>) of signed(23 downto 0);
-- Storing a variant for 18 iterations
constant a : signed_array(0 to 18) := ( ... );
```

数组含 19 项，对应 $\arctan(2^{-i})$，$i = 0, 1, \dots, 18$。迭代由 generate 语句展开：

```vhdl
iterations : for i in 0 to 17 generate
```

即第 0 级做初始旋转，其后 18 级迭代，共 19 级。内部运算位宽为 24 位，输入输出为 16 位——内部增加 8 位余量用于抑制迭代过程的累积截断误差。

相位与幅度的归一化约定为：相位值 `x8000` 代表 $\pm\pi$，幅度值 `x7586a5` 代表 1.0。CORDIC 的固有增益

$$
K = \prod_{i=0}^{n-1}\sqrt{1 + 2^{-2i}} \approx 1.64676
$$

通过初值预缩放补偿，初始常量取 `c(0) <= x"475e34"`，即 $0.607253 \times \texttt{x7586a5}$，其中 $0.607253 = 1/K$。

流水线结构并非每级一拍。源码中以 `buf_odd` generate 对奇数级插入寄存器（9 拍），`no_buf_even` generate 则为纯组合直通，故 19 级迭代共 10 个寄存器级。这是面积—延迟—时序的三方折衷：全流水可达最高时钟但占用 19 级寄存器，纯组合延迟最小但无法满足 250 MHz 时序。

反三角函数运算器 `modules/inv_trigonometric/inv_trigonometric.vhdl` 结构对称（源码注释："Reworked pipelining structure similar to trigonometric.vhdl"），用于从正交分量解算相位，是相位检测链路的核心。其输入端另有一级预缩放（乘 `x"6DED"`）以防止向量模长溢出。

> 【待补充】两个 CORDIC 模块的总延迟周期数与相位/幅度精度的实测值。按寄存器级数推算分别为 12 拍与 13 拍（`buf_for_io` 配置下），但源码未标注，建议经仿真确认后填入。

### 4.2.3 数字混频器

混频器 `modules/mixer/mixer.vhdl` 是全系统最简洁的模块，实现 PDH 误差信号的解调：

```vhdl
product     <= sig_a_buf * sig_b_buf;      -- signed(31 downto 0)
sig_out_buf <= product(31 downto 16);      -- 取高 16 位
```

两路 16 位有符号输入相乘得 32 位全精度积，取高 16 位输出。这一截断方式等效于乘以 $2^{-16}$ 的定标：由于两个 Q1.15 格式数的乘积为 Q2.30 格式，取高 16 位即还原为 Q1.15，且**永不溢出**。源码文件头注释明确了这一设计意图，并指出若需增益应在输入端预先放大。

该模块无可配置参数，其封装 `module_mixer.vhdl` 使用 `parameter_ram_0`（零容量参数存储）。延迟为 2 个时钟周期（`buf_for_io` 配置下输入输出各一级缓冲）。

### 4.2.4 FIR 低通滤波器

FIR 滤波器 `modules/fir_filter/fir_filter.vhdl` 的文件头注释给出了核心规格："Simple FIR filter that uses 24bit coefficient accuracy and supports exactly 64 taps."

系数存储与定标：

```vhdl
type coef_type is array (0 to 63) of signed(23 downto 0); -- Normalized to Q1.23, -1 to 1
signal norm_64 : signed(17 downto 0); -- Q5.13
signal norm_32 : signed(17 downto 0); -- Q6.12
signal norm_16 : signed(17 downto 0); -- Q7.11
signal taps    : unsigned(5 downto 0);
```

结构为 64 抽头直接型，**未利用线性相位滤波器的系数对称性做折叠优化**——`gen_product` generate 语句实例化 64 个独立乘法器。这是一个明确的资源—通用性折衷：折叠结构可将乘法器数量减半，但要求系数严格对称，从而排除了非线性相位滤波器的使用。

可变抽头数通过三条并行缩放支路实现：当 `taps <= 15` 时选用 `scaled_16` 支路，`taps <= 31` 时选用 `scaled_32`，否则选用 `scaled_64`，每条支路配有独立的 L1 范数归一化系数。抽头数减少时需要更大的缩放因子以维持相同的冲激响应 L1 范数（即相同的直流增益），源码注释对此有说明。

加法树分三级实现：`sum_0`（16 个四输入加法器）→ `sum_1`（4 个）→ `sum_2`（1 个），中间结果均为 Q6.21 格式。延迟按寄存器级数计为 7 拍（输入缓冲、乘积、三级加法树、缩放、输出缓冲各一级）。

### 4.2.5 IIR 滤波器

IIR 滤波器 `modules/iir_filter/iir_filter.vhdl` 的设计显著复杂于 FIR，文件头注释概括为："4th order IIR employing the parallel biquad structure"，并采用了四阶散射前瞻（scattered look-ahead）变换。

结构为**两节双二次型并联**，输出为两节之和：

```vhdl
result <= bq1_sum_ya_0 + bq2_sum_ya_0;
```

系数格式与数量：

```vhdl
-- Each biquad is 4th order scattered, so it takes 9 b and 2 a coefficients
signal bq1_b_0 : signed(26 downto 0);
...
```

每节需 9 个 b 系数（Q3.24）与 2 个 a 系数（Q2.25），均为 27 位。两节合计 22 个系数。

采用并联而非串联、并引入散射前瞻变换，根本原因在于 IIR 的递归结构与高速流水线的内在冲突。直接型 IIR 的反馈环路要求上一个输出在下一个采样时刻前完成计算，即环路内不能插入流水线寄存器，这直接限制了最高时钟频率。四阶散射前瞻变换通过在分子分母同乘一个多项式，将递归的最小延迟从 1 拍扩展到 4 拍，从而允许环路内插入 4 级流水线——代价是系数数量从 3 个 b、2 个 a 膨胀至 9 个 b、2 个 a。这是本系统在 250 MHz 下实现 IIR 滤波的关键技术。

反馈路径的乘法采用长乘法拆分：将 Q4.26 的中间结果拆为高 18 位与低 12 位分别相乘再合并，以适配 DSP48 硬核的 18×27 位输入格式。输出端带饱和检测，溢出时钳位至 `x"7FFF"` 或 `x"8000"` 而非回绕，避免递归结构中溢出回绕引发的自激振荡。

滤波器系数的设计由上位机完成，详见第五章 5.3 节。

### 4.2.6 高性能数字 PID 控制器

PID 控制器 `modules/pid_controller/pid_controller.vhdl` 是闭环系统的核心，其定点设计体现了多项工程考量。

**位宽分配**：

```vhdl
signal error_in_buf  : signed(15 downto 0);
signal integral      : signed(47 downto 0);  -- 48 位积分器
signal gain_p        : signed(23 downto 0);
signal gain_i        : signed(31 downto 0);
signal gain_d        : signed(23 downto 0);
signal product_p     : signed(39 downto 0);
signal product_i     : signed(47 downto 0);
signal product_d     : signed(39 downto 0);
signal limit_integral: signed(47 downto 0);
signal limit_sum     : signed(27 downto 0);
```

积分器取 48 位远宽于 16 位数据通路，这是为积分作用预留足够的动态范围——积分项需累积微小误差至显著修正量，位宽不足将导致小误差被截断而无法消除静态偏差。

**增益定标**：源码在 `gain_p` 声明处给出了关键的标定注释："When gain_p equals gain_i, PI corner at clk / 2pi / 65536 = 600Hz for 250MHz clock"。即当比例与积分增益相等时，PI 转折频率为

$$
f_{PI} = \frac{f_{clk}}{2\pi \cdot 2^{16}} = \frac{2.5\times 10^8}{2\pi \times 65536} \approx 600\ \mathrm{Hz}
$$

该式为参数配置提供了物理标定基准，上位机据此实现物理量到寄存器值的换算（见第五章 5.2 节）。

**三项实现**：误差先减设定点 `error_from_setpoint <= error_in_buf - setpoint`；微分项采用一阶后向差分 `differential <= error_in_buf - error_1`；三项各自独立乘法后求和

```vhdl
sum_buf <= product_p(39 downto 12) + integral(47 downto 20) + product_d(39 downto 12);
```

**抗积分饱和**采用两级限幅。其一为积分器限幅：

```vhdl
-- integral_buf_limited 按 ±limit_integral 钳位后写回 integral
```

关键在于钳位后的值**写回积分器状态**，而非仅限制输出——这才构成真正的 anti-windup。若仅限制输出而放任积分器继续累积，误差反向后需要很长时间才能退出饱和，表现为明显的恢复滞后。其二为总输出限幅，按 `±limit_sum` 钳位，防止送往 DAC 的修正量超出量程。

**漏积分**（leaky integral）机制用于抑制长期漂移。由于 FPGA 内除法器资源昂贵，源码采用移位近似：

```vhdl
signal leak_digit : std_logic_vector(31 downto 0);
-- Not enough resource to implement a division for leaky integral,
-- so use this signal to represent the digits to be shifted
```

由 `leak_array` 生成 32 个移位版本后逐位或运算合成泄漏量，再从积分项中减去。等效泄漏系数为 $\alpha = 1 - 1/(\texttt{leak\_digit} \cdot 2^8)$。因实现方式为移位，`leak_digit` 只能取 2 的整数次幂，上位机在换算时需做幂次对齐并提示量化误差（见 5.2 节）。

**流水线与延迟**：积分支路采用 `interleaving_clk` 二分频交错计算，源码注释说明这等效于将积分运算的采样率降至系统时钟的一半（125 MHz）。这一细节对参数换算至关重要——积分路径与微分路径的有效采样率不同，上位机的 PI 转折频率换算使用 125 MHz，PD 转折频率换算使用 250 MHz。主数据通路的寄存器级数为：输入缓冲、误差求差、乘积、求和、输出缓冲各一级。需注意其封装 `module_pid_controller.vhdl:59` 实例化时使用 `io_buf => buf_none`，省去了输入输出缓冲以最小化环路延迟，此配置下 P/D 通路为 3 级。

## 4.3 PDH 自动锁定状态机

PDH 自动锁定状态机 `modules/pdh_state_machine/pdh_state_machine.vhdl`（305 行）是本系统最具特色的模块。其价值在于将"扫描—判定—锁定"的决策逻辑完全置于 FPGA 硬件内部，响应时间为时钟周期量级，而非依赖上位机软件轮询的毫秒量级。

### 4.3.1 接口与状态划分

模块接口为：

```vhdl
port (
    clk, rst        : in  std_logic;
    core_param_in   : in  std_logic_vector(255 downto 0);
    sig_in          : in  std_logic_vector(15 downto 0);  -- 用于有效性判定的输入信号
    pid_enable      : out std_logic;  -- PID 控制器使能
    mixer_enable    : out std_logic;  -- 混频器使能
    sawtooth_enable : out std_logic;  -- 扫描锯齿波使能
    saw_input       : in  std_logic_vector(15 downto 0)
);
```

三路使能输出分别门控 PID、混频器与锯齿波发生器，构成状态机对信号链路的控制手段。需注意这三个信号为**低有效**语义——锁定态下置 '0'。

状态定义为八个状态：

```vhdl
type state_type is (IDLE, AUTO_AMP, AUTO_TIME, AUTO_WAIT,
                    AUTO_SCANNING, SCANNING, AUTO_LOCKING, LOCKING);
```

> **与研究计划的差异说明**：原研究计划将状态机描述为"扫描（Scan）→ 判定（Judge）→ 锁定（Lock）→ 保持（Hold）"四态流程。实际实现为八态，其中增加的 `AUTO_AMP`、`AUTO_TIME`、`AUTO_WAIT` 三态构成自动参数标定阶段，而手动与自动流程各有独立的扫描/锁定状态。实现较原计划更为完整，本节按代码实况描述。

八个状态构成两条并行的分支链路：

**手动链路**（由上位机指定阈值）：
$$
\texttt{IDLE} \xrightarrow{\texttt{pc\_cmd}=01} \texttt{SCANNING} \xrightarrow{\text{信号持续低于扫描阈值}} \texttt{LOCKING} \xrightarrow{\text{信号持续高于锁定阈值}} \texttt{IDLE}
$$

**自动链路**（硬件自行标定阈值）：
$$
\texttt{IDLE} \xrightarrow{\texttt{pc\_cmd}=10} \texttt{AUTO\_WAIT} \to \texttt{AUTO\_AMP} \to \texttt{AUTO\_TIME} \to \texttt{AUTO\_SCANNING} \to \texttt{AUTO\_LOCKING}
$$

状态跳转由两位命令字 `pc_cmd`（来自参数总线地址 0x00 的最低两位）与锯齿波回扫沿 `sawtooth_jump` 共同驱动。

### 4.3.2 锯齿波回扫沿检测

自动标定的各阶段均以扫描周期为单位推进，因此需要可靠的周期边界标志。源码采用如下判据：

```vhdl
if ((saw_input_signed(15) XOR saw_input_signed(14)) = '1'
    and saw_input_signed(15) /= saw_input_prev(15)) then
    sawtooth_jump <= '1';
```

该条件同时要求符号位与次高位相异（即信号处于量程两端的回扫区）、且符号位发生翻转。相比单纯的符号跳变检测，附加的幅度条件可抑制信号在零点附近的噪声抖动误触发。

### 4.3.3 自动幅度标定与阈值计算

这是本模块的算法核心，对应研究计划中"自动计算阈值逻辑"的要求。

**`AUTO_AMP` 态**在一个完整扫描周期内追踪输入信号的极值：

```vhdl
if sig_in_buf < min_sig_in then min_sig_in <= sig_in_buf; end if;
if sig_in_buf > max_sig_in then max_sig_in <= sig_in_buf; end if;
```

两个极值寄存器在进入该态时被初始化为相反的极端值（`min_sig_in` 置为最大正值、`max_sig_in` 置为最小负值），以保证首个采样即可正确更新。

**阈值计算**由组合逻辑完成，分三级流水：

```vhdl
diff_sig_in_buf <= resize(max_sig_in, 17) - resize(min_sig_in, 17);     -- Q17.0 峰峰值
scaled_scan_sig_in_buf <= diff_sig_in * coef_scan;                      -- Q18.15
auto_threshold_signal_scanning_buf <= min_sig_in + scaled_scan_sig_in(30 downto 15); -- Q16.0
```

即阈值按下式计算：

$$
V_{th} = V_{min} + (V_{max} - V_{min}) \cdot c
$$

其中系数 $c$（`coef_scan` 与 `coef_lock`）为 Q1.15 格式的 16 位有符号数，由上位机配置。扫描阈值与锁定阈值使用各自独立的系数，因而可设置不同的判定水平——通常锁定判据应比扫描判据更严格，以避免在共振峰边缘误判为已锁定。

这一相对阈值方案的优势在于**自适应于信号幅度**。激光功率漂移、光路耦合效率变化、探测器增益差异都会改变误差信号的绝对幅度，固定阈值在此情况下需频繁重新标定；而相对阈值仅依赖峰峰值的比例，对幅度变化免疫。

**`AUTO_TIME` 态**进一步自动标定时间门限。该态测量信号持续低于扫描阈值的时长 `time_able`，并据此导出两个时间参数：

```vhdl
if time_able > min_AUTO_TIME then
    measurement_done <= '1';
    auto_time_duration_scanning <= '0' & time_able(31 downto 1);  -- ×0.5
    auto_time_duration_locking  <= time_able(29 downto 0) & "00"; -- ×4
```

扫描判定时长取测得值的一半，锁定判定时长取四倍——两者均以移位实现，无需乘法器。取半的用意是使扫描阶段的判定比实测的共振峰宽度更宽松以确保捕获，取四倍则使锁定阶段的失锁判定更为迟缓以避免瞬态扰动引发误判。

另设下限门限防止噪声误触发：

```vhdl
constant min_AUTO_TIME : unsigned(15 downto 0) := to_unsigned(500, 16);
```

即过阈时长须超过 500 个时钟周期（250 MHz 下为 2 μs）才被认可为有效的共振峰。

### 4.3.4 判定与锁定

**`AUTO_SCANNING` 态**执行持续时间判定：信号低于阈值时计数器累加，达到 `auto_time_duration_scanning` 则转入锁定；信号一旦高于阈值即将计数器清零。这一"连续满足"而非"瞬时满足"的判据有效抑制了噪声尖峰造成的误锁定。

**`AUTO_LOCKING` 态**置 `pid_enable <= '0'`、`mixer_enable <= '0'`（低有效，即启用 PID 与混频器），同时 `sawtooth_enable <= '1'` 停止扫描，系统进入闭环锁定。

### 4.3.5 关于自动重锁机制

研究计划中列有"自动重新锁定机制（Auto-relogin）"一项。经核查代码，**该功能当前尚未实现**。`AUTO_LOCKING` 态在检测到信号不再满足锁定条件时，仅执行计数器清零：

```vhdl
when AUTO_LOCKING =>
    ...
    -- 失锁时仅 time_able <= (others => '0')，不发生状态跳转
```

离开该状态的唯一路径是 `pc_cmd` 被上位机改写为 `"00"` 或 `"11"` 而回到 `IDLE`。手动链路的 `LOCKING` 态同理。因此当前的失锁恢复仍需上位机介入，不属于硬件自主重锁。

实现硬件自动重锁在结构上并不困难——只需在 `AUTO_LOCKING` 态增加一条指向 `AUTO_SCANNING` 的跳转，条件为失锁持续时间超过 `auto_time_duration_locking`。由于阈值与时间参数已在自动标定阶段求得并保存，重锁无需重新标定即可直接复用。该项列为第七章的改进方向。

### 4.4.2 延迟预算

各模块延迟（以时钟周期计，250 MHz 下每周期 4 ns）：

| 模块 | 推算延迟 | 说明 |
|------|---------|------|
| 信号路由矩阵 | 1 | 输出寄存器一级 |

| CORDIC 三角函数 | 12 | 10 个迭代寄存器级 + 输入输出缓冲 |
| CORDIC 反三角函数 | 13 | 另含一级输入预缩放 |
| PID 控制器 | 3 | `buf_none` 配置，P/D 通路 |
| IIR 滤波器 | 【待测】 | 递归环路，需仿真确认 |

> 上表除混频器与路由矩阵外，均为按源码寄存器级数推算的结果，**源码中未标注总延迟**。IIR 滤波器因含递归环路与组合/寄存混合结构，无法由静态分析确定，须经仿真测定。论文定稿前建议通过行为级仿真对全部模块的延迟做实测确认。

环路总延迟是决定控制带宽上限的关键参数。按第二章 2.3 节的分析，延迟 $\tau$ 在频率 $\omega$ 处引入相移 $\Delta\phi = -\omega\tau$，若要求相位裕度不低于 $45°$，则闭环带宽上限约为

$$
f_{BW} \lesssim \frac{1}{8\tau}
$$

典型 PDH 链路为 ADC → 混频器 → FIR → PID → DAC，其 FPGA 内部延迟为各模块延迟与路由级延迟之和。完整的环路延迟还须计入 ADC 与 DAC 的转换延迟及模拟电路响应，需实测确定，见第六章 6.1 节。

## 4.5 本章小结

本章详述了 FPGA 侧的逻辑设计与算法实现。信号路由矩阵以 64×64 双套全交叉结构（数据与控制分离）实现任意模块互联，配合保持位支持无扰动切换，使信号链路的重构由重新综合降为寄存器写入。核心 DSP 模块均采用定点实现并针对 250 MHz 时钟做了专门优化：相位累加器以 64 位累加实现 $1.36\times10^{-11}$ Hz 的频率分辨率；CORDIC 以 19 级迭代、24 位内部精度实现三角函数与相位解算，采用隔级插入寄存器的半流水结构平衡时序与面积；FIR 为 64 抽头直接型并支持 16/32/64 抽头可变配置；IIR 采用两节并联双二次结构配合四阶散射前瞻变换，化解了递归结构与高速流水线的冲突；PID 控制器以 48 位积分器、两级限幅抗饱和与移位实现的漏积分构成完整的控制内核，并通过积分支路二分频交错降低资源压力。PDH 自动锁定状态机以八态流程实现硬件级自动锁定，其中 `AUTO_AMP` / `AUTO_TIME` 两态构成自动参数标定环节，采用基于峰峰值比例的相对阈值方案，对信号幅度漂移具有免疫性。需要指出的是，自动重锁机制当前尚未实现，各模块的资源占用与时序数据亦待综合报告补充。

# 第五章 上位机软件系统设计

本章介绍上位机软件的分层架构、面向对象的模块封装与参数物理量映射机制、自动化初始化与校准流程，以及可视化节点编辑器与智能体辅助设计工具。

## 5.1 软件架构分层

上位机软件采用四层结构，每一层仅依赖其直接下层，层间以明确的数据类型边界划分职责：

```
应用层（App）          实验脚本 / 可视化编辑器 / LLM 智能体
      ↓                        物理量（Hz、dB、V）
硬件抽象层（HAL）       ModuleBase 及其子类
      ↓                        模块名 + 寄存器地址 + 整数值
协议层                 Bus / Spi
      ↓                        ASCII 命令帧（字节串）
驱动层                 MySerial
      ↓                        串行字节流
                            FPGA
```

分层的核心价值在于**关注点分离**：应用层的实验脚本只需表达"把 PI 转折频率设为 1 kHz"，无需知晓该参数对应哪个寄存器、采用何种定点格式、需要几次总线写入。

### 5.1.1 驱动层

驱动层由 `python control/uart.py` 中的 `MySerial` 类实现，继承自 pyserial 的 `Serial`，仅扩展一个方法：

```python
def post(self, message, repeated = True, verbose = False):
```

该方法实现了**两阶段握手**，这是全系统可靠性的第一道保障：

1. **回显校验阶段**（`repeated=True` 时启用）：读取 FPGA 回传数据直至遇到帧结束符 `b"!"`，循环等待至响应长度不小于 11 字节且在倒数第 6、第 11 字节位置出现分隔符 `.`，随后将回显与原始命令逐字节比对，不一致则抛出异常。FPGA 对每条命令原样回显，使链路上的位错误可被立即发现。

2. **应答校验阶段**：再次读取至 `b"!"`，要求响应前 5 字节为 `b":ACKN"`，否则判定为执行失败。

两阶段分别校验"命令是否被正确接收"与"命令是否被正确执行"，二者是不同的失效模式：前者对应链路误码，后者对应地址越界、参数非法等逻辑错误。

链路参数为 115200 波特、8 数据位、偶校验、1 停止位。FPGA 侧的偶校验在 `uart_rx.vhdl` 中以组合逻辑实现（`parity <= xor data`），与上位机的 `parity="E"` 配置对应。因此系统共有三重错误检测：硬件偶校验、完整命令回显、`:ACKN` 应答。

> 需要指出代码中的一处不一致：`uart.py:34` 的 `__main__` 演示代码使用 19200 波特，而实际运行配置 `env.py:16` 与硬件常量 `mypak.vhdl:82` 均为 115200。前者属于遗留的演示代码，论文以 115200 为准。

### 5.1.2 协议层

协议层将寄存器访问翻译为 ASCII 命令帧，由 `python control/bus.py` 的 `Bus` 类实现。该文件仅 41 行，是分层设计简洁性的体现。

写操作的组帧逻辑：

```python
def write(self, module, address, data, hold = False):
    module = module.upper()
    if type(address) == int:
        address = address.to_bytes(4, "big")
    ...
    message = b":BUS_." + module.encode() + b".WRTE.ADDR." + address \
            + b".DATA." + data
    message += b".HOLD!" if hold else b"!"
    self.serial.post(message)
```

地址与数据均接受整数或十六进制字符串两种输入，统一规整为 4 字节大端序。命令帧以 `:` 起始、`!` 结束、`.` 分隔字段，模块名为 4 字符大写标识（如 `ROUT`、`PIDC`、`FIRF`），与 `mypak.vhdl` 中的 `BUS_*_ADDR` 常量一一对应。

读操作组帧后从应答帧中切出数据载荷：

```python
def read(self, module, address):
    message = b":BUS_." + module.encode() + b".READ.ADDR." + address + b"!"
    response = self.serial.post(message)
    return response[-5:-1]
```

`hold` 参数直接对应第三章 3.2.2 节所述的 `WRITE_HOLD` 总线命令，是实现多寄存器原子更新的协议层支点。

SPI 通路由 `python control/spi.py` 的 `Spi` 类并列实现。由于 SPI 为全双工，读写在同一次事务中完成，帧格式编码了总传输字节数与写入字节数：

```python
message = b":SPI_." + module.encode() + b".\x00\x00" \
        + (write_length * 8 - 1).to_bytes(1, "big") \
        + (length * 8 - 1).to_bytes(1, "big") + b"." + data + b"!"
```

返回数据为 `response[-1 - read_length:-1]`，其中 `read_length = length - write_length`。`SpiChip` 子类针对 ADI 系列器件的 2 字节寄存器地址做了特化：写操作为 3 字节出、0 字节回，读操作为 2 字节出、1 字节回。这解释了 `chips.py` 中所有调用均为 6 位十六进制字符串的原因——`"057115"` 表示向地址 `0x0571` 写入 `0x15`，而读操作通过置位地址最高位实现（`"856F"` 即读 `0x056F`），符合 ADI 器件的读写位约定。

### 5.1.3 硬件抽象层

硬件抽象层由 `python control/module.py` 的 `ModuleBase` 及其 8 个子类构成（共 793 行），是上位机软件的核心。详见 5.2 节。

## 5.2 面向对象的模块化控制

### 5.2.1 参数描述的三类字典

`ModuleBase` 以三个类级字典描述一个硬件模块的全部可配置参数：

```python
class ModuleBase():
    # parameter_list[(int)address] = {"name": (str)name, "width": (int)width}
    parameter_list = {}
    # deduced_parameter_list[(str)name] = method
    deduced_parameter_list = {}
    # alias_list[(str)alias] = (int)address
    alias_list = {}
```

三者分工如下：

- `parameter_list` 是**寄存器映射表**，记录每个地址对应的参数名与位宽。位宽信息用于负数的补码转换与布尔参数的合法性校验。
- `alias_list` 提供**人性化别名**。例如 `ModulePID` 将 `"gain_p"`、`"p"`、`"kp"`、`"k_p"` 四个名称均映射到地址 0，使实验脚本的书写更自然。
- `deduced_parameter_list` 是**间接参数**，即没有单一寄存器与之对应、需经计算才能落地的物理量，其值为一个方法而非地址。

三类参数的统一入口是 `process_designator`：

```python
def process_designator(self, designator):
    if type(designator) == str:
        address = self.alias_list.get(designator, None)
        if address is None:
            parameter_func = self.deduced_parameter_list.get(designator, None)
            if parameter_func is None:
                raise ValueError("Invalid address or parameter name")
            return parameter_func(self)   # 返回可调用对象
        return address                     # 返回整数地址
    return designator
```

该方法对字符串先查别名表、再查间接参数表，返回**整数地址或可调用对象**两种类型之一。上层方法据返回类型分支处理——这是一种以返回类型携带语义的设计，使单一接口同时支持直接与间接参数。

### 5.2.2 原子化多寄存器写入

`write` 方法的间接参数分支是本层最具价值的设计：

```python
def write(self, designator, data, hold = False):
    ret = self.process_designator(designator)
    if type(ret) == int:
        # 直接参数：单次写入，负数按位宽转补码
        if type(data) == int and data < 0:
            width = self.parameter_list.get(address, {...})["width"]
            data = 2 ** width + data
        return self.bus.write(self.name, address, data, hold)
    elif callable(ret):
        address_data_pairs = ret(data)
        for addr, dat in address_data_pairs[:-1]:
            ...
            self.bus.write(self.name, addr, dat, True)   # 前 N-1 条置 hold
        addr, dat = address_data_pairs[-1]
        return self.bus.write(self.name, addr, dat, hold) # 最后一条提交
```

间接参数的处理函数返回一个 `(地址, 数据)` 对的列表，`write` 将前 N−1 条以 `hold=True` 发送、最后一条才提交。于是一次物理量赋值在硬件侧表现为**单次原子生效**，中间状态不会作用于运行中的控制环路。这是协议层 `hold` 机制、硬件 `wen`/`wval` 分离机制与软件层参数抽象三者协同的结果，贯穿三个层次。

`ModuleBase` 的其余方法各司其职：`reset()` 依次发送 `RSTR`/`SETR`/`RSTC`/`SETC` 四条控制命令，分别复位参数 RAM 与模块内核；`set()` 仅接受位宽为 1 的布尔参数并容纳多种真值写法；`readv()` 在 `read()` 之上做有符号整数转换；`flip_on()`/`flip_off()` 用于为脉冲触发型参数制造干净的边沿——先读当前值，若已处于目标电平则先写反相值，再写目标值，确保边沿必然产生。

### 5.2.3 参数的物理量映射

物理量映射是间接参数机制的主要用途。`ModulePID` 的源码注释完整给出了全套换算关系：

$$
\text{总增益(dB)} = 20\log_{10}\left(\frac{g_p}{2^{16}}\right)
$$

$$
f_{PI} = \frac{f_s}{2\pi}\cdot\frac{g_i}{g_p}\cdot\frac{1}{2^{16}}, \qquad
f_{PD} = \frac{f_s}{2\pi}\cdot\frac{g_p}{g_d}
$$

$$
\alpha = 1 - \frac{1}{\texttt{leak\_digit}\cdot 2^{8}}, \qquad
f_{sat} = \frac{f_s}{2\pi\cdot\texttt{leak\_digit}\cdot 256}
$$

**两个采样率的区别**必须特别注意。源码注释明确说明："Sampling frequency involving integral is set to 125MHz at half system clock due to pipelining"。因此代码中 PI 转折频率换算使用 125 MHz：

```python
target_gain_i = int(round(current_gain_p * data * 2 * np.pi / 125000000 * 2 ** 16))
```

而 PD 转折频率换算使用 250 MHz：

```python
target_gain_d = int(round(current_gain_p * 250000000 / (data * 2 * np.pi)))
```

这直接源于第四章 4.2.6 节所述的积分支路二分频交错设计——软硬件的这一对应关系是软硬件协同设计的典型例证。

**总增益调节的增益形状保持**是另一处精心设计。`overall_gain_func` 在改变 $g_p$ 时，按同一比例同步缩放 $g_i$ 与 $g_d$：

```python
scale_factor = np.abs(target_gain_p / current_gain_p)
target_gain_i = int(round(current_gain_i * scale_factor))
target_gain_d = int(round(current_gain_d * scale_factor))
...
return [(0, target_gain_p), (1, target_gain_i), (2, target_gain_d)]
```

三项同时按比例变化意味着两个转折频率 $f_{PI}$、$f_{PD}$ 保持不变，即**环路的频率响应形状不变、仅整体增益平移**。这正是实验中调节环路增益时所期望的行为：先整形后调增益，而不必每次改增益都重新整形。三个寄存器经上述 `hold` 机制原子提交。

**DDS 频率字换算**是最直观的映射实例：

```python
def freq_func(self, data = None):
    if data > 250000000 / 2:
        raise ValueError("Frequency exceeds Nyquist limit")
    ratio = self.read("ratio")
    target_var = int(round(data * 2 ** 64 / 250000000 / ratio))
    low  =  target_var        & 0xFFFFFFFF
    high = (target_var >> 32) & 0xFFFFFFFF
    return [(0, low), (1, high)]
```

即 $\Delta = \mathrm{round}\!\left(f \cdot 2^{64} / (f_{clk}\cdot r)\right)$，64 位频率字拆为两个 32 位寄存器原子写入，并在入口处做奈奎斯特限制校验。反向换算为 $f = \Delta \cdot f_{clk} / 2^{64} \cdot r$，分辨率即第四章给出的 $1.36\times10^{-11}$ Hz。

**量化误差的显式提示**。漏积分系数因硬件以移位实现而只能取 2 的幂，`saturation_gain_func` 在对齐幂次后主动打印实际实现值与请求值的差异：

```python
target_leak_digit = 2 ** log_target_leak_digit
print(f"Implemented saturation gain: {...} dB, requested: {data} dB")
```

这种"不静默吞掉量化误差"的做法对实验可信度有实际意义——使用者能立即知道所设参数与实际生效值的偏差。

**线性变换矩阵系数**的映射较为直接：系数取值限定在 $[-1, 1]$，按 `coef_int = int(round(data * (2 ** 15 - 1)))` 转为 Q1.15 整数，负数以 `2 ** 16 + coef_int` 转补码。

定点数运算的通用支撑由 `python control/fixed.py` 的 `fixed` 类提供。该类以 `Qm.n` 格式字符串构造（正则 `^Q([0-9]+)\.([0-9]+)$`），`scale = 2 ** frac_bits`，`value = int(round(value * scale))`，并实现了完整的算符重载与溢出检查。该类主要服务于 `IIR.py` 的系数量化与测试向量生成；`module.py` 中的换算则以 `2 **` 字面量内联实现。

## 5.3 自动化脚本与校准流程

### 5.3.1 环境初始化

`python control/env.py` 是实验的操作入口，在模块加载时即打开串口，并定义了一组实验配置例程：

| 函数 | 用途 |
|------|------|
| `init()` | 标准初始化（含外部参考） |
| `init_no_ref()` | 无外部参考初始化 |
| `setup_pll()` | 锁相环配置 |
| `setup_duallock()` | 双路锁定配置 |
| `setup_pdh()` | PDH 锁定配置 |
| `setup_sclodpllpid()` | SCLO + 数字锁相环 + PID 配置 |
| `setup_sclo()` | SCLO 配置 |
| `setup_iir_test()` | IIR 滤波器测试配置 |

这些例程将"搭建某个实验拓扑"固化为一次函数调用，内容包括配置信号路由矩阵的互联关系、设置各模块参数、使能相应模块。它们是实验可重复性的保障——同一配置可被精确复现，而非依赖手工操作记录。

### 5.3.2 时钟与 PLL 校准

板级器件的校准由 `chips.py`、`boards.py` 两级组织。`boards.py` 定义板卡与芯片的组合关系：

```python
def init_FH8052(spi, port):
    init_AD9528(spi, port, 3)   # 时钟分发，片选 3
    init_AD9680(spi, port, 1)   # ADC，片选 1
    init_AD9152(spi, port, 2)   # DAC，片选 2
```

初始化顺序有其必然性：时钟分发器件必须先于 ADC/DAC 配置并锁定，否则后者缺乏有效的采样时钟。

`chips.py` 中各初始化函数的末尾均带锁定校验：

| 函数 | 校验寄存器 | 期望值 |
|------|-----------|--------|
| `init_AD9680` | `0x056F` | `0x80` |
| `init_AD9152` | `0x0281` | `0x03` |
| `init_AD9528` | `0x0508` | `f2`/`f3`/`e6`/`e7` 之一 |

校验失败即抛出异常，使配置错误在初始化阶段暴露而非在实验中表现为难以定位的信号异常。

AD9528 的配置包含 PLL2 校准序列（先写 `020301` 启动校准、再写 `020300` 结束）、SYSREF 请求（`040397`）与同步序列（`032A01`/`032A00`），每组写入后均跟一条 `000F01`（update all）使配置生效。各输出通道的频率规划在源码注释中逐条标注：

| 通道 | 频率 | 用途 |
|------|------|------|
| 2 | 1 GHz | ADC 器件时钟 |
| 4 | 1 GHz | DAC 器件时钟 |
| 1, 5, 8, 9 | 3.90625 MHz | SYSREF |
| 3, 6, 7, 10, 13 | 250 MHz | 参考/核心时钟 |

`init_AD9528_ext_ref` 为外部参考变体，差异在于寄存器 `0106`/`0107`（使能 PLL1）以及通道 6、10 输出 200 MHz 而非 250 MHz。

### 5.3.3 FIR 系数加载

FIR 系数的加载流程体现了定点实现对数值范围的严格要求。`qt_env.py:277` 的 `load_fir` 方法：

```python
coef = [float(line.strip()) for line in lines]
coef = np.array(coef)
coef /= np.max(np.abs(coef))      # 归一化至单位峰值
coef *= 0.98                       # 预留 2% 余量
l1_norm = sum(np.abs(coef))
norm = 32 / l1_norm * 0.98
self.fir.load_coef(coef, norm)
self.fir2.load_coef(coef, norm)
```

两步缩放各有其由：

1. **峰值归一化**使系数落入 Q1.23 格式可表示的 $[-1, 1]$ 区间，`×0.98` 的余量防止舍入后溢出；
2. **L1 范数归一化**决定滤波器的直流增益。冲激响应的 L1 范数即最坏情况下的增益上界，令 `norm = 32 / l1_norm * 0.98` 可保证任意输入下输出不溢出。

系数被加载到 `fir` 与 `fir2` 两个实例，对应正交解调链路的 I、Q 两路。

`ModuleFIRFilter.load_coef` 完成量化与写入：

```python
coef_int = np.round(coef_list * (2 ** 23 - 1))              # Q1.23
if coef_int[i] < 0: coef_int[i] = 2 ** 24 + coef_int[i]      # 补码
```

64 个系数写入地址 0–63，归一化因子按抽头数写入不同地址（64 抽头→地址 64，32 抽头→65，16 抽头→66），最后将 `taps - 1` 写入地址 67 作为提交写入——即抽头数的写入同时充当"配置生效"的触发，使 68 个寄存器的更新构成一次原子事务。

`fir_coef.txt` 为纯文本格式，每行一个十进制系数，共 64 个值，呈对称低通冲激响应。

除文件加载外，`design_lowpass` 方法提供在线设计能力，采用 Parks-McClellan 等波纹逼近：

```python
signal.remez(taps, [0, freq_pass, freq_stop, freq_sample / 2], [1, 0],
             fs=freq_sample, weight=[1, weight])
```

### 5.3.4 IIR 系数设计

IIR 的系数设计显著复杂于 FIR，`python control/IIR.py` 的文件头注释说明了目标格式："Dedicated for 4th order IIR of parallel biquad structure with 4-sla. Optimal range and precisions: b: Q3.24, a: Q2.25, interm: Q4.26"。

`get_IIR_parameters(ftype, cutoff_frequency, sample_frequency)` 的处理流程分五步：

1. **原型设计**：`signal.iirfilter(4, ..., btype='lowpass', ftype=ftype, rs=80, rp=0.05)`，四阶低通，阻带衰减 80 dB、通带波纹 0.05 dB。`ftype` 透传至 scipy，故 `butter`、`cheby1`、`cheby2`、`ellip`、`bessel` 均可使用。
2. **部分分式分解**：`signal.residuez(b, a)` 将直接型转为留数—极点表示，为并联结构做准备。
3. **共轭极点配对重组**：将共轭极点对重组为实系数双二次节，如 `a_0 = [1, -2*Re(p[0]), |p[0]|**2]`。
4. **增益均衡**：`balance_direct` 在两节之间分配常数增益，使系数落入定点可表示范围。提供 `uniform`、`min_max`、`balanced_gain`、`balanced_norm`、`balanced_pole` 五种策略，按滤波器类型自动选择（`butter`→`balanced_pole`，`ellip`→`balanced_gain`，其余→`balanced_norm`），其中两种策略通过黄金分割搜索寻优。
5. **散射前瞻变换**：`scatter_look_ahead` 求解 6×6 线性方程组得到乘子多项式，再将其卷积进分子分母，使每节递归获得 4 拍延迟余量——即第四章 4.2.5 节所述变换的系数求解实现。

最后做符号翻转以适配硬件的累加约定（`a_0[1:] = -a_0[1:]`）。

`load_coef` 按 b、a 不同格式分别量化：

```python
bq1_b_int = np.round(bq1_b * 2 ** 24)   # Q3.24
bq1_a_int = np.round(bq1_a * 2 ** 25)   # Q2.25
```

22 个系数中前 21 个以 `hold=True` 写入、最后一个提交。

## 5.4 可视化节点编辑器与智能体辅助设计

### 5.4.1 节点编辑器

图形界面基于 PySide6 实现，模块划分为：`qt_UI1.py` 为应用入口；`qt_ui_mainwindow.py`（1431 行）为编排层，负责串口连接、参数同步、路由配置与配置存取；`qt_ui_graph.py` 提供 `DiagramScene`、`DiagramView`、`EdgeItem` 与组件面板；`qt_module.py` 包含 `NodeItem` 基类与 10 个模块类，经 `module_factory` 字典映射覆盖 14 种模块类型。

交互方式为：从右侧面板拖拽模块到画布、点击输出端口拖至输入端口建立连线、双击模块弹出参数对话框、拖动节点至右侧区域删除、点击已连接的输入端口断开连线。

画布上的拓扑与硬件状态存在直接映射：建立一条连线即对应向信号路由矩阵写入一个选择码。因此图形编辑不是示意图绘制，而是**硬件配置的直接操作界面**。

### 5.4.2 设计期类型检查

系统定义了四类信号类型，并以不同图形标记区分端口：

| 信号类型 | 图形标记 | 可接受输入 | 含义 |
|---------|---------|-----------|------|
| `level` | 五角星 | level, phase, differential | 通用幅度量 |
| `phase` | 圆形 | phase | 相位量 |
| `differential` | 菱形 | level, differential | 相位差分量 |
| `bool` | 方形 | bool | 单比特控制 |

标记由 `PortItem._draw_signal_markers`（位于 `qt_module.py`）绘制，类型不匹配的连线在建立阶段即被拒绝。

这一机制的意义在于将一类错误前移至设计阶段。相位量与幅度量在硬件上均为 16 位整数，混接不会产生任何电气错误，但物理含义错误——例如把相位信号直接送入 PID 的误差输入，环路会因相位的 $2\pi$ 回绕而无法稳定。此类错误在实验中表现为难以归因的"锁不住"，而类型系统使其在连线时即被阻止。开发者模式可解除物理信号类型间的限制，以支持非常规实验。

### 5.4.3 智能体辅助设计

`FPGA_Agent/` 目录实现了一个基于大语言模型的设计辅助层，通过函数调用操作画布，使实验拓扑可由自然语言描述生成。

共定义 9 个工具（`tool_definitions.py`）：`create_module`、`connect_modules`、`list_modules`、`disconnect_module`、`set_parameter`、`get_module_info`、`generate_module`、`auto_layout`、`clear_canvas`。

架构上的关键设计是 `CanvasBridge` 门面类。智能体的工具调用不直接触碰 Qt 对象，而经由该类提供的字典化接口（`create_node`、`create_connection`、`list_nodes`、`get_port_info`、`set_node_params`、`remove_node`、`disconnect_input` 等 13 个公开方法）。这一隔离使模型的输出无法破坏图形界面的内部状态——工具调用的失败最坏情况是返回错误字典，而非使界面崩溃。

`agent_core.py` 在 `QThread` 工作线程中执行函数调用循环，迭代上限由配置项 `max_tool_iterations` 控制（默认 15），防止模型陷入无限工具调用。模块知识库 `module_registry.py` 收录 12 个基础模块（`MODULE_REGISTRY`）、2 个复合模块（`COMPOSITE_MODULES`：正弦波发生器、数字控制振荡器）与 2 个特殊节点（`SPECIAL_NODES`：布尔常量），并内置 `PDH_LOCKING_PATTERN` 作为标准 PDH 拓扑的参考连线清单。

语言模型接口 `llm_client.py` 采用 OpenAI 兼容的 `/chat/completions` 协议，可对接多种服务端。

`code_generator.py` 提供新模块的代码生成能力，为单个模块产出 VHDL 内核骨架、VHDL 模块封装、Python 硬件类、Python 节点类、参数模式与端口分配记录共六类文件。需要明确其局限：生成的 VHDL 内核仅为**骨架**，输入输出缓冲与总线接口完整，但信号处理主体仍需硬件工程师填写；且生成的 Python 类需重启应用后方可生效。

## 5.5 本章小结

本章介绍了上位机软件系统的设计。软件采用驱动层、协议层、硬件抽象层、应用层四层结构，层间以明确的数据类型边界划分职责。驱动层以回显校验与 `:ACKN` 应答构成两阶段握手，配合硬件偶校验形成三重错误检测；协议层以 41 行代码完成寄存器访问到 ASCII 命令帧的翻译；硬件抽象层以 `parameter_list`、`alias_list`、`deduced_parameter_list` 三类字典描述模块参数，并通过"间接参数返回地址—数据对列表 + 前 N−1 条置 hold"的机制实现多寄存器参数的原子化更新，与协议层 `hold` 命令、硬件 `wen`/`wval` 分离机制三层协同。参数物理量映射将寄存器整数值与频率、增益、转折频率等物理量双向换算，其中 PID 积分支路采用 125 MHz、微分支路采用 250 MHz 的差异直接反映了硬件的二分频交错设计；总增益调节时同步缩放三项增益以保持环路频响形状不变；漏积分系数的幂次量化误差被显式提示。自动化脚本层面，`env.py` 将实验拓扑固化为可复现的函数调用，板级校准以"时钟先行 + 逐级锁定校验"组织，FIR 与 IIR 的系数设计分别实现了两步缩放归一化与五步定点化流程。图形界面将画布拓扑直接映射为硬件路由配置，并以四类信号类型的设计期检查前移一类物理含义错误；智能体层则以门面隔离的 9 个工具实现自然语言到实验拓扑的转换。

## 6.1 板级性能测试

### 6.1.1 ADC/DAC 有效位数与信噪比测试

**测试目的**：确定模拟前端的实际有效位数（ENOB）与信噪比，这决定了误差信号的检测精度下限，是第 6.3 节噪声建模的输入参数。

**理论依据**：理想 $N$ 位量化器的信噪比上限为

$$
\mathrm{SNR}_{\max} = 6.02N + 1.76\ \mathrm{dB}
$$

对 16 位系统即 98.1 dB。实测值必然低于此上界，差值来自孔径抖动、参考电压噪声、输入缓冲非线性与 FPGA 内部定点截断。由实测信噪比可反推有效位数：

$$
\mathrm{ENOB} = \frac{\mathrm{SNR}_{\mathrm{measured}} - 1.76}{6.02}
$$

采样时钟抖动 $\sigma_t$ 对信噪比的限制为

$$
\mathrm{SNR}_{\mathrm{jitter}} = -20\log_{10}(2\pi f_{in}\sigma_t)
$$

当该项与量化噪声可比时成为主导因素，故需在不同输入频率下测量以分离两项贡献。

**测试方法**：向 ADC 输入低噪声单频正弦信号，经 FPGA 内部的数据记录模块（`modules/data_logger/`）或波形存储上传通路（`modules/waveform_storage_upload/`，含 DDR4 缓存与以太网回传）采集时域数据，在上位机做 FFT 分析，由基波与噪声底的功率比计算 SNR、SINAD 与 ENOB。DAC 测试则由 FPGA 内部 DDS 产生单频信号，经 DAC 输出后用频谱分析仪测量。

**测试步骤**：
1. 完成板级初始化（`boards.py` 中对应板卡的 `init_*` 函数），确认 AD9528 / AD9680 / AD9152 均通过锁定校验；
2. 输入信号源经带通滤波后接入 ADC 通道，幅度设为满量程的约 −1 dBFS；
3. 采集不少于 $2^{16}$ 点数据，加窗后做 FFT；
4. 分别在若干输入频率下重复，以区分量化噪声与抖动贡献。

### 6.1.2 系统环路延迟测量

**测试目的**：测定闭环系统的总延迟，这是决定控制带宽上限的关键参数，直接验证第四章 4.4.2 节的延迟预算推算。

**理论依据**：按第二章 2.3 节的分析，延迟 $\tau$ 在频率 $\omega$ 处引入附加相移 $\Delta\phi = -\omega\tau$。若要求相位裕度不低于 $\varphi_m$，单位增益带宽上限为

$$
f_{UGF} \le \frac{1}{2\pi\tau}\left(\frac{\pi}{2} - \varphi_m\right)
$$

取 $\varphi_m = 45°$ 时简化为 $f_{UGF} \lesssim 1/(8\tau)$。

**测试方法**：采用阶跃响应法与频响法两种方式交叉验证。

*阶跃响应法*：配置信号路由矩阵建立"ADC 输入 → 待测链路 → DAC 输出"的开环通路，在 ADC 输入端施加阶跃信号，用示波器同时观测输入与 DAC 输出，两者跳变的时间差即为总延迟。该方法直观但分辨率受示波器带宽限制。

*频响法*：以网络分析仪或信号源+锁相放大器测量开环链路的相频特性，由相位斜率求群延迟 $\tau = -d\phi/d\omega$。该方法精度更高，且可分辨延迟的频率依赖性。

**延迟分解**：总延迟应分项核算以便定位优化空间：

| 环节 | 理论估算 | 实测 | 说明 |
|------|---------|------|------|
| 模拟前端 + 抗混叠滤波 | 【待测】 | 【待测】 | 群延迟 |
| ADC 转换与输出流水线 | 【待测】 | 【待测】 | 查器件手册 + 实测 |
| 采样保持等效延迟 | $T/2 = 2$ ns | — | 理论值，$T = 4$ ns |
| 信号路由矩阵 | 1 周期 = 4 ns | 【待测】 | 第四章 4.4.2 节 |
| 混频器 | 2 周期 = 8 ns | 【待测】 | 同上 |
| FIR 滤波器 | 7 周期 = 28 ns | 【待测】 | 同上 |
| PID 控制器 | 3 周期 = 12 ns | 【待测】 | `buf_none` 配置 |

### 6.3.3 锁定性能评估

**测试目的**：定量评估锁定性能，这是全文的最终性能指标。

**理论依据**：按第二章 2.1.5 节，闭环下的残余频率噪声谱密度为

$$
S_\nu^{\mathrm{closed}}(f) = \frac{S_\nu^{\mathrm{free}}(f)}{|1 + G(f)|^2}
$$

其中 $G(f)$ 为环路增益。中长期稳定度以阿伦方差表征：

$$
\sigma_y^2(\tau) = \frac{1}{2}\left\langle (\bar{y}_{k+1} - \bar{y}_k)^2 \right\rangle
$$

**测试方法**：

*时域*：长时间记录误差信号，统计残余误差的均方根值与漂移趋势，由频率计数器数据计算阿伦方差。

*频域*：用频谱分析仪或 FFT 分析仪测量误差信号的功率谱密度，分别在开环与闭环条件下测量，两者之比即环路的噪声抑制比，可与理论 $|1+G(f)|^{-2}$ 对照。

| 误差信号 PSD @1 Hz | 【待测】 | 【待测】 |
| 误差信号 PSD @100 Hz | 【待测】 | 【待测】 |

# 第七章 总结与展望

本章总结全文工作，回顾主要创新点，并讨论当前系统的不足与后续改进方向。

## 7.1 工作总结

本文围绕激光频率稳定的实际需求，设计并实现了一套基于 Xilinx Kintex UltraScale FPGA 的全数字自动 PDH 锁定系统。工作内容涵盖从物理原理分析、硬件平台搭建、RTL 逻辑设计、上位机软件开发到测试方案设计的完整链路。

**理论分析**方面，本文从 Fabry–Pérot 腔的反射特性出发，经相位调制光场的边带展开推导了 PDH 误差信号的完整表达式，给出了近共振线性区的鉴频斜率 $D = -8\sqrt{P_cP_s}/\delta\nu$，并建立了稳频性能的评价指标体系。在数字控制方面，分析了离散时间系统的稳定性条件、双线性变换的频率预畸、数字滤波器的延迟特性与 CORDIC 算法原理，特别明确了环路延迟 $\tau$ 与控制带宽上限的定量关系 $f_{UGF} \le \frac{1}{2\pi\tau}(\frac{\pi}{2}-\varphi_m)$，该关系贯穿后续全部设计决策。

**硬件架构**方面，系统以 250 MHz 系统时钟、16 位有符号定点数据通路为基础，通过 FMC 接口支持多种 ADC/DAC 子卡，高速射频链路由 AD9680 ADC、AD9152 DAC 与 AD9528 时钟分发器件构成，经 SPI 接口配置并逐级校验锁定状态。接口设计分三层：UART 承担参数配置并以回显校验保证可靠性；片内自定义并行总线以 32 位数据、7 位地址、6 位模块选择的方案连接 34 个功能模块，其分层命令编码降低了解码逻辑深度，`HOLD` 机制则解决了超宽参数的原子化更新问题；SPI 接口以固化查找表与上位机下发两条通路完成器件配置，使单板上电即可进入可用状态。

**FPGA 逻辑**方面，完成了以下设计：

- **信号路由矩阵**——64×64 双套全交叉结构（16 位数据与 1 位布尔控制分离），每通道 8 位配置字，配合保持位实现无扰动切换，使信号链路重构由重新综合降为寄存器写入；
- **相位累加器**——64 位累加结构，频率分辨率达 $1.36\times10^{-11}$ Hz，并提供可配置倍频的辅助输出，内置环路滤波器使其可直接作为数字锁相环的压控振荡器；
- **CORDIC 运算器**——19 级迭代、24 位内部精度，采用隔级插入寄存器的半流水结构，在 250 MHz 时序约束与资源占用之间取得平衡；
- **FIR 滤波器**——64 抽头直接型，24 位 Q1.23 系数，支持 16/32/64 抽头可变配置并配有各自的 L1 范数归一化系数；
- **IIR 滤波器**——两节并联双二次结构配合四阶散射前瞻变换，将递归依赖的跨度由 1 个采样周期拉长至 4 个，化解了 IIR 递归结构与高速流水线的固有冲突；
- **PID 控制器**——48 位积分器、两级限幅抗饱和（钳位值写回积分器状态以实现真正的 anti-windup）、以移位实现的漏积分，并通过积分支路二分频交错缓解时序压力；
- **PDH 自动锁定状态机**——八态流程，含 `AUTO_AMP`/`AUTO_TIME` 自动参数标定环节，采用基于峰峰值比例的相对阈值方案。

**上位机软件**方面，构建了驱动层、协议层、硬件抽象层、应用层四层结构。硬件抽象层以三类参数字典描述模块，并通过"间接参数返回地址—数据对列表 + 前 N−1 条置 hold"的机制实现多寄存器参数的原子化更新，与协议层命令、硬件信号分离机制三层协同。参数物理量映射实现了寄存器整数值与频率、增益、转折频率的双向换算，其中总增益调节时同步缩放三项增益以保持环路频响形状不变、漏积分系数的幂次量化误差被显式提示等细节，体现了面向实验可用性的设计考虑。此外实现了可视化节点编辑器，其画布拓扑直接映射硬件路由配置，并以四类信号类型的设计期检查将一类物理含义错误前移至连线阶段；在此基础上集成了基于大语言模型的智能体层，以门面隔离的 9 个工具支持自然语言生成实验拓扑。

**测试方案**方面，设计了覆盖板级性能、功能验证与激光锁定实验三个层次的完整测试方案，并在方案中安排了若干交叉验证环节以确认硬件实现与理论分析的自洽性。

## 7.2 创新点回顾

### 7.2.1 软件定义的信号处理链路

传统 FPGA 锁频系统的信号处理链路在 RTL 代码中硬连线，改变拓扑需重新综合布线，耗时数十分钟。本系统通过 64×64 全交叉信号路由矩阵，将全部功能模块的输入输出纳入统一的可配置互联网络，改变信号流向退化为改写配置寄存器，耗时降至串口命令往返的毫秒量级。

该设计的价值不止于速度。更本质的改变是**实验范式**：拓扑成为运行时可探索的变量而非设计时固化的常量，使"同一套硬件验证多种控制方案"成为可能。配置字中的保持位进一步使切换过程可做到无扰动，这对运行中的闭环系统尤为重要。

代价是资源消耗随端口数平方增长，路由矩阵成为全系统最大的单一资源消耗项与布线压力来源，源码中以 `max_fanout` 约束做了针对性优化。

### 7.2.2 硬件级全自动锁定与自动参数标定

PDH 自动锁定状态机将"扫描腔共振峰—判定—启动 PID"的决策逻辑完全置于 FPGA 硬件内部，响应时间为时钟周期量级，而非依赖上位机软件轮询的毫秒量级。

更值得强调的是**自动参数标定**能力。`AUTO_AMP` 态在一个扫描周期内追踪信号极值，`AUTO_TIME` 态测量过阈时长，据此自动导出阈值与时间门限：

$$
V_{th} = V_{min} + c\,(V_{max} - V_{min})
$$

时间门限则以移位实现的 ×0.5 与 ×4 导出，无需乘法器。这一相对阈值方案的关键优势是**对信号幅度变化免疫**——激光功率漂移、光路耦合效率变化、探测器增益差异均会改变误差信号的绝对幅度，固定阈值方案需频繁重新标定，而相对阈值仅依赖峰峰值比例。配合 500 时钟周期（2 μs）的最小时长门限抑制噪声误触发，系统可在实验条件变化后自行适应而无需人工介入。

### 7.2.3 高集成度全数字架构

系统直接驱动高速射频转换器件，解调、滤波、控制、相位解算全部在 FPGA 内部以定点运算完成，模拟环节仅保留必要的信号调理。相较模拟方案，消除了温漂与元件老化带来的参数漂移；相较"FPGA + 外部 DSP"的分立方案，消除了器件间通信延迟。

### 7.2.4 软硬件协同设计方法学

本文展现了从底层 VHDL 到顶层自然语言接口的完整嵌入式仪器开发链路：VHDL 模块 → 自定义总线协议 → Python 对象封装 → 可视化节点编辑器 → 智能体工具层。五个层次各自解决一类问题，层间以明确契约衔接。

协同设计的效果在若干细节上可见：总线 `HOLD` 命令、硬件 `wen`/`wval` 信号分离、软件间接参数的 `hold` 序列三者协同实现了超宽参数的原子更新；PID 积分支路的二分频交错设计直接反映为上位机换算中积分路径用 125 MHz、微分路径用 250 MHz 的差异；漏积分的移位实现方式决定了上位机必须做幂次对齐并提示量化误差。这些都不是单侧设计可以得到的结果。

### 7.2.5 设计期类型安全

四类信号类型（level/phase/differential/bool）的区分与连线阶段的类型检查，将一类物理含义错误前移至设计阶段。相位量与幅度量在硬件上均为 16 位整数，混接不产生任何电气错误，但物理含义错误——例如将相位信号直接送入 PID 误差输入，环路会因 $2\pi$ 回绕而无法稳定，在实验中表现为难以归因的"锁不住"。类型系统使此类错误在连线时即被阻止。

### 7.2.6 通用模块库与性能分析框架

系统实现了一套可复用的定点信号处理模块库，各模块遵循统一的架构范式（内核 + 总线封装 + 参数 RAM），并提供可配置的 IO 缓冲模式以在延迟与时序裕量之间权衡。配套的测试方案（第六章）为各模块的可靠性验证与时空复杂度分析提供了框架。

## 7.3 不足与改进方向

### 7.3.1 实验验证数据尚待补齐

这是当前工作最主要的不足。截至初稿撰写时，系统的 Vivado 综合实现报告、时序分析报告与激光锁定实验的实测数据尚未归档，第六章以测试方案的形式给出了完整的测量方法与数据记录框架，但各项指标仍待实验填入。

其中优先级最高的三项为：激光锁定实验的性能数据（残余误差、误差信号功率谱密度、阿伦方差）、系统环路延迟实测值、以及综合实现报告中的资源占用与时序收敛情况。前者是全文的最终性能证明，中者决定控制带宽上限并可验证第四章的延迟推算，后者则确认设计在目标器件上的可实现性。

此外，第四章各模块的延迟数据当前为按源码寄存器级数的推算值，源码中未标注总延迟，IIR 滤波器因含递归环路更无法由静态分析确定，这些均须经行为级仿真实测确认。仓库中已有 ILA 探针定义文件，说明曾进行片上调试，但波形记录未归档。

### 7.3.2 硬件自主重锁机制尚未实现

研究计划中列有"自动重新锁定机制"一项，当前尚未实现。`AUTO_LOCKING` 态在检测到信号跌出锁定条件时仅清零计数器而不发生状态跳转，离开该状态的唯一路径是上位机改写命令字回到 `IDLE`。因此当前的失锁恢复仍需上位机介入，响应速度受串口通信与软件轮询周期制约，不具备硬件级的快速重捕获能力。

该功能在结构上并不困难：只需在 `AUTO_LOCKING` 态增加一条指向 `AUTO_SCANNING` 的跳转，条件为失锁持续时间超过 `auto_time_duration_locking`。由于阈值与时间门限已在自动标定阶段求得并保存在寄存器中，重锁可直接复用而无需重新标定。实现后系统将具备完整的"失锁—重扫描—重锁定"闭环，这是高稳定性系统的关键特征，应作为后续工作的首要项。

### 7.3.3 神经网络自适应 PID 控制

研究计划中提出的神经网络 PID 控制算法当前尚未实现。该方向的潜在价值在于：PDH 锁定的最优环路参数依赖于腔线宽、激光噪声谱、机械环境等多个因素，传统做法是人工整形后固定参数，而自适应算法可根据误差信号的统计特征在线调整增益与转折频率，在环境变化时维持最优性能。

考虑到 FPGA 资源约束与实时性要求，可行的实现路径是分层架构：在 FPGA 内保留现有的定点 PID 作为快速环路，由上位机或片上软核运行轻量级网络以较慢的速率调整 PID 参数。现有系统的参数物理量映射接口（第五章 5.2.3 节）已为此提供了良好基础——自适应算法可直接以物理量（转折频率、总增益）为操作对象，而无需关心定点格式与寄存器布局。该方向列为后续研究工作。

### 7.3.4 代码生成工具的局限

智能体层的 `code_generator.py` 可为新模块生成 VHDL 内核骨架、模块封装、Python 硬件类与节点类，但生成的 VHDL 内核仅为骨架——输入输出缓冲与总线接口完整，信号处理主体仍需硬件工程师填写。生成的 Python 类亦需重启应用后方可生效。因此该工具当前的价值在于消除样板代码的编写负担，而非真正的算法自动实现。

更进一步的方向是针对特定模块类型（如各类滤波器、固定结构的控制器）建立参数化模板库，使常见模块可由规格描述直接生成完整实现。

### 7.3.5 其他改进方向

**多通道并行锁定**。当前系统的模块实例数有限（如 PID 控制器最多 2 个实例），难以支持多路激光同时锁定。路由矩阵的 64 端口规模为扩展预留了空间，但需权衡资源占用——如 7.2.1 节所述，全交叉结构的消耗随端口数平方增长，大规模扩展时可能需要改用多级交换网络（如 Clos 网络）以降低资源消耗。

**状态回读能力**。当前上位机无法直接读取状态机的当前状态，只能通过观测使能输出间接推断。增加状态回读寄存器将显著改善调试体验与实验记录的完整性。

**定点位宽的系统性优化**。现有各模块的位宽分配基于经验与保守估计，尚未做系统的噪声预算分析。若第六章 6.3.4 节的噪声建模显示定点截断噪声成为主导项，则需针对性地增加关键路径的位宽；反之若量化噪声远低于其他噪声源，则可适当缩减位宽以释放资源。

**跨时钟域设计的规范化**。当前跨时钟域处理由 `async_fifo` 模块承担（封装 `xpm_fifo_async`，三级同步），实现规范；但仓库中另有一个 `cdc_sync.vhdl` 文件从未被实例化，且其 `ASYNC_REG` 属性仅存在于注释中未实际施加。应清理该文件或将其补全为可用的同步器，避免后续开发者误用。

**文档与测试资产的归档**。测试平台（testbench）目录被 `.gitignore` 排除、实验记录与笔记文件亦未纳入版本管理，导致验证工作的可追溯性不足。建议将测试平台、仿真脚本与关键实验数据纳入版本控制。

## 7.4 结语

本文完成了一套全数字自动激光 PDH 锁定系统的设计与实现。系统以可动态重构的信号路由矩阵为架构核心，以硬件级自动锁定状态机实现快速锁定与自动参数标定，并构建了从 VHDL 到自然语言接口的完整软硬件协同开发链路。相较传统模拟方案，系统在参数重配置、拓扑重构与自动锁定三方面具有明显优势；相较商用数字锁频产品，则在定制化能力与开放性方面更适合科研场景的需求。

当前工作的主要欠缺在于实验验证数据的完整性与硬件自主重锁功能的缺失，这些已在 7.3 节明确列出并给出了改进路径。后续工作应优先完成实验数据的采集与归档，并实现硬件自主重锁，使系统具备完整的失锁恢复闭环。
