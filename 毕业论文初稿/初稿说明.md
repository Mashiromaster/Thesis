# 初稿说明与定稿清单

论文题目：**基于 FPGA 架构的微纳光学控制平台**。

## 论文结构

| 章节 | 研究内容 |
|------|----------|
| 第一章 绪论 | 研究需求、相关工作、PDH 与双光梳物理基础、研究目标 |
| 第二章 硬件架构与数字控制实现 | 控制约束、板级接口、片内总线、可配置互联和运算模块 |
| 第三章 上位机软件设计 | 通信协议、物理参数映射、器件初始化与可视化拓扑配置 |
| 第四章 大语言模型智能体辅助设计系统 | 工具调用、知识表示、错误反馈及能力边界 |
| 第五章 实验设计与验证 | 板级与模块测试方案、两类应用实现及其验证方法 |
| 第六章 总结与展望 | 已实现工作、可支持的结论、局限与后续研究 |

`全文.md` 由摘要、目录、六章正文和参考文献合并生成；修改分章文件后应同步更新目录与全文。

## 证据边界

当前可依据已有实现说明平台结构、模块接口、状态机流程和软件参数映射。目标器件的完整综合实现报告、板级测量结果及光学锁定实验记录尚未归档。正文表格中的“—”表示缺少测量结果，不代表零值或通过测试。测试方案、理论估计和实测结论须分别表述。

Moku、Red Pitaya 等产品的具体功能范围与性能指标需要引用相应型号的可靠资料；当前不作定量优劣判断。微腔热锁定、光机械控制等扩展场景属于后续适用性研究，不计入已验证应用。

## 定稿前优先完成的工作

1. **器件与时钟信息**：确认 FPGA 完整型号、封装及速度等级；核对 ADC、DAC 和时钟器件配置，并测量实际采样率与时钟抖动。
2. **资源与时序**：保存 Vivado 综合、实现、资源利用率和时序报告；记录工具版本、约束文件及最差时序路径。
3. **模块功能**：对 CORDIC、FIR、IIR、PID 和路由矩阵开展仿真或硬件测试，记录定点误差、流水延迟及边界行为。
4. **拓扑配置**：测量同一比特流在 PDH 与双梳构型间切换的时间、连通性与切换扰动，并验证多寄存器参数提交的一致性。
5. **PDH 实验**：补充光学装置参数、自动捕获过程、闭环带宽、残余误差谱和长期稳定度，明确环路内与独立参考测量的区别。
6. **双梳实验**：测量本振偏置估计误差、重复校准行为及滑动窗抑噪效果；对相邻差分样本的相关性进行分析，再评价两类差频锁定性能。
7. **智能体评价**：固定模型版本与任务集，保存工具调用轨迹，统计首次成功率、最终成功率、迭代次数和非法配置拦截情况。
8. **文献与引文**：核对现有七条参考文献的作者、题名、卷期和页码；为商用及开源平台比较补充可追溯来源，并检查正文引文与文末条目逐项对应。

以上数据补齐后，再依据实测结果调整摘要、第五章和第六章的性能结论。任何尚未验证的指标不应由理论值、代码结构或预期目标代替。
