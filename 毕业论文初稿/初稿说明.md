# 毕业论文初稿说明

论文题目：**基于 FPGA 架构的微纳光学控制平台**

本初稿的技术内容全部取自项目代码仓库
[hosinonisiki/DClocking](https://github.com/hosinonisiki/DClocking)（及其 `FPGA_Agent` 智能体层）的实际实现。

## 论文定位

本文以**平台**为论述主体，而非以单一实验为主体。其立论是：微纳光学实验（激光稳频、双光梳锁定、微腔热锁定、光机械冷却等）在反馈控制结构上高度共通，差异仅在误差信号提取方式、控制器形式与执行器类型三处；因此一个在这三处均可配置的通用平台可服务于形态各异的实验。

PDH 锁定在本文中的角色是**平台的一个应用案例**，与双光梳自校准本振锁定并列（第六章）。这一定位与代码仓库的实际情况相符：`Top.vhdl` 的文件头注释说明系统设计目标为"lock the fr diff and fceo diff in a dual comb system"，仓库同时包含 `pdh_state_machine` 与 `SCALO_state_machine` 两个应用层状态机，且 34 个模块实例共用同一套运算层与互联层。

## 写作原则

**不编造数据。** 全文未填入任何未经核实的实测数值、器件指标或文献数据。需要作者补充之处以
`【待测】``【待补充】``【待核实】``[指标待查证]` 标注，各章末尾的
"本章待补充事项"小节汇总了该章的全部待办及其获取方法。各章标注数量：

| 章节 | 【待测】 | 【待补充】 | 【待核实】 |
|------|---------|-----------|-----------|

**技术细节以代码为准。** 位宽、状态名、参数地址、换算公式等均引自源码并标注
`文件名:行号`，可逐条回溯核对。

**能力边界如实界定。** 凡属架构层面的推断而非已验证事实之处，均明确标注。例如第六章 6.4.3 节
将平台对微腔、光机械等场景的适用性界定为推断，不写入结论；第八章 8.5.3 节说明代码生成的
VHDL 仅为接口完整的骨架，算法主体仍需人工填写。

## 与原提纲的偏差

原提纲（`蒋政毕业设计提纲.md`）以"基于硬件架构的自动激光 PDH 锁定系统研究"为题，
以 PDH 为论述主线。本稿按平台定位重构，主要偏差如下：

1. **论述主体由实验改为平台。** 新增第三章（平台架构与设计方法）与第六章（实验应用的平台实现），
   PDH 状态机由原第四章的一节移入第六章，与双梳应用并列。
2. **双光梳应用纳入论述。** 原提纲未涉及，但代码中 `SCALO_state_machine` 确实存在且
   `Top.vhdl` 顶层注释即以双梳锁定为设计目标，故补入第二章理论与第六章实现。
3. **PDH 状态机为八态，非四态。** 提纲描述为"扫描 → 判定 → 锁定 → 保持"，实际实现为
   `IDLE / AUTO_AMP / AUTO_TIME / AUTO_WAIT / AUTO_SCANNING / SCANNING / AUTO_LOCKING / LOCKING`
   八个状态，其中 `AUTO_AMP`、`AUTO_TIME` 构成自动参数标定环节。见 6.2.2 节。
4. **自动重锁机制尚未实现。** 提纲列有该项，但 `AUTO_LOCKING` 态在失锁时仅清零计数器而不跳转。
   已在 6.2.6 节如实说明，并在 10.3.2 节列为首要改进项（附实现路径）。
5. **神经网络 PID 代码中无实现。** 提纲列有该算法，但代码中无相关实现，故移至 10.3.3 节
   作为后续研究方向讨论。

提纲 3.1 节的硬件选型（AD9680 / AD9152 / AD9528）**经核实确实存在**，
位于 `python control/chips.py` 的 SPI 初始化例程与 `packages/PZ_KU060_config.vhdl` 的固化查找表中。

## 待补数据的优先级

第九章末给出了完整清单。最值得注意的是其中**第零优先**的几项——它们无需光学装置、
成本极低，却直接支撑本文的核心架构主张：

1. **跨应用拓扑切换验证**（9.2.4 节）——平台通用性的直接证据，支撑第三章全部架构论述与
   第十章创新点 10.2.1、10.2.2。仅需确认信号链路连通性。
2. **路由矩阵灵活性验证**（9.2.2 节）——附带给出切换耗时与重新综合耗时的量级对比。
3. **智能体拓扑生成成功率**（9.2.5 节）——离线即可验证。
4. **本振自校准与滑动窗平均验证**（9.4.1、9.4.2 节）——以信号源替代真实拍频即可。
5. **Vivado 综合实现报告**（9.1.3 节）——仅需运行工具链，可回填第三章 3.4.3 节与第五章 5.3.1 节表格。

**第一优先**（核心性能指标）为两类应用的锁定实验数据与环路延迟实测值。

**需补充的装置信息**包括两类应用的光学装置参数、ADC/DAC 子卡型号与 FPGA 完整器件型号
（代码 `.xdc` 中无 `part` 声明）。
