## 与提纲的三处偏差

撰写过程中核对代码，发现提纲有三处与实现不符，已按代码实况撰写并在正文中明确说明：

1. **PDH 状态机为八态，非四态。** 提纲描述为"扫描 → 判定 → 锁定 → 保持"，实际实现为
   `IDLE / AUTO_AMP / AUTO_TIME / AUTO_WAIT / AUTO_SCANNING / SCANNING / AUTO_LOCKING / LOCKING`
   八个状态，其中 `AUTO_AMP`、`AUTO_TIME` 构成自动参数标定环节，手动与自动流程各有独立分支。
   实现比提纲更完整，已作为创新点在 8.2.2 节强调。见 4.3.1 节。

2. **自动重锁机制尚未实现。** 提纲 4.2 节列有"自动重新锁定机制（Auto-relogin）"，但
   `AUTO_LOCKING` 态在失锁时仅清零计数器而不跳转，离开该态的唯一路径是上位机改写命令字。
   已在 4.3.5 节如实说明，并在 8.3.2 节列为首要改进项（附实现路径）。

3. **神经网络 PID 代码中无实现。** 提纲 2.3 节列有该算法，但代码中完全没有相关实现。
   若写入理论章会与后文脱节，故移至 8.3.3 节作为后续研究方向讨论。

另有一处需注意：提纲 3.1 节的硬件选型（AD9680 / AD9152 / AD9528）**经核实确实存在**，
位于 `python control/chips.py` 的 SPI 初始化例程与 `packages/PZ_KU060_config.vhdl` 的固化查找表中，
提纲此处准确无误。
