# 初稿说明

论文题目：**基于 FPGA 架构的微纳光学控制平台**。

## 六章结构与旧稿对应

| 新章 | 主题 | 旧稿来源 |
|---|---|---|
| 第一章 | 绪论、光学锁定原理与研究目标 | 原第一章、原第二章的物理原理部分 |
| 第二章 | 数字控制理论、平台与硬件实现 | 原第二章的数字控制部分、原第三至五章 |

| 第四章 | Agent 辅助设计系统 | 原第七章 |

## 论证与数据状态

本文以平台为主体，PDH 与双光梳是两个应用案例。代码实现与实验验证必须分开陈述。当前综合报告、板级实测和光学锁定数据尚未归档，正文中的【待测】【待补充】【待核实】标记均须在定稿前逐项处理。论文不得把测试方案写成已完成结果，也不得把微腔、光机械等未验证场景写成已支持的结论。

## 优先补齐的证据

1. 跨应用拓扑切换与路由矩阵切换耗时（5.2 节）。
2. Agent 拓扑生成的成功率与完整调用记录（4.2、5.2 节）。
3. Vivado 综合、资源及时序报告（2.7、5.2 节）。
4. 本振自校准与滑动窗平均的信号源验证（5.6 节）。
5. PDH 锁定数据、环路延迟与双梳锁定数据（5.2、5.4、5.6 节）。
