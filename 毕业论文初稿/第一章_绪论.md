# 第一章 绪论

本章阐述微纳光学与精密测量实验对实时反馈控制的普遍需求，分析传统模拟方案与现有商用数字平台的局限，介绍作为典型应用的 PDH 稳频技术原理，并在此基础上提出本文自研 FPGA 微纳光学控制平台的研究内容与目标。

## 1.1 研究背景与意义

### 1.1.1 微纳光学实验中的实时反馈控制需求

现代光学实验的精度边界，往往不由光学元件本身决定，而由实验者能否把系统稳定在期望的工作点上决定。无论是把激光频率锁定到参考腔、把微腔的谐振波长锁定到激光、把光机械振子冷却到基态，还是把两台光梳锁定为相干对，其共同的技术内核都是同一件事：**从物理系统中提取误差信号，经信号处理整形后，实时反馈至执行器**。

这一共性可以形式化地表述。设被控物理量为 $x(t)$，期望值为 $x_0$，则反馈控制系统须实现

$$
u(t) = \mathcal{K}\left[x(t) - x_0\right]
$$

其中 $\mathcal{K}$ 为控制器的传递算子，$u(t)$ 为施加于执行器的校正量。不同实验的差异仅在于三处：误差信号的提取方式（直接探测、相位调制解调、拍频检测）、控制器 $\mathcal{K}$ 的具体形式（比例积分、高阶滤波、状态反馈），以及执行器的类型（压电陶瓷、声光调制器、电光调制器、激光二极管电流、加热器）。而控制回路的结构、对延迟与噪声的要求、自动化的诉求，则是高度共通的。

这一共性具有重要的工程含义：**若能构建一个在上述三处都可配置的通用平台，则同一套硬件可服务于形态各异的实验。** 本文正是沿这一思路展开。

以下三类实验说明了需求的多样性与共通性。

**激光频率稳定。** 自光频标与光学频率梳技术成熟以来，以中性原子光晶格钟和单离子光钟为代表的光频标，其系统不确定度与频率稳定度已进入 $10^{-18}$ 量级 [1]。而自由运转的半导体激光器或固体激光器，受增益介质自发辐射、谐振腔机械振动、温度漂移与泵浦源噪声的共同作用，其线宽通常在百千赫兹至兆赫兹量级，与光频标所需的赫兹乃至亚赫兹线宽相差六个数量级以上。必须引入外部频率参考与伺服反馈，将激光频率锁定到稳定的鉴频器上——这正是 1.1.3 节 PDH 技术的用途。

**双光梳相干锁定。** 光学频率梳的输出由重复频率 $f_r$ 与载波包络偏移频率 $f_{ceo}$ 两个射频参量完全描述，第 $n$ 根梳齿的频率为 $\nu_n = n f_r + f_{ceo}$。双光梳系统须将两台梳源的这两个差频分别锁定，方能维持相干。此类应用的被控量是**相位**而非幅度，须经相位解算与解卷绕处理，对信号处理的要求与激光稳频显著不同。本文平台的第二个应用案例（第六章 6.3 节）正属此类。

**微腔与光机械系统。** 高品质因子微腔的谐振频率随温度与光功率漂移，须经热锁定或自适应反馈维持在工作点；光机械系统中的模式冷却则须对振子的位移信号作相位精确的反馈。这类实验的控制带宽要求往往更高，对环路延迟更为敏感。

三类实验的误差信号形态、控制带宽与执行器各不相同，但都需要：低延迟的信号通路、可灵活整形的控制器、以及能自动寻找并维持工作点的逻辑。这构成了本文平台的设计需求来源。

### 1.1.2 传统模拟方案与分立仪器的局限

长期以来，上述反馈环路主要由分立的模拟电路模块实现：混频器完成解调，运算放大器构成的比例–积分–微分（PID）网络提供环路增益，再经高压放大器驱动压电陶瓷或经电流调制端口驱动激光二极管。模拟方案的优势在于不存在采样延迟与量化噪声，理论上可以获得极高的单位增益带宽。但在工程实践中，它存在若干难以回避的问题。

首先是直流漂移与温度稳定性。模拟积分器的输出会随运算放大器的输入失调电压及其温漂而缓慢移动，混频器的直流偏置同样随环境温度变化。这些漂移在误差信号中表现为一个随时间变化的虚假零点，使系统锁定在偏离真实工作点的位置上，并引入难以区分的长期漂移。

其次是参数调节的不可重复性。模拟 PID 的增益与转折频率由电阻、电容的具体取值确定，调节依赖电位器或更换元件。这使得环路参数既无法精确记录和复现，也无法在实验过程中按需快速扫描寻优；在需要多路同时锁定的系统中，逐路手工整定的工作量迅速变得不可接受。

第三是互连复杂与串扰。一套完整的锁定系统通常需要本振源、相移器、混频器、低通滤波器、伺服放大器、扫描斜坡发生器、高压放大器等多个独立机箱，彼此以同轴电缆连接。连线数量随通道数呈平方增长，不仅引入地环路与射频串扰，也使系统的拓扑一旦确定便难以改动。

第四是功能不可重构。模拟硬件的信号流向由物理连线决定。当实验需求从简单的单环锁定扩展到调制转移光谱、双色锁定、腔长伺服与激光伺服级联等更复杂的方案时，往往意味着重新设计电路板。**这一点对科研场景尤为关键**：研究工作的本质是探索未知，实验方案在研究过程中不断演化，而硬件的固化与这种演化需求直接冲突。

最后是自动化程度低。寻找工作点、判断是否捕获、失锁后重新捕获等操作在模拟系统中难以实现，通常需要实验人员目视示波器并手动操作。这既限制了实验效率，也使长时间无人值守运行难以保证。

### 1.1.3 典型应用：PDH 稳频技术原理概述

作为本文平台的主要应用案例，本节先介绍 PDH 技术的基本原理，为后续章节建立物理背景。完整的数学推导见第二章 2.1 节。

高精细度 Fabry–Pérot（F-P）光学参考腔可充当频率鉴别器。将激光锁定到超稳腔的本征模式上，可以把腔长的稳定度转移为激光频率的稳定度。但直接利用腔的透射或反射强度存在一个根本困难：**强度信号在共振点附近是偶对称的**，无法区分频率偏高还是偏低，因而不能作为误差信号。

Pound–Drever–Hall（PDH）技术 [2,3] 解决了这一问题。其思路是对入射光进行相位调制，在载波两侧产生频率为 $\omega \pm \Omega$ 的边带；载波与边带经腔反射后获得不同的相位响应，彼此干涉使反射光强出现 $\Omega$ 频率的分量，其幅度与相位携带了载波相对于共振点的偏离方向。对反射光作 $\Omega$ 频率的同步解调，即可得到一个在共振点**反对称、过零且斜率陡峭**的误差信号。

该误差信号在近共振区的鉴频斜率为

$$
D = -\frac{8\sqrt{P_c P_s}}{\delta\nu}
$$

其中 $P_c$ 与 $P_s$ 分别为载波与边带功率，$\delta\nu$ 为腔线宽。这一结果有两重含义。其一，斜率与腔线宽成反比，故高精细度腔可获得极高的鉴频灵敏度——这是 PDH 能实现亚赫兹线宽 [4] 的根本原因。其二，**高灵敏度必然伴随窄捕获范围**：误差信号的线性区仅约一个腔线宽，远窄于激光的自由运转漂移范围。

第二项含义直接决定了系统的自动化需求：环路无法自行捕获，必须先主动扫描寻找共振，再在越过共振的瞬间闭合环路；且由于扫描经过线性区的时间极短，捕获时机的判断必须足够快。这正是本文将自动锁定逻辑下沉至 FPGA 硬件的物理依据（第六章 6.2 节）。

需要强调的是，PDH 技术给出的只是误差信号；把误差信号转化为有效的频率抑制，依赖于伺服电子学。伺服环路的增益、带宽、相位裕度以及自身的电子学噪声，共同决定了最终可达到的稳定度。在腔体与隔振技术日趋成熟的今天，伺服电子学的性能与可靠性常常成为系统的实际瓶颈——这是本文研究的出发点。

### 1.1.4 全数字控制平台的优势与代价

随着现场可编程门阵列（FPGA）以及高速模数/数模转换器（ADC/DAC）性能的提升与成本的下降，将反馈环路的信号处理部分整体数字化已成为可行且主流的技术路线 [5]。在全数字方案中，光电探测器输出的射频信号经 ADC 采样后进入 FPGA，在数字域内完成解调、滤波、环路整形与状态判决，再经 DAC 输出到执行器。

数字化带来的优势是系统性的。其一，参数的绝对可重复性：增益、滤波器系数、阈值等全部以寄存器数值形式存在，可被精确记录、保存与恢复，为自动整定提供了前提。其二，不存在模拟漂移：数字积分器的状态是一个整数寄存器，不会因温度变化而漂移，直流偏置可以通过数字方式精确扣除。其三，功能由固件定义：同一套硬件通过加载不同配置即可实现不同功能，极大提升了设备的复用率。其四，易于实现复杂算法：数字域内可以方便地实现高阶无限冲激响应（IIR）滤波器、CORDIC 相位解算、相位解卷绕等在模拟域中代价高昂或根本无法实现的运算。其五，便于集成与自动化：状态机、数据记录、网络通信可与信号处理共存于同一芯片，使自动锁定、失锁检测与远程监控成为硬件的内生能力。

数字方案固有的代价是采样延迟与量化噪声。采样保持、ADC/DAC 转换以及流水线运算共同构成环路的纯延迟 $\tau$，它在频率 $\omega$ 处引入与频率成正比的附加相移 $\Delta\phi = -\omega\tau$，从而限制可达到的单位增益带宽。第二章 2.3.2 节将定量给出这一约束：

$$
f_{UGF} \le \frac{1}{2\pi\tau}\left(\frac{\pi}{2} - \varphi_m\right)
$$

因此数字控制平台设计的核心矛盾在于：**以尽可能低的延迟实现尽可能复杂的信号处理**。本文采用的高时钟频率、深度流水线与并行结构的设计策略，正是针对这一矛盾展开的；而"延迟作为一等设计变量"也成为贯穿本文架构决策的主线。

## 1.2 国内外研究现状

### 1.2.1 商用与开源数字控制平台分析

目前已有若干基于 FPGA 的通用化数字控制产品被广泛用于原子分子光物理与微纳光学实验室，其中以 Liquid Instruments 公司的 Moku 系列（Moku:Lab、Moku:Pro 等）与 Red Pitaya 开源硬件平台最具代表性。两者在架构上具有共同特征：均以 Xilinx Zynq 系列 SoC 为核心，将 ARM 处理器与 FPGA 可编程逻辑集成于单芯片内，由 ARM 端运行 Linux 承担网络通信与用户界面，FPGA 端承担实时信号处理；设备的功能由固件定义，用户通过切换"仪器"固件，使同一硬件分别表现为示波器、锁相放大器、PID 控制器或频率响应分析仪。

**Moku 系列**采用封闭的商业模式。其硬件设计与 FPGA 固件源码均不公开，用户通过官方应用或 Python/MATLAB 接口调用预定义的仪器功能，可配置的范围限于厂商暴露的参数集。这一模式的优点是开箱可用、指标明确、软件成熟度高，对不以电子学为研究内容的实验室极具吸引力。其局限则在于：用户无法在数据通路中插入自定义运算，不同仪器之间的互连受限于厂商提供的多仪器模式所允许的拓扑；当实验需要一个厂商未预见的信号处理环节（例如特定形式的相位解卷绕、与实验时序深度耦合的自动捕获逻辑）时，便无从下手。其各项具体指标（输入带宽、噪声本底、环路延迟、价格）`[指标待查证]`。

**Red Pitaya** 走的是另一条路线。其硬件原理图与 FPGA 工程以开源形式发布，用户可以修改 Verilog/VHDL 源码并重新综合，社区亦围绕其发展出 PyRPL 等用于 PDH 锁定与锁相检测的开源软件框架 `[待核实文献]`。开源带来了充分的可定制性，但 Red Pitaya 的定位是低成本通用平台，其 FPGA 规模、ADC 位数与采样率、模拟前端的噪声性能均受限于该定位；在需要多通道、高位宽数据通路或大量并行滤波器资源的场合容易遇到资源与性能上限。相关指标 `[指标待查证]`。

除商用产品外，科研界也发表了多套开源数字伺服方案。Leibrandt 与 Heidecker 报道了一种面向 AMO 实验的开源数字伺服，详细讨论了数字环路延迟与可达带宽的权衡 [5]；基于 Red Pitaya 的锁相与实验控制器亦有报道 `[待核实文献]`。这些工作证明了数字控制在精密光学实验中的可行性，但多以单一功能为目标，其信号通路在综合时即固定，缺乏运行时重构能力。

### 1.2.2 现有方案的共同局限：拓扑的编译期固化

归纳上述方案，可以发现一个贯穿性的局限：**信号处理模块与它们之间的连接关系被耦合在同一份设计中，拓扑在编译期固化。**

对封闭产品而言，拓扑由厂商预设，用户只能在其允许的组合内选择。对开源平台而言，拓扑虽可修改，但修改意味着重新综合——而一次中等规模设计的综合与实现往往耗时数十分钟乃至数小时。这一时间尺度与实验现场的工作节奏完全不匹配：实验者在光学平台前调试时，往往需要在几分钟内尝试数种不同的信号链路构型，以判断哪一种对当前的噪声环境最有效。

这一局限的后果是，数字平台虽然在**参数**层面实现了充分的灵活性（增益、系数、阈值均可实时修改），却在**拓扑**层面依然是刚性的。而如 1.1.1 节所述，不同实验的差异恰恰大量体现在拓扑上——误差信号如何提取、控制器如何级联、哪些信号需要交叉耦合。

因此，一个真正通用的微纳光学控制平台，应当把拓扑也纳入运行时可配置的范畴。本文的核心架构设计正是为此。

### 1.2.3 自研高性能平台的必要性

综合上述分析，现有方案在三个维度上留下了空白，构成了自研平台的必要性。

第一是**运行时可重构**的需求。理想的平台应当在不重新综合的前提下，允许用户任意改变模块之间的连接关系，即把"改接线"从编译期操作变为运行期操作。本文采用的全交叉路由矩阵正是为此设计（第三章 3.4 节）。

第二是**性能与资源**的需求。高性能控制要求低延迟与高采样率，复杂方案又要求大量并行的滤波与运算资源，二者共同指向更大规模、更高速度等级的 FPGA。选用独立的 Kintex UltraScale 器件而非入门级 SoC，可以在数据通路上同时容纳数十个全精度流水线运算模块，并以较高的系统时钟降低单位运算的延迟代价。

第三是**开放性与成本**的需求。对于需要同时锁定多路的实验装置，设备成本按通道数线性累加；而自研方案在硬件成本之外几乎不存在许可费用。更重要的是，完全掌握硬件描述语言源码与通信协议意味着系统具备长期可维护性，不会因厂商停产或接口变更而失效，也便于在课题组内部传承与二次开发。

需要说明的是，自研并不意味着在所有指标上超越商用产品。本文的目标是在架构层面提供商用产品所不具备的拓扑可重构性与自动化能力，并使平台的每一层都对使用者开放。

## 1.3 本文研究内容与目标

本文的研究内容可概括为：**构建一个以运行时拓扑可重构为核心特征的 FPGA 微纳光学控制平台，并以两类实验应用验证其通用性。**

### 1.3.1 平台架构与设计方法

本文的首要工作是确立平台的组织原则（第三章）。其核心思想是把"有哪些运算单元"与"它们如何连接"彻底分离：前者在综合时一次性固化，后者留给运行时的寄存器配置决定。

依此原则，平台在纵向上划分为应用层、运算层、互联层与接口层四层，层间以明确契约衔接，使任一层的变更不波及其余层。支撑该结构的三项机制分别是：统一的模块设计范式（三段式结构、可配置 IO 缓冲、自动复位契约）、总线契约（二级寻址、分层命令编码、影子寄存器原子更新）与全交叉路由矩阵。平台的核心抽象是**数据流图**——它与实验者的物理直觉同构，与流水线实现相容，且使环路延迟可加，从而让 1.1.4 节的带宽约束可直接用于指导拓扑设计。

### 1.3.2 硬件平台与运算模块

本文以 Xilinx Kintex UltraScale 系列 FPGA（KU060）为核心搭建硬件平台 `[具体器件型号与速度等级待补充]`。系统数据通路采用 16 位定点表示，满量程对应 $\pm 32768$；系统工作时钟为 250 MHz，即单个时钟周期为 4 ns，这一时钟频率同时决定了流水线延迟的时间粒度与数字滤波器的采样率。高速射频链路由 AD9680 ADC、AD9152 DAC 与 AD9528 时钟分发器件构成（第四章）。

在互联层之上，本文实现了一套完整的 VHDL 信号处理模块库（第五章），主要包括：

- **PID 控制器**：并行（位置）型结构，具备可编程的积分限幅抗饱和、可编程泄漏积分以及输出限幅；为在高时钟频率下闭合长位宽积分路径的时序，积分支路采用半速率交织处理。
- **相位累加器（DDS）**：64 位相位累加器，取高 16 位作为相位输出，配合三角函数模块构成数控振荡器；内部另集成比例–积分环路滤波器，可直接用于相位跟踪。
- **CORDIC 三角函数与反三角函数**：分别工作于旋转模式与向量模式，提供正弦/余弦生成与四象限反正切（atan2）解算，19 级迭代，内部 24 位精度。
- **FIR 滤波器**：64 抽头直接型结构，系数 24 位定点，可在运行时重新加载；支持 16/32/64 抽头长度切换并自动调整归一化因子。
- **IIR 滤波器**：四阶，采用两节双二次（biquad）并联结构，并对每节施加四阶散射超前变换，以打破递归反馈对时钟频率的制约。
- **混频器、线性变换器、缩放器、相位解卷绕器**等辅助模块，分别用于解调、双路线性组合、输出调理与相位连续化。

这些模块均遵循统一范式，因而可被不同应用以统一方式复用。

### 1.3.3 两类实验应用的实现与平台通用性验证

平台的通用性须由具体应用检验。本文实现并报告两类应用（第六章）。

**激光 PDH 锁定。** 如 1.1.3 节所述，PDH 的窄捕获范围要求主动扫描与快速捕获判断。本文将这一流程下沉为八态硬件状态机，其中 `AUTO_AMP` 与 `AUTO_TIME` 两态构成自动参数标定环节：前者在一个扫描周期内追踪信号极值，后者测量过阈时长，据此按

$$
V_{th} = V_{min} + c\,(V_{max} - V_{min})
$$

导出相对阈值。该方案的关键优势是**对信号幅度变化免疫**——激光功率漂移、耦合效率变化、探测器增益差异均会改变误差信号的绝对幅度，固定阈值方案需频繁重新标定，而相对阈值仅依赖峰峰值比例。捕获瞬间状态机在同一时钟沿冻结扫描斜坡并释放 PID，交接过程无软件介入。

**双光梳自校准本振锁定。** 该应用的被控量是相位而非幅度，其未知参量是拍频频率而非共振位置。`SCALO` 状态机以相位差分推算频率偏差 $\Delta f = \frac{1}{2\pi}\frac{d\phi}{dt}$，经 256 级滑动窗平均抑制差分噪声，将结果补偿进本振相位增量后再释放 PID。

两类应用在物理场景、信号类型与自动化策略上均不相同，却共用同一套运算层与互联层，未为任一应用增加专用运算模块。这一事实构成了对平台通用性的实证。

### 1.3.4 上位机软件与智能体辅助设计

硬件的可重构性只有在易用的配置手段支持下才能转化为实际效率。本文为此设计了分层的 Python 上位机软件（第七章）：驱动层、协议层、硬件抽象层与应用层四层结构，其中硬件抽象层完成寄存器整数值与物理量（频率、增益、转折频率）的双向换算，使实验脚本可直接以物理量表达意图。应用层实现了一个可视化节点编辑器，用户以拖放方式实例化模块、以连线方式建立数据通路；每一次连线操作都被翻译为路由矩阵的寄存器写入，从而在界面操作与硬件拓扑之间建立直接对应，并以四类信号类型的设计期检查将一类物理含义错误前移至连线阶段。

在此之上，本文进一步引入基于大语言模型的智能体辅助设计层（第八章），使实验拓扑可由自然语言描述生成。该层的设计重点不在于模型本身，而在于**如何以系统侧的多道约束使输出不确定的模型能够安全地操作硬件配置界面**。

### 1.3.5 研究目标

综上，本文的总体目标是：**建立一套以自研 Kintex UltraScale 硬件为基础、以运行时拓扑可重构为架构特征、以硬件自动状态机为自动化手段、以分层上位机与智能体为交互入口的通用微纳光学实时控制平台**，并以激光 PDH 锁定与双光梳锁定两类实验验证其通用性与可用性。

## 1.4 本文组织结构

全文共分十章，组织如下。

**第一章 绪论**。阐述微纳光学实验对实时反馈控制的普遍需求，分析模拟方案与现有商用数字平台的局限，介绍作为典型应用的 PDH 技术原理，提出本文的研究内容与目标。

**第二章 光学锁定原理与全数字控制理论**。建立全文的理论基础：推导 PDH 误差信号表达式及其鉴频斜率、给出双光梳锁定的频率关系，并介绍离散时间系统的稳定性分析、数字滤波器与 CORDIC 算法；最后讨论数字 PID 的实现以及环路延迟对控制带宽与噪声抑制能力的制约。

**第三章 平台架构与设计方法**。本文方法论的核心。确立"运算单元与连接关系分离"的设计哲学与四层结构，依次展开支撑该结构的模块设计范式、总线契约与运行时可重构的实现原理，并给出平台的扩展流程。

**第四章 硬件平台与接口实现**。介绍以 Kintex UltraScale FPGA 为核心的总体硬件方案、模数/数模转换与时钟分发架构，并分三个层次说明接口实现：上位机 UART 通信链路、片内自定义总线协议以及板上射频器件的 SPI 配置接口。

**第五章 核心运算模块实现**。给出互联层的路由矩阵实现，以及 PID、相位累加器、CORDIC、FIR、IIR、混频器等运算模块的定点格式、流水线结构与延迟，重点讨论为在 250 MHz 时钟下闭合时序所采用的关键技术，最后汇总资源占用与延迟预算。

**第六章 实验应用的平台实现**。以激光 PDH 锁定与双光梳自校准本振锁定两类应用检验平台的通用性，详述二者的自动化状态机与自动参数标定算法，并对比归纳平台通用性的来源与边界。

**第七章 上位机软件系统设计**。介绍 Python 上位机的四层分层架构，面向对象的模块封装与参数物理量映射关系，自动化初始化与系数加载校准流程，以及可视化节点编辑器与设计期类型检查机制。

**第八章 智能体辅助设计系统**。介绍位于平台最顶层的大语言模型智能体层，其以九个工具操作可视化画布，使实验拓扑可由自然语言描述生成；重点讨论门面隔离、结构化错误反馈、迭代上限等保证可靠性的架构机制，以及模块知识库与新模块代码生成的实现与能力边界。

**第九章 系统测试与实验结果**。给出板级性能测试、功能验证实验与激光 PDH 锁定实验的测试方案，包括 ADC/DAC 有效位数与信噪比测试、系统环路延迟测量、硬件资源与时序预算、路由矩阵灵活性验证与锁定性能评估。

**第十章 总结与展望**。总结本文工作，回顾创新点，并讨论不足与改进方向。
