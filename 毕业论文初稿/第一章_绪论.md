# 第一章 绪论

本章阐述激光频率稳定技术在精密物理测量中的作用，分析传统模拟锁定方案与现有商用数字锁频产品的局限，并在此基础上提出本文自研全数字激光锁定系统的研究内容与目标。

## 1.1 研究背景与意义

### 1.1.1 精密物理测量对激光频率稳定度的需求

频率是目前人类能够测量得最为精确的物理量。自光频标与光学频率梳技术成熟以来，以中性原子光晶格钟和单离子光钟为代表的光频标，其系统不确定度与频率稳定度已进入 $10^{-18}$ 量级 [1]，较基于铯原子微波跃迁的秒定义提升了两个数量级以上。这一进展直接支撑了基本物理常数测量、相对论大地测量、暗物质候选粒子搜寻以及引力波探测等前沿研究，同时也推动了"秒"的重新定义进程。

在上述所有应用中，激光器都充当连接原子跃迁与可观测信号的桥梁，其频率噪声直接决定了测量的极限精度。以光晶格钟为例，钟激光的线宽与短期稳定度决定了原子跃迁谱线的可分辨程度；由于量子投影噪声与 Dick 效应的存在，钟跃迁探询激光的频率噪声会经由采样过程混叠到钟的输出，成为限制稳定度的主要技术噪声之一。而自由运转的半导体激光器或固体激光器，受增益介质自发辐射、谐振腔机械振动、温度漂移与泵浦源噪声的共同作用，其线宽通常在百千赫兹至兆赫兹量级，频率漂移可达每秒数兆赫兹，与光频标所需的赫兹乃至亚赫兹线宽相差六个数量级以上。因此，必须引入外部频率参考与伺服反馈，将激光频率锁定到一个稳定的鉴频器上。

高精细度 Fabry–Pérot（F-P）光学参考腔正是这样一个鉴频器。将激光锁定到超稳腔的本征模式上，可以把腔长的稳定度转移为激光频率的稳定度。Pound–Drever–Hall（PDH）技术 [2,3] 通过对入射光进行相位调制并对腔反射光作同步解调，得到一个在共振点附近线性、过零且斜率陡峭的误差信号，是实现这一转移的标准手段。借助低热膨胀材料腔体、振动隔离与温度控制，PDH 锁定已实现亚赫兹量级的激光线宽 [4]。

然而，PDH 技术给出的只是误差信号；把误差信号转化为对激光频率的有效抑制，依赖于伺服电子学。伺服环路的增益、带宽、相位裕度以及自身的电子学噪声，共同决定了最终可达到的频率稳定度。在腔体与隔振技术日趋成熟的今天，伺服电子学的性能与可靠性常常成为系统的实际瓶颈，这也是本文研究的出发点。

### 1.1.2 传统模拟锁定模块的局限性

长期以来，PDH 伺服环路主要由分立的模拟电路模块实现：混频器完成解调，运算放大器构成的比例–积分–微分（PID）网络提供环路增益，再经高压放大器驱动压电陶瓷（PZT）或经电流调制端口驱动激光二极管。模拟方案的优势在于不存在采样延迟与量化噪声，理论上可以获得极高的单位增益带宽。但在工程实践中，它存在若干难以回避的问题。

首先是直流漂移与温度稳定性。模拟积分器的输出会随运算放大器的输入失调电压及其温漂而缓慢移动，混频器的直流偏置同样随环境温度变化。这些漂移在误差信号中表现为一个随时间变化的虚假零点，使激光锁定在偏离腔共振中心的位置上，并引入难以区分的长期频率漂移。

其次是参数调节的不可重复性。模拟 PID 的增益与转折频率由电阻、电容的具体取值确定，调节依赖电位器或更换元件。这使得环路参数既无法精确记录和复现，也无法在实验过程中按需快速扫描寻优；在需要多台激光器同时锁定的系统中，逐台手工整定的工作量迅速变得不可接受。

第三是互连复杂与串扰。一套完整的 PDH 系统通常需要本振源、相移器、混频器、低通滤波器、伺服放大器、扫描斜坡发生器、高压放大器等多个独立机箱，彼此以同轴电缆连接。连线数量随通道数呈平方增长，不仅引入地环路与射频串扰，也使系统的拓扑一旦确定便难以改动。

第四是功能不可重构。模拟硬件的信号流向由物理连线决定。当实验需求从简单的 PDH 锁定扩展到调制转移光谱、双色锁定、腔长伺服与激光伺服级联等更复杂的方案时，往往意味着重新设计电路板。

最后是自动化程度低。寻找共振、判断是否捕获、失锁后重新捕获等操作在模拟系统中难以实现，通常需要实验人员目视示波器并手动操作扫描幅度与积分开关。这既限制了实验效率，也使长时间无人值守运行难以保证。

### 1.1.3 全数字控制系统的发展现状与优势

随着现场可编程门阵列（FPGA）以及高速模数/数模转换器（ADC/DAC）性能的提升与成本的下降，将伺服环路的信号处理部分整体数字化已成为可行且主流的技术路线 [5]。在全数字方案中，光电探测器输出的射频信号经 ADC 采样后进入 FPGA，在数字域内完成混频解调、滤波、环路整形与状态判决，再经 DAC 输出到执行器。

数字化带来的优势是系统性的。其一，参数的绝对可重复性：增益、滤波器系数、阈值等全部以寄存器数值形式存在，可被精确记录、保存与恢复，为自动整定提供了前提。其二，不存在模拟漂移：数字积分器的状态是一个整数寄存器，不会因温度变化而漂移，直流偏置可以通过数字方式精确扣除。其三，功能由固件定义：同一套硬件通过加载不同配置即可实现 PDH 锁定、锁相放大、频率计数等不同功能，极大提升了设备的复用率。其四，易于实现复杂算法：数字域内可以方便地实现高阶无限冲激响应（IIR）滤波器、CORDIC 相位解算、相位解卷绕等在模拟域中代价高昂或根本无法实现的运算。其五，便于集成与自动化：状态机、数据记录、网络通信可与信号处理共存于同一芯片，使自动锁定、失锁检测与远程监控成为硬件的内生能力。

数字方案固有的代价是采样延迟与量化噪声。采样保持、ADC/DAC 转换以及流水线运算共同构成环路的纯延迟，它在高频处引入与频率成正比的附加相移，从而限制可达到的单位增益带宽；这一机理将在第 2.3 节中定量分析。因此数字伺服设计的核心矛盾，在于以尽可能低的延迟实现尽可能复杂的信号处理。本文采用的高时钟频率、深度流水线与并行结构的设计策略，正是针对这一矛盾展开的。

## 1.2 国内外研究现状

### 1.2.1 商用 FPGA 锁频产品分析

目前已有若干基于 FPGA 的通用化数字伺服产品被广泛用于原子分子光物理实验室，其中以 Liquid Instruments 公司的 Moku 系列（Moku:Lab、Moku:Pro 等）与 Red Pitaya 开源硬件平台最具代表性。两者在架构上具有共同特征：均以 Xilinx Zynq 系列 SoC 为核心，将 ARM 处理器与 FPGA 可编程逻辑集成于单芯片内，由 ARM 端运行 Linux 承担网络通信与用户界面，FPGA 端承担实时信号处理；设备的功能由固件定义，用户通过切换"仪器"固件，使同一硬件分别表现为示波器、锁相放大器、PID 控制器或频率响应分析仪。

Moku 系列采用封闭的商业模式。其硬件设计与 FPGA 固件源码均不公开，用户通过官方应用或 Python/MATLAB 接口调用预定义的仪器功能，可配置的范围限于厂商暴露的参数集。这一模式的优点是开箱可用、指标明确、软件成熟度高，对不以电子学为研究内容的实验室极具吸引力。其局限则在于：用户无法在数据通路中插入自定义运算，不同仪器之间的互连受限于厂商提供的多仪器模式所允许的拓扑；当实验需要一个厂商未预见的信号处理环节（例如特定形式的相位解卷绕、与实验时序深度耦合的自动捕获逻辑）时，便无从下手。其各项具体指标（输入带宽、噪声本底、环路延迟、价格）`[指标待查证]`。

Red Pitaya 走的是另一条路线。其硬件原理图与 FPGA 工程以开源形式发布，用户可以修改 Verilog/VHDL 源码并重新综合，社区亦围绕其发展出 PyRPL 等用于 PDH 锁定与锁相检测的开源软件框架 `[待核实文献]`。开源带来了充分的可定制性，但 Red Pitaya 的定位是低成本通用平台，其 FPGA 规模、ADC 位数与采样率、模拟前端的噪声性能均受限于该定位；在需要多通道、高位宽数据通路或大量并行滤波器资源的场合容易遇到资源与性能上限。相关指标 `[指标待查证]`。

除商用产品外，科研界也发表了多套开源数字伺服方案。Leibrandt 与 Heidecker 报道了一种面向 AMO 实验的开源数字伺服，详细讨论了数字环路延迟与可达带宽的权衡 [5]；基于 Red Pitaya 的锁相与实验控制器亦有报道 `[待核实文献]`。这些工作证明了数字伺服在激光稳频中的可行性，但多以单一功能为目标，其信号通路在综合时即固定，缺乏运行时重构能力。

### 1.2.2 自研高性能 FPGA 控制系统的必要性

综合上述分析，现有方案在三个维度上留下了空白，构成了自研系统的必要性。

第一是定制化与运行时可重构的需求。封闭产品不允许修改数据通路，开源平台虽允许修改却需要重新综合——而一次综合与实现在中等规模设计上往往耗时数十分钟乃至数小时，这与实验现场反复尝试不同锁定方案的节奏完全不匹配。理想的系统应当在不重新综合的前提下，允许用户任意改变模块之间的连接关系，即把"改接线"从编译期操作变为运行期操作。本文采用的全交叉路由矩阵正是为此设计。

第二是性能与资源的需求。高性能稳频要求低延迟与高采样率，复杂方案又要求大量并行的滤波与运算资源，二者共同指向更大规模、更高速度等级的 FPGA。选用独立的 Kintex UltraScale 器件而非入门级 SoC，可以在数据通路上同时容纳数十个全精度流水线运算模块，并以较高的系统时钟降低单位运算的延迟代价。

第三是开放性与成本的需求。对于需要同时锁定多台激光器的实验装置，设备成本按通道数线性累加；而自研方案在硬件成本之外几乎不存在许可费用。更重要的是，完全掌握硬件描述语言源码与通信协议意味着系统具备长期可维护性，不会因厂商停产或接口变更而失效，也便于在课题组内部传承与二次开发。

需要说明的是，自研并不意味着在所有指标上超越商用产品。本文的目标是在架构层面提供商用产品所不具备的可重构性与自动化能力，并使系统的每一层都对使用者开放。

## 1.3 本文研究内容与目标

围绕上述问题，本文的研究内容可概括为"一个平台、一条可重构链路、一套自动锁定逻辑"，并辅以相应的上位机软件体系。

### 1.3.1 搭建自定义 FPGA 硬件平台

本文以 Xilinx Kintex UltraScale 系列 FPGA（KU060）为核心搭建硬件平台 `[具体器件型号与速度等级待补充]`。系统数据通路采用 16 位定点表示，所有信号统一以 16 位有符号整数在模块间传递，满量程对应 $\pm 32768$；系统工作时钟为 250 MHz，即单个时钟周期为 4 ns，这一时钟频率同时决定了流水线延迟的时间粒度与数字滤波器的采样率。

平台包含多路 ADC 与 DAC 通道，并通过一个统一的模块总线实现参数配置。该总线采用"模块编号 + 寄存器地址"的二级寻址方式：6 位模块选择信号可寻址至多 64 个功能模块，7 位地址在模块内部选择 32 位参数字。每个功能模块均由"运算内核 + 参数 RAM + 总线接口"三部分构成统一骨架，参数 RAM 采用影子寄存器结构，使宽度超过 32 位的参数（如 64 位频率控制字、64 个滤波器系数）能够以原子方式整体生效，避免参数更新过程中出现中间非法状态。上位机经串行接口与总线主控通信，由中央控制状态机完成协议解析。

### 1.3.2 设计可动态重构的信号处理链路

本文的核心架构特征是在 FPGA 内部实现一个全交叉信号路由矩阵。该矩阵由两个相互独立的 $64\times64$ 无阻塞交叉开关组成：一个用于 16 位数据信号，一个用于 1 位布尔控制信号。任一输入端口均可被连接到任意数量的输出端口，连接关系完全由寄存器配置决定。每个输出通道占用一个配置字节，其中 6 位指定源端口编号，1 位为通道使能，1 位为保持位；保持位的作用是在重新配置路由期间冻结输出，使拓扑切换不会在数据通路上产生毛刺。矩阵的输出为寄存器输出，引入一个时钟周期的延迟。

这一设计的意义在于，它把信号处理模块与它们之间的连接关系彻底解耦。各类运算模块在综合时一次性实例化并固定在芯片中，而"用哪些模块、以何种顺序串接"则完全交由运行时的寄存器写入决定。用户因此能够像在光学平台上连接真实仪器那样自由地组合数字模块，而无需任何重新综合。

在矩阵之上，本文实现了一套完整的 VHDL 信号处理模块库，各模块的算法原理将在第二章讨论，实现细节见第四章，主要包括：

- **PID 控制器**：并行（位置）型结构，具备可编程的积分限幅抗饱和、可编程泄漏积分以及输出限幅；为在高时钟频率下闭合长位宽积分路径的时序，积分支路采用半速率交织处理。
- **相位累加器（DDS）**：64 位相位累加器，取高 16 位作为相位输出，配合三角函数模块构成数控振荡器；内部另集成比例–积分环路滤波器，可直接用于相位跟踪。
- **CORDIC 三角函数与反三角函数**：分别工作于旋转模式与向量模式，提供正弦/余弦生成与四象限反正切（atan2）解算，19 级迭代，内部 24 位精度。
- **FIR 滤波器**：64 抽头直接型结构，系数 24 位定点，可在运行时重新加载；支持 16/32/64 抽头长度切换并自动调整归一化因子。
- **IIR 滤波器**：四阶，采用两节双二次（biquad）并联结构，并对每节施加四阶散射超前变换，以打破递归反馈对时钟频率的制约。
- **混频器、线性变换器、缩放器、相位解卷绕器**等辅助模块，分别用于解调、双路线性组合、输出调理与相位连续化。

### 1.3.3 实现自动 PDH 锁定状态机

本文将自动锁定流程下沉到硬件，实现为一个独立的 PDH 锁定状态机模块，使锁定的全过程无需上位机参与实时决策。状态机包含空闲、同步等待、幅度标定、时间标定、自动扫描、自动锁定以及一组对应的手动扫描/锁定状态。其关键机制有三。

其一是**自动幅度标定**。状态机以外部斜坡信号的满量程翻转作为扫描周期的边界标志，在一个完整扫描周期内对输入信号作最小值/最大值跟踪，从而测得当前光学信号的实际动态范围。该机制使系统无须预先知道探测器增益与光功率。

其二是**自动阈值计算**。在测得极值后，阈值按

$$
\text{threshold} = \min + \text{coef}\times(\max - \min)
$$

计算，其中系数为 Q1.15 定点数，扫描判决与锁定判决各用一个独立系数。由此得到的阈值随信号幅度自动缩放，避免了人工设定绝对阈值的繁琐与易失效。与此同时，状态机通过统计信号低于阈值的持续时长，推算出共振之间的间隔，并据此自动生成扫描判决与锁定判决所需的时间窗长度。

其三是**扫描与反馈的交接**。状态机本身不产生斜坡，而是通过控制交叉矩阵中的布尔通道，分别门控相位累加器的暂停输入与 PID 控制器的自动复位输入。标定与扫描阶段 PID 保持复位、斜坡自由扫描；当信号连续满足捕获条件达到预定时长时，状态机在同一个时钟沿上冻结斜坡并释放 PID，使累加器保持捕获时刻的偏置、由 PID 接管后续校正。整个交接过程在硬件内部单周期完成，不存在软件轮询带来的不确定延迟。

### 1.3.4 上位机软件与智能体辅助设计

硬件的可重构性只有在易用的配置手段支持下才能转化为实际效率。本文为此设计了分层的 Python 上位机软件：入口层负责启动与主窗口装配，编排层负责参数分发与配置文件读写，图形层与工具层负责可视化与端口映射，设备与模块层负责串行通信与各模块寄存器的抽象。其中图形层实现了一个可视化节点编辑器，用户以拖放方式实例化模块、以连线方式建立数据通路，连线的颜色与线型编码信号的来源与类型，并在建立时进行类型检查；每一次连线操作都被翻译为交叉矩阵的寄存器写入，从而在界面操作与硬件拓扑之间建立直接对应。

在此之上，本文进一步引入基于大语言模型的智能体辅助设计模块。该模块以函数调用方式操作节点画布，可根据自然语言描述创建模块、建立连接、设置参数并自动布局，其提示词中内置了 PDH 锁定的参考拓扑，使系统具备从自然语言需求直接生成信号处理方案的能力。

### 1.3.5 研究目标

综上，本文的总体目标是：建立一套以自研 Kintex UltraScale 硬件平台为基础、以运行时全交叉重构为架构特征、以硬件自动状态机为自动化手段、以分层上位机与智能体为交互入口的全数字激光 PDH 锁定系统，并验证其在激光稳频应用中的可用性。

## 1.4 本文组织结构

全文共分七章，组织如下。

**第一章 绪论**。阐述精密物理测量对激光频率稳定度的需求，分析模拟锁定方案与现有商用数字锁频产品的局限，提出本文的研究内容与目标，并给出全文结构。

**第二章 激光稳频原理与全数字控制理论**。推导 PDH 稳频的误差信号表达式及其鉴频斜率，给出稳频性能的评价指标；在此基础上介绍离散时间控制系统的稳定性分析方法、数字滤波器的设计与延迟特性、CORDIC 算法在数字混频与相位解算中的应用；最后讨论 PID 的数字化实现以及控制带宽、相位裕度与噪声抑制比之间的制约关系。

**第三章 系统硬件架构与接口设计**。介绍以 Kintex UltraScale FPGA 为核心的总体硬件方案、模数/数模转换与时钟分发架构，并分三个层次说明接口设计：上位机 UART 通信链路、片内自定义总线协议（含分层命令编码与超宽参数的原子化更新机制）以及板上射频器件的 SPI 配置接口。

**第四章 FPGA 逻辑设计与控制算法实现**。首先给出作为架构核心的 $64\times64$ 全交叉信号路由矩阵的设计与实现；随后逐一说明 PID、相位累加器、CORDIC 三角与反三角函数、FIR、IIR、混频器等模块的定点格式、流水线结构与延迟，重点讨论为在 250 MHz 时钟下闭合时序所采用的关键技术；最后详述 PDH 自动锁定状态机的八态转移关系、自动幅度标定与自动阈值计算算法，并对各模块做资源占用与延迟分析。

**第五章 上位机软件系统设计**。介绍 Python 上位机的驱动层、硬件抽象层与应用层分层架构，面向对象的模块封装与参数物理量映射关系，自动化初始化与系数加载校准流程，以及可视化节点编辑器与基于大语言模型的智能体辅助设计。

**第六章 系统测试与实验结果**。给出板级性能测试、功能验证实验与激光 PDH 锁定实验的测试方案，包括 ADC/DAC 有效位数与信噪比测试、系统环路延迟测量、硬件资源与时序预算、DDS 信号质量分析、自动锁定过程记录与误差信号功率谱密度分析。

**第七章 总结与展望**。总结本文工作，回顾创新点，并讨论不足与改进方向，其中包括将基于神经网络的自适应 PID 控制引入环路整形、增加硬件自主重捕获机制、以及向多通道并行锁定扩展等。
