# 第五章 核心运算模块实现

本章介绍平台运算层与互联层的具体实现。依第三章确立的范式，先给出作为互联层核心的动态信号路由矩阵，再逐一说明各运算模块（DDS 信号发生器、CORDIC 运算器、数字混频器、FIR/IIR 滤波器、PID 控制器）的定点格式、流水线结构与延迟，最后汇总各模块的资源占用与延迟预算。建立在这些模块之上的应用层状态机见第八章。

## 5.1 动态信号路由矩阵设计

### 5.1.1 设计动机

传统 FPGA 锁频系统的信号处理链路通常在 RTL 代码中硬连线，形如 ADC → 混频器 → 滤波器 → PID → DAC 的固定拓扑。实验中若需改变处理顺序、插入额外环节或复用某个模块，必须修改源码并重新综合布线——对于中等规模设计，一次完整的综合实现耗时可达数十分钟，严重制约实验迭代效率。

本系统的解决思路是：在 FPGA 内部一次性实例化全部功能模块，并在它们之间插入一个全交叉的可配置互联网络。改变信号流向退化为改写若干配置寄存器，耗时从"分钟级重新综合"降至"毫秒级串口写入"。这是第十章所述"软件定义信号链路"创新点的硬件基础。

### 5.1.2 结构与实现

信号路由矩阵实现于 `modules/signal_router/signal_router.vhdl`，其端口声明揭示了矩阵规模：

```vhdl
port(
    core_param_in : in  std_logic_vector(1023 downto 0);
    sig_in        : in  signal_array(63 downto 0);   -- 64 路 16 位数据输入
    sig_out       : out signal_array(63 downto 0);   -- 64 路 16 位数据输出
    ctrl_in       : in  std_logic_vector(63 downto 0); -- 64 路 1 位控制输入
    ctrl_out      : out std_logic_vector(63 downto 0)  -- 64 路 1 位控制输出
);
```

系统实际包含**两套相互独立的交叉开关**：一套处理 64 路 16 位宽的物理信号（`sig_in`/`sig_out`），另一套处理 64 路单比特的布尔控制信号（`ctrl_in`/`ctrl_out`）。将数据与控制分离的理由是资源效率——布尔信号的交叉开关每路仅需 1 位宽的多路选择器，若与 16 位数据混用同一套网络，将浪费 15/16 的选择器资源。

每个输出通道由一个寄存的 64 选 1 多路选择器驱动，核心逻辑为一行 generate 语句：

```vhdl
sig_out_buf(i) <= sig_in_buf(to_integer(unsigned(control(i * 8 + 5 downto i * 8))));
```

即第 $i$ 路输出的数据源，由配置字中对应该通道的 6 位选择码决定。每通道占用 8 位配置空间，位域分配为：

| 位域 | 功能 |
|------|------|
| `[5:0]` | 源端口编号（0–63） |
| `[6]` | 通道使能 |
| `[7]` | 保持（hold） |

64 个通道共需 $64 \times 8 = 512$ 位配置空间，两套交叉开关合计 1024 位，正对应 `core_param_in` 的宽度。控制交叉开关的配置基址定义为

```vhdl
constant ctrl_base_addr : integer := 512;
```

即低 512 位配置数据路由、高 512 位配置控制路由。

端口 0 被保留为特殊值：上位机常量定义 `VOID = 0`，注释说明"Signals to port 0 are ignored. Signals from port 0 are always zero"。这一约定使"未连接"成为一个合法的可表达状态，而无需额外的使能位判断。

`[7]` 位的保持功能由 `sig_out_hold_reg` 与 `ctrl_out_hold_reg` 两组寄存器实现。切换路由配置时，若直接改变选择码，输出将在新旧数据源之间产生一次跳变；置位保持位可令输出锁定在当前值，待配置稳定后再释放，从而实现**无扰动的信号源切换**。这对运行中的闭环系统尤为重要——锁定状态下的输出跳变足以导致失锁。

### 5.1.3 资源与时序考量

全交叉结构的资源消耗随端口数呈平方增长。64 路 16 位的数据交叉开关理论上需要 $64 \times 16 = 1024$ 个 64 选 1 多路选择器，是全系统中布线压力最大的模块。源码中对此有专门的优化约束：

```vhdl
attribute max_fanout : integer;
attribute max_fanout of ... : signal is 10;
```

将扇出上限设为 10，强制综合工具复制驱动寄存器以缩短关键路径。此外每个输出通道均经过寄存器缓冲（`sig_out_buf`），使交叉开关自身构成一级流水，代价是引入 1 个时钟周期的延迟。

> 【待补充】路由矩阵的实际资源占用（LUT / FF 数量）与时序收敛情况（WNS）。需运行 Vivado 综合实现后从资源报告与时序报告中提取，这是评估平方增长代价的关键数据，见第九章 9.1 节。

## 5.2 核心 DSP 模块设计

全部 DSP 模块遵循统一的架构范式：VHDL 内核（`<name>.vhdl`）实现算法，模块封装（`module_<name>.vhdl`）将内核与总线处理器 `bus_handler.vhdl`、参数存储 `parameter_ram.vhdl` 组装为可挂载到片内总线的单元。各内核均带有 `io_buf : buf_type` 泛型参数，可在 `buf_for_io`（输入输出均缓冲）、`buf_i_only`、`buf_o_only`、`buf_none` 四种模式间选择，用于在延迟与时序裕量之间做权衡——对延迟敏感的环路可去掉缓冲级，对时序紧张的路径则保留。

### 5.2.1 直接数字频率合成与信号发生器

DDS 由相位累加器 `modules/accumulator/accumulator.vhdl` 与 CORDIC 三角函数运算器级联构成。

累加器采用 64 位相位累加结构：

```vhdl
signal delta       : unsigned(63 downto 0);  -- 频率字
signal total_incre : unsigned(63 downto 0);  -- 实际累加增量
```

每个时钟周期执行 `acc <= acc + total_incre`。输出频率与频率字的关系为

$$
f_{out} = \frac{\Delta \cdot f_{clk}}{2^{64}}
$$

其中 $f_{clk} = 250$ MHz。由此得到频率分辨率

$$
\Delta f = \frac{f_{clk}}{2^{64}} = \frac{2.5 \times 10^8}{1.8447 \times 10^{19}} \approx 1.36 \times 10^{-11}\ \mathrm{Hz}
$$

这一极高的分辨率对激光稳频有实际意义：扫描腔共振峰时需要极精细的频率步进，而锁定后的频率修正量也可能远小于 1 Hz。

累加器提供两路输出：

```vhdl
acc_out  : out std_logic_vector(15 downto 0);
fast_out : out std_logic_vector(15 downto 0); -- provide an aux output N times the frequency of acc_out
```

取值方式为

```vhdl
acc_out_buf  <= acc(63 downto 48);
fast_out_buf <= acc(63 - to_integer(divisor_digit) downto 48 - to_integer(divisor_digit));
```

`acc_out` 取累加器最高 16 位作为相位输出；`fast_out` 取一个向低位偏移 `divisor_digit` 的 16 位窗口，其相位变化速度为 `acc_out` 的 $2^{\text{divisor\_digit}}$ 倍，即**倍频输出**。偏移量由 `divisor` 参数经优先级编码器求出对数得到，故 `divisor` 仅支持 2 的整数次幂。

> 需要说明：源码注释将 `fast_out` 描述为"N times the frequency of acc_out"，即倍频关系。上位机 Python 层中该端口的显示名为"默认输出"，而 `acc_out` 对应"分频输出"。论文中统一按硬件实际关系表述为倍频。

这一设计的意图在源码注释中说明：使 `fast_out` 可调至接近 0.5 倍采样率，代价是 `acc_out` 的动态范围缩小相应倍数。在 PDH 应用中，`fast_out` 用作扫描锯齿波与状态机的扫描监测输入，`acc_out` 则作为相位送入 CORDIC 生成调制信号。

累加器内部另集成一个环路滤波器（比例系数 `lf_kp` 为 24 位、积分系数 `lf_ki` 为 32 位，积分项带饱和钳位），使累加器本身即可作为数字锁相环的压控振荡器使用。实际累加增量为 `total_incre <= delta + total_feedback`，其中反馈项由 `bias_in` 外部偏置与环路滤波器输出移位合成。

### 5.2.2 CORDIC 三角函数与相位解算

三角函数运算器 `modules/trigonometric/trigonometric.vhdl` 采用 CORDIC（Coordinate Rotation Digital Computer）算法，以纯移位加法实现正余弦生成，避免查找表的存储开销与乘法器占用。

算法的旋转角序列以常量数组存储：

```vhdl
type signed_array is array(natural range <>) of signed(23 downto 0);
-- Storing a variant for 18 iterations
constant a : signed_array(0 to 18) := ( ... );
```

数组含 19 项，对应 $\arctan(2^{-i})$，$i = 0, 1, \dots, 18$。迭代由 generate 语句展开：

```vhdl
iterations : for i in 0 to 17 generate
```

即第 0 级做初始旋转，其后 18 级迭代，共 19 级。内部运算位宽为 24 位，输入输出为 16 位——内部增加 8 位余量用于抑制迭代过程的累积截断误差。

相位与幅度的归一化约定为：相位值 `x8000` 代表 $\pm\pi$，幅度值 `x7586a5` 代表 1.0。CORDIC 的固有增益

$$
K = \prod_{i=0}^{n-1}\sqrt{1 + 2^{-2i}} \approx 1.64676
$$

通过初值预缩放补偿，初始常量取 `c(0) <= x"475e34"`，即 $0.607253 \times \texttt{x7586a5}$，其中 $0.607253 = 1/K$。

流水线结构并非每级一拍。源码中以 `buf_odd` generate 对奇数级插入寄存器（9 拍），`no_buf_even` generate 则为纯组合直通，故 19 级迭代共 10 个寄存器级。这是面积—延迟—时序的三方折衷：全流水可达最高时钟但占用 19 级寄存器，纯组合延迟最小但无法满足 250 MHz 时序。

反三角函数运算器 `modules/inv_trigonometric/inv_trigonometric.vhdl` 结构对称（源码注释："Reworked pipelining structure similar to trigonometric.vhdl"），用于从正交分量解算相位，是相位检测链路的核心。其输入端另有一级预缩放（乘 `x"6DED"`）以防止向量模长溢出。

> 【待补充】两个 CORDIC 模块的总延迟周期数与相位/幅度精度的实测值。按寄存器级数推算分别为 12 拍与 13 拍（`buf_for_io` 配置下），但源码未标注，建议经仿真确认后填入。

### 5.2.3 数字混频器

混频器 `modules/mixer/mixer.vhdl` 是全系统最简洁的模块，实现 PDH 误差信号的解调：

```vhdl
product     <= sig_a_buf * sig_b_buf;      -- signed(31 downto 0)
sig_out_buf <= product(31 downto 16);      -- 取高 16 位
```

两路 16 位有符号输入相乘得 32 位全精度积，取高 16 位输出。这一截断方式等效于乘以 $2^{-16}$ 的定标：由于两个 Q1.15 格式数的乘积为 Q2.30 格式，取高 16 位即还原为 Q1.15，且**永不溢出**。源码文件头注释明确了这一设计意图，并指出若需增益应在输入端预先放大。

该模块无可配置参数，其封装 `module_mixer.vhdl` 使用 `parameter_ram_0`（零容量参数存储）。延迟为 2 个时钟周期（`buf_for_io` 配置下输入输出各一级缓冲）。

### 5.2.4 FIR 低通滤波器

FIR 滤波器 `modules/fir_filter/fir_filter.vhdl` 的文件头注释给出了核心规格："Simple FIR filter that uses 24bit coefficient accuracy and supports exactly 64 taps."

系数存储与定标：

```vhdl
type coef_type is array (0 to 63) of signed(23 downto 0); -- Normalized to Q1.23, -1 to 1
signal norm_64 : signed(17 downto 0); -- Q5.13
signal norm_32 : signed(17 downto 0); -- Q6.12
signal norm_16 : signed(17 downto 0); -- Q7.11
signal taps    : unsigned(5 downto 0);
```

结构为 64 抽头直接型，**未利用线性相位滤波器的系数对称性做折叠优化**——`gen_product` generate 语句实例化 64 个独立乘法器。这是一个明确的资源—通用性折衷：折叠结构可将乘法器数量减半，但要求系数严格对称，从而排除了非线性相位滤波器的使用。

可变抽头数通过三条并行缩放支路实现：当 `taps <= 15` 时选用 `scaled_16` 支路，`taps <= 31` 时选用 `scaled_32`，否则选用 `scaled_64`，每条支路配有独立的 L1 范数归一化系数。抽头数减少时需要更大的缩放因子以维持相同的冲激响应 L1 范数（即相同的直流增益），源码注释对此有说明。

加法树分三级实现：`sum_0`（16 个四输入加法器）→ `sum_1`（4 个）→ `sum_2`（1 个），中间结果均为 Q6.21 格式。延迟按寄存器级数计为 7 拍（输入缓冲、乘积、三级加法树、缩放、输出缓冲各一级）。

### 5.2.5 IIR 滤波器

IIR 滤波器 `modules/iir_filter/iir_filter.vhdl` 的设计显著复杂于 FIR，文件头注释概括为："4th order IIR employing the parallel biquad structure"，并采用了四阶散射前瞻（scattered look-ahead）变换。

结构为**两节双二次型并联**，输出为两节之和：

```vhdl
result <= bq1_sum_ya_0 + bq2_sum_ya_0;
```

系数格式与数量：

```vhdl
-- Each biquad is 4th order scattered, so it takes 9 b and 2 a coefficients
signal bq1_b_0 : signed(26 downto 0);
...
```

每节需 9 个 b 系数（Q3.24）与 2 个 a 系数（Q2.25），均为 27 位。两节合计 22 个系数。

采用并联而非串联、并引入散射前瞻变换，根本原因在于 IIR 的递归结构与高速流水线的内在冲突。直接型 IIR 的反馈环路要求上一个输出在下一个采样时刻前完成计算，即环路内不能插入流水线寄存器，这直接限制了最高时钟频率。四阶散射前瞻变换通过在分子分母同乘一个多项式，将递归的最小延迟从 1 拍扩展到 4 拍，从而允许环路内插入 4 级流水线——代价是系数数量从 3 个 b、2 个 a 膨胀至 9 个 b、2 个 a。这是本系统在 250 MHz 下实现 IIR 滤波的关键技术。

反馈路径的乘法采用长乘法拆分：将 Q4.26 的中间结果拆为高 18 位与低 12 位分别相乘再合并，以适配 DSP48 硬核的 18×27 位输入格式。输出端带饱和检测，溢出时钳位至 `x"7FFF"` 或 `x"8000"` 而非回绕，避免递归结构中溢出回绕引发的自激振荡。

滤波器系数的设计由上位机完成，详见第六章 6.3 节。

### 5.2.6 高性能数字 PID 控制器

PID 控制器 `modules/pid_controller/pid_controller.vhdl` 是闭环系统的核心，其定点设计体现了多项工程考量。

**位宽分配**：

```vhdl
signal error_in_buf  : signed(15 downto 0);
signal integral      : signed(47 downto 0);  -- 48 位积分器
signal gain_p        : signed(23 downto 0);
signal gain_i        : signed(31 downto 0);
signal gain_d        : signed(23 downto 0);
signal product_p     : signed(39 downto 0);
signal product_i     : signed(47 downto 0);
signal product_d     : signed(39 downto 0);
signal limit_integral: signed(47 downto 0);
signal limit_sum     : signed(27 downto 0);
```

积分器取 48 位远宽于 16 位数据通路，这是为积分作用预留足够的动态范围——积分项需累积微小误差至显著修正量，位宽不足将导致小误差被截断而无法消除静态偏差。

**增益定标**：源码在 `gain_p` 声明处给出了关键的标定注释："When gain_p equals gain_i, PI corner at clk / 2pi / 65536 = 600Hz for 250MHz clock"。即当比例与积分增益相等时，PI 转折频率为

$$
f_{PI} = \frac{f_{clk}}{2\pi \cdot 2^{16}} = \frac{2.5\times 10^8}{2\pi \times 65536} \approx 600\ \mathrm{Hz}
$$

该式为参数配置提供了物理标定基准，上位机据此实现物理量到寄存器值的换算（见第六章 6.2.3 节）。

**三项实现**：误差先减设定点 `error_from_setpoint <= error_in_buf - setpoint`；微分项采用一阶后向差分 `differential <= error_in_buf - error_1`；三项各自独立乘法后求和

```vhdl
sum_buf <= product_p(39 downto 12) + integral(47 downto 20) + product_d(39 downto 12);
```

**抗积分饱和**采用两级限幅。其一为积分器限幅：

```vhdl
-- integral_buf_limited 按 ±limit_integral 钳位后写回 integral
```

关键在于钳位后的值**写回积分器状态**，而非仅限制输出——这才构成真正的 anti-windup。若仅限制输出而放任积分器继续累积，误差反向后需要很长时间才能退出饱和，表现为明显的恢复滞后。其二为总输出限幅，按 `±limit_sum` 钳位，防止送往 DAC 的修正量超出量程。

**漏积分**（leaky integral）机制用于抑制长期漂移。由于 FPGA 内除法器资源昂贵，源码采用移位近似：

```vhdl
signal leak_digit : std_logic_vector(31 downto 0);
-- Not enough resource to implement a division for leaky integral,
-- so use this signal to represent the digits to be shifted
```

由 `leak_array` 生成 32 个移位版本后逐位或运算合成泄漏量，再从积分项中减去。等效泄漏系数为 $\alpha = 1 - 1/(\texttt{leak\_digit} \cdot 2^8)$。因实现方式为移位，`leak_digit` 只能取 2 的整数次幂，上位机在换算时需做幂次对齐并提示量化误差（见 5.2 节）。

**流水线与延迟**：积分支路采用 `interleaving_clk` 二分频交错计算，源码注释说明这等效于将积分运算的采样率降至系统时钟的一半（125 MHz）。这一细节对参数换算至关重要——积分路径与微分路径的有效采样率不同，上位机的 PI 转折频率换算使用 125 MHz，PD 转折频率换算使用 250 MHz。主数据通路的寄存器级数为：输入缓冲、误差求差、乘积、求和、输出缓冲各一级。需注意其封装 `module_pid_controller.vhdl:59` 实例化时使用 `io_buf => buf_none`，省去了输入输出缓冲以最小化环路延迟，此配置下 P/D 通路为 3 级。

### 5.3.2 延迟预算

各模块延迟（以时钟周期计，250 MHz 下每周期 4 ns）：

| 模块 | 推算延迟 | 说明 |
|------|---------|------|
| 信号路由矩阵 | 1 | 输出寄存器一级 |
| 混频器 | 2 | `buf_for_io` 下输入输出各一级 |
| FIR 滤波器 | 7 | 输入、乘积、三级加法树、缩放、输出 |
| CORDIC 三角函数 | 12 | 10 个迭代寄存器级 + 输入输出缓冲 |
| CORDIC 反三角函数 | 13 | 另含一级输入预缩放 |
| PID 控制器 | 3 | `buf_none` 配置，P/D 通路 |
| IIR 滤波器 | 【待测】 | 递归环路，需仿真确认 |

> 上表除混频器与路由矩阵外，均为按源码寄存器级数推算的结果，**源码中未标注总延迟**。IIR 滤波器因含递归环路与组合/寄存混合结构，无法由静态分析确定，须经仿真测定。论文定稿前建议通过行为级仿真对全部模块的延迟做实测确认。

环路总延迟是决定控制带宽上限的关键参数。按第二章 2.3 节的分析，延迟 $\tau$ 在频率 $\omega$ 处引入相移 $\Delta\phi = -\omega\tau$，若要求相位裕度不低于 $45°$，则闭环带宽上限约为

$$
f_{BW} \lesssim \frac{1}{8\tau}
$$

典型 PDH 链路为 ADC → 混频器 → FIR → PID → DAC，其 FPGA 内部延迟为各模块延迟与路由级延迟之和。完整的环路延迟还须计入 ADC 与 DAC 的转换延迟及模拟电路响应，需实测确定，见第九章 9.1 节。

## 5.4 本章小结

本章详述了 FPGA 侧的逻辑设计与算法实现。信号路由矩阵以 64×64 双套全交叉结构（数据与控制分离）实现任意模块互联，配合保持位支持无扰动切换，使信号链路的重构由重新综合降为寄存器写入。核心 DSP 模块均采用定点实现并针对 250 MHz 时钟做了专门优化：相位累加器以 64 位累加实现 $1.36\times10^{-11}$ Hz 的频率分辨率；CORDIC 以 19 级迭代、24 位内部精度实现三角函数与相位解算，采用隔级插入寄存器的半流水结构平衡时序与面积；FIR 为 64 抽头直接型并支持 16/32/64 抽头可变配置；IIR 采用两节并联双二次结构配合四阶散射前瞻变换，化解了递归结构与高速流水线的冲突；PID 控制器以 48 位积分器、两级限幅抗饱和与移位实现的漏积分构成完整的控制内核，并通过积分支路二分频交错降低资源压力。各模块均遵循第三章 3.2 节的三段式范式与可配置 IO 缓冲约定，因而可被应用层状态机以统一方式复用——第八章的两类实验应用即完全建立在本章模块之上，未新增任何专用运算模块。需要指出的是，各模块的资源占用与时序数据仍待综合报告补充。
