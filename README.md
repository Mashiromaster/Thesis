## 写作与验证状态

论文以可配置的 FPGA 控制平台为研究主体，PDH 与双光梳是两类应用案例。第四章介绍经验证的 Vivado 仿真反馈与 ReAct 修正闭环；第五章按板级性能、模块功能、跨应用切换和光学控制过程组织实验分析。实验复现所用的器件配置、工具约束、波形与日志记录格式见论文结构与实验复现说明。
