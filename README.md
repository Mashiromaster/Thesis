# 基于 FPGA 架构的微纳光学控制平台

## 论文初稿

初稿位于 [`毕业论文初稿/`](毕业论文初稿/)，共十章约 64800 汉字。

### 论文定位

本文以**平台**为论述主体。其立论是：微纳光学实验（激光稳频、双光梳锁定、微腔热锁定、光机械冷却等）在反馈控制结构上高度共通，差异仅在误差信号提取方式、控制器形式与执行器类型三处；因此一个在这三处均可配置的通用平台可服务于形态各异的实验。

PDH 锁定是**平台的一个应用案例**，与双光梳自校准本振锁定并列（第八章）。

这一定位与代码仓库相符：`Top.vhdl` 顶层注释即以双梳锁定为设计目标，仓库同时包含 `pdh_state_machine` 与 `SCALO_state_machine` 两个应用层状态机，34 个模块实例共用同一套运算层与互联层。

章节顺序遵循"逐层建立、最后贯穿"：第三至七章自下而上建立平台各层（设计方法 → 硬件 → 运算模块 → 上位机软件 → 智能体），第八章的实验应用纵向贯穿全部层次，故置于各层之后；第九章测试、第十章总结依次收束。

## 论文提纲

### 第一章 绪论
**1.1 研究背景与意义**
- 精密物理测量（如光钟、光梳）对激光频率稳定度的需求。
- 传统模拟锁定模块的局限性（温漂、连线复杂、不易重构）。
- 全数字控制系统的发展现状与优势（灵活、低噪声、便于集成）。

### 第二章 PDH稳频技术与全数字控制原理
**2.1 PDH (Pound-Drever-Hall) 稳频原理**
- F-P腔的反射特性与误差信号生成机制。
- 相位调制与解调的数学模型。

**2.2 全数字锁定系统的理论架构**
- 数字信号处理链路（ADC -> DDC -> PID -> DAC）。
- 数字域下的误差信号提取方法（CORDIC算法 vs 乘法器混频）。
- 系统稳定性分析（Z变换域下的闭环传递函数）。

### 第三章 基于FPGA的系统硬件架构设计
**3.1 系统总体硬件方案**
- FPGA选型与外围电路（高速ADC/DAC模块选择与接口设计）。
- 时钟树设计与噪声考量。

**3.2 关键模块的RTL实现**
- 直接数字频率合成器 (DDS) 设计（用于产生调制信号和本振信号）。
- 数字低通滤波器 (FIR/CIC) 的设计与资源优化。
- PID控制器的定点数实现与参数调节接口。

**3.3 自动锁定逻辑设计**
- 扫频与寻峰状态机设计。
- 锁定判据与自动重锁机制。

### 第四章 系统仿真与实验测试平台搭建
**4.1 ModelSim/Vivado 联合仿真**
- 各功能模块的时序仿真与功能验证。
- 闭环控制系统的行为级仿真。

**4.2 实验光路搭建**
- 激光器、电光调制器(EOM)、参考腔的光路准直与耦合。
- 光电探测器(PD)的信号调理。

**4.3 软硬件联调测试**
- FPGA比特流下载与板级调试。
- 上位机（如Python/Matlab）监控界面设计。

### 第五章 系统性能测试与分析
**5.1 误差信号的开环测试**
- 不同调制频率下的误差谱线对比。

**5.2 闭环锁定性能评估**
- 时域稳定性分析（长时间锁定的残余误差监测）。
- 频域噪声分析（功率谱密度PSD测试）。
- 阿伦方差 (Allan Variance) 计算与分析（评估中长期稳定度）。
